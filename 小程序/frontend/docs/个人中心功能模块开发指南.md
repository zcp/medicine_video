# 个人中心功能模块开发指南

## 1. 功能概述

### 1.1 核心功能
- 用户信息：个人资料展示和编辑
- 我的内容：收藏、历史、关注等个人数据
- 设置管理：系统设置、主题切换、通知设置
- 账户安全：密码修改、账户绑定（暂时占位）

### 1.2 页面结构
```
Profile.vue (个人中心主页)
├── UserHeader.vue (用户信息头部)
├── QuickStats.vue (快捷统计)
├── ActionMenu.vue (功能菜单)
└── SettingsSection.vue (设置区域)

子页面：
├── ProfileEdit.vue (编辑资料)
├── Settings.vue (系统设置)
├── CollectionList.vue (我的收藏，需登录)
├── ViewHistory.vue (观看历史，需登录)
└── FollowingList.vue (我的关注，需登录)
```

### 1.3 开发策略
**渐进式开发**：
- 阶段1：基础展示（无需登录）
- 阶段2：登录功能完善后再开发数据功能
- 阶段3：完整的用户中心体验

## 5. 主题管理实现

### 5.1 主题Store
```typescript
// src/store/theme.ts
import { defineStore } from 'pinia'

export interface ThemeState {
  theme: 'light' | 'dark' | 'auto'
  fontSize: 'small' | 'normal' | 'large'
  isDarkMode: boolean
}

export const useThemeStore = defineStore('theme', {
  state: (): ThemeState => ({
    theme: 'light',
    fontSize: 'normal', 
    isDarkMode: false
  }),
  
  actions: {
    // 初始化主题
    initTheme() {
      const savedTheme = uni.getStorageSync('app_theme') || 'light'
      const savedFontSize = uni.getStorageSync('app_font_size') || 'normal'
      
      this.setTheme(savedTheme)
      this.setFontSize(savedFontSize)
    },
    
    // 设置主题
    setTheme(theme: 'light' | 'dark' | 'auto') {
      this.theme = theme
      
      if (theme === 'auto') {
        // 跟随系统
        this.isDarkMode = this.getSystemDarkMode()
      } else {
        this.isDarkMode = theme === 'dark'
      }
      
      this.applyTheme()
      uni.setStorageSync('app_theme', theme)
    },
    
    // 设置字体大小
    setFontSize(fontSize: 'small' | 'normal' | 'large') {
      this.fontSize = fontSize
      this.applyFontSize()
      uni.setStorageSync('app_font_size', fontSize)
    },
    
    // 应用主题
    applyTheme() {
      const root = document.documentElement
      if (this.isDarkMode) {
        root.classList.add('dark')
      } else {
        root.classList.remove('dark')
      }
    },
    
    // 应用字体大小
    applyFontSize() {
      const root = document.documentElement
      root.setAttribute('data-font-size', this.fontSize)
    },
    
    // 获取系统深色模式
    getSystemDarkMode(): boolean {
      // 小程序环境
      const systemInfo = uni.getSystemInfoSync()
      return systemInfo.theme === 'dark'
    }
  }
})
```

## 7. 微信授权登录对接

### 7.1 微信登录集成方案

#### **前端实现**
```typescript
// src/composables/useWechatAuth.ts
import { ref } from 'vue'
import { useUserStore } from '@/store/user'
import { wechatLogin, checkAuthStatus } from '@/api/auth'

export const useWechatAuth = () => {
  const userStore = useUserStore()
  const isLoggingIn = ref(false)
  
  // 微信授权登录
  const performWechatLogin = async () => {
    try {
      isLoggingIn.value = true
      
      // 1. 获取微信登录凭证
      const { code } = await uni.login({ provider: 'weixin' })
      
      if (!code) {
        throw new Error('获取微信授权失败')
      }
      
      // 2. 调用后端登录接口
      const response = await wechatLogin({ code })
      
      // 3. 存储登录状态
      uni.setStorageSync('access_token', response.access_token)
      userStore.setLoginState(true)
      userStore.setUserInfo(response.user_info)
      
      uni.showToast({
        title: '登录成功',
        icon: 'success'
      })
      
      return { success: true, userInfo: response.user_info }
      
    } catch (error: any) {
      console.error('微信登录失败:', error)
      
      uni.showModal({
        title: '登录失败',
        content: error.message || '网络异常，请稍后重试',
        showCancel: false
      })
      
      return { success: false, error }
    } finally {
      isLoggingIn.value = false
    }
  }
  
  // 检查登录状态
  const checkLoginStatus = async () => {
    const token = uni.getStorageSync('access_token')
    if (!token) return false
    
    try {
      const response = await checkAuthStatus()
      if (response.is_valid && response.user_info) {
        userStore.setLoginState(true)
        userStore.setUserInfo(response.user_info)
        return true
      }
    } catch (error) {
      console.error('检查登录状态失败:', error)
      // Token无效，清除本地状态
      uni.removeStorageSync('access_token')
      userStore.setLoginState(false)
    }
    
    return false
  }
  
  // 自动登录检查
  const autoLogin = async () => {
    const isValid = await checkLoginStatus()
    return isValid
  }
  
  return {
    isLoggingIn,
    performWechatLogin,
    checkLoginStatus,
    autoLogin
  }
}
```

## 11. 开发注意事项

1. **渐进增强**：先实现基础功能，登录完善后再扩展
2. **状态管理**：合理使用Store管理用户状态
3. **缓存策略**：设置项需要持久化存储
4. **主题适配**：确保所有页面支持深色模式
5. **占位设计**：未登录状态的用户引导要友好
6. **性能考虑**：避免不必要的数据加载

通过这种渐进式的开发方式，个人中心模块可以为用户提供基础的设置功能，同时为登录功能的完善预留了充足的扩展空间。
