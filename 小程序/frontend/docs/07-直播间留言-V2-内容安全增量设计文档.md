## 📌 本次增量范围

### 1. 变更目标

将留言发布入口统一接入内容安全引擎，对 `content` 字段做后端强校验（scene=`message`，目标字段 `content`）。

### 2. 变更类型

- 【修改】`POST /api/v1/rooms/{roomId}/messages` 执行流程
- 【新增】`scene=message` 规则组接入（live_core 库，默认 4 条 block 规则）
- 【新增】留言命中 block 规则后错误码统一为 `2005`

### 3. 明确不在本次范围

- 不改动留言表 `room_messages` 结构
- 不改动留言查询/删除接口协议
- 不新增公告审核能力

## 🔍 规则与决策

### 1. 双库分治（live_core 侧）

| 维度 | 说明 |
|------|------|
| 数据库 | `live_core_test` |
| 校验场景 | `message` |
| 默认规则 | message-content 四类 block（url / contact / fraud / keyword） |
| 规则维护 | live_core 管理端 API（GET/POST/PATCH `/api/v1/admin/content-safety/rules`） |
| 审计日志 | 存 live_core 库；管理端 `GET /api/v1/admin/content-safety/logs` 可查询 |

### 2. 检测口径（与 12 §1.4.2 一致）

| 检测类型 | `match_type` | 默认 action |
|----------|--------------|-------------|
| 外链 | `url` | block |
| 联系方式 | `contact` | block |
| 广告引流 | `fraud` | block |
| 敏感词 | `keyword` | block |

### 3. 处理策略（与 12 §1.4.5 一致）

| 决策 | 行为 | HTTP | code |
|------|------|------|------|
| `block` | 拒绝发布留言 | 422 | 2005 |
| `warn` | 允许发布，写审计日志（`reason_code=2006`） | 200 | 200 |
| `allow` | 正常发布，**不写审计日志** | 200 | 200 |

### 4. 异常策略

- 发布型接口在安全服务异常时默认拒绝：`422 + code=2004`

### 5. API 路径约定（与 12 §1.7 一致）

| 对外网关路径（nginx） | 服务内路径 | 所属服务 |
|----------------------|------------|----------|
| `POST /api/core/rooms/{roomId}/messages` | `/api/v1/rooms/{roomId}/messages` | live_core |

## 1. 核心流程增量

### 1.1 发送留言（修改后流程）

```
POST /api/v1/rooms/{roomId}/messages
  → 1. JWT 鉴权（提取 user_id）+ 房间可见性校验
  → 2. 参数校验（content 非空且 <=500）
  → 3. check_content_safety(scene="message", field="content")
  → 4. block → 422/2005；安全服务异常 → 422/2004
  → 5. allow/warn → INSERT room_messages
  → 6. 仅 warn/block 时写入 content_safety_logs（纯 allow 不写日志）
  → 7. 提交事务，返回留言详情
```

### 1.2 违规返回示例

```json
{
  "code": 2005,
  "message": "内容违规：留言命中外链拦截规则",
  "data": null,
  "timestamp": "2026-07-03T10:00:00Z"
}
```

### 1.3 warn 返回示例

```json
{
  "code": 200,
  "message": "success",
  "data": { "...留言详情..." },
  "timestamp": "2026-07-03T10:00:00Z"
}
```

> warn 决策写入审计日志，`reason_code=2006`；HTTP 仍返回 200。
