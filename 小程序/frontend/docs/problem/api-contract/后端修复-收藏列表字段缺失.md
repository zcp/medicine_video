# 后端修复报告：收藏列表缺少 room_title / room_cover_url

**问题来源**: [`前后端接口偏差_2026-04-22.md` — 偏差二](前后端接口偏差_2026-04-22.md)  
**接口**: `GET /api/v1/users/me/favorites`  
**影响**: 收藏页标题和封面为空（前端有降级方案，但产生 N 条额外 GET /rooms/{id} 请求）  
**优先级**: 🔴 高（影响用户体验，且拖累性能）

---

## 一、问题定位

设计文档（V2.0 Section 4.8.2）执行流程第 3 步明确要求：

```
3. JOIN live_rooms 表获取 room_title 和 cover_url
```

但后端实际返回的字段仅为 `user_favorites` 表自身字段：

```json
["id", "room_id", "is_active", "created_at"]
```

缺少 `room_title`、`room_cover_url`，**JOIN 未实现**。

---

## 二、预期响应结构

设计文档（V2.0 Section 4.8.2）定义的标准响应：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 5,
    "page": 1,
    "size": 10,
    "items": [
      {
        "id": "favorite_uuid_1",

      }
    ]
  },
  "timestamp": "2025-10-23T14:25:00Z"
}
```

> ⚠️ 注意字段名：列表响应用 **`room_cover_url`**（带 `room_` 前缀），非 `cover_url`。

## 三、数据库层修复

### 当前（错误）查询逻辑

```sql
SELECT *
FROM user_favorites
WHERE user_id = :user_id
  AND is_active = true
ORDER BY created_at DESC
LIMIT :size OFFSET :offset
```

仅查 `user_favorites` 表，缺少 JOIN。

### 修复后的查询

```sql
SELECT
    uf.id,
    uf.room_id,
    lr.title        AS room_title,
    lr.cover_url    AS room_cover_url,
    uf.created_at
FROM user_favorites uf
JOIN live_rooms lr
    ON uf.room_id = lr.id
WHERE uf.user_id = :user_id
  AND uf.is_active = true
ORDER BY uf.created_at DESC
LIMIT :size OFFSET :offset
```

COUNT 查询（分页用）：

```sql
SELECT COUNT(*)
FROM user_favorites uf
JOIN live_rooms lr
    ON uf.room_id = lr.id
WHERE uf.user_id = :user_id
  AND uf.is_active = true
```

> 使用 INNER JOIN：若 `live_rooms` 中对应记录已被删除（`ON DELETE CASCADE` 会级联删除 `user_favorites` 记录），理论上不会出现孤儿记录，INNER JOIN 安全。

## 四、ORM 层修复（SQLAlchemy 示例）

### 当前错误写法（推测）

```python
# 仅查 UserFavorite 模型，未关联 LiveRoom
favorites = db.query(UserFavorite)\
    .filter(
        UserFavorite.user_id == user_id,
        UserFavorite.is_active == True
    )\
    .order_by(UserFavorite.created_at.desc())\
    .offset(offset).limit(size)\
    .all()
```

### 修复后写法

```python
from sqlalchemy.orm import joinedload
# 或使用显式 join

favorites = (
    db.query(UserFavorite)
    .join(LiveRoom, UserFavorite.room_id == LiveRoom.id)
    .filter(
        UserFavorite.user_id == user_id,
        UserFavorite.is_active == True
    )
    .options(joinedload(UserFavorite.room))   # 若定义了 relationship
    .order_by(UserFavorite.created_at.desc())
    .offset(offset)
    .limit(size)
    .all()
)
```

序列化时：

```python
def serialize_favorite(fav: UserFavorite) -> dict:
    return {
        "id": str(fav.id),
        "room_id": str(fav.room_id),
        "room_title": fav.room.title if fav.room else "",
        "room_cover_url": fav.room.cover_url if fav.room else "",
        "created_at": fav.created_at.isoformat()
    }
```
