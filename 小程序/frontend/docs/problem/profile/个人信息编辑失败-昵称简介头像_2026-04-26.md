# 可执行缺陷单：个人信息编辑失败（昵称/简介/头像）

缺陷ID: FE-BE-USER-20260426-04  
发现时间: 2026-04-26  
当前状态: 后端待修复，前端提示已修复  
优先级: P1  
责任域: BE + FE + QA

## 1. 一句话结论
编辑资料失败的根本原因是用户资料接口在当前环境返回 404；前端当前绝对请求路径为 `/api/users/me*`，路由归属正确，不能再用“临时路径映射”掩盖后端未落地的问题。

## 2. 复现步骤（可直接执行）
前置条件:
1. 已登录账号。

操作步骤:
1. 打开个人资料编辑页。
2. 修改昵称/简介后点击保存。
3. 上传头像后再次保存。

实际结果:
1. 保存失败。
2. 控制台出现 `/api/users/me` 404。

期望结果:
1. 可成功保存昵称与简介。
2. 头像上传返回地址并立即预览生效。
