# 可执行缺陷单：收藏/观看历史/订阅“没有更多了”去卡片化
 
缺陷ID: FE-UI-20260426-05  
发现时间: 2026-04-26  
当前状态: 前端已修复，待 UI/QA 走查  
优先级: P2  
责任域: FE + UI + QA

## 1. 一句话结论
“没有更多了”提示目前嵌在列表容器内，视觉上仍绑定卡片区块，需要改为独立弱提示以实现彻底去卡片化。

## 2. 复现步骤（可直接执行）
前置条件:
1. 收藏、观看历史、订阅任一列表达到末页。

操作步骤:
1. 滚动到底部触发 `!hasMore`。

实际结果:
1. “没有更多了”位于 `.list` 内部，视觉仍像列表的一部分。

期望结果:
1. 提示文本在列表容器外独立渲染。
2. 提示样式为弱文本，不带卡片、边框、背景。

## 3. 证据分级
| 结论 | 证据等级 | 证据 | 备注 |
|---|---|---|---|
| 三页都在 `.list` 内渲染 `.more` | E1-已验证 | 三个页面模板均为 `v-else-if="!hasMore" class="more"` | 代码静态证据 |
| 当前样式与列表容器视觉绑定 | E1-已验证 | `.list` 有背景与边框，`.more` 在容器内部 | 样式静态证据 |
| 去卡片化需要结构调整而非仅改颜色 | 设计推导 | 仅调色无法改变结构附着关系 | 非运行时证据 |

## 4. 影响范围
功能影响:
1. 不影响业务逻辑，仅影响列表末态 UI。

体验影响:
1. 末态提示视觉噪音偏高。
2. 三页视觉一致性不足。

## 5. 关联文件
1. `src/pages/profile/CollectionList.vue`
2. `src/pages/profile/ViewHistory.vue`
3. `src/pages/profile/SubscriptionList.vue`
4. `src/common/uni.scss`

## 6. 明确设计规格（执行基线）
结构要求:
1. 将“没有更多了”节点移出 `.list`，放到 `.list` 后方。
2. 保持 `loadingMore` 仍在列表内，`no-more` 在列表外。

样式要求:
1. 类名统一为 `.no-more-plain`。
2. 字号使用设计系统小号文本 token（实现为 `uni.scss` 中的小号字号）。
3. 颜色使用 `var(--color-text-tertiary)`。
4. 上下间距 `padding: 12px 0 20px`。
5. 禁止 `background`、`border`、`box-shadow`。
