### 通用发布门禁（Go/No-Go）

1. `P1` 缺陷未达到文档量化验收标准，禁止发布。
2. 任一缺陷缺少责任方（或已指派 `Owner`）或缺少回归记录，禁止发布。
3. 触发回滚阈值（见各文档）时，必须执行回滚并在 30 分钟内完成复测结论。

### 缺陷关闭统一要求

1. 必须有代码PR（或后端工单）链接。
2. 必须有 QA 回归结论（含时间与执行人）。
3. 必须有 24h 观测窗口结果（日志/监控）。

### 状态字典（统一口径）

1. `已修复`：代码与环境已完成修复并通过验收。
2. `部分修复`：已完成止血或局部修复，但主链路仍有未完成项。
3. `待修复`：根因项尚未落地修复。
4. `待排查`：结论未收敛，需继续定位。
