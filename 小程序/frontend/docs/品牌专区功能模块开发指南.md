# 品牌专区功能模块开发指南

> **修订（2026-08-07）**：对齐现网实现；**本版不做专题相关能力**（展示 / 关联 / 专区推荐均不接线）。

## 1. 功能概述

### 1.1 本版范围
- 品牌专区列表与搜索（含精选横滑、搜索历史/热门）
- 品牌详情（资料 + 官网复制/打开 + 关联直播间）
- 管理端品牌主体库 CRUD（搜/筛、启停、Logo 上传）
- 直播间品牌 Tab / 创建直播绑品牌（既有能力，见交付说明）

### 1.2 本版非目标（封印）
- 品牌专题关联 UI、详情专题列表、专区专题推荐
- 品牌分类 Tab
- 品牌成员工作台 / 成员货架
- 品牌审批流、关注粉丝体系

### 1.3 现网页结构
```
BrandZone.vue（品牌专区 Tab）
├── BrandHeader.vue（搜索）
├── FeaturedBrands.vue（精选横滑，按 sort_order 取前 N）
└── BrandGrid.vue → BrandCard.vue

BrandDetail.vue（品牌详情）
├── BrandProfile.vue（名称 / Logo / 简介）
├── 官网：复制 + 打开（H5 新开；小程序复制提示）
└── 关联直播间：优先 content 内公开 rooms；否则仅 Admin 调 getAdminBrandRooms

BrandAdminList.vue（管理端）
└── 搜名称 + 状态筛 + 小 Logo 行列表 + 弹窗表单 + Logo 上传 + 停用/启用
```

### 1.4 闲置组件（本版不接入）
| 组件 | 状态 |
|------|------|
| `TopicList.vue` | 专题暂缓，不挂页 |
| `SpecialTopics.vue` | 专题暂缓，不挂页 |
| `BrandTabs.vue` | 专区暂不做分类 |
| `SessionList.vue` | 未挂详情页，可后续评估 |

## 2. 主要 API

| 场景 | 接口 |
|------|------|
| 公开列表 | `GET /brands` |
| 公开详情内容 | `GET /brands/{id}/content`（本版忽略 `associated_topics` 展示） |
| 房间品牌 Tab | `GET /rooms/{id}/brands` |
| Admin 列表 | `GET /admin/brands`（`name` / `is_active`） |
| Admin CRUD | `POST/PATCH/DELETE /admin/brands/{id}` |
| Admin Logo | `POST /admin/brands/{id}/logo` multipart `file` |
| Admin 关联房 | `GET /admin/brands/{id}/rooms`（仅管理员详情可用） |

**已知边界（F2）**：无公开「品牌→房间」端点时，普通用户详情可能看不到关联房；空态会说明权限/契约原因，不再静默调 Admin 造成假空。

## 3. 联调与自测建议

- [ ] 详情：品牌名/简介突出；无「入驻天数」运营条
- [ ] 官网：复制 / 打开
