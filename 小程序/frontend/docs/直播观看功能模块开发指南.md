# 直播观看功能模块开发指南

## 1. 功能概述

### 1.1 核心功能
- 视频播放：支持直播与回放（同一页面承载）
- 画质切换：提供 UI 入口；是否可用取决于后端是否提供 `/sessions/{id}/play-url` 多画质列表
- 全屏模式：使用 video 原生全屏
- 互动统计：观看/评论/分享
- 互动操作：收藏、分享
- 订阅提醒：仅在“未开播”场次展示订阅入口，用于开播前通知
- 专家关注：直播页专家区域提供“关注/已关注”（对齐 Expert Follow）

约束（以项目为准）：
- 不做“下载”功能（直播观看页不提供下载入口）
- 直播间不提供“点赞”按钮（无点赞交互）

### 1.2 页面结构
```
LiveView.vue（直播/回放观看页）
├── video 播放器（直播或回放地址）
├── 统计栏（观看/评论/分享）
├── 专家信息（含关注按钮）
├── 操作区（收藏、订阅[仅未开播]、分享）
└── 功能性 Tabs（房间 tabs + 专家介绍 + 品牌介绍）
```

## 2. 开发步骤

### 第一步：阶段2组件开发
参考：
- 直播SaaS前端阶段二：组件层代码生成提示词.md (直播相关组件)
- 移动端设计文档 (7.6章节)

关键组件：
1. VideoPlayer.vue (核心播放器)
2. ChatPanel.vue (聊天功能) 
3. LiveControls.vue (播放控制)
4. QualitySelector.vue (画质选择)

### 第二步：阶段3页面组装
- LiveView.vue 竖屏观看页
- FullScreen.vue 全屏播放页
- 屏幕旋转监听和处理

### 第三步：流媒体集成
参考接口：
- GET /api/v1/sessions/{id} (直播详情)
- （可选）GET /api/v1/sessions/{id}/play-url（当 session 详情未提供可用播放地址时兜底）

互动与订阅：
- 收藏：对齐“我的收藏”模块的房间收藏接口/Store
- 订阅：对齐“我的订阅”模块（仅未开播展示，用于开播前提醒）
