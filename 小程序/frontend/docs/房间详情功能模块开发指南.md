# 房间详情功能模块开发指南

## 1. 功能概述

### 1.1 核心功能
- 房间信息：直播间详细信息展示
- 预约功能：直播预约和提醒设置
- 专家信息：主讲专家详细资料
- 相关推荐：相关直播和专家推荐
- 社交功能：分享和收藏（需登录）

### 1.2 页面结构
```
RoomDetail.vue (房间详情页)
├── RoomHeader.vue (房间头部信息)
├── RoomBanner.vue (房间封面图)
├── RoomInfo.vue (房间基本信息)
├── ExpertSection.vue (专家信息区)
├── SessionList.vue (场次列表)
├── ActionButtons.vue (操作按钮区)
└── RecommendList.vue (相关推荐)
```

### 1.3 业务价值
- **用户价值**：详细了解直播内容，做观看决策
- **平台价值**：提升用户转化率，增加预约量
- **专家价值**：专业形象展示，吸引更多观众

## 3. 数据模型

### 房间详情
```typescript
interface RoomDetail {
  id: string
  title: string
  description: string
  cover_url?: string
  banner_url?: string
  category_id: string
  category_name: string
  status: 'upcoming' | 'live' | 'ended' | 'cancelled'
  
  // 专家信息
  expert: {
    id: string
    name: string
    title: string
    hospital: string
    avatar_url?: string
    specialties: string[]
  }
  
  // 统计信息
  stats: {
    total_sessions: number
    upcoming_sessions: number
    total_views: number
    subscribers_count: number
  }
  
  // 时间信息
  created_at: string
  updated_at: string
}
```

### 直播场次
```typescript
interface Session {
  id: string
  room_id: string
  title: string
  description?: string
  start_time: string
  end_time: string
  duration_minutes: number
  status: 'scheduled' | 'live' | 'ended' | 'cancelled'
  
  // 统计信息
  max_viewers: number
  current_viewers?: number
  reserved_count: number
  
  // 媒体信息
  thumbnail_url?: string
  stream_url?: string
  playback_url?: string
  
  created_at: string
}
```
