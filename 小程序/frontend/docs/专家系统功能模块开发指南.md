# 专家系统功能模块开发指南

## 1. 功能概述

### 1.1 核心功能  
- 专家发现：专家列表浏览
- 专家详情：个人信息和直播列表
- 搜索筛选：按科室、姓名等筛选
- 关注管理：关注/取关功能(暂时占位)

### 1.1.1 鉴权边界（公开浏览 vs 用户行为）

专家信息为公开资源（与后端专家模块双轨鉴权一致）：

| 场景 | 是否需要登录 | 未登录表现 |
|------|-------------|-----------|
| 浏览专家列表 / 搜索 / 详情 / 场次列表 | 否 | 正常展示，不 Toast、不跳登录 |
| 关注 / 取消关注 | 是 | Toast「请先登录」并引导登录 |
| 收藏直播间（详情页内） | 是 | Toast「请先登录」并引导登录 |

实现约束：

- 详情页 `onLoad` 仅请求公开接口；未登录时**不得**调用 `/users/me/favorites`、`/users/me/followed-experts` 等用户态接口。
- 用户态状态（是否已关注、是否已收藏）未登录时默认按「未关注 / 未收藏」渲染即可。

### 1.1.2 头像 / 封面兜底（与全局 DEFAULT_CONFIG 对齐）

| 场景 | 常量 | 说明 |
|------|------|------|
| 专家头像空值或加载失败 | `DEFAULT_CONFIG.DEFAULT_AVATAR` | 统一经 `src/utils/mediaFallback.ts` |
| 专家场次封面空值 | `DEFAULT_CONFIG.DEFAULT_COVER` | 失败用 `COVER_LOAD_ERROR` |

约束：

- 所有头像/封面/Logo/Banner 展示必须走 `mediaFallback`（空值 + `@error`）。
- `@error` 回落对齐 Banner3D：本地兜底图失败不得再写 broken 状态。
- 专家列表 `ExpertCard`、详情 `ExpertProfile`、精选 `FeaturedExperts`、搜索专家结果均不得留空白圆。

### 1.2 页面结构
```
ExpertList.vue

├── FilterTabs.vue (科室筛选)
├── LetterIndex.vue (字母索引)

ExpertDetail.vue  
├── ExpertProfile.vue (专家信息)
├── ExpertStats.vue (统计信息)
├── LiveHistory.vue (直播历史)
└── FollowButton.vue (关注按钮-占位)
```
