# 搜索功能模块开发指南

## 1. 功能概述

### 1.1 核心功能
- 全局搜索：跨内容类型的统一搜索入口
- 智能提示：搜索建议和自动补全
- 历史记录：用户搜索历史管理
- 热门搜索：平台热门搜索词展示
- 结果分类：按内容类型分类展示结果

### 1.2 页面结构
```
Search.vue (搜索主页)
├── SearchInput.vue (搜索输入框)
├── SearchSuggestions.vue (搜索建议)
├── SearchHistory.vue (搜索历史)
├── HotSearches.vue (热门搜索)
└── SearchResults.vue (搜索结果)

SearchResults.vue (搜索结果页)
├── ResultTabs.vue (结果分类Tab)
├── RoomResults.vue (房间结果列表)
├── ExpertResults.vue (专家结果列表)
├── BrandResults.vue (品牌结果列表)
└── EmptyResults.vue (空结果状态)
```

### 1.3 业务价值
- **用户价值**：快速找到感兴趣的内容
- **平台价值**：提升内容发现效率，增加用户停留
- **运营价值**：了解用户兴趣，优化内容推荐

### 搜索历史本地存储
```typescript
// 存储搜索历史
export const saveSearchHistory = (keyword: string) => {
  const history = getSearchHistory()
  const newItem: SearchHistory = {
    keyword,
    timestamp: Date.now()
  }
  
  // 去重并添加到开头
  const filteredHistory = history.filter(item => item.keyword !== keyword)
  const newHistory = [newItem, ...filteredHistory].slice(0, 10) // 最多保存10条
  
  uni.setStorageSync('search_history', newHistory)
}

// 获取搜索历史
export const getSearchHistory = (): SearchHistory[] => {
  try {
    return uni.getStorageSync('search_history') || []
  } catch (error) {
    return []
  }
}
```

## 7. 搜索结果展示

### 高亮显示
```typescript
// 关键词高亮处理
export const highlightKeyword = (text: string, keyword: string): string => {
  if (!keyword) return text
  
  const regex = new RegExp(`(${keyword})`, 'gi')
  return text.replace(regex, '<mark>$1</mark>')
}
```

### 结果排序优化
```typescript
// 搜索结果排序策略
export const sortSearchResults = (
  results: SearchResultItem[], 
  keyword: string,
  sortType: 'relevance' | 'time' | 'popularity' = 'relevance'
) => {
  switch (sortType) {
    case 'relevance':
      // 按相关度排序（标题匹配优先）
      return results.sort((a, b) => {
        const aRelevance = calculateRelevance(a, keyword)
        const bRelevance = calculateRelevance(b, keyword)
        return bRelevance - aRelevance
      })
      
    case 'time':
      // 按时间排序
      return results.sort((a, b) => 
        new Date(b.extra_info?.created_at || 0).getTime() - 
        new Date(a.extra_info?.created_at || 0).getTime()
      )
      
    case 'popularity':
      // 按热度排序
      return results.sort((a, b) => 
        (b.extra_info?.view_count || 0) - (a.extra_info?.view_count || 0)
      )
      
    default:
      return results
  }
}
```

## 8. 性能优化

### 搜索缓存策略
```typescript
// 搜索结果缓存
const searchCache = new Map<string, {
  result: SearchResult
  timestamp: number
  expiry: number
}>()

const CACHE_EXPIRY = 5 * 60 * 1000 // 5分钟

export const getCachedSearchResult = (keyword: string): SearchResult | null => {
  const cached = searchCache.get(keyword)
  if (cached && Date.now() < cached.timestamp + cached.expiry) {
    return cached.result
  }
  return null
}
```

### 分页加载
```typescript
// 搜索结果分页加载
const loadMoreResults = async () => {
  if (hasMore.value && !isLoading.value) {
    isLoading.value = true
    try {
      const nextPage = currentPage.value + 1
      const moreResults = await searchApi.search({
        ...currentSearchParams.value,
        page: nextPage
      })
      
      // 追加结果
      results.value.rooms.push(...moreResults.rooms)
      results.value.experts.push(...moreResults.experts)
      results.value.brands.push(...moreResults.brands)
      
      currentPage.value = nextPage
      hasMore.value = nextPage * pageSize < results.value.total
    } finally {
      isLoading.value = false
    }
  }
}
```

```typescript
// 搜索行为埋点
export const trackSearchEvent = (eventType: string, data: any) => {
  // 搜索关键词埋点
  if (eventType === 'search_keyword') {
    analytics.track('search_performed', {
      keyword: data.keyword,
      result_count: data.resultCount,
      search_type: data.searchType
    })
  }
  
  // 搜索结果点击埋点
  if (eventType === 'search_result_click') {
    analytics.track('search_result_clicked', {
      keyword: data.keyword,
      result_type: data.resultType,
      result_id: data.resultId,
      position: data.position
    })
  }
}
```
