# 首页功能模块开发指南

## 1. 功能概述

### 1.1 核心功能
- 内容发现：分类 Tabs + 直播间列表（双列瀑布流）
- 搜索入口：快速内容搜索
- 轮播图：本地 Banner 展示

直播间分类展示（以项目为准）：
- 卡片通过 `liveStatus` 展示 “LIVE（正在直播）/回放” 标识
- `liveStatus` 优先使用后端实际返回字段（如 `status`/`live_status`/`is_live`/`has_replay`），若缺失则回退为 `scheduled`

### 1.2 页面结构
```
Home.vue
├── TopBar.vue (顶部搜索栏)
├── CategoryTabs.vue (科室分类Tab)
├── Banner3D.vue (3D轮播图)
├── LiveCard.vue (直播间卡片)
└── QuickMenu.vue (快捷菜单)
```
