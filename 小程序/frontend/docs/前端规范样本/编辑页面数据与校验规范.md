## 一、规范概述

本规范旨在统一所有编辑页面的数据处理与校验逻辑，确保：

1. **用户未修改字段时**：系统自动使用原始数据，不要求重新输入或报错。
2. **表单验证**：根据创建/编辑模式及是否有原始数据，动态调整必填规则。
3. **提交数据**：优先使用用户修改值，缺失时回退到原始数据，避免提交失败。

**命名约定**：表单数据统一使用 `formData`（与《Vue3与项目编程规范》一致）。若存量页面使用 `formModel`，后续新增与重构时统一为 `formData`。

## 二、核心原则

### 2.1 数据保留原则

在编辑模式下，若用户未修改某字段，**系统应自动使用该字段的原始数据**。

### 2.2 数据保存原则

编辑页打开时，必须保存所有原始数据，用于：

- **表单回填**：填充到 `formData`
- **变更检测**：判断用户是否修改字段
- **提交回退**：未修改字段提交时使用原始数据

### 2.3 验证规则原则

- **创建模式**：所有必填字段必须验证。
- **编辑模式**：若字段有原始数据，该字段可不做必填验证；无原始数据则必须验证。

### 2.4 提交数据原则

对每个字段：

1. **用户已修改**：使用修改后的值
2. **用户未修改**：使用原始数据
3. **为空且无原始数据**（仅创建模式）：提示必填

### 2.5 数据加载顺序

1. 先加载**关联数据**（如场次、用户信息等）
2. 再**填充表单** `formData`
3. 最后**保存原始数据**到 `originalFormData`

## 三、实现模式

### 3.1 数据结构定义

```typescript
// 1. 原始数据存储
const originalFormData = ref<{
  field1: string | null;
  field2: string | null;
  // ... 其他字段
} | null>(null);

// 2. 表单数据模型（统一使用 formData）
const formData = reactive({
  field1: '',
  field2: null as string | null,
  // ... 其他字段
});

// 3. 编辑模式标识
const editingId = ref<string | null>(null);
```

若为弹窗内编辑，可同时使用 `dialogVisible`、`editingRoomId` 等，与 `editingId` 等价用于判断编辑模式。

### 3.2 动态验证规则

验证规则必须使用 `computed`，根据编辑模式与原始数据动态调整：

```typescript
const formRules = computed(() => ({
  field1: [
    {
      required: !editingId.value || !originalFormData.value?.field1,
      message: '请输入field1',
      trigger: 'blur',
    },
  ],
  field2: [
    {
      required: !editingId.value || !originalFormData.value?.field2,
      message: '请选择field2',
      trigger: 'change',
    },
  ],
}));
```

- `editingId.value`：是否为编辑模式
- `originalFormData.value?.fieldX`：是否有原始数据
- 编辑模式且存在原始数据时，`required` 为 `false`

### 3.3 编辑时加载数据

```typescript
const handleEdit = async (id: string) => {
  editingId.value = id;

  try {
    const response = await getDetail(id);
    const data = response.data || response;

    // 1. 若有关联数据，先加载
    let originalField2: string | null = null;
    try {
      const rel = await getRelated(id);
      if (rel?.data?.items?.length) originalField2 = rel.data.items[0].field2;
    } catch (e) {
      console.warn('加载关联数据失败:', e);
    }

    // 2. 填充表单
    Object.assign(formData, {
      field1: data.field1 || '',
      field2: originalField2 ?? data.field2 ?? null,
    });

    // 3. 保存原始数据（关键）
    originalFormData.value = {
      field1: data.field1 || null,
      field2: originalField2 ?? data.field2 ?? null,
    };
  } catch (error) {
    ElMessage.error('加载数据失败');
    handleCancel();
  }
};
```

### 3.4 创建时重置数据

```typescript
const handleCreate = () => {
  editingId.value = null;
  Object.assign(formData, { field1: '', field2: null /* ... */ });
  originalFormData.value = null;
};
```

### 3.5 提交数据处理

```typescript
const handleSubmit = async () => {
  if (!formData.field1?.trim()) {
    ElMessage.error('请输入field1');
    return;
  }

  let field2ToUse = formData.field2;
  if (editingId.value && !field2ToUse && originalFormData.value?.field2) {
    field2ToUse = originalFormData.value.field2;
  }
  if (!editingId.value && !field2ToUse) {
    ElMessage.error('请选择field2');
    return;
  }

  const payload = {
    field1: formData.field1.trim(),
    field2: field2ToUse,
  };

  if (editingId.value) {
    await updateItem(editingId.value, payload);
  } else {
    await createItem(payload);
  }
};
```

### 3.6 表单重置与关闭

关闭编辑弹窗或重置表单时，必须同时清空原始数据：

```typescript
const resetForm = () => {
  Object.assign(formData, { field1: '', field2: null /* ... */ });
  originalFormData.value = null;
};

const handleDialogClose = () => {
  dialogVisible.value = false;
  editingId.value = null;
  resetForm();
};
```

## 四、字段分类与处理策略

| 类型 | 创建模式 | 编辑模式 |
|------|----------|----------|
| **必填** | 必须提供，否则报错 | 表单为空时用原始数据；原始数据也为空则报错 |
| **可选（有默认值）** | 为空时用默认值 | 表单为空用原始数据；都无则用默认值 |
| **关联数据** | 为空则不创建关联 | 表单为空用原始数据；都无则不更新关联；**仅当值变化时**才调用更新接口 |

关联数据更新示例：

```typescript
if (startTimeToUse) {
  const needUpdate =
    !editingId.value ||
    (originalFormData.value?.start_time !== startTimeToUse);
  if (needUpdate) await updateSession(startTimeToUse);
}
```

## 五、完整实现示例

以分会场编辑（弹窗内）为例，`formData` 使用 `ref` 时按 `.value` 访问即可，此处用 `reactive` 简化示意。

```typescript
const editingRoomId = ref<string | null>(null);
const originalFormData = ref<{
  start_time: string | null;
  title: string;
  description: string;
  cover_url: string;
} | null>(null);

const formData = reactive({
  title: '',
  description: '',
  cover_url: '',
  start_time: null as string | null,
});

const formRules = computed(() => ({
  title: [
    { required: true, message: '请输入分会场名称', trigger: 'blur' },
    { min: 1, max: 50, message: '长度在 1 到 50 个字符', trigger: 'blur' },
  ],
  start_time: [
    {
      required: !editingRoomId.value || !originalFormData.value?.start_time,
      message: '请选择直播时间',
      trigger: 'change',
    },
  ],
}));

const handleEditSubVenue = async (subRoomId: string) => {
  editingRoomId.value = subRoomId;
  dialogVisible.value = true;
  try {
    const roomDetail = await getRoomDetail(subRoomId);
    const room = roomDetail.data || roomDetail;
    let originalStartTime: string | null = null;
    try {
      const sessionResponse = await getSessionList(subRoomId, { page: 1, size: 1 });
      const sessions = sessionResponse.data?.items || [];
      if (sessions.length > 0) originalStartTime = sessions[0].start_time;
    } catch (e) {
      console.warn('加载场次失败:', e);
    }
    Object.assign(formData, {
      title: room.title || '',
      description: room.description || '',
      cover_url: room.cover_url || '',
      start_time: originalStartTime,
    });
    originalFormData.value = {
      start_time: originalStartTime,
      title: room.title || '',
      description: room.description || '',
      cover_url: room.cover_url || '',
    };
  } catch (e: any) {
    ElMessage.error('加载分会场详情失败: ' + (e?.message || '未知错误'));
    handleDialogClose();
  }
};

const resetForm = () => {
  Object.assign(formData, {
    title: '',
    description: '',
    cover_url: '',
    start_time: null,
  });
  originalFormData.value = null;
};

const handleSubmit = async () => {
  if (!formData.title?.trim()) {
    ElMessage.error('请输入分会场名称');
    return;
  }
  let startTimeToUse = formData.start_time;
  if (
    editingRoomId.value &&
    !startTimeToUse &&
    originalFormData.value?.start_time
  ) {
    startTimeToUse = originalFormData.value.start_time;
  }
  if (!editingRoomId.value && !startTimeToUse) {
    ElMessage.error('请选择直播时间');
    return;
  }
  try {
    if (editingRoomId.value) {
      await updateRoom(editingRoomId.value, {
        title: formData.title.trim(),
        description: formData.description?.trim() || '分会场',
        cover_url: formData.cover_url,
        /* ... */
      });
      if (startTimeToUse) {
        const needUpdate =
          originalFormData.value?.start_time !== startTimeToUse;
        if (needUpdate) await updateSession(startTimeToUse);
      }
    } else {
      await createRoom({
        title: formData.title.trim(),
        start_time: startTimeToUse!,
        /* ... */
      });
    }
    ElMessage.success('操作成功');
    handleDialogClose();
  } catch (e: any) {
    ElMessage.error(e?.message || '操作失败');
  }
};
```

## 六、常见错误与正确做法

### 6.1 验证规则使用静态 ref

```typescript
// ❌ 错误：编辑模式仍强制必填
const formRules = ref({
  start_time: [
    { required: true, message: '请选择直播时间', trigger: 'change' },
  ],
});

// ✅ 正确：computed + 根据编辑模式与原始数据决定 required
const formRules = computed(() => ({
  start_time: [
    {
      required:
        !editingRoomId.value || !originalFormData.value?.start_time,
      message: '请选择直播时间',
      trigger: 'change',
    },
  ],
}));
```

### 6.2 编辑时未保存原始数据

```typescript
// ❌ 错误
const handleEdit = async (id: string) => {
  const data = await getDetail(id);
  Object.assign(formData, data);
  // 缺少 originalFormData.value = { ... }
};

// ✅ 正确
const handleEdit = async (id: string) => {
  const data = await getDetail(id);
  Object.assign(formData, data);
  originalFormData.value = { ...data };
};
```

### 6.3 提交时未回退原始数据

```typescript
// ❌ 错误：直接交表单值，可能为 null
const handleSubmit = async () => {
  await updateItem(id, { start_time: formData.start_time });
};

// ✅ 正确：空时用原始数据
let startTimeToUse = formData.start_time;
if (editingId.value && !startTimeToUse && originalFormData.value?.start_time) {
  startTimeToUse = originalFormData.value.start_time;
}
await updateItem(id, { start_time: startTimeToUse });
```

### 6.4 关联数据未判断是否变更即更新

```typescript
// ❌ 错误：始终调用更新
await updateSession(formData.start_time);

// ✅ 正确：仅变化时更新
const needUpdate =
  originalFormData.value?.start_time !== formData.start_time;
if (needUpdate) await updateSession(formData.start_time);
```

## 七、UI/UX 要求

### 7.1 编辑弹窗返回按钮

通过按钮打开的编辑弹窗，应在标题栏提供「返回」按钮，用于关闭弹窗（并执行 `resetForm`）。

```vue
<el-dialog v-model="dialogVisible">
  <template #header="{ titleId, titleClass }">
    <div class="dialog-header-with-back">
      <el-button
        type="text"
        :icon="ArrowLeft"
        @click="handleDialogClose"
        class="dialog-back-button"
      >
        返回
      </el-button>
      <span :id="titleId" :class="titleClass">{{ title }}</span>
    </div>
  </template>
  <!-- 表单内容 -->
</el-dialog>
```

```css
.dialog-header-with-back {
  display: flex;
  align-items: center;
  gap: 12px;
}
.dialog-back-button {
  padding: 0;
  margin-right: 4px;
  color: var(--el-text-color-primary);
}
.dialog-back-button:hover {
  color: var(--el-color-primary);
}
```

### 7.2 可选字段提示（可选）

若编辑模式下某可选字段使用原始数据，可在提交时打日志或轻提示，便于调试或用户确认。

## 八、检查清单

实现编辑功能时，请确认：

- [ ] 使用 `formData` 作为表单数据，`originalFormData` 保存原始数据
- [ ] 使用 `editingId` 或等价标识区分创建/编辑模式
- [ ] 验证规则使用 `computed` 动态控制 required
- [ ] 编辑时先加载关联数据，再填充 `formData`，最后写入 `originalFormData`
- [ ] 创建或关闭时 `originalFormData` 置为 `null`，并重置 `formData`
- [ ] 提交时对可选/关联字段做「表单空 → 用原始数据」回退
- [ ] 关联数据仅在值变化时调用更新接口
- [ ] 弹窗编辑具备返回按钮并调用 `handleDialogClose` / `resetForm`

## 九、测试要点

### 9.1 功能测试

1. **编辑 - 不修改**：打开编辑，不改任何字段直接保存 → 全部使用原始数据，保存成功。
2. **编辑 - 部分修改**：只改部分字段保存 → 已改用新值，未改用原值。
3. **编辑 - 清空某字段**：必填字段清空 → 回退原值；可选字段 → 按策略用默认或空。
4. **创建**：必填未填即保存 → 提示错误。

### 9.2 边界测试

- 原始数据为空时，按默认值或提示处理。
- 关联数据加载失败时，打警告，不阻塞编辑。
- 日期等格式在原始数据与表单间保持一致。
