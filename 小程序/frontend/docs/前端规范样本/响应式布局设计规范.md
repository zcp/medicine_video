## 一、适用范围

### 1.1 技术栈要求

本规范包含通用的响应式设计理念，以及针对不同技术栈的具体实现规范：

- ✅ **通用理念**：适用于所有前端项目
- ✅ **uni-app项目**：使用 `rpx` 单位（移动端优先）
- ✅ **Element Plus项目**：使用 `px/rem/vw` 单位（标准CSS）
- ✅ **管理后台类 H5/PC 页面**（含 uni-app H5、Element Plus）：以 Element Plus + `px` 为主，与 [skills/uni-ui-beauty.md](../../../skills/uni-ui-beauty.md) 一致

### 1.2 核心原则

**移动端优先策略**：
- ✅ 默认样式针对移动端设计
- ✅ 使用媒体查询适配大屏幕设备
- ✅ 通过断点定义实现布局结构变化

## 二、设计理念

### 2.1 核心理念

**响应式设计的双重策略**：

1. **基础适配**：保证在各类屏幕上的等比缩放效果和一致性
   - uni-app项目：使用 `rpx` 单位（自动适配）
   - Element Plus项目：使用 `px/rem/vw` 单位（手动适配）

2. **布局调整**：使用媒体查询处理从窄屏到宽屏的布局结构变化
   - 单列布局 → 多列网格布局
   - 限制内容区域的最大宽度以提高可读性
   - 调整间距、字体大小等

### 2.2 设计原则

1. **移动端优先**：默认样式针对移动端，然后通过媒体查询适配大屏幕
2. **渐进增强**：从小屏幕开始设计，逐步增强到大屏幕
3. **内容优先**：确保内容在所有设备上都能正常显示
4. **性能优先**：避免不必要的布局计算和重绘

## 三、通用断点定义

### 3.1 标准断点

为了保持项目的一致性，所有媒体查询都应使用预定义的全局断点变量。

**标准断点定义**：

```scss
/* --- 响应式断点 --- */
/* 可根据项目目标设备微调 */
$breakpoint-sm: 576px;  // 小屏幕 (手机竖屏)
$breakpoint-md: 768px;  // 中等屏幕 (平板)
$breakpoint-lg: 992px;  // 大屏幕 (桌面显示器)
$breakpoint-xl: 1200px; // 超大屏幕 (宽屏桌面)
```

### 3.2 断点使用规范

**要求**：
- ✅ 所有媒体查询使用预定义的断点变量
- ✅ 不在媒体查询中硬编码像素值
- ✅ 断点定义文件统一管理

## 四、uni-app项目实现规范

### 4.1 适用前提条件

**技术栈要求**：
- ✅ 使用 uni-app 框架
- ✅ 需要编译到多端（H5、小程序、App）
- ✅ 使用 uni-ui 组件库或 uni-app 官方组件

### 4.2 样式单位规范

#### 4.2.1 基础单位：rpx

**规范**：所有基础样式（字体大小、边距、圆角等）应首先使用 `rpx` 单位。

**说明**：
- `rpx` 是 uni-app 的响应式单位
- 750rpx = 屏幕宽度
- 会自动根据屏幕宽度等比缩放

**示例**：
```scss
.my-element {
  width: 750rpx;      // 全屏宽度
  padding: 20rpx;     // 内边距
  font-size: 28rpx;   // 字体大小
  border-radius: 12rpx; // 圆角
}
```

#### 4.2.2 布局单位优先级

**优先级顺序**：
1. **rpx**：基础样式首选
2. **vw/vh**：全屏布局
3. **百分比**：相对布局
4. **px**：仅用于边框、阴影等固定尺寸

**禁止**：
- ❌ 禁止在行内 style 使用 rpx
- ❌ 必须通过类名配合 `<style>`/SCSS 设置尺寸

#### 4.2.3 全局样式文件

**文件路径**：`styles/global.scss`

**内容**：
```scss
/* --- 响应式断点 --- */
$breakpoint-sm: 576px;
$breakpoint-md: 768px;
$breakpoint-lg: 992px;
$breakpoint-xl: 1200px;
```

### 4.3 媒体查询使用规范

#### 4.3.1 导入全局样式

**规范**：所有需要进行响应式布局的页面或组件，**必须** 在其 `<style lang="scss" scoped">` 块的顶部导入全局样式文件。

**示例**：
```vue
<style lang="scss" scoped>
@import '@/styles/global.scss';

.my-element {
  // 默认样式 (移动端优先，使用rpx)
  width: 100%;
  padding: 20rpx;
  font-size: 28rpx;

  // 在屏幕宽度 >= 768px 时应用的样式
  @media (min-width: $breakpoint-md) {
    width: 50%;
    padding: 30rpx;
    font-size: 32rpx;
  }

  // 在屏幕宽度 >= 992px 时应用的样式
  @media (min-width: $breakpoint-lg) {
    width: 33.33%;
    padding: 40rpx;
    font-size: 36rpx;
  }
}
</style>
```

#### 4.3.2 布局结构变化

**示例：单列变多列**：
```vue
<style lang="scss" scoped>
@import '@/styles/global.scss';

.card-list {
  // 默认：单列布局（移动端）
  display: flex;
  flex-direction: column;
  gap: 20rpx;

  // 平板：两列布局
  @media (min-width: $breakpoint-md) {
    flex-direction: row;
    flex-wrap: wrap;
    
    .card-item {
      width: calc(50% - 10rpx);
    }
  }

  // 桌面：三列布局
  @media (min-width: $breakpoint-lg) {
    .card-item {
      width: calc(33.33% - 14rpx);
    }
  }
}
</style>
```

### 4.4 uni-ui组件适配

**规范**：uni-ui组件本身已做多端适配，开发者主要关注：
- ✅ 使用 `rpx` 单位设置尺寸
- ✅ 通过媒体查询调整布局结构
- ✅ 避免硬编码像素值

## 五、Element Plus项目实现规范

### 5.1 适用前提条件

**技术栈要求**：
- ✅ 使用 Vue3 + Element Plus
- ✅ 主要面向 H5/Web 平台
- ✅ 使用标准 CSS 单位

### 5.2 样式单位规范

#### 5.2.1 基础单位：px/rem/vw

**规范**：根据场景选择合适的单位。

**单位选择指南**：
- **px**：固定尺寸（边框、阴影、固定宽高）
- **rem**：字体大小、间距（相对于根字体大小）
- **vw/vh**：全屏布局、响应式尺寸
- **百分比**：相对布局

**示例**：
```scss
.my-element {
  width: 100%;           // 相对宽度
  padding: 16px;         // 固定内边距
  font-size: 14px;       // 固定字体大小
  border-radius: 4px;    // 固定圆角
  max-width: 1200px;     // 最大宽度限制
}
```

#### 5.2.2 响应式尺寸处理

**规范**：通过媒体查询调整尺寸，使用 `px` 或 `rem`。

**示例**：
```scss
.my-element {
  // 默认：移动端
  width: 100%;
  padding: 12px;
  font-size: 14px;

  // 平板
  @media (min-width: $breakpoint-md) {
    width: 90%;
    padding: 16px;
    font-size: 16px;
  }

  // 桌面
  @media (min-width: $breakpoint-lg) {
    width: 1200px;      // 最大宽度限制
    margin: 0 auto;     // 居中
    padding: 24px;
    font-size: 18px;
  }
}
```

#### 5.2.3 全局样式文件

**文件路径**：`src/common/responsive.scss` 或 `src/styles/global.scss`

**内容**：
```scss
/* --- 响应式断点 --- */
$breakpoint-sm: 576px;
$breakpoint-md: 768px;
$breakpoint-lg: 992px;
$breakpoint-xl: 1200px;
```

### 5.3 媒体查询使用规范

#### 5.3.1 导入全局样式

**规范**：所有需要进行响应式布局的页面或组件，**必须** 在其 `<style lang="scss" scoped">` 块的顶部导入全局样式文件。

**示例**：
```vue
<style lang="scss" scoped>
@import '@/common/responsive.scss';

.my-element {
  // 默认样式 (移动端优先)
  width: 100%;
  padding: 16px;

  // 在屏幕宽度 >= 768px 时应用的样式
  @media (min-width: $breakpoint-md) {
    width: 50%;
    padding: 24px;
  }

  // 在屏幕宽度 >= 992px 时应用的样式
  @media (min-width: $breakpoint-lg) {
    width: 33.33%;
    padding: 32px;
  }
}
</style>
```

#### 5.3.2 Element Plus组件响应式

**规范**：Element Plus组件本身已做响应式适配，开发者主要关注：
- ✅ 通过媒体查询调整布局结构
- ✅ 限制内容区域最大宽度
- ✅ 调整间距和字体大小

**示例**：
```vue
<template>
  <div class="page-container">
    <el-card class="content-card">
      <!-- 内容 -->
    </el-card>
  </div>
</template>

<style lang="scss" scoped>
@import '@/common/responsive.scss';

.page-container {
  padding: 16px;

  @media (min-width: $breakpoint-md) {
    padding: 24px;
  }

  @media (min-width: $breakpoint-lg) {
    max-width: 1200px;
    margin: 0 auto;
    padding: 32px;
  }
}

.content-card {
  // Element Plus组件已做响应式，主要调整间距
}
</style>
```
