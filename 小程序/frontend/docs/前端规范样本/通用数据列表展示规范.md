# 通用数据列表展示规范（弹性布局版）

本规范旨在解决后台管理系统中常见的数据列表（Table）展示问题：包括内容遮挡、列宽分配不均、长文本阅读困难等，确保界面清爽、自适应且具备专业美感。

**相关规范**：分页实现（后端/前端分页、`pagination.total`、Store）见《前端分页实现规范与常见错误》；响应式断点见《响应式布局设计规范》。

## 1. 布局核心原则

### 1.1 弹性列宽分配
- **禁止全量固定宽度**：表格必须包含至少一个使用 `min-width` 的弹性列，确保表格在不同屏幕分辨率下均能 100% 撑满容器。
- **列宽分配标准**：
  - **选择框**：固定 `50px`，居中。
  - **标识符/状态标签**：固定 `100px - 120px`。
  - **日期时间**：固定 `160px - 180px`。
  - **操作列**：根据按钮数量固定宽度（如 3 个按钮建议 `220px`），必须设为 `fixed="right"`。
  - **核心业务内容**：如“擅长领域”、“描述”、“详情”，设为 `min-width="200"` 或以上，不设上限。

### 1.2 信息聚合（Aggregation）
- **减少视觉碎片**：将关联性强的信息聚合在同一单元格内。
- **示例**：
  - **聚合前**：头像（1列）+ 姓名（1列）+ ID（1列） = 3列，约 450px。
  - **聚合后**：基本信息（1列） = 1列，180px。内部使用 Flex 布局垂直排列姓名与短 ID。

## 2. 文本展示方案

### 2.1 强制换行规范
- **原则**：对于管理端，信息的可视性（Visibility）高于整齐度（Neatness）。禁止使用 `show-overflow-tooltip` 隐藏核心业务信息。
- **实现**：
  ```css
  /* 单元格内容包裹容器 */
  .cell-content-wrap {
    word-break: break-all;   /* 允许在单词内换行 */
    white-space: normal;    /* 允许正常换行 */
    line-height: 1.5;       /* 增加行高，提升易读性 */
    padding: 4px 0;
  }
  ```

### 2.2 视觉引导
- **固定列阴影**：为右侧固定操作列增加左侧投影，增强层级感。
  ```css
  :deep(.el-table__fixed-right) {
    box-shadow: -2px 0 8px rgba(0, 0, 0, 0.05);
  }
  ```

## 3. 列精简策略（Column Pruning）

当列表项超过 7 列或出现横向滚动条影响操作时，应按以下优先级移除列，并将其移入“详情”弹窗或详情页：
1. **低频次列**：创建时间、修改时间、排序权重。
2. **长字符串列**：完整 UUID、详细备注、原始 JSON 数据。
3. **辅助分类列**：次要的标签、层级较深的科室/部门名称。

## 4. 推荐代码结构 (Vue + Element Plus)

```html
<el-table :data="list" style="width: 100%" border stripe>
  <!-- 1. 选择 -->
  <el-table-column type="selection" width="50" align="center" />
  
  <!-- 2. 聚合识别列 (固定宽度) -->
  <el-table-column label="基本信息" width="180">
    <template #default="{ row }">
      <div class="info-cell">
        <el-avatar :src="row.logo" :size="40" />
        <div class="text-group">
          <div class="main-text">{{ row.name }}</div>
          <div class="sub-text">ID: {{ row.id.slice(0, 8) }}</div>
        </div>
      </div>
    </template>
  </el-table-column>

  <!-- 3. 核心业务列 (弹性宽度 + 自动换行) -->
  <el-table-column prop="desc" label="业务描述" min-width="250" class-name="cell-wrap">
    <template #default="{ row }">
      <div class="cell-content-wrap">{{ row.desc }}</div>
    </template>
  </el-table-column>

  <!-- 4. 状态列 (固定宽度) -->
  <el-table-column prop="status" label="状态" width="100" align="center" />

  <!-- 5. 操作列 (固定在右侧) -->
  <el-table-column label="操作" width="220" fixed="right" align="center">
    <template #default="{ row }">
      <el-space :size="4">
        <el-button size="small" type="primary">详情</el-button>
        <el-button size="small" type="warning">编辑</el-button>
        <el-button size="small" type="danger">删除</el-button>
      </el-space>
    </template>
  </el-table-column>
</el-table>
```

## 6. 响应式适配规范

为了确保列表在移动端和平板设备上依然可用，必须遵循以下适配策略（断点遵循《响应式布局设计规范.md》）。

### 6.1 响应式断点定义
| 设备类型 | 断点 (Breakpoint) | 像素值 | 说明 |
| :--- | :--- | :--- | :--- |
| 小屏幕 (手机) | `$breakpoint-sm` | 576px | 手机竖屏 |
| 中屏幕 (平板) | `$breakpoint-md` | 768px | 平板设备 |
| 大屏幕 (桌面) | `$breakpoint-lg` | 992px | 标准桌面显示器 |
| 超大屏幕 (宽屏) | `$breakpoint-xl` | 1200px | 宽屏桌面显示器 |

### 6.2 不同分辨率下的处理策略

1. **小屏幕 (< 768px) - 手机端**：
   - **列隐藏**：使用媒体查询 + CSS 隐藏非核心列（如状态标签、日期），或使用 `v-if` 条件渲染。
   - **滚动提示**：表格容器必须允许横向滚动，并在视觉上通过右侧固定列的阴影提示。
   - **按钮合并**：操作列中的按钮若超过 2 个，建议使用 `el-dropdown` 下拉菜单。
   - **字体调整**：适当减小字体大小（如从 13px 降至 12px）。

2. **中屏幕 (768px - 992px) - 平板端**：
   - **列压缩**：将弹性列的 `min-width` 调小（如从 250px 降至 180px）。
   - **信息简化**：聚合列中的“短 ID”可以隐藏，仅保留“姓名”。
   - **按钮布局**：操作按钮保持并排，但间距可适当减小。

3. **大屏幕 (992px - 1200px) - PC端**：
   - **全量显示**：显示 Section 3 中定义的所有核心列。
   - **容器限制**：表格容器建议设置最大宽度（如 `max-width: 1400px`）并居中，避免内容过度拉伸。
   - **列宽优化**：弹性列可使用较大的 `min-width`（如 250px - 300px）。

4. **超大屏幕 (≥ 1200px) - 宽屏PC**：
   - **内容居中**：表格容器居中显示，两侧留白。
   - **列宽扩展**：弹性列可进一步扩展（如 `min-width="350"`），充分利用屏幕空间。
   - **间距优化**：适当增加内边距，提升视觉舒适度。

### 6.3 Element Plus 列隐藏实现方法

**方法一：使用媒体查询 + CSS（推荐）**
```scss
@import '@/common/responsive.scss';

:deep(.el-table) {
  /* 小屏幕隐藏状态列 */
  @media (max-width: $breakpoint-md - 1px) {
    .status-column {
      display: none;
    }
  }
}
```

**方法二：使用 v-if 条件渲染**
```vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue';

const screenWidth = ref(window.innerWidth);

const updateScreenWidth = () => {
  screenWidth.value = window.innerWidth;
};

onMounted(() => {
  window.addEventListener('resize', updateScreenWidth);
  updateScreenWidth();
});

onUnmounted(() => {
  window.removeEventListener('resize', updateScreenWidth);
});
</script>

<template>
  <el-table-column 
    v-if="screenWidth >= 768"
    prop="status" 
    label="状态" 
    width="100"
  />
</template>
```

### 6.4 完整响应式样式示例 (SCSS)

```scss
@import '@/common/responsive.scss';

/* 表格容器响应式 */
.table-container {
  width: 100%;
  
  /* PC端：限制最大宽度并居中 */
  @media (min-width: $breakpoint-lg) {
    max-width: 1400px;
    margin: 0 auto;
  }
}

:deep(.el-table) {
  /* 小屏幕：隐藏次要信息，压缩列宽 */
  @media (max-width: $breakpoint-md - 1px) {
    .sub-text {
      display: none; /* 隐藏次要 ID 信息 */
    }
    
    /* 调整操作列宽度 */
    .el-table__fixed-right {
      width: 120px !important;
    }
    
    /* 压缩弹性列 */
    .el-table-column[prop="desc"] {
      min-width: 150px !important;
    }
  }
  
  /* 平板：适度压缩 */
  @media (min-width: $breakpoint-md) and (max-width: $breakpoint-lg - 1px) {
    .sub-text {
      display: none;
    }
    
    .el-table-column[prop="desc"] {
      min-width: 180px;
    }
  }
  
  /* PC端：标准显示 */
  @media (min-width: $breakpoint-lg) {
    .el-table-column[prop="desc"] {
      min-width: 250px;
    }
  }
  
  /* 超大屏幕：扩展显示 */
  @media (min-width: $breakpoint-xl) {
    .el-table-column[prop="desc"] {
      min-width: 350px;
    }
  }
}
```
