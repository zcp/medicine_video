## 🎯 设计要点与约定

### 1.1 数据库设计规范

1. **UUID主键**: 所有表使用 `UUID` 类型作为主键
2. **时间戳**: 所有时间字段使用 `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
3. **软删除**: `featured_content` 表使用 `is_active` 字段实现软删除
4. **索引策略**: 高频查询字段建立索引
5. **字段注释**: 所有表和关键字段使用 `COMMENT ON` 添加中文注释

### 1.2 API设计规范

1. **HTTP方法**: GET（查询）、POST（创建）、PATCH（部分更新）、DELETE（删除）
2. **URL路径**: 使用 `/api/v1/featured-content` 格式
3. **认证策略**: 公开读取 + 管理员写入
4. **时间过滤**: 公开查询自动过滤 `start_at <= now <= end_at` 的记录

### 1.3 软删除策略

| 表名 | 策略 | 说明 |
|------|------|------|
| `featured_content` | `is_active` 字段 | 删除时设置 `is_active = false`，公开查询默认过滤 |

### 1.4 安全与配置规范

**架构分层原则**:
- **API 层**: 仅负责认证
- **Service 层**: 负责授权（权限守卫函数）
- **CRUD 层**: 负责SQL级别的权限过滤

**权限守卫函数**:

```python
def _check_admin_permission(user_role: str) -> None:
    """检查管理员权限"""
    if user_role != "admin":
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail={"code": 3002, "message": "权限不足：需要管理员权限"}
        )
```

**文件上传安全**:
- 允许的MIME类型: `image/jpeg`, `image/png`, `image/webp`
- 最大文件大小: 5MB
- 文件名使用UUID生成，防止路径遍历攻击

**image_url 校验规则（创建+更新）**:

收到 `image_url` 后，按以下顺序校验：
1. 匹配黑名单 → 422 拒绝，返回明确错误
2. 不匹配白名单 → 422 拒绝，返回明确错误
3. 通过 → 正常处理

```python
import re

# 黑名单：需要拒绝的模式（小程序本地临时路径）
REJECTED_IMAGE_URL_PATTERNS = [
    re.compile(r'^https?://tmp/', re.IGNORECASE),   # uni.chooseImage 临时路径
    re.compile(r'^file://', re.IGNORECASE),          # 本地文件协议
    re.compile(r'^wxfile://', re.IGNORECASE),        # 微信小程序本地文件
]

# 白名单：合法的 image_url 模式
VALID_IMAGE_URL_PATTERN = re.compile(
    r'^('
    r'/media/featured/[a-f0-9\-]+\.(jpg|jpeg|png|webp)'  # 上传后的服务器路径
    r'|/static/images/banners/.*'                           # 占位SVG
    r'|https?://[^\s]+'                                     # 外部CDN URL
    r')$',
    re.IGNORECASE
)
```

**公开端点防御性过滤**:
公开列表 `GET /api/v1/featured-content` 在 Service 层过滤掉 `image_url` 匹配 `REJECTED_IMAGE_URL_PATTERNS` 的记录，确保前端拿到的每条数据 `image_url` 都是合法可加载的。

### 1.0 前置准备：触发器函数

-- 自动更新 updated_at 触发器函数（如已创建则跳过）
CREATE OR REPLACE FUNCTION trigger_set_timestamp()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

### 1.1 featured_content（焦点图表）

-- 表：featured_content（焦点图/轮播图表）
-- 说明：存储首页焦点图信息，支持多目标类型、时间范围控制
-- ==========================================================

CREATE TABLE featured_content (
    id UUID PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    subtitle VARCHAR(500),
    image_url VARCHAR(500) NOT NULL,
    target_type VARCHAR(50) NOT NULL,
    target_id UUID,
    target_url VARCHAR(1000),
    sort_order INTEGER NOT NULL DEFAULT 0,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    start_at TIMESTAMPTZ,
    end_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT chk_fc_target_type CHECK (
        target_type IN ('room', 'session', 'topic', 'brand', 'external')
    ),
    CONSTRAINT chk_fc_target_logic CHECK (
        (target_type = 'external' AND target_url IS NOT NULL) OR
        (target_type != 'external' AND target_id IS NOT NULL)
    )
);

-- 普通索引：is_active（用于过滤活跃焦点图）
CREATE INDEX idx_fc_is_active ON featured_content(is_active);

-- 普通索引：sort_order（用于排序查询）
CREATE INDEX idx_fc_sort_order ON featured_content(sort_order);

-- 复合索引：is_active + sort_order（用于公开查询排序）
CREATE INDEX idx_fc_active_sort ON featured_content(is_active, sort_order);

-- 复合索引：时间范围查询
CREATE INDEX idx_fc_time_range ON featured_content(start_at, end_at);

-- 触发器：自动更新 updated_at

    target_type: TargetType = Field(..., description="跳转目标类型")

    target_url: Optional[str] = Field(None, max_length=1000, description="外部链接URL")
    sort_order: int = Field(0, ge=0, description="排序权重")
    is_active: bool = Field(True, description="是否启用")
    start_at: Optional[datetime] = Field(None, description="生效开始时间")
    end_at: Optional[datetime] = Field(None, description="生效结束时间")

    @field_validator("target_id", "target_url")
    @classmethod
    def validate_target(cls, v, info):
        """校验target_id和target_url的逻辑一致性"""
        # 注意：完整的交叉字段校验需要在Service层处理
        return v


class FeaturedContentCreate(FeaturedContentBase):
    """创建焦点图请求Schema"""
    pass


class FeaturedContentUpdate(BaseModel):
    """更新焦点图请求Schema（部分更新）"""
    title: Optional[str] = Field(None, min_length=1, max_length=200)
    subtitle: Optional[str] = Field(None, max_length=500)
    image_url: Optional[str] = Field(None, max_length=500)
    target_type: Optional[TargetType] = None
    target_id: Optional[UUID] = None

    sort_order: Optional[int] = Field(None, ge=0)

class FeaturedContentItem(FeaturedContentBase):

    id: UUID
    created_at: datetime
    updated_at: datetime

    model_config = ConfigDict(from_attributes=True)


class FeaturedContentListResponse(BaseModel):

### 3.2 管理端API

#### 3.2.1 管理端分页查询焦点图（ADMIN）

**Endpoint**: `GET /api/v1/admin/featured-content`

**描述**: 管理端分页查询焦点图列表（包含已禁用和过期的）

**认证**: JWT认证 + 管理员权限

**请求参数 (Query)**:
- `page` (int, 可选, 默认1): 页码
- `page_size` (int, 可选, 默认20): 每页数量
- `is_active` (bool, 可选): 过滤启用状态

**成功响应** (`200 OK`):
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 25,
    "page": 1,
    "size": 20,
    "items": [ ... ]
  },
  "timestamp": "2026-06-07T10:00:00Z"
}
```

**执行流程**:

1. **接收请求**: API路由接收GET请求，解析Query参数
2. **JWT验证**: 通过 `Depends(get_current_user)` 提取当前用户
3. **权限检查**: 调用 `_check_admin_permission(user.role)` 校验管理员权限
4. **构建查询**: 使用SQLAlchemy构建SELECT查询
5. **过滤条件**: 若 `is_active` 参数存在，添加对应过滤
6. **分页**: 计算 `offset` 和 `LIMIT`
7. **执行查询**: 异步执行数据库查询，同时执行 `COUNT` 查询获取总数
8. **返回响应**: 返回统一分页格式的JSON响应

**HTTP状态码**:
- `200 OK`: 查询成功
- `401 Unauthorized`: JWT Token无效（code=3001）
- `403 Forbidden`: 非管理员（code=3002）
- `500 Internal Server Error`: 数据库异常

### 3.3 图片上传API

#### 3.3.1 上传焦点图图片（ADMIN）

**Endpoint**: `POST /api/v1/admin/featured-content/{contentId}/image`

**描述**: 上传焦点图图片

**认证**: JWT认证 + 管理员权限

**路径参数**:
- `contentId` (UUID, required): 焦点图UUID

```json
{
  "code": 200,
  "message": "图片上传成功",

  },
  "timestamp": "2026-06-07T10:00:00Z"
}
```

**执行流程**:

1. **接收请求**: API路由接收POST请求，解析multipart文件
2. **JWT验证**: 通过 `Depends(get_current_user)` 提取当前用户
3. **权限检查**: 调用 `_check_admin_permission(user.role)` 校验管理员权限
4. **存在性检查**: 查询焦点图是否存在
5. **文件校验**: 检查文件类型（MIME type，仅 jpg/png/webp）和大小（≤5MB）

7. **存储文件**: 保存到 `media/featured/` 目录，URL 路径为 `/media/featured/{uuid}.{ext}`
8. **更新数据库**: `UPDATE featured_content SET image_url = :image_url WHERE id = :contentId`
9. **提交事务**: `await db.commit()`
10. **返回响应**: 返回图片URL

**HTTP状态码**:
- `200 OK`: 上传成功
- `401 Unauthorized`: JWT Token无效（code=3001）
- `403 Forbidden`: 非管理员（code=3002）
- `404 Not Found`: 焦点图不存在（code=2001）
- `413 Payload Too Large`: 文件超过5MB
- `415 Unsupported Media Type`: 不支持的文件类型
- `500 Internal Server Error`: 文件存储失败
