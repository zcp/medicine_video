### 7.7 填充 / 守约总判与 §7 字段缺口（F*）

**总判（代码对照，非 OpenAPI 逐键）**

1. 多数业务页**确实在用后端数据填 UI**；常见模式是「列表字段不全 → Store 补拉房间/场次」+「媒体 URL 兜底」。  
2. 生命周期类规则（注销清私货、删房级联、留言占位、品牌软下架）前端以**消费后端结果**为主，不在前端重算；锚点见 §5。  
3. 真正「同实体多页不同步 / 没吃到后端」集中在下表 **F\***；跨页即时性仍见 §0.1 **G\***。

| # | 缺口简述 | 涉及路由 | 建议 | 与 G* 关系 |
|---|----------|----------|------|------------|
| **F1** | 首页房状态 Tab 对已拉列表客户端再筛，与分页脱节 | Home | 将状态参数交给 `getHomepageRooms` 或接受「仅当前页筛选」并改文案 | 读一致性 |
| **F2** | BrandDetail 关联房走 Admin API | BrandDetail | 换公开契约或网关授权明确 | 边界 |
| **F3** | 专家列表/详情 stats 硬编码 0 | ExpertList / ExpertDetail | 映射后端统计字段（若有）或隐藏统计区 | 未填 |
| **F4** | 专家场次 `roomId` 未映射 → 收藏钮不显示 | ExpertDetail | 映射 `room_id` | 未填 |
| **F5** | 观看历史 Tab 客户端二次过滤 | ViewHistory | 与后端 `sessionType` 参数对齐 | 读一致性 |
| **F6** | OneTapLogin `mockToken` 硬编码 | OneTapLogin | 接真运营商 SDK / 去 mock | 认证 |
| **F7** | SearchByTag 跳转未注册路由 | SearchByTag | 改跳 LiveView 或注册页 | 死链 |
| **F8** | 搜索品牌 Tab 未滤 `is_active`（Zone 有滤） | search/index | 与 BrandZone 同口径 | 同实体口径；对照 G4 |

> **刻意不做（§7）**：Admin Dialog 字段矩阵；OpenAPI 逐键 diff；把 F* 升格为《16》新规则。
