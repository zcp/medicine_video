## 二、服务概述

### 2.1 服务定位
媒体下载服务是一个独立的微服务，负责处理直播平台中的媒体资源下载任务，包括视频流下载（HLS、MP4）、图片下载等功能。该服务采用异步处理方式，支持高并发下载任务处理，并提供完善的失败处理和重试机制。

### 2.2 核心功能
- HLS视频流下载
- MP4视频文件下载
- 图片资源下载
- 并发下载控制
- 断点续传
- 下载任务管理
- 资源存储管理
- 失败任务重试
- 下载状态检查
- 失败记录管理

### 2.3 技术栈选型
- 开发语言：Python 3.8+
- Web框架：FastAPI
- 任务队列：Celery + Redis
- 存储系统：本地文件系统 + 对象存储
- 数据库：PostgreSQL
- 监控：Prometheus + Grafana

### 2.4 身份认证与授权
媒体下载服务采用JWT Token认证机制，与用户服务集成实现统一的身份验证：

- **认证方式**: JWT Token (JSON Web Token)
- **认证流程**: 用户通过用户服务进行SSO登录，获得JWT Token后访问媒体下载服务
- **权限控制**: 用户只能访问和操作自己创建的下载任务
- **Token验证**: 使用与用户服务相同的JWT密钥进行Token验证
- **安全机制**: 支持Token过期检查、签名验证、用户权限验证

## 四、数据库设计

### 4.1 下载任务表（download_tasks）

#### 4.1.1 表结构
```sql
CREATE TABLE download_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL,                          -- 用户ID，关联到用户服务
    video_id UUID NOT NULL,                         -- 视频ID，格式：UUID
    liveroom_id VARCHAR(20) NOT NULL,               -- 直播间ID
    liveroom_title VARCHAR(255),                    -- 直播间标题
    liveroom_url VARCHAR(255),                      -- 直播间URL
    resource_url VARCHAR(255) NOT NULL,             -- 资源下载URL(m3u8/mp4/image)
    resource_type VARCHAR(20) NOT NULL,             -- 资源类型: hls, mp4, image
    status VARCHAR(20) NOT NULL DEFAULT 'pending',  -- 任务状态
    progress FLOAT NOT NULL DEFAULT 0,              -- 下载进度（0-1）
    retry_count INT NOT NULL DEFAULT 0,             -- 重试次数
    last_error TEXT,                                -- 最后错误信息
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,  -- 创建时间(UTC)
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,  -- 更新时间(UTC)
    completed_at TIMESTAMP,                         -- 完成时间(UTC)
    
    -- 约束
    CONSTRAINT check_status CHECK (status IN ('pending', 'processing', 'completed', 'partial_completed', 'failed', 'cancelled')),
    CONSTRAINT check_progress_range CHECK (progress >= 0 AND progress <= 1),
    CONSTRAINT check_resource_type CHECK (resource_type IN ('hls', 'mp4', 'image'))
);

-- 索引设计
CREATE INDEX idx_download_tasks_user_id ON download_tasks(user_id);
CREATE INDEX idx_download_tasks_video_id ON download_tasks(video_id);
CREATE INDEX idx_download_tasks_liveroom_id ON download_tasks(liveroom_id);
CREATE INDEX idx_download_tasks_status ON download_tasks(status);
CREATE INDEX idx_download_tasks_created_at ON download_tasks(created_at);
```

#### 4.1.2 字段说明

| 字段名 | 类型 | 约束 | 说明 |
|:---|:---|:---|:---|
| id | UUID | PK | 任务唯一标识 |
| user_id | UUID | NOT NULL | 用户ID，用于数据隔离和权限验证 |
| video_id | UUID | NOT NULL | 视频唯一标识，UUID格式 |
| liveroom_id | String(20) | NOT NULL | 直播间ID，长度10-20 |
| liveroom_title | String(255) | NULL | 直播间标题 |
| liveroom_url | String(255) | NULL | 直播间URL |
| resource_url | String(255) | NOT NULL | 资源下载URL（注意：不是video_url） |
| resource_type | String(20) | NOT NULL | 资源类型：hls, mp4, image |
| status | String(20) | NOT NULL | 任务状态，见TaskStatus枚举 |
| progress | Float | NOT NULL | 下载进度，范围0-1 |
| retry_count | Integer | NOT NULL | 重试次数 |
| last_error | Text | NULL | 最后错误信息 |
| created_at | DateTime | NOT NULL | 创建时间（UTC） |
| updated_at | DateTime | NOT NULL | 更新时间（UTC） |
| completed_at | DateTime | NULL | 完成时间（UTC） |

#### 4.1.3 状态枚举（TaskStatus）
- `pending`: 等待下载
- `processing`: 下载中
- `completed`: 完全成功
- `partial_completed`: 部分成功（HLS分片失败率≤30%）
- `failed`: 失败
- `cancelled`: 已取消

#### 5.1.2 错误码约定

| HTTP状态码 | 说明 | 处理建议 |
|:---|:---|:---|
| 200 | 成功 | - |
| 400 | 请求参数错误 | 检查参数格式 |
| 401 | 未授权 | 重新登录获取token |
| 403 | 禁止访问 | 检查权限 |
| 404 | 资源不存在 | 检查资源ID |

**请求参数（Query）：**

| 参数名 | 类型 | 描述 |
|:---|:---|:---|

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "page": 1,
    "size": 10,
    "items": []
  },
  "timestamp": "2025-06-14T10:00:00Z"
}
```

#### 5.1.4 认证授权规范

**认证要求：**
- **所有API接口都需要JWT Token认证**
- 请求头必须包含：`Authorization: Bearer <JWT_TOKEN>`
- Token由用户服务颁发，包含用户身份信息
- 未认证的请求返回401状态码

**权限控制：**
- 用户只能访问自己创建的下载任务
- 用户只能修改/删除自己的任务
- 所有涉及用户数据的操作都必须验证用户权限
- 通过JWT Token中的user_id进行权限验证

**认证失败响应：**
| HTTP状态码 | 错误码 | 说明 | 处理建议 |
|:---|:---|:---|:---|
| 401 | 401001 | 认证凭证缺失 | 检查Authorization头 |
| 401 | 401002 | 认证凭证无效 | 重新登录获取Token |
| 401 | 401003 | 认证凭证已过期 | 刷新Token或重新登录 |
| 403 | 403001 | 权限不足 | 检查用户权限 |

### 5.2 任务管理接口

#### 5.2.1 创建下载任务
- **接口**: `POST /api/v1/download/tasks`
- **认证**: 需要JWT Token
- **描述**: 创建一个新的下载任务
- **请求体**: `DownloadTaskCreate`
- **响应**: `ResponseModel[DownloadTask]`
- **HTTP状态码**: 201

**业务逻辑：**
1. 从JWT Token中提取user_id
2. 后端重新生成video_id（不使用前端传入值）
3. 创建下载任务记录
4. 返回任务信息

#### 5.2.2 获取下载任务列表
- **接口**: `GET /api/v1/download/tasks`
- **认证**: 需要JWT Token
- **描述**: 分页查询当前用户的下载任务列表
- **查询参数**: `page`, `size`, `sort`, `status`（可选）
- **响应**: `ResponseModel[PageResponse[DownloadTask]]`

**业务逻辑：**
1. 仅返回当前用户的任务（user_id过滤）
2. 支持按状态筛选
3. 支持分页和排序

#### 5.2.3 获取下载任务详情
- **接口**: `GET /api/v1/download/tasks/{task_id}`
- **认证**: 需要JWT Token
- **描述**: 获取指定任务的详细信息
- **路径参数**: `task_id` (UUID)
- **响应**: `ResponseModel[DownloadTask]`

**业务逻辑：**
1. 验证任务是否属于当前用户
2. 返回任务详细信息

#### 5.2.4 更新下载任务

```python
def verify_user_authentication(token: str) -> Dict:
    """验证用户JWT Token"""
    try:
        # 1. 验证Token签名和格式
        payload = jwt.decode(
            token, 
            JWT_SECRET_KEY, 
            algorithms=[JWT_ALGORITHM]
        )
        
        # 2. 检查Token过期时间
        if payload.get('exp') and time.time() > payload['exp']:
            raise HTTPException(status_code=401, detail="认证凭证已过期")
        
        # 3. 提取用户信息
        user_info = {
            "user_id": payload.get("user_id"),
            "username": payload.get("username"),
            "role": payload.get("role", "user"),
            "permissions": payload.get("permissions", [])
        }
        
        # 4. 验证必要字段
        if not user_info["user_id"]:
            raise HTTPException(status_code=401, detail="Token中缺少用户ID")
        
        return user_info
        
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=401, detail="认证凭证无效")
```

### 6.2 下载状态检查流程

```python
def check_download_status(video_id: str, liveroom_id: str, user_id: str) -> Dict:
    """
    检查视频下载状态
```

#### 6.3.2 文件命名生成函数
```python
def generate_standard_filename(
    resource_type: str,
    video_id: str,
    operation_type: str,
    extension: str,
    segment_index: Optional[int] = None
) -> str:
    """
    生成标准化文件名
    :param resource_type: 资源类型（hls/mp4/image/ts）
    :param video_id: 视频ID（UUID）
    :param operation_type: 操作类型（fetch/upload/transcode）
    :param extension: 文件扩展名（不含点）
    :param segment_index: 分片索引（仅用于ts分片）
    :return: 标准化文件名
    """
    timestamp = datetime.now().strftime("%Y%m%dT%H%M%S")
    
    if resource_type == 'ts' and segment_index is not None:
        return f"segment_{segment_index:06d}_{video_id}_{operation_type}_{timestamp}.{extension}"
    elif resource_type == 'mp4':
        return f"video_{video_id}_{operation_type}_{timestamp}.{extension}"
    elif resource_type == 'image':
        return f"cover_{video_id}_{operation_type}_{timestamp}.{extension}"
    elif resource_type == 'hls':
        return f"video_{video_id}_{operation_type}_{timestamp}.{extension}"
    else:
        return f"{video_id}_{operation_type}_{timestamp}.{extension}"
```

### 6.4 HLS视频下载流程

```python
def download_hls_video(task: DownloadTask, save_dir: Path) -> Dict:
    """
    HLS视频下载流程
    :param task: 下载任务
    :param save_dir: 保存目录
    :return: 下载结果
    """
    logger = logging.getLogger('download_service')
    
    try:
        # 1. 创建存储目录
        hls_dir = save_dir / "hls"
        ts_dir = hls_dir / "ts"
        ts_dir.mkdir(parents=True, exist_ok=True)
        
        # 2. 下载m3u8文件
        m3u8_content = download_m3u8_file(task.resource_url)
        m3u8_filename = "index.m3u8"  # 或使用原始文件名
        m3u8_path = hls_dir / m3u8_filename
        
        with open(m3u8_path, 'w', encoding='utf-8') as f:
            f.write(m3u8_content)
        
        # 3. 解析m3u8，获取ts分片列表
        segments = parse_m3u8_segments(m3u8_content, task.resource_url)
        total_segments = len(segments)
        
        # 4. 并发下载ts分片（最大并发数20）
        failed_segments = []
        ts_mapping = {}
        
        with ThreadPoolExecutor(max_workers=20) as executor:
            future_to_segment = {}
            for index, segment_url in enumerate(segments):
                # 生成标准化文件名
                ts_filename = generate_standard_filename(
                    'ts',
                    str(task.video_id),
                    'fetch',
                    'ts',
                    segment_index=index
                )
                ts_path = ts_dir / ts_filename
                
                future = executor.submit(
                    download_ts_segment,
                    segment_url,
                    ts_path,
                    index
                )
                future_to_segment[future] = (index, segment_url, ts_filename)
            
            # 5. 收集下载结果
            for future in as_completed(future_to_segment):
                index, segment_url, ts_filename = future_to_segment[future]
                try:
                    success = future.result()
                    if success:
                        ts_mapping[segment_url] = ts_filename
                    else:
                        failed_segments.append({
                            'index': index,
                            'url': segment_url,
                            'filename': ts_filename
                        })
                except Exception as e:
                    logger.error(f"下载ts分片失败: {segment_url}, 错误: {str(e)}")
                    failed_segments.append({
                        'index': index,
                        'url': segment_url,
                        'filename': ts_filename,
                        'error': str(e)
                    })
        
        # 6. 保存ts映射关系
        ts_mapping_path = ts_dir / "ts_mapping.json"
        with open(ts_mapping_path, 'w', encoding='utf-8') as f:
            json.dump(ts_mapping, f, indent=2, ensure_ascii=False)
        
        # 7. 修改m3u8文件，指向本地ts文件
        modify_m3u8_for_local_playback(
            str(m3u8_path),
            str(task.video_id),
            "ts",
            segments,
            ts_mapping
        )
        
        # 8. 判断下载结果
        failed_count = len(failed_segments)
        failure_rate = failed_count / total_segments if total_segments > 0 else 0
        
        if failed_count == 0:
            status = 'completed'
        elif failure_rate <= 0.3:  # HLS失败容忍度30%
            status = 'partial_completed'
        else:
            status = 'failed'
        
        return {
            'status': status,
            'total_segments': total_segments,
            'failed_segments': failed_segments,
            'failure_rate': failure_rate,
            'storage_path': str(save_dir),
            'hls_path': str(hls_dir),
            'm3u8_file': str(m3u8_path)
        }
        
    except Exception as e:
        logger.error(f"HLS视频下载失败: {str(e)}", exc_info=True)
        return {
            'status': 'failed',
            'error': str(e)
        }
```

### 6.5 失败处理流程

```python
def handle_download_failure(
    task_id: str,
    resource_url: str,
    expected_path: str,
    standard_name: str,
    resource_type: str,
    error: Exception,
    user_id: str
):
    """
    处理下载失败
    :param task_id: 任务ID
    :param resource_url: 资源URL
    :param expected_path: 预期保存路径
    :param standard_name: 标准化文件名
    :param resource_type: 资源类型
    :param error: 错误信息
    :param user_id: 用户ID
    """
    # 1. 确定失败类型
    failure_type = classify_error(error)
    
    # 2. 创建失败记录
    failure_data = DownloadFailureCreate(
        task_id=task_id,
        resource_url=resource_url,
        expected_path=expected_path,
        standard_name=standard_name,
        resource_type=resource_type,
        failure_type=failure_type,
        error_message=str(error),
        retry_count=0
    )
    
    create_download_failure(task_id, failure_data, user_id)
    
    # 3. 记录日志
    logger.error(
        f"下载失败 - 任务:{task_id}, 资源:{resource_url}, "
        f"类型:{failure_type}, 错误:{str(error)}"
    )

def classify_error(error: Exception) -> str:
    """分类错误类型"""
    error_str = str(error).lower()
    
    if 'timeout' in error_str:
        return 'timeout'
    elif 'connection' in error_str or 'network' in error_str:
        return 'network_error'
    elif 'permission' in error_str or 'forbidden' in error_str:
        return 'permission_error'
    elif 'disk' in error_str or 'storage' in error_str:
        return 'storage_error'
    else:
        return 'invalid_content'
```

### 6.6 任务状态转换规则

```
创建任务:
  pending (初始状态)
    ↓
启动任务:
  processing (下载中)
    ↓
下载完成:
  ├─ completed (全部成功)
  ├─ partial_completed (失败率≤30%)
  └─ failed (失败率>30% 或 m3u8/mp4/image失败)
    ↓
重试任务:
  ├─ 全量重新下载 (m3u8/mp4/image级别失败)
  └─ 仅重试失败分片 (ts级别失败)
    ↓
重试结果:
  ├─ completed (全部成功)
  ├─ partial_completed (仍有少量失败)
  └─ failed (仍有大量失败)
```

## 七、业务规则

### 7.1 重试策略
- **最大重试次数**: 3次
- **HLS分片失败容忍度**: 30%（失败率≤30%视为部分成功）
- **自动放弃**: `retry_count >= 3` 时，自动将status改为abandoned

### 7.2 智能重试
1. **M3U8级别失败**: 全量重新下载整个视频
2. **TS分片级别失败**: 仅重试失败的ts分片
3. **MP4级别失败**: 全量重新下载
4. **Image级别失败**: 重新下载图片

### 7.3 并发控制
- **全局限制**:
  - 最大并发下载任务: 100
  - 任务队列容量: 1000
- **单任务限制**:
  - 最大并发下载数: 20（HLS分片）
- **超时设置**:
  - 单个请求超时: 30秒

### 7.4 权限验证
1. 所有接口需要JWT Token认证
2. 用户只能操作自己的任务
3. 通过`str(task.user_id) != str(user_id)`进行权限验证
4. 失败记录和视频记录通过task_id关联验证权限

### 7.5 任务删除规则
- 不允许删除`completed`状态的任务
- 删除任务时级联删除相关的:
  - download_failures记录
  - downloaded_videos记录
