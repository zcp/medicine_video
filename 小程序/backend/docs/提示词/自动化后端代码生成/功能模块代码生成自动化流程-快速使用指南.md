## 2. 异常情况处理

### 2.1. 网络断开/VPN断开

**场景**: 执行过程中网络中断

**处理步骤**:
1. **不要担心** - 状态文件已自动保存
2. **恢复网络** - 切换VPN或重新连接网络
3. **恢复执行** - 使用以下指令：

```
请从断点继续执行代码生成流程：

**状态文件**: @docs/提示词/直播核心功能模块/.generation_state/content_management_state.json

**说明**: 网络已恢复，请从上次中断的位置继续执行
```

**AI会自动**:
- ✅ 读取状态文件
- ✅ 找到最后一个完成的步骤
- ✅ 从下一个步骤继续执行
- ✅ 不会重复已完成的步骤

---

### 2.2. AI输入过长

**场景**: AI报错"输入过长"或"token limit exceeded"

**处理步骤**:
1. **AI会自动检测** - 如果输入过长，会自动拆分任务
2. **手动拆分** - 如果AI没有自动拆分，使用以下指令：

```
检测到输入过长，请使用任务拆分策略执行：

**状态文件**: @docs/提示词/直播核心功能模块/.generation_state/content_management_state.json

**当前步骤**: step2
**拆分策略**: 先生成SQLAlchemy模型代码，保存状态后再生成Pydantic Schema代码
```

**AI会自动**:
- ✅ 将大任务拆分成小任务
- ✅ 每个小任务完成后保存状态
- ✅ 继续执行下一个子任务

---

### 2.3. AI模型报错

**场景**: AI返回错误（如"模型暂时不可用"）

**处理步骤**:
1. **等待一段时间** - AI会自动重试（最多3次）
2. **如果重试失败** - 使用以下指令：

```
请重试执行代码生成流程：

**状态文件**: @docs/提示词/直播核心功能模块/.generation_state/content_management_state.json

**说明**: AI模型已恢复，请重试失败的步骤
```

---

### 2.4. 用户主动中断

**场景**: 用户需要暂停执行（切换网络、处理其他事情）

**处理步骤**:
1. **直接中断** - 可以随时中断（Ctrl+C或关闭窗口）
2. **状态已保存** - AI会在中断前自动保存状态
3. **恢复执行** - 使用以下指令：

```
请从上次中断的位置继续执行代码生成流程：

**状态文件**: @docs/提示词/直播核心功能模块/.generation_state/content_management_state.json
```

## 4. 常见问题

### Q1: 这个文档能让AI自动生成代码吗？

**A**: ✅ **可以**！

这个文档是一个**主控流程文档**，AI会：
1. 读取文档中的执行步骤
2. 按照步骤顺序自动执行
3. 每个步骤完成后保存状态
4. 如果发现问题，自动修复
5. 最终生成所有代码文件

**你只需要**:
- 提供设计文档路径
- 提供基本参数（module_name等）
- 等待AI完成所有步骤

---

### Q2: 如果执行中断，能恢复吗？

**A**: ✅ **可以完全恢复**！

**恢复机制**:
1. **状态文件自动保存** - 每个步骤完成后立即保存
2. **断点续传** - 从任意步骤恢复执行
3. **不重复执行** - 已完成的步骤会自动跳过

**恢复方法**:
```
请从断点继续执行代码生成流程：

**状态文件**: @docs/提示词/直播核心功能模块/.generation_state/content_management_state.json
```

---

### Q3: 如果输入过长怎么办？

**A**: ✅ **自动拆分任务**！

**处理方式**:
1. **AI自动检测** - 如果输入过长，自动拆分
2. **任务拆分策略** - 将大步骤拆分成小步骤
3. **分批执行** - 每个小步骤完成后保存状态

**示例**:
- 步骤2（生成代码）可以拆分为：
  - 子任务2.1: 生成SQLAlchemy模型代码 → 保存
  - 子任务2.2: 生成Pydantic Schema代码 → 保存

---

### Q4: 如果发现问题，会自动修复吗？

**A**: ✅ **会自动修复**（如果auto_fix=true）！

**修复流程**:
1. **检测问题** - 一致性检测发现问题
2. **分析原因** - 分析是提示词文档问题还是代码问题
3. **自动修复** - 修复问题
4. **重新检测** - 重新执行一致性检测
5. **验证修复** - 如果通过，继续下一步；如果未通过，继续修复（最多3次）

---

### Q5: 如何手动控制执行？

**A**: ✅ **可以单步执行**！

**单步执行**:
```
请执行步骤 {step_number}：

**状态文件**: @docs/提示词/直播核心功能模块/.generation_state/content_management_state.json
```

**AI会**:
- ✅ 只执行指定的步骤
- ✅ 完成后保存状态
- ✅ 等待你的下一步指令

## 6. 执行流程图

```
开始
  ↓
读取输入参数
  ↓
检查状态文件是否存在？
  ├─ 是 → 读取状态，找到最后一个完成的步骤
  └─ 否 → 创建新状态文件，从步骤1开始
  ↓
执行当前步骤
  ↓
步骤完成？
  ├─ 是 → 保存状态，继续下一步
  └─ 否 → 检查是否异常？
      ├─ 网络断开 → 保存状态，等待恢复
      ├─ 输入过长 → 拆分任务，分批执行
      ├─ AI报错 → 重试（最多3次）
      └─ 发现问题 → 自动修复（如果auto_fix=true）
  ↓
所有步骤完成？
  ├─ 是 → 标记为COMPLETED，结束
  └─ 否 → 继续执行下一步
```
