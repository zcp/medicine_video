  - `room_id`: UUID, NOT NULL, 外键 `live_rooms.id`，带 `ondelete="CASCADE"` ✅  
  - `is_active`: BOOLEAN NOT NULL DEFAULT true，用于软删除语义 ✅  
  - `created_at`: TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP ✅  
- **唯一约束**:
