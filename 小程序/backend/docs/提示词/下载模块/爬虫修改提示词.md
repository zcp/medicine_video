3.  **新增 `setup_database(self)` 函数：**

    * 执行 `CREATE TABLE IF NOT EXISTS liverooms ...`。

    * （可选但推荐）为 `addtime` 创建索引：`CREATE INDEX IF NOT EXISTS idx_addtime ON liverooms (addtime);`
4.  **替换 `load_state_from_main_file` 函数：**
    * 删除 `extract_liveroom_ids_from_csv` (在 `parse_all_liveroomlist_data` 中被调用)。
    * 创建一个新函数 `load_state_from_db(self)`。
    * 此函数实现“阶段1 - 步骤3和4”：
        * `SELECT id FROM liverooms WHERE (play_url IS NOT NULL AND play_url != '') OR (original_playback_url IS NOT NULL AND original_playback_url != '') ...` 来填充一个 `successful_ids` (set)。
        * `SELECT id FROM liverooms WHERE (play_url IS NULL OR play_url = '') AND (original_playback_url IS NULL OR original_playback_url = '') ...` 来填充一个 `failed_ids` (set)。
        * `SELECT MAX(addtime) FROM liverooms WHERE id IN (successful_ids)` 来获取 `latest_success_time` (字符串)。
    * 此函数必须返回 `(successful_ids, failed_ids, latest_success_time)`。

#### 阶段 2：执行 (爬取与决策) - 修改核心函数

1.  **新增 `save_data_to_db(self, data_list)` 函数：**
    * 此函数接收一个 `live_info` 字典的列表。
    * 它使用 `INSERT OR REPLACE INTO liverooms (id, title, ...) VALUES (?, ?, ...)` 和 `cursor.executemany(...)` 将数据批量写入 SQLite。
    * **这必须在一个事务中完成** (`conn.commit()`)。
2.  **修改 `extract_liveroomlist_data` 函数：**
    * 函数签名现在必须接受 `successful_ids`, `failed_ids`, `latest_success_time` 作为参数。
    * 在 `for item in live_list:` 循环内部，**必须**实现“阶段2 - 步骤3”的**“决策 A, B, C”** 逻辑：
        * `item_id = str(item.get('id', '')).strip()`
        * `item_time = item.get('addtime', '').strip()`
        * **决策 A (停止)：** `if (latest_success_time and item_time < latest_success_time and item_id not in failed_ids):` -> `stop_crawling = True` 然后 `break`。
        * **决策 B (跳过)：** `if item_id in successful_ids:` -> `continue`。
        * **决策 C (爬取)：** (即 `else`) ... 执行现有的详细爬取逻辑。
    * 函数最后必须返回 `(extracted_data, failed_data, stop_crawling)`。（`extracted_data` 包含爬取成功的数据，`failed_data` 包含爬取失败的数据）。
3.  **修改 `parse_all_liveroomlist_data` 函数 (主循环)：**
    * 在开头，**调用** `successful_ids, failed_ids, latest_success_time = self.load_state_from_db()`。
    * 初始化 `all_live_data_for_inc = []` (用于 `inc.csv`)。
    * 在 `for page in range(1, total_pages + 1):` 循环中：
        * 调用 `live_data, failed_data, stop_page = self.extract_liveroomlist_data(page_data, successful_ids, failed_ids, latest_success_time)`。
        * **(关键：写入数据库)** **立即**调用 `self.save_data_to_db(live_data + failed_data)`。这实现了 `INSERT OR REPLACE` 的实时更新。
        * **(关键：填充增量)** `if live_data:` -> `all_live_data_for_inc.extend(live_data)` (只把**成功**的数据放入增量列表)。
        * `if stop_page:` -> `break` (停止分页)。
