### 4. VzanCrawler测试中的假设错误

**测试提示词（错误）**:
```python
# test_vzan_crawler.py line 676-683
@patch('app.crawlers.vzan_crawler.requests.get')
def test_crawl_timeout(self, mock_get, vzan_crawler):
    mock_get.side_effect = requests.Timeout("Connection timeout")
    
    with pytest.raises(CrawlerTimeoutError, match="请求超时"):
        vzan_crawler.crawl('https://api.vzan.com/test')  # ❌ 参数类型错误
    
    assert mock_get.call_count == vzan_crawler.max_retries  # ❌ 不存在max_retries
```

**实际代码** (`vzan_crawler.py`):
- `crawl()`方法接受`config: Dict`作为第一个参数，不是URL字符串
- VzanCrawler是适配器，调用`DuanShuCrawler_vzan.parse_all_liveroomlist_data()`
- 没有`max_retries`属性

**修正方案**:
- `crawl()`的第一个参数应该是`config`字典
- 移除`max_retries`相关断言
- Mock `DuanShuCrawler_vzan.parse_all_liveroomlist_data`而不是`requests.get`
