### 2.1 采用适配器模式复用已有代码

**设计思路**：

```
┌─────────────────────────────────────────────┐
│         VzanCrawler (适配器，约60行)          │
│  - 导入 DuanShuCrawler_vzan                  │
│  - 调用 parse_all_liveroomlist_data()       │
│  - 适配返回格式为 Dict                        │
└─────────────────┬───────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────┐
│    DuanShuCrawler_vzan (已有爬虫，不变)       │
│  - parse_all_liveroomlist_data(config)      │
│  - liveroom_list_savefile                   │
│  - liveroom_list_savefile_inc               │
│  - failed_liveroomlist_url                  │
└─────────────────────────────────────────────┘
```

**关键改进**：
- ✅ 代码量从约400行 → 约60行
- ✅ 100%复用已有的爬取逻辑
- ✅ 仅需适配返回格式

### 2.2 文档风格简化

**从**：大量完整代码（约1000行）  
**到**：流程描述 + 关键点（约200行）

**示例对比**：

```markdown
【修改前】
```python

    result = {"crawl_status": "failed", ...}
    try:
        crawler = CrawlerFactory.create(...)
        crawl_result = crawler.crawl(...)
        # ... 200行完整实现代码
    except Exception as e:
        ...
```

【修改后】
#### 实现流程

**【第一步：变量提取】**
```python
user_id_for_logging = str(user_id)
```

**【第二步：初始化返回结果】**
- 创建result字典，初始值为"failed"

**【第三步：参数验证】**
- 验证crawler_type不为空
- ...

**【第四步：执行爬取】**
- 使用 `crawler.crawl(config, **crawl_kwargs)`
- 从返回字典提取：csv_path, total_rows等
```
