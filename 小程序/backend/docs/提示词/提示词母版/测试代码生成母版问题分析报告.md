#### 错误信息
```
AssertionError: expected call not found.

```

#### 错误原因

#### 解决方法
修改测试代码中的断言，将关键字参数改为位置参数：

```python

mock_check.assert_called_once_with(db=db)

# 修改后（正确）

```

### 问题2: async_client AttributeError

#### 错误信息
```
AttributeError: 'async_generator' object has no attribute 'get'
```

#### 错误原因
- `async_client` fixture 是**异步生成器**（`AsyncGenerator[AsyncClient, None]`），返回的是生成器对象，不是 `AsyncClient` 实例。
- 测试直接使用 `async_client.get()`，试图在生成器上调用方法。
- 根据文档 Section 3.3 的要求，使用异步 fixture 必须用 `async for` 解包。

#### 解决方法
在所有 API 测试中使用 `async for` 语法解包 `async_client`：

```python
# 修改前（错误）
async def test_api_health_check_success(self, async_client):
    response = await async_client.get("/api/v1/health")  # ❌ 错误

# 修改后（正确）
async def test_api_health_check_success(self, async_client):
    async for client in async_client:  # ✅ 正确：使用 async for 解包
        response = await client.get("/api/v1/health")
        # 所有断言都在 async for 块内
```

#### 需要修改的文件
- `backend/live_core_service/tests/integration/test_api_health.py`（4个测试函数全部修改）
