# 直播SaaS平台部署文档

## 一、环境要求

### 1.1 硬件要求
- CPU：8核以上
- 内存：16GB以上
- 硬盘：500GB以上
- 网络：千兆网卡

### 1.2 软件要求
- 操作系统：CentOS 7/8 或 Ubuntu 20.04 LTS
- 容器：Docker 20.10+
- 数据库：PostgreSQL 13+
- 缓存：Redis 6+
- 消息队列：RabbitMQ 3.8+

### 1.3 网络要求
- 公网IP
- 域名
- SSL证书
- 防火墙配置

## 二、环境配置

### 2.1 系统配置
```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y git curl wget vim

# 配置时区
sudo timedatectl set-timezone Asia/Shanghai

# 配置系统参数
sudo sysctl -w net.core.somaxconn=65535
sudo sysctl -w vm.max_map_count=262144
```

### 2.2 Docker配置
```bash
# 安装Docker
curl -fsSL https://get.docker.com | sh

# 配置Docker镜像加速
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://registry.docker-cn.com"
  ]
}
EOF

# 重启Docker
sudo systemctl restart docker
```

### 2.3 数据库配置
```bash
# 安装PostgreSQL
sudo apt install -y postgresql postgresql-contrib

# 配置PostgreSQL
sudo -u postgres psql -c "CREATE USER saas WITH PASSWORD 'your_password';"
sudo -u postgres psql -c "CREATE DATABASE saas_db OWNER saas;"
```

## 三、部署流程

### 3.1 代码部署
```bash
# 克隆代码
git clone https://github.com/your-org/live-streaming-saas.git
cd live-streaming-saas

# 构建镜像
docker build -t saas-backend:latest ./backend
docker build -t saas-frontend:latest ./frontend

# 推送镜像
docker tag saas-backend:latest your-registry.com/saas-backend:latest
docker tag saas-frontend:latest your-registry.com/saas-frontend:latest
docker push your-registry.com/saas-backend:latest
docker push your-registry.com/saas-frontend:latest
```

### 3.2 配置文件
```yaml
# docker-compose.yml
version: '3'
services:
  backend:
    image: your-registry.com/saas-backend:latest
    ports:
      - "8000:8000"
    environment:
      - DB_HOST=postgres
      - DB_PORT=5432
      - DB_NAME=saas_db
      - DB_USER=saas
      - DB_PASSWORD=your_password
      - REDIS_HOST=redis
      - REDIS_PORT=6379
    depends_on:
      - postgres
      - redis

  frontend:
    image: your-registry.com/saas-frontend:latest
    ports:
      - "80:80"
    depends_on:
      - backend

  postgres:
    image: postgres:13
    environment:
      - POSTGRES_DB=saas_db
      - POSTGRES_USER=saas
      - POSTGRES_PASSWORD=your_password
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:6
    volumes:
      - redis_data:/data
```

### 3.3 启动服务
```bash
# 启动服务
docker-compose up -d

# 检查服务状态
docker-compose ps

# 查看服务日志
docker-compose logs -f
```

## 四、监控配置

### 4.1 系统监控
- 使用Prometheus收集指标
- 使用Grafana展示监控数据
- 配置告警规则
- 设置告警通知
- 监控指标：
  - CPU使用率
  - 内存使用率
  - 磁盘使用率
  - 网络流量
  - 响应时间
  - 错误率
  - 代码质量指标
  - 性能指标

### 4.2 应用监控
- 使用ELK收集日志
- 使用SkyWalking监控应用性能
- 配置业务监控指标
- 设置性能告警阈值
- 日志级别：
  - ERROR：系统错误、业务异常
  - WARNING：警告信息
  - INFO：重要业务操作
  - DEBUG：调试信息

### 4.3 日志规范
- 日志格式：
  - 时间戳
  - 日志级别
  - 模块名
  - 函数名
  - 行号
  - 消息内容
  - 异常堆栈（如果有）
- 日志内容：
  - 系统启动/关闭
  - 用户登录/登出
  - 重要业务操作
  - 异常信息
  - 性能监控数据
- 日志存储：
  - 按日期分割
  - 定期归档
  - 敏感信息脱敏
  - 使用ELK进行日志管理

### 4.4 异常处理
- 异常分类：
  - 系统异常：系统级错误
  - 业务异常：业务逻辑错误
  - 参数异常：输入参数错误
  - 权限异常：访问权限错误
- 异常处理原则：
  - 明确异常类型
  - 提供详细错误信息
  - 记录异常日志
  - 优雅降级处理
  - 避免异常吞没
- 错误码规范：
  - 系统错误：5xx
  - 业务错误：4xx
  - 成功：2xx
