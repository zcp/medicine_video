# 部署配置快速参考

## 1. docker-compose.prod.yml 修改示例

在 `live_core_service` 服务中添加以下配置：

```yaml
live_core_service:
  build: ./backend/live_core_service
  restart: unless-stopped
  expose: ["8000"]
  environment:
    POSTGRES_DB: "live_core_test"
    ROOM_MEDIA_ROOT_PATH: "/app/media"  # ← 新增：使用绝对路径
  env_file: .env.docker
  volumes:
    - ./data/live_core_media:/app/media  # ← 新增：挂载媒体文件目录
```

在 `nginx` 服务中添加以下 volume：

```yaml
nginx:
  image: nginx:alpine
  restart: unless-stopped
  ports: ["80:80","443:443"]
  volumes:
    - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
    - ./nginx/ssl:/etc/nginx/ssl:ro
    - ./data/srs:/var/www/srs:ro
    - ./data/live_core_media:/var/www/html/live-core-media:ro  # ← 新增
  depends_on: [srs,live_core_service,media_download_service]
```

## 2. nginx.conf 修改示例

在 HTTPS 服务器配置中，**在 `/api/core/` location 之前**添加：

```nginx
# ========================================================================
# 直播核心服务媒体文件（必须放在 /api/core/ 之前）
# ========================================================================
location /media/ {
    alias /var/www/html/live-core-media/;
    expires 7d;
    add_header Cache-Control "public";
    access_log off;
    
    types {
        image/jpeg jpg jpeg;
        image/png png;
        image/gif gif;
    }
    
    try_files $uri =404;
}

# 直播核心服务 API
location /api/core/ {
    proxy_pass http://core_api/api/v1/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## 3. .env.docker 环境变量

添加或确认以下环境变量：

```bash
# 直播核心服务媒体文件路径（容器内绝对路径）
ROOM_MEDIA_ROOT_PATH=/app/media
```

## 4. 部署前准备脚本

创建并执行以下脚本：

```bash
#!/bin/bash
# 创建媒体文件目录
mkdir -p ./data/live_core_media/rooms
mkdir -p ./data/live_core_media/topics

# 设置权限
chmod -R 755 ./data/live_core_media

echo "媒体文件目录创建完成！"
```

## 5. 验证命令

```bash
# 检查目录
ls -la ./data/live_core_media/

# 检查容器内路径
docker exec -it <live_core_service_container_id> ls -la /app/media/

# 测试访问（替换实际路径）
curl -I https://mp.dayilive.com/media/rooms/<room_id>/cover_<timestamp>.jpg
```
