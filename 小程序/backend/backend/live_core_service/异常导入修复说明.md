# InvalidParameterException 导入错误修复

## 🚨 问题诊断

**错误信息**：
```
ImportError: cannot import name 'InvalidParameterException' from 'app.core.exceptions'
```

**根本原因**：`InvalidParameterException` 定义在 `app.exceptions.py` 中，但部分文件错误地从 `app.core.exceptions` 导入。

---

## ✅ 已修复的文件

### 1. API 层：`app/api/v1/endpoints/batch_import.py`

**修复前**：
```python
from app.core.exceptions import InvalidParameterException
```

**修复后**：
```python
from app.exceptions import InvalidParameterException
```

### 2. Service 层：`app/services/batch_import.py`

**修复前**：
```python
from app.core.exceptions import (
    InvalidParameterException,
    PermissionDeniedException,
    DatabaseIntegrityException,
    DatabaseOperationException
)
```

**修复后**：
```python
from app.exceptions import (
    InvalidParameterException,
    PermissionDeniedException
)
from app.core.exceptions import (
    DatabaseIntegrityException,
    DatabaseOperationException
)
```

---

## 📋 异常类定义位置说明

根据代码结构，异常类分为两类：

### 1. 业务异常（定义在 `app.exceptions.py`）

- `InvalidParameterException` - 业务参数无效
- `PermissionDeniedException` - 权限不足
- `RoomNotFoundException` - 房间不存在
- `SessionNotFoundException` - 会话不存在
- 等等...

### 2. 数据库异常（定义在 `app.core.exceptions.py`）

- `DatabaseIntegrityException` - 数据库完整性错误（唯一键冲突等）
- `DatabaseOperationException` - 数据库操作错误
