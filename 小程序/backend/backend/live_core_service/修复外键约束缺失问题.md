# 修复外键约束缺失问题

## 问题确认

从数据库查询结果来看，`live_room_tabs` 和 `live_room_messages` 表**没有外键约束**，但模型定义中确实有：

- `LiveRoomTab.room_id` → `ForeignKey("live_rooms.id", ondelete="CASCADE")`
- `LiveRoomMessage.room_id` → `ForeignKey("live_rooms.id", ondelete="CASCADE")`
- `LiveRoomMessage.session_id` → `ForeignKey("live_sessions.id", ondelete="SET NULL")`

## 原因分析

`Base.metadata.create_all()` 在表已存在时**不会修改现有表结构**，只会创建不存在的表。如果表是在外键约束定义之前创建的，或者创建时出现了问题，外键约束就不会被创建。

## 解决方案

### 方案 1：删除并重新创建表（推荐用于测试环境）

**⚠️ 警告：这会删除表中的所有数据！**

```sql
-- 1. 删除依赖表（先删除有外键的表）
DROP TABLE IF EXISTS live_room_tabs CASCADE;
DROP TABLE IF EXISTS live_room_messages CASCADE;

-- 2. 重新运行 init_db.py
-- python app/init_db.py
```

### 方案 2：手动添加外键约束（推荐用于生产环境）

如果表中有数据，不想删除，可以手动添加外键约束：

```sql
-- 1. 为 live_room_tabs 添加外键约束
ALTER TABLE live_room_tabs
ADD CONSTRAINT fk_live_room_tabs_room_id
FOREIGN KEY (room_id)
REFERENCES live_rooms(id)
ON DELETE CASCADE;

-- 2. 为 live_room_messages 添加外键约束
ALTER TABLE live_room_messages
ADD CONSTRAINT fk_live_room_messages_room_id
FOREIGN KEY (room_id)
REFERENCES live_rooms(id)
ON DELETE CASCADE;

ALTER TABLE live_room_messages
ADD CONSTRAINT fk_live_room_messages_session_id
FOREIGN KEY (session_id)
REFERENCES live_sessions(id)
ON DELETE SET NULL;
```

### 方案 3：修改 init_db.py 强制重建（仅用于开发/测试）

修改 `app/init_db.py`，在创建表之前先删除表：

```python
def init_db():
    """初始化数据库，创建所有表"""
    try:
        # 先删除所有表（如果存在）
        print("删除现有表...")
        Base.metadata.drop_all(bind=engine)
        
        # 创建所有表
        print("当前 metadata 中的表名列表：", Base.metadata.tables.keys())
        Base.metadata.create_all(bind=engine)
        logger.info("数据库表创建成功")
    except Exception as e:
        logger.error(f"数据库表创建失败: {str(e)}")
        raise
```

**⚠️ 注意：这会删除所有数据！**

## 验证修复

执行以下 SQL 查询，确认外键约束已创建：

```sql
-- 检查 live_room_tabs 表的外键约束
SELECT 
    conname AS constraint_name,
    conrelid::regclass AS table_name,
    confrelid::regclass AS referenced_table,
    a.attname AS column_name
FROM pg_constraint c
JOIN pg_attribute a ON a.attnum = ANY(c.conkey) AND a.attrelid = c.conrelid
WHERE conrelid = 'live_room_tabs'::regclass 
  AND contype = 'f';

-- 检查 live_room_messages 表的外键约束
SELECT 
    conname AS constraint_name,
    conrelid::regclass AS table_name,
    confrelid::regclass AS referenced_table,
    a.attname AS column_name
FROM pg_constraint c
JOIN pg_attribute a ON a.attnum = ANY(c.conkey) AND a.attrelid = c.conrelid
WHERE conrelid = 'live_room_messages'::regclass 
  AND contype = 'f';
```

修复后，应该能看到：
- `live_room_tabs` 有 1 个外键约束（`room_id` → `live_rooms.id`）
- `live_room_messages` 有 2 个外键约束（`room_id` → `live_rooms.id`，`session_id` → `live_sessions.id`）
