## 3. 小程序测播（文档 18）

### 3.1 新接口

**`POST /rooms/{room_id}/test-room`**

- 认证：JWT（主播 owner 或 Admin）
- `room_id`：**正式间** ID
- Body（可空）: `{ "title_suffix"?: "连接测试" }`
- 幂等：同一正式间重复调用返回同一测播间，`created: false`

**成功 `data`：**

```json
{
  "source_room_id": "uuid-正式间",
  "test_room": {
    "id": "uuid-测播间",
    "title": "某预告标题·连接测试",
    "is_private": true,
    "stream_key": "example_stream_key_placeholder",
    "cover_url": "...",
    "source_room_id": "uuid-正式间",
    "created_at": "..."
  },
  "created": true
}
```

| 场景 | HTTP / code |
|------|-------------|
| 未登录 | 401 / 3001 |
| 非 owner 且非 Admin | 403 / 3002 |
| 正式间不存在 | 404 / 2001 |
| 对测播间再调 | 400 / 4001「请对正式间调用…」 |

### 3.2 `api.ts`（已加）

```ts
// ROOM 模块 — 已写入 Live-Saas-Wechat/src/config/api.ts
TEST_ROOM: (roomId: string) => `/rooms/${roomId}/test-room`,
```

### 3.3 主播主路径（页面）

```text
我的直播 / 正式间推流入口
  → 「测试连接」
  → POST /rooms/{正式间id}/test-room
  → 展示测播 stream_key（可复制）+「打开预览」
  → navigateTo /pages/live/LiveView?roomId={测播间id}
  → （可选）LiveView 分享邀请协助
  → 「测试完成，正式开播」→ 回正式间推流信息
```

| 页面 | 改动 |
|------|------|
| `pages/my-live/MyLive.vue`（或推流面板） | 入口按钮「测试连接」；调 API；展示密钥 |
| `pages/live/LiveView.vue` | `is_private===true` 顶栏弱提示「连接测试」；分享 path 保持 `roomId` 当前页 |
| `pages/home/Home.vue` | **不改过滤逻辑**（以后端为准） |
| `pages/live/CreateLive.vue` | 勿把正式预告拨成 `is_private` 当测播 |

### 3.4 协助者 / 观众

| 角色 | 行为 |
|------|------|
| 观众 | 首页三 Tab 看不到测播；点预告进正式间 |
| 协助者 | 微信分享卡片 → `LiveView?roomId=测播间` → **直接播，无密码** |

分享复用现网 `onShareAppMessage`（`path = /pages/live/LiveView?roomId=...`）。

### 3.5 读接口行为变化（前端勿再当 404）

| 接口 | 旧（私密） | 新（不公开） |
|------|------------|--------------|
| `GET /rooms/{id}` | 非房主 404 | 持 id **200** |
| 留言列表 / Tab 公开读 | 非房主 404 | 持 id **可读** |
| `GET /homepage/rooms`、公开搜索 | 曾漏滤 | **不含** `is_private=true` |
| `GET /users/me/rooms` | 含自己的不公开房 | **不变**（主播管理视图） |
| `PATCH/DELETE /rooms/{id}` | 非 owner 403 | **不变** |
