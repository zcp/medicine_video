# add-docs（临时自用文档区）

> 目的：给你在协助修后端 bug 时做“快速理解 + 变更记录 + 协作约定”的临时沉淀区。
>
> 约定：
> - 这里的内容不属于正式产品文档，可在合并/交付后删除。
> - 尽量只写事实（入口/命令/现象/结论），避免长篇“推测”。
> - 不要把任何真实密钥/账号/患者数据写入此目录。

## 建议使用方式

- 你每接一个 bug：在《定位 bug 与最小改动修复流程》里复制一份小节，记录复现、根因、改动点、验证方式。
- 你每看懂一个模块：在《项目速览》里补 3 行（入口、数据流、关键文件）。
- 和同事对齐协作：按《协作与合并约定》执行，避免互相踩同一个文件。

## 本目录文件

- `项目速览.md`
- `定位bug与最小改动修复流程.md`
- `协作与合并约定.md`
- `代码风格速记.md`
