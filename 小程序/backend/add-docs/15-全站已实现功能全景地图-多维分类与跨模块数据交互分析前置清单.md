| 功能点 | 主要能力 | 代表性路径（服务内） | 状态 | 设计文档索引 |

| 登录 | 账密、手机验证码、邮箱验证码、微信小程序、一键登录、SSO | `POST /api/v1/auth/login`、`/login/phone`、`/login/email`、`/wechat-login`、`/one-tap-login*`、`/sso-login` | ✅ | 《10》及 V3/V4/V5 |
| 验证码 | 图形验证码；短信/邮箱验证码申请与校验 | `GET /api/v1/auth/captcha*`；`POST /api/v1/auth/verification-codes*` | ✅ | 《10》 |
| Token 生命周期 | 刷新、登出、密码重置申请/完成 | `POST /api/v1/auth/refresh`、`/logout`、`/password-reset*` | ✅ | 《10》 |
| 个人资料 | 查改资料、头像、改密、绑手机、注销 | `GET/PATCH/DELETE /api/v1/users/me`；`POST .../avatar`、`/password`、`/phone` | ✅ | 《10》 |
| 开播能力 | `can_stream`（默认 true）；JWT 声明；建房门禁（false→403） | Admin PATCH 禁止/恢复；`POST /api/v1/rooms` 读 JWT | ✅ | 《14-V2》P0 + V2.1 |
| 会话吊销 | Redis `user_sessions_revoked:{user_id}` 共用 | 封禁/撤开播/降权/注销触发 | ✅ | 《14-V2》C1–C3 |

**限定（代码核对）**：

- 无独立「绑定邮箱」接口（有邮箱注册 / `POST /auth/login/email`；绑手机为 `POST /users/me/phone`）。  
- 《10》写明活跃会员订阅可阻塞注销；**当前代码**中该检查为注释预留（`user_service.deactivate_account`），**未强制执行**——交互设计仍应按「可能阻塞」预留，实现状态勿写成已强制。
