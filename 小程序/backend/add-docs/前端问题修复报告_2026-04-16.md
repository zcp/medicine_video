#### 1. **订阅功能参数校验失败错误** (422错误)
- **问题**: POST /api/v1/users/me/subscriptions 返回422 Unprocessable Entity
- **根因**: Service层变量名冲突，`room`和`session`既是导入的模块名，又被用作变量名
- **修复**: 重命名导入模块为`crud_room`, `crud_session`，变量名改为`room_obj`, `session_obj`
- **文件**: `backend/live_core_service/app/services/user_behavior_service.py:176-187`
- **状态**: ✅ 已修复并重启服务

#### 2. **直播间状态分类错误** (直播状态显示在预告分类)
- **问题**: 创建直播间选择"直播"状态，但显示在"预告"分类中
- **根因**: 首页房间查询SQL中`LEFT JOIN live_sessions`没有指定获取哪个session，导致随机获取session状态
- **修复**: 使用`LATERAL JOIN`确保获取每个房间的最新session
- **文件**: `backend/live_core_service/app/crud/homepage_search.py:418-424`
- **修复前**:
  ```sql
  LEFT JOIN live_sessions ls ON ls.room_id = lr.id
  ```
- **修复后**:
  ```sql
  LEFT JOIN LATERAL (
      SELECT id, status, start_time, end_time, room_id
      FROM live_sessions
      WHERE room_id = lr.id
      ORDER BY created_at DESC
      LIMIT 1
  ) ls ON TRUE
  ```
- **状态**: ✅ 已修复并重启服务
