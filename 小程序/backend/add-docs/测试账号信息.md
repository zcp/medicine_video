## 登录说明

### A. 用户名/邮箱 + 密码（图形验证码）

1. 获取验证码：`GET http://localhost:8002/api/v1/auth/captcha`
2. 登录：`POST http://localhost:8002/api/v1/auth/login`

```json
{
  "username": "testemail",
  "password": "Test123!",
  "captcha_id": "<上一步返回的 captcha_id>",
  "captcha_solution": "<图形验证码答案>"
}
```

网关等价路径：`POST http://localhost:8080/api/users/auth/login`。

也可用：`u_fe106d61f7` + 密码 `Test123!`（同样需要图形验证码）。

### B. 邮箱验证码登录（V5，无需图形验证码）

> 账号须已存在且绑定邮箱（本种子账号：`superadmin@test.com`；普通邮箱账号：`testemail@test.com`）。真实邮箱联调见上文占位说明，勿把个人邮箱写进文档。

1. 发码：`POST http://localhost:8080/api/users/auth/verification-codes`

```json
{
  "channel": "EMAIL",
  "recipient": "testemail@test.com",
  "scenario": "LOGIN"
}
```

2. 验码：`POST http://localhost:8080/api/users/auth/verification-codes/verify`

```json
{
  "channel": "EMAIL",
  "recipient": "testemail@test.com",
  "scenario": "LOGIN",
  "code": "<邮件或 mock 日志 / Redis 中的 OTP>"
}
```

3. 登录：`POST http://localhost:8080/api/users/auth/login/email`

```json
{
  "login_ticket": "<上一步返回的 ticket>"
}
```

服务内直连：将 `/api/users/auth/` 换成 `http://localhost:8002/api/v1/auth/`。

### C. 忘记密码（邮件含 reset_token）

1. 图形验证码：`GET .../auth/captcha`
2. 申请重置：`POST .../auth/password-reset-request`（`email` + 图形验证码）→ 邮箱收到 **reset_token**（15 分钟有效）
3. 确认重置：`POST .../auth/password-reset`，body：`{ "reset_token": "...", "new_password": "Test123!" }`

本地若 `EMAIL_PROVIDER=mock`，token 在 `user_service` 日志 `[MOCK EMAIL] password_reset ... reset_token=`。
