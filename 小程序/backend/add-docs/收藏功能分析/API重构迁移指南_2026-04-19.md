## 🔄 **迁移步骤**

### **第一步: 使用新的统一API**
```typescript
// 旧方式
import { addFavorite, getFavoriteList } from '@/api/favorites'
import { login, logout } from '@/api/auth'
import { getRoomList } from '@/api/room'

// 新方式
import api from '@/api/all-apis'
const { addFavorite, getFavoriteList } = api.user
const { login, logout } = api.auth
const { getList: getRoomList } = api.room
```

### **第二步: 更新API调用方式**
```typescript
// 旧方式
addFavorite(roomId)
getFavoriteList({ page: 1, size: 10 })

// 新方式（API签名相同，无需修改调用）
api.user.addFavorite(roomId)
api.user.getFavorites({ page: 1, size: 10 })
```

### **第三步: 批量替换导入语句**
需要在以下文件中批量替换：
- 所有`.vue`文件中的API导入
- 所有`.ts`文件中的API导入
- 所有store文件中的API导入

## 🛠 **批量替换规则**

### **常见替换模式**:
```typescript
// 模式1: 单个API导入
import { functionName } from '@/api/moduleName'
// 替换为:
import api from '@/api/all-apis'
const { functionName } = api.moduleName

// 模式2: 多个API导入
import { func1, func2, func3 } from '@/api/moduleName'
// 替换为:
import api from '@/api/all-apis'
const { func1, func2, func3 } = api.moduleName

// 模式3: 重命名导入
import { originalName as newName } from '@/api/moduleName'
// 替换为:
import api from '@/api/all-apis'
const { originalName: newName } = api.moduleName
```

### **API模块映射**:
- `@/api/auth` → `api.auth`
- `@/api/favorites` → `api.user` (收藏功能在user下)
