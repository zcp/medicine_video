# 前端API架构重构方案 - 解决路径重复问题

**问题发现时间**: 2026年4月19日 19:32  
**问题类型**: 前端API架构混乱，路径重复拼接  
**影响范围**: 所有API调用都可能受影响  

## 🚨 **核心问题分析**

### **URL重复拼接问题**:
```
实际请求: POST http://localhost:8080/api/core/api/core/users/me/favorites
错误原因: /api/core + /api/core/users/me/favorites = 重复拼接
```

### **request.ts 的复杂逻辑问题**:
1. **过度复杂的路径处理** - 800行代码，逻辑混乱
2. **多层路径转换** - `normalizePathForGateway`, `normalizeGatewayBaseURL` 等
3. **环境变量处理混乱** - 多个baseURL配置互相冲突
4. **网关前缀自动推断** - 容易出错的智能路径处理

#### **1.2 重写简化的request工具**
```typescript
// src/utils/request-v2.ts
class SimpleRequest {
  private baseURL: string
  
  constructor() {
    this.baseURL = API_CONFIG.BASE_URL
  }
  
  // 简单直接的URL拼接，不做复杂转换
  private getFullURL(url: string): string {
    if (url.startsWith('http')) return url
    
    // 直接拼接，不做任何路径转换
    const cleanBase = this.baseURL.replace(/\/+$/, '')
    const cleanPath = url.startsWith('/') ? url : '/' + url
    
    return `${cleanBase}${cleanPath}`
  }
  
  async request<T>(config: RequestConfig): Promise<T> {
    // 简化的请求逻辑，去掉复杂的路径处理
    const requestOptions = {
      url: this.getFullURL(config.url),
      method: config.method || 'GET',
      data: config.data,
      // ... 其他配置
    }
    
    return new Promise((resolve, reject) => {
      uni.request({
        ...requestOptions,
        success: (res) => {
          if (res.statusCode >= 400) {
            reject(new Error(`HTTP ${res.statusCode}`))
          } else {
            resolve(res.data)
          }
        },
        fail: reject
      })
    })
  }
}
```

### **方案2: 修复现有request.ts（临时方案）**

如果不想大规模重构，可以先修复现有的路径重复问题：

```typescript
// 在 getFullURL 方法中添加重复路径检测
private getFullURL(url: string, baseURLOverride?: string): string {
  if (url.startsWith('http')) return url
  
  const baseURL = baseURLOverride || this.baseURL
  const fullURL = `${baseURL}${url}`
  
  // 检测并修复重复路径
  const duplicatePattern = /\/api\/(core|users|v1)\/api\/(core|users|v1)/
  if (duplicatePattern.test(fullURL)) {
    console.warn('🔧 检测到重复API路径，自动修复:', fullURL)
    return fullURL.replace(duplicatePattern, '/api/$2')
  }
  
  return fullURL
}
```
