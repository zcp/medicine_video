# 前端API路径错误分析报告 - 收藏功能404问题

**问题发现时间**: 2026年4月19日 19:22  
**问题类型**: 前端API路径配置错误  
**影响范围**: 收藏功能完全无法使用  

## 🚨 **问题现象**

从微信小程序控制台日志可以看出：
```
POST http://localhost:8080/api/users/me/favorites 404 (Not Found)
GET http://localhost:8080/api/users/me/favorites 404 (Not Found)  
GET http://localhost:8080/api/users/me/favorites/check 404 (Not Found)
```

**关键发现**：
- ❌ 前端调用: `/api/users/me/favorites` → **404错误**
- ✅ 后端实际路径: `/api/v1/users/me/favorites` → **正常工作**
- ❌ 错误原因: **API路径不匹配**

## 🔍 **根本原因分析**

### **1. Nginx代理配置分析**

查看 `nginx/nginx.conf` 第255-261行：
```nginx
# 用户服务 API
location /api/users/ {
    proxy_pass http://users_api/api/v1/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

**问题**: 
- 前端调用 `/api/users/me/favorites`
- Nginx代理到 `user_service:8002/api/v1/me/favorites`
- **但收藏功能在 `live_core_service:8000`，不在用户服务！**

### **2. 后端服务架构分析**

**收藏功能实际位置**:
- **服务**: `live_core_service` (端口8000)
- **路由**: `/api/v1/users/me/favorites`
- **Nginx代理路径**: `/api/core/` → `live_core_service:8000/api/v1/`

**正确的调用路径应该是**: `/api/core/users/me/favorites`

### **3. 前端API配置错误**

查看 `D:\Programming\Live-Saas-Wechat\src\api\favorites.ts`:
```typescript
// ❌ 错误的路径
export const addFavorite = (roomId: string) => {
  return request({
    url: '/api/users/me/favorites',  // 指向了用户服务
    method: 'POST',
    data: { room_id: roomId }
  })
}
```

## 💡 **解决方案**

### **方案1: 修改前端API路径（推荐）**

修改 `D:\Programming\Live-Saas-Wechat\src\api\favorites.ts` 中的所有API路径：

```typescript
// ✅ 正确的路径
export const addFavorite = (roomId: string) => {
  return request({
    url: '/api/core/users/me/favorites',  // 指向直播核心服务
    method: 'POST',
    data: { room_id: roomId }
  })
}

export const getFavoriteList = (params?) => {
  return request({
    url: '/api/core/users/me/favorites',  // 修改路径
    method: 'GET',
    data: params
  })
}

export const checkIsFavorited = (roomId: string) => {
  return request({
    url: '/api/core/users/me/favorites/check',  // 修改路径
    method: 'GET',
    data: { room_id: roomId }
  })
}

export const removeFavorite = (roomId: string) => {
  return request({
    url: `/api/core/users/me/favorites/${roomId}`,  // 修改路径
    method: 'DELETE'
  })
}
```

### **方案2: 修改Nginx配置（不推荐）**

在nginx中添加收藏功能的特殊代理规则，但这会增加配置复杂性。

## 📝 **经验总结**

### **问题教训**:
1. **微服务架构中API路径配置至关重要**
2. **前端开发时必须明确每个功能属于哪个后端服务**
3. **Nginx代理配置需要与前端API调用保持一致**

### **预防措施**:
1. **建立API路径映射文档**，明确每个功能的服务归属
2. **前端API配置集中管理**，避免路径分散配置
3. **开发环境搭建时验证所有API路径**
