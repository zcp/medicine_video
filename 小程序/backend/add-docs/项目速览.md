# 项目速览（你自己的快速地图）

## 1. 运行形态（Windows/Docker 开发）

- 主要通过 Docker Compose 启动（见根目录 `compose-app.windows.yml`）。
- 已公开的本地端口（开发环境）：
  - Live Core API: `http://localhost:8000`
  - Media Download API: `http://localhost:8001`
  - User Service API: `http://localhost:8002`
  - Nginx 代理: `http://localhost:8080`
  - SRS: `rtmp://localhost:1935`（推流），控制台 `http://localhost:8080/srs`
- 一键命令（见 `README-Windows开发环境.md`）：
  - 启动：`start-dev.bat`
  - 停止：`stop-dev.bat`
  - 重建：`rebuild.bat -c`（仅代码）/ `rebuild.bat -f`（完整）

## 2. 后端服务划分（FastAPI）

- `backend/live_core_service`
  - 入口：`backend/live_core_service/app/main.py`
  - 特征：挂载 `/media` 静态目录；`redirect_slashes=False` 避免 307；含 Celery worker
  - Compose 对应 service：`live_core_service`（端口 8000） + `celery_worker`

- `backend/media_download_service`
  - 入口：`backend/media_download_service/app/main.py`
  - Compose 对应 service：`media_download_service`（端口 8001）

- `backend/users`
  - 入口：`backend/users/app/main.py`
  - 特征：有日志脱敏 `setup_sanitized_logging()`
  - Compose 对应 service：`user_service`（端口 8002）

## 3. 路由组织（常见路径）

每个服务大体结构类似：

- `app/main.py`：FastAPI 实例 + middleware + include_router
- `app/api/v1/api.py`：聚合 v1 路由（`include_router`、prefix、tags）
- `app/api/v1/endpoints/*`：具体 API
- `app/core/config.py`：Settings / 环境变量读取
- `app/database.py`、`app/core/deps.py`：DB Session 依赖注入（`get_db`）

## 4. 你要优先读的文件（建议顺序）

1) `compose-app.windows.yml`（搞清楚服务/端口/依赖）
2) 各服务 `app/main.py`（搞清楚 FastAPI 初始化、中间件、prefix）
3) 各服务 `app/api/v1/api.py`（搞清楚路由入口与 prefix 约定）
4) `app/core/config.py`（搞清楚配置项从哪来）
5) `app/core/deps.py` + `app/database.py`（搞清楚 DB 会话与依赖注入）
