**日期**: 2026-08-08

**后端状态**: 已落地全局 422 映射 + 中文审核文案

---

## 一句话

**违规不是服务器挂了。** HTTP `422` + 业务码 `2005` 时，直接 Toast/弹窗展示响应体里的 `message`。

---

## 响应约定

统一结构：

```json
{
  "code": 2005,
  "message": "标题未通过审核：疑似含绝对化用语，请修改后重试",
  "data": null
}
```

| HTTP | `code` | 含义 | 前端怎么做 |
|------|--------|------|------------|
| **422** | **2005** | 内容违规（违禁词等） | **展示 `message`**（审核原因） |
| **422** | **2004** | 内容安全服务暂不可用 | 展示 `message`，或「审核服务暂不可用，请稍后再试」 |
| **422** | **4001** | 普通参数校验失败 | 展示 `message` / 表单错误 |
| **≥500** | * | 真·服务端异常 | 才可用「服务器内部错误」 |

---

## 拦截器建议（最小改动）

```ts
// 伪代码：优先认 body.code，不要只看 status>=500
const status = error.response?.status
const body = error.response?.data
const code = body?.code
const msg = body?.message

if (status === 422 && (code === 2005 || code === 2004)) {
  showToast(msg || (code === 2005 ? '内容未通过审核，请修改后重试' : '审核服务暂不可用'))
  return
}
if (status >= 500) {
  showToast('服务器内部错误，请稍后重试')
  return
}
// 其它：继续用现有逻辑，但仍优先展示 msg
showToast(msg || '请求失败')
```

**禁止**：把所有非 200、或所有 422，一律显示成「服务器内部错误」。
