### 密码哈希验证
```python
# SHA256哈希方法
def _hash_password(self, password: str) -> str:
    return hashlib.sha256(password.encode()).hexdigest()

def _verify_password(self, password: str, password_hash: str) -> bool:
    return self._hash_password(password) == password_hash
```
