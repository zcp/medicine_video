#### 参考 1：`app/services/expert_service.py` 的 `_resolve_active_category_id` (当前第 149-188 行)

```python
async def _resolve_active_category_id(
    self,
    category_id_raw: Optional[str],
    category_name_raw: Optional[str],
) -> Optional[uuid.UUID]:
    """
    解析 CSV 导入中的专家主分类。

    category_id 和 category_name 都必须指向启用的全局分类，避免批量导入绕过
    create/update 接口中对专家主专业分类的有效性校验。
    """
    from app.models.content_management import Category

    if category_id_raw:
        try:
            category_id = uuid.UUID(category_id_raw)
        except (ValueError, TypeError):
            raise ValueError(f"无效的 category_id 格式: {category_id_raw}")

        cat_stmt = select(Category.id).where(
            Category.id == category_id,
            Category.is_active == True,
        )
        cat_result = await self.db.execute(cat_stmt)
        if cat_result.scalar_one_or_none():
            return category_id
        raise ValueError(f"分类不存在或已禁用: {category_id_raw}")

    if category_name_raw:
        cat_stmt = select(Category.id).where(
            Category.name == category_name_raw,
            Category.is_active == True,
        )
        cat_result = await self.db.execute(cat_stmt)
        cat_id = cat_result.scalar_one_or_none()
        if cat_id:
            return cat_id
        raise ValueError(f"分类不存在或已禁用: {category_name_raw}")

    return None  # ← 当 category_id 和 category_name 都未传入时，返回 None
```

**当前问题**：
1. 当 `category_id` 和 `category_name` 都未传入时，返回 `None`
2. 当 `category_name_raw` 精确匹配不到任何 `Category.name` 时，抛出 `ValueError` → 批量导入中断
3. 两个调用路径（第 516 行和第 611 行）都直接使用这个返回值，不做空值检查

**需要修改为**：
1. 三个出口都返回有效的 UUID（匹配不到 → "其他"）
2. `category_name_raw` 匹配不到时**不再抛 ValueError**，而是返回"其他"

**关键观察点**：
- 函数返回类型从 `Optional[uuid.UUID]` 改为 `uuid.UUID`（不再返回 None）
- `select(Category.id).where(Category.name == '其他', Category.is_active == True)` 作为兜底查询
- "其他"分类通过 `seed.py` 的 `CATEGORIES_DATA` 预先创建

### 5.2 expert_service.py 修改（重写函数出口逻辑）

**文件**：`backend/live_core_service/app/services/expert_service.py`

**修改位置**：`_resolve_active_category_id` 函数（当前第 149-188 行）

**难度**：中等（需要正确处理"其他"分类的 look-up 和出口逻辑）

**修改方案**：

```python
async def _resolve_active_category_id(
    self,
    category_id_raw: Optional[str],
    category_name_raw: Optional[str],
) -> uuid.UUID:  # ← 返回类型从 Optional[uuid.UUID] 改为 uuid.UUID
    """
    解析专家主分类。

    优先精确匹配，匹配不到回退到"其他"兜底分类。
    永远不返回 None（P0 修复）。
    """
    from app.models.content_management import Category

    # 1. 按 UUID 精确查找
    if category_id_raw:
        try:
            category_id = uuid.UUID(category_id_raw)
        except (ValueError, TypeError):
            raise ValueError(f"无效的 category_id 格式: {category_id_raw}")

        cat_stmt = select(Category.id).where(
            Category.id == category_id,
            Category.is_active == True,
        )
        cat_result = await self.db.execute(cat_stmt)
        if cat_result.scalar_one_or_none():
            return category_id
        raise ValueError(f"分类不存在或已禁用: {category_id_raw}")

    # 2. 按名称精确查找
    if category_name_raw and category_name_raw.strip():
        cat_stmt = select(Category.id).where(
            Category.name == category_name_raw.strip(),
            Category.is_active == True,
        )
        cat_result = await self.db.execute(cat_stmt)
        cat_id = cat_result.scalar_one_or_none()
        if cat_id:
            return cat_id
        # ← P0 修复：不再 raise ValueError，改为 fallback 到"其他"
        self.logger.warning(
            f"分类名称未匹配，回退到'其他': category_name_raw={category_name_raw}"
        )

    # 3. 兜底：返回"其他"分类的 ID
    other_stmt = select(Category.id).where(
        Category.name == "其他",
        Category.is_active == True,
    )
    other_result = await self.db.execute(other_stmt)
    other_id = other_result.scalar_one_or_none()
    if other_id:
        return other_id

    # 如果"其他"分类也不存在（seed 未执行），抛出明确错误
    raise InvalidParameterException(
        "兜底分类'其他'不存在，请先运行 seed.py 初始化种子数据"
    )
```

**关键改动点**（与当前代码的精确差异）：

| 行 | 当前代码 | 修改后 |
|:--|:------|:-----|
| 函数签名 | `-> Optional[uuid.UUID]:` | `-> uuid.UUID:` |
| `category_name_raw` 匹配不到时 | `raise ValueError(f"分类不存在或已禁用: ...")` | `self.logger.warning(...)` + 继续执行兜底 |
| `return None` | `return None` | 不再出现，替换为查"其他"分类 |
| 新增 | — | 查"其他"分类 + 返回 other_id 或抛异常 |

**需要确保**：
- ✅ 三个出口均返回有效的 `uuid.UUID`（不再返回 None）
- ✅ `category_name_raw` 为空字符串时也走兜底逻辑（不跳过 empty string）
- ✅ `category_name_raw` 精确匹配不到时**不抛异常**，记录 warning 后走兜底
- ✅ `category_id_raw` 格式错误仍抛 `ValueError`（保持现有行为）
- ✅ `category_id_raw` 指向的 ID 不存在仍抛 `ValueError`（保持现有行为）
- ✅ 函数签名中的返回类型精确改为 `uuid.UUID`（不是 `Optional[uuid.UUID]`）

**调用方不需要改动**（两个调用位置直接使用返回值，不做空值检查即可）：
