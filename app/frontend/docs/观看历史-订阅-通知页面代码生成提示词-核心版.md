## API需求说明

### 必需API

**观看历史相关**：
- `POST /users/me/watch-history` - 记录观看行为
- `GET /users/me/watch-history` - 获取观看历史列表
- `DELETE /users/me/watch-history/{id}` - 删除单条历史
- `POST /users/me/watch-history/clear` - 清空全部历史

**订阅相关**：
- `GET /users/me/subscriptions` - 获取订阅列表
- `POST /users/me/subscriptions` - 添加订阅
- `DELETE /users/me/subscriptions/{id}` - 取消订阅
- `POST /users/me/subscriptions/clear-history` - 清空历史订阅

**通知相关**：
- `GET /users/me/notifications` - 获取通知列表
- `PATCH /users/me/notifications/{id}/read` - 标记单条已读
- `POST /users/me/notifications/mark-all-read` - 标记全部已读

## API 路径规范

**项目使用的API路径格式**（基于现有代码分析）：

```typescript
// ✅ 正确格式：直接拼接，无需版本号
const BASE_URL = 'https://mp.dayilive.com/api/core'

// 示例：
// - 观看历史：/users/me/watch-history
// - 订阅列表：/users/me/subscriptions
// - 通知列表：/users/me/notifications

// request工具自动拼接base URL，所以API函数中只写相对路径：

  // ❌ 错误：不要写完整URL
```

1. ✅ API函数中只写相对路径（如 `/users/me/watch-history`）
