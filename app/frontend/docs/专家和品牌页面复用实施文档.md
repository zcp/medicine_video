### 步骤1：创建工具函数

**文件**: `src/utils/url.ts`

**功能**:
- `normalizeImageUrl()` - 规范化图片URL（http→https）
- `resolveMediaUrl()` - 解析媒体资源URL

**关键代码**:
```typescript
export function resolveMediaUrl(path?: string | null): string {
  const trimmed = String(path || '').trim();
  if (!trimmed) return '';
  
  // 已经是完整URL
  if (/^https?:\/\//i.test(trimmed)) {
    return normalizeImageUrl(trimmed) || '';
  }
  
  // 处理相对路径
  const origin = getMediaOrigin();
  return origin ? `${origin}${trimmed}` : trimmed;
}
```

## 八、问题修复记录

### 8.1 422 API错误修复

**问题描述**:
- 专家列表页面显示422错误
- API调用 `/featured-experts` 返回参数验证失败

**问题原因**:
- 原代码传递了 `limit: 100` 参数
- 根据后端API文档，`limit` 参数最大值为 **50**
- 超过最大值导致422验证失败

**解决方案**:
```typescript
// ❌ 修复前
const res = await getFeaturedExperts({ limit: 100 });

// ✅ 修复后
const res = await getFeaturedExperts({ limit: 50 });
```

**修改文件**: `src/store/expert.ts`

---

### 8.2 详情页无法跳转问题修复

**问题描述**:
- 点击专家卡片和品牌卡片无反应
- 无法跳转到详情页

**问题原因**:
- 详情页面已创建，但未在 `pages.json` 中注册
- `uni.navigateTo()` 无法找到页面路由

**解决方案**:
在 `src/pages.json` 中添加详情页路由配置：
```json
{
  "path": "pages/app/expert/detail",
  "style": {
    "navigationBarTitleText": "专家详情",
    "enablePullDownRefresh": false
  }
},
{
  "path": "pages/app/brand/detail",
  "style": {
    "navigationBarTitleText": "品牌详情",
    "enablePullDownRefresh": false
  }
}
```

**修改文件**: `src/pages.json`

## 十、专家页 UI/UX 设计规范与已实施优化

本节与 **当前实现代码** 保持一致，供后续维护与扩展时遵守；所有样式均基于 Design Tokens，不硬编码颜色/圆角/阴影/字体/间距。

### 10.1 设计基准与角色

- **角色**：Design System Architect（UI-UX-PRO-MAX-SKILLS）
- **必须优先遵守的文档**：
  1. `Design-System-Rules_UI-UX-PRO-MAX.md`
  2. 《登录注册找回-统一设计语言与自适配方案.md》
- **目标页面**：`pages/Expert`（专家专题页）
- **原则**：不改业务逻辑，仅优化 UI；所有样式来自 tokens + components + layout pattern。

### 10.2 问题与优化目标（已实施）

**问题**：
- 列表右侧 Follow CTA 与右侧 AlphabetIndex 字母索引视觉冲突
- Follow 按钮视觉权重过强，破坏 ConsumerLayout 的轻列表节奏

**已执行的优化目标**：
1. Follow CTA 从大按钮降级为 **icon-only（IconButton）**
2. 使用 **Star 图标** 表示关注/收藏（不用 heart，避免社交化）
3. IconButton 位于 AlphabetIndex **左侧**，禁止重叠
4. 点击热区 **≥ 44×44px**
5. 颜色/圆角/动效均使用 **tokens**，禁止硬编码
6. **未关注**：Neutral icon；**已关注**：品牌主色（Color.Primary）
7. **点击列表行** → 进入详情；**点击 Star** → 仅切换关注状态，不跳转
8. hover / active / focus-visible / disabled 状态齐全，动效 **180–220ms**
9. AlphabetIndex **默认弱化**（Neutral + 低对比），仅交互/激活时增强

### 10.6 专家列表页优化建议总结（已实施，可交付 Cursor）

**1. 信息结构优化（提升专业感）**  
- **职称信息更简洁专业**  
  - 建议：由「主任医师，教授，博士生导师」改为紧凑展示，如「主任医师 | 教授 | 博导」。  
  - **实现**：`ExpertCard` 内 `formattedTitle` 将逗号改为竖线，博士生导师→博导、硕士生导师→硕导。

**2. 交互优化（提升可用性）**  
- **收藏按钮更符合用户习惯**  
  - 建议：无边框图标；收藏后实心高亮。  
  - **实现**：Star 无边框；未关注 ☆（Neutral），已关注 ★（主色）；hover/active 轻背景反馈，热区 ≥44px。

**3. 搜索体验优化（提升可理解性）**  
- **搜索栏补充提示文案**  
  - 建议：占位如「搜索专家姓名 / 擅长疾病」，明确可搜索范围。  
  - **实现**：默认占位「搜索专家姓名/医院」；采用假占位（独立 `<text>`）保证 App 端显示。若产品后续改为「搜索专家姓名/擅长疾病」，仅改 `ExpertSearch` 的 `placeholder` 默认值即可。

**4. 筛选状态强化（提升识别效率）**  
- **科室筛选选中态更明显**  
  - 建议：增强选中对比或增加底部指示线。  
  - **实现**：`FilterTabs` 选中项浅色主色背景（rgba 0.14）+ 字重 500 + 底部主色短线（::after）。

**5. 视觉层级优化（提升整体高级感）**  
- **医院名称弱化，突出医生姓名**  
  - 建议：医院名灰度再降低。  
  - **实现**：`.dept` 使用 `opacity: 0.85`，姓名与职称保持主色/常规对比。

**6. 列表密度优化（去卡片设计）**  
- **弱化分割线，用留白建立节奏**  
  - 建议：减少分割线存在感，增加 item 间距/留白。  
  - **实现**：列表项分割线 `1rpx solid rgba(0,0,0,0.04)`；item 上下 padding 24rpx；无厚重卡片框。

**7. 产品定位优化（医疗机构感）**  
- **替换「粉丝/直播/观看」等弱医疗指标**  
  - 建议：优先展示擅长领域等更可信的医疗信息。  
  - **实现**：有 `specialization` 时展示「擅长：xxx」（多词用顿号）；无则回退展示粉丝/直播/观看。
