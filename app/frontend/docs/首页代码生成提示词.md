## 1️⃣ 角色与目标

你是资深 uni-app 前端工程师，为「医学直播 SaaS 平台」移动端生成**首页完整代码**。

**核心目标**：生成可直接运行的首页代码，包含顶部搜索栏、分类筛选器、焦点图轮播、双列直播卡片网格。

## 1.5️⃣ 功能范围说明

### 本期实现功能
- **顶部搜索栏**: 固定顶部，包含 Logo/头像、搜索框、消息图标
- **分类筛选器**: 吸顶横向滚动，支持分类切换
- **焦点图轮播**: 3-5 张图片，自动轮播 + 手动滑动
- **双列直播卡片网格**: 显示直播卡片，包含状态标签
- **下拉刷新**: 重置页码，重新加载数据
- **无限滚动加载**: 触底加载更多数据
- **点击跳转**: 卡片/焦点图点击跳转占位页

### 暂缓实现功能
- **“我的关注”区域**: 首版跳过，简化复杂度
- **观看人数显示**: 后端字段缺失，首版跳过
- **搜索页实际功能**: 使用占位页
- **消息页实际功能**: 使用占位页
- **直播间实际功能**: 使用占位页

  - ✅ 使用 `<style lang="scss" scoped>`

## 5.5️⃣ 数据流设计

### 页面加载流程
```
1. 页面初始化 (onLoad)
   ↓
2. 显示骨架屏 (isLoading = true)
   ↓
3. 并行加载数据 (Promise.all)
   ├── 分类列表: getCategories() 或 mockCategories
   ├── 焦点图: getFeaturedContent() 或 mockFeaturedData
   └── 直播列表: getRoomList() 或 mockRoomData
   ↓
4. 前端过滤 (Mock 模式下按分类筛选)
   ↓
5. 更新响应式数据
   ↓
6. 隐藏骨架屏 (isLoading = false)
   ↓
7. 渲染页面内容
```

### 状态管理
```typescript
// 页面状态
const isLoading = ref(true);           // 页面加载中
const isLoadingMore = ref(false);      // 加载更多中
const hasMore = ref(true);             // 是否有更多数据
const currentPage = ref(1);            // 当前页码
const activeCategoryId = ref('recommend'); // 当前分类

// 数据状态
const categories = ref<Category[]>([]);
const featuredList = ref<FeaturedContent[]>([]);
const roomList = ref<Room[]>([]);
```

### 用户交互流程
```
分类切换:
  用户点击分类 Tab → 更新 activeCategoryId → 重置列表 → 重新加载并过滤

下拉刷新:
  用户下拉 → 触发 onPullDownRefresh → 重置页码 → 重新加载 → 显示 Toast

无限滚动:
  触底 → 检查 hasMore → page++ → 加载更多 → 追加到列表

卡片点击:
  用户点击卡片 → uni.navigateTo → 跳转占位页
```

## 6️⃣ 交互逻辑详细说明

### 6.1 页面初始化
```typescript
async function onPageLoad() {
  // 1. 显示骨架屏
  isLoading.value = true;
  
  // 2. 并行加载数据
  try {
    const [categoriesRes, featuredRes, roomsRes] = await Promise.all([
      fetchCategories(),
      fetchFeaturedContent(),
      fetchRooms({ page: 1, size: PAGE_SIZE })  // 注意：API 不支持 category_id
    ]);
    
    categories.value = categoriesRes;
    featuredList.value = featuredRes;
    // Mock 模式下前端过滤，真实 API 模式下直接使用返回数据
    roomList.value = filterRoomsByCategory(roomsRes.items, activeCategoryId.value);
    currentPage.value = 1;
    hasMore.value = roomsRes.items.length >= PAGE_SIZE;
    
  } catch (error) {
    handleError(error);
  } finally {
    isLoading.value = false;
  }
}

/** 前端过滤房间列表（Mock 模式下使用） */
function filterRoomsByCategory(rooms: Room[], categoryId: string): Room[] {
  if (categoryId === 'recommend' || !categoryId) {
    return rooms; // 推荐分类返回全部
  }
  return rooms.filter(room => room.category_id === categoryId);
}
```

### 6.2 分类切换
```typescript
function handleCategoryChange(categoryId: string) {
  activeCategoryId.value = categoryId;
  currentPage.value = 1;
  roomList.value = [];
  // Mock 模式下前端过滤，真实 API 模式下可能需要后端支持
  fetchRooms({ page: 1, size: PAGE_SIZE }).then(res => {
    roomList.value = filterRoomsByCategory(res.items, categoryId);
  });
}
```

### 6.3 下拉刷新
```typescript
async function onPullDownRefresh() {
  currentPage.value = 1;
  
  try {
    const roomsRes = await fetchRooms({ page: 1, size: PAGE_SIZE });
    
    // Mock 模式下前端过滤
    roomList.value = filterRoomsByCategory(roomsRes.items, activeCategoryId.value);
    hasMore.value = roomsRes.items.length >= PAGE_SIZE;
    
    uni.showToast({ title: '刷新成功', icon: 'success' });
  } catch (error) {
    uni.showToast({ title: '刷新失败', icon: 'none' });
  } finally {
    uni.stopPullDownRefresh();
  }
}
```

### 6.4 无限滚动加载
```typescript
async function onScrollToLower() {
  if (isLoadingMore.value || !hasMore.value) return;
  
  isLoadingMore.value = true;
  
  try {
    const nextPage = currentPage.value + 1;
    const roomsRes = await fetchRooms({ page: nextPage, size: PAGE_SIZE });
    
    // Mock 模式下前端过滤
    const filteredRooms = filterRoomsByCategory(roomsRes.items, activeCategoryId.value);
    roomList.value.push(...filteredRooms);
    currentPage.value = nextPage;
    hasMore.value = roomsRes.items.length >= PAGE_SIZE;
    
  } catch (error) {
    uni.showToast({ title: '加载失败', icon: 'none' });
  } finally {
    isLoadingMore.value = false;
  }
}
```

    case 'brand':

      break;
    case 'expert':
      // 跳转专家 Tab

    case 'external':
      // 打开外部链接
