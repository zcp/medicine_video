# 创建直播功能设计文档 - 移动端 (V1.0)

---

## 1. 功能概述

### 1.1 功能定位

创建直播功能是医学直播SaaS平台的核心功能之一，为主播（医生、专家）提供便捷的直播间创建和配置能力。移动端设计遵循"快速创建"与"完整配置"双入口策略，满足不同场景下的使用需求。

### 1.2 设计目标

- **快速创建**：TabBar入口提供抽屉式半屏弹窗，30秒内完成核心配置
- **完整配置**：我的页面入口提供全屏页面，支持所有功能字段的详细设置
- **移动优化**：针对触屏操作、单手使用、弱网环境进行优化
- **渐进增强**：核心功能优先实现，扩展功能（分类、标签、时长）采用占位设计

## 2. 功能入口与交互流程

### 2.1 双入口设计

#### 入口1：TabBar中间"+"按钮（快速创建）

**触发方式**：
- 用户点击底部TabBar中间的加号按钮
- 适用场景：临时直播、快速开播、移动办公

**展示形式**：
- 抽屉式半屏弹窗（从底部滑出）
- 高度：60-70vh
- 动画：cubic-bezier(0.4, 0, 0.2, 1) 0.3s

**功能范围**：
- 直播标题（必填）
- 特邀专家（可选）
- 关联品牌（可选）
- 直播封面（可选）
- 开始时间（必填）

#### 入口2：我的页面"创建直播"按钮（完整配置）

**触发方式**：
- 用户在"我的"页面点击"创建直播"按钮
- 路由跳转：`/pages/app/live-manage/create`
- 适用场景：正式直播、专业配置、提前预约

**展示形式**：
- 全屏独立页面
- 顶部导航栏：uni-app 原生导航栏（返回按钮 + "创建直播"标题）
- 底部固定按钮组：保存草稿 + 立即创建

**功能范围**：
- 所有快速创建字段
- 直播简介（可选）
- 直播分类（占位）
- 场次标签（占位）
- 预计时长（占位）
- 观看方式（可选）
- 回放设置（可选）

### 3.2 字段详细设计

#### 3.2.1 直播标题（必填）

**组件类型**：单行文本输入框

**UI规格**：
- 高度：88rpx
- 背景色：#f7f8fa（未聚焦）/ #ffffff（聚焦）
- 边框：2rpx solid transparent（未聚焦）/ 2rpx solid #1890ff（聚焦）
- 圆角：12rpx
- 内边距：24rpx
- 字体大小：28rpx
- 字体颜色：#333333

**交互行为**：
- 点击输入框自动聚焦，弹出系统键盘
- 实时显示字数统计（0/100）
- 超过100字符后禁止输入
- 失焦时验证：为空显示红色边框 + 错误提示

**错误提示**：
```
┌─────────────────────────────┐
│ 请输入直播标题...            │ ← 红色边框
└─────────────────────────────┘
⚠️ 请输入直播标题              ← 红色文字（24rpx）
```

#### 3.2.2 直播封面（可选）

**组件类型**：图片上传组件

**UI规格**：
- 未上传状态：
  - 宽度：100%
  - 高度：240rpx
  - 背景色：#f7f8fa
  - 边框：2rpx dashed #d9d9d9
  - 圆角：12rpx

  - 文字："上传封面"（28rpx，#666666）
  - 提示："建议尺寸：16:9"（24rpx，#999999）

- 已上传状态：
  - 显示预览图（宽度100%，高度360rpx）
  - 右上角删除按钮（48rpx圆形，半透明黑色背景）

**交互行为**：
- 点击触发 `uni.chooseImage()`
- 支持相册选择和拍照
- 图片压缩：sizeType: ['compressed']
- 上传时机：创建直播间成功后调用上传封面API

#### 3.2.5 开始时间（必填）

**组件类型**：日期时间选择器

**UI规格**：
```
┌─────────────────────────────┐
│ 2026年1月30日 16:30     ▼   │
└─────────────────────────────┘
```
- 高度：88rpx
- 背景色：#f7f8fa
- 文字颜色：#333333
- 右侧箭头：icon-arrow-down（24rpx，#999999）

**选择器配置**：
- 模式：`mode="multiSelector"`
- 五列：年 | 月 | 日 | 小时 | 分钟
- 年份范围：过去10年 ~ 未来2年（如2016年-2028年）
- 月份范围：1 ~ 12月
- 日期范围：1 ~ 31日
- 小时范围：00 ~ 23
- 分钟范围：00, 05, 10, ..., 55（每5分钟）

**默认值**：
- 当前时间 + 30分钟（向上取整到5分钟）
- 示例：当前2026年1月30日15:37 → 默认2026年1月30日16:05

**支持场景**：
- ✅ 创建未来直播：选择未来日期
- ✅ 发布历史回放：选择过去日期（如2020年的回放视频）
- ✅ 跨年直播：自由选择年份

**交互行为**：
- 点击触发 `picker` 组件
- 选择后更新显示文字
- 转换为ISO 8601格式传给后端

### 5.3 错误处理

```typescript
try {
  // API调用
} catch (error: any) {
  console.error('创建直播失败:', error);
  
  // 根据错误码显示不同提示
  let message = '创建失败，请重试';
  
  if (error.code === 4001) {
    message = '参数校验失败，请检查输入';
  } else if (error.code === 4003) {
    message = '登录已过期，请重新登录';
  } else if (error.code === 5000) {
    message = '服务器错误，请稍后重试';
  }
  
  uni.showToast({
    title: message,
    icon: 'none',
    duration: 2000
  });
}
```

## 9. 注意事项

### 9.1 开发注意事项

1. **占位功能处理**：
   - 直播分类、场次标签、预计时长暂时只做UI占位
   - 点击后显示Toast提示，不影响其他功能
   - 后续开启时只需移除占位样式和禁用逻辑

2. **品牌关联功能**：
   - 品牌选择页面参考专家选择页面实现
   - 品牌数据需要后端提供API支持
   - 暂时可以使用Mock数据进行开发

3. **图片上传时机**：
   - 封面图片在创建直播间成功后再上传
   - 上传失败不阻断流程，只记录日志

4. **时间处理**：
   - 前端使用ISO 8601格式传给后端
   - 默认时间为当前时间+30分钟
   - 时间选择器精确到5分钟

5. **表单验证**：

## 11. 专家和品牌选择实现方案（V2.0更新）

### 11.1 设计变更说明

**原设计方案**：
- 点击后跳转到独立的选择页面（`/pages/app/expert/select`、`/pages/app/brand/select`）
- 需要创建两个独立页面
- 页面间通过事件通道传递数据

**优化后方案**：
- 点击后在当前页面弹出选择弹窗（半屏弹窗）
- 无需创建独立页面，减少开发工作量
- 直接调用API获取列表数据，无需页面跳转
- 参考截图效果，用户体验更流畅

### 11.2 专家选择实现细节

### 11.4 弹窗组件设计

#### 11.4.1 组件结构

```vue
<template>
  <view class="select-dialog" v-if="visible">
    <!-- 遮罩层 -->
    <view class="dialog-mask" @click="handleClose"></view>
    
    <!-- 弹窗内容 -->
    <view class="dialog-content">
      <!-- 标题栏 -->
      <view class="dialog-header">

          v-model="searchKeyword"

          @input="handleSearch"
        />

      <scroll-view scroll-y class="dialog-list">
        <view 
          v-for="item in filteredList" 
          :key="item.id"
          class="list-item"
          @click="handleSelect(item)"
        >
```

#### 11.4.2 搜索过滤

```typescript
// 搜索关键词
const searchKeyword = ref('');

// 过滤后的列表
const filteredList = computed(() => {
  if (!searchKeyword.value) {
    return expertList.value; // 或 brandList.value
  }
  
  return expertList.value.filter(item => 
    item.name.includes(searchKeyword.value)
  );
});
```

### 11.5 与后端API的对应关系

| 功能 | 前端API | 后端接口 | 字段映射 |
|------|---------|---------|---------|
| 获取专家列表 | `getFeaturedExperts({ limit: 50 })` | `GET /api/v1/featured-experts?limit=50` | `id` → `featured_expert_id` |
