## 1. 需求背景

### 1.1 业务需求

医学直播平台需要为用户提供便捷、安全的账号注册功能，支持用户通过用户名+密码方式创建账号。注册流程需要平衡安全性与用户体验，采用分阶段开发策略：

- **第一阶段**（当前实现）：使用图形验证码进行人机识别，快速上线MVP版本
- **第二阶段**（未来增强）：增加邮箱/手机号OTP验证，提升账户安全性

### 1.2 用户场景

- **新用户**：首次访问平台，需要创建账号观看直播、参与互动
- **医学专业人士**：注册后可创建直播间、发布专业内容
- **移动端用户**：在手机上快速完成注册，流程简洁流畅

### 1.3 入口说明

注册页面通过**登录页面左下角的"注册账号"按钮**触发，采用页面跳转方式（非弹窗），确保用户专注于注册流程。

```
登录页面 (pages/auth/login)
    ↓ 点击"注册账号"按钮
注册页面 (pages/auth/register)
    ↓ 注册成功
    ↓ 自动登录（调用登录API）
    ↓ 跳转到首页
```

### 2.2 表单字段设计

| 字段 | 类型 | 必填 | 长度限制 | 校验规则 | 错误提示 |
|------|------|------|---------|---------|---------|
| **username** | 文本 | ✅ | 2-50字符 | 字母、数字、下划线 | "用户名格式不正确" |
| **email** | 邮箱 | ✅ | 符合邮箱格式 | 标准邮箱正则 | "请输入有效的邮箱地址" |
| **password** | 密码 | ✅ | 最小8位 | 大小写+数字+特殊字符 | "密码强度不足" |
| **nickname** | 文本 | ✅ | 2-50字符 | 任意字符 | "昵称不能为空" |
| **captcha_solution** | 文本 | ✅ | 4-6位 | 字母数字组合 | "请输入验证码" |

### 2.3 密码强度规则

**后端要求**（必须全部满足）：
- ✅ 最小长度8位
- ✅ 至少1个大写字母 (A-Z)
- ✅ 至少1个小写字母 (a-z)
- ✅ 至少1个数字 (0-9)
- ✅ 至少1个特殊字符 (!@#$%^&*())

**前端强度指示器**（5级）：

| 强度等级 | 颜色 | 条件 | 提示文字 |
|---------|------|------|---------|
| 很弱 | 红色 | 长度<8 | "密码太短" |
| 弱 | 橙色 | 满足1-2项 | "密码较弱" |
| 中 | 黄色 | 满足3项 | "密码一般" |
| 强 | 浅绿 | 满足4项 | "密码较强" |
| 很强 | 深绿 | 满足全部5项 | "密码很强" |

### 2.4 图形验证码流程

**完整工作流程**：

```
步骤1：页面加载
    ↓ onMounted()
    ↓ 调用 getCaptcha() → GET /auth/captcha
    ↓ 后端返回 { captcha_id, image_base64 }
    ↓ 保存 captcha_id
    ↓ 显示验证码图片

步骤2：用户填写表单
    ↓ 用户看到图片上的字符
    ↓ 在输入框输入验证码
    ↓ 实时密码强度校验
    ↓ 点击"换一张"可刷新验证码（重复步骤1）

步骤3：提交注册
    ↓ 前端表单校验（字段格式、必填项）
    ↓ 调用 registerUser() → POST /users/register
    ↓ 请求体包含：username, email, password, nickname, captcha_id, captcha_solution
    ↓ 后端验证
    ↓ 成功：返回用户信息
    ↓ 失败：返回错误信息（验证码错误、用户名已存在等）

步骤4：处理响应
    ✅ 成功 (200)：
       - 显示成功提示"注册成功，正在登录..."
       - 调用 authStore.login() 自动登录
       - 登录成功后Token和用户信息已保存到Store
       - 跳转到首页
    ❌ 失败 (400/409)：
       - 显示错误信息
       - 自动刷新验证码
       - 用户可修改后重新提交
```

### 2.5 用户反馈设计

**实时反馈**：
- 输入框失去焦点时校验，错误提示显示在字段下方
- 密码输入时实时更新强度指示器
- 验证码输入完成自动转换为小写（后端不区分大小写）
- 用户名/邮箱已存在时，输入框显示红色边框+错误提示

**提交反馈**：
- 点击注册按钮→按钮显示"注册中..."，禁用防重复提交
- 成功：显示Toast提示"注册成功，正在登录..."，自动调用authStore.login()，然后跳转首页
- 失败：显示Toast提示错误信息，按钮恢复可点击状态

## 4. 核心代码实现

### 4.1 API封装

**重要说明**：认证服务（验证码、登录、注册等）使用独立的API基础URL。

**API基础URL配置**：
```bash
# .env 文件配置
VITE_AUTH_API_URL=https://mp.dayilive.com/api/users
```

**接口说明**：
- 所有认证相关接口（注册、登录、验证码、刷新Token、登出）都使用此基础URL
- 与其他业务接口（直播、用户信息等）的基础URL不同，需单独配置
- 前端请求时需要根据接口类型选择正确的基础URL

---

**文件**: `src/api/auth.ts`

```typescript
import { post, get } from '@/utils/request';
import { AUTH_API_URL } from '@/constants/api';
import type { ApiResponse } from '@/types/common';

/**
 * 路径拼接工具函数
 * 将认证基础URL与相对路径拼接，自动处理斜杠
 */
const authUrl = (path: string) => `${AUTH_API_URL.replace(/\/+$/, '')}/${path.replace(/^\/+/, '')}`;

/**
 * 获取图形验证码
 * @returns {Promise} 返回 { captcha_id, image_base64 }
 * @example
 * const response = await getCaptcha();
 * const { captcha_id, image_base64 } = response.data;
 */
export interface CaptchaResponse {
  captcha_id: string;
  image_base64: string;
}

export const getCaptcha = (): Promise<ApiResponse<CaptchaResponse>> => {
  return get<ApiResponse<CaptchaResponse>>(authUrl('/auth/captcha'));
};

/**
 * 用户注册（第一阶段：图形验证码版）
 * @param data 注册表单数据
 * @returns {Promise} 返回用户基本信息
 * @example
 * const response = await registerUser({
 *   username: 'testuser',
 *   email: 'test@example.com',
 *   password: 'Test@123',
 *   nickname: '测试用户',
 *   captcha_id: 'xxx',
 *   captcha_solution: '1234'
 * });
 */
export interface RegisterRequest {
  username: string;
  email: string;
  password: string;
  nickname: string;
  captcha_id: string;
  captcha_solution: string;
}

export interface RegisterResponse {
  uuid: string;
  username: string;
  nickname: string;
  email: string;
}

export const registerUser = (data: RegisterRequest): Promise<ApiResponse<RegisterResponse>> => {
  return post<ApiResponse<RegisterResponse>>(authUrl('/users/register'), data);
};

/**
 * 用户登录
 * @param data 登录表单数据
 * @returns {Promise} 返回 Access Token 和 Refresh Token
 * @example
 * const response = await login({
 *   username: 'testuser',
 *   password: 'Test@123',
 *   captcha_id: 'xxx',
 *   captcha_solution: '1234'
 * });
 */
export interface LoginRequest {
  username: string;
  password: string;
  captcha_id: string;
  captcha_solution: string;
}

export interface LoginResponse {
  access_token: string;
  refresh_token: string;
  token_type: string;
}

export const login = (data: LoginRequest): Promise<ApiResponse<LoginResponse>> => {
  return post<ApiResponse<LoginResponse>>(authUrl('/auth/login'), data);
};
```

**关键说明**：

1. **路径拼接**：使用 `authUrl()` 函数统一处理路径拼接，自动去除多余斜杠
2. **基础URL**：从 `@/constants/api.ts` 导入 `AUTH_API_URL`（=VITE_AUTH_API_URL）
3. **请求方法**：从 `@/utils/request.ts` 导入统一的 `get` 和 `post` 方法
4. **类型安全**：使用 `ApiResponse<T>` 包装返回类型，确保类型一致性
5. **函数风格**：使用箭头函数和 `export const`，与现有代码风格一致

```vue
/**
 * 校验单个字段
 */
function validateField(field: keyof RegisterForm): boolean {
  let isValid = true;
  errors[field] = '';

  switch (field) {
    case 'username':
      if (!formData.username) {
        errors.username = '请输入用户名';
        isValid = false;
      } else if (!validateUsername(formData.username)) {
        errors.username = '用户名格式不正确（2-50字符，字母/数字/下划线）';
        isValid = false;
      }
      break;

    case 'email':
      if (!formData.email) {
        errors.email = '请输入邮箱';
        isValid = false;
      } else if (!validateEmail(formData.email)) {
        errors.email = '请输入有效的邮箱地址';
        isValid = false;
      }
      break;

    case 'password':
      if (!formData.password) {
        errors.password = '请输入密码';
        isValid = false;
      } else if (!validatePassword(formData.password)) {
        errors.password = '密码强度不足（至少8位，包含大小写字母+数字+特殊字符）';
        isValid = false;
      }
      break;

    case 'nickname':
      if (!formData.nickname) {
        errors.nickname = '请输入昵称';
        isValid = false;
      } else if (formData.nickname.length < 2 || formData.nickname.length > 50) {
        errors.nickname = '昵称长度为2-50字符';
        isValid = false;
      }
      break;

    case 'captcha_solution':
      if (!formData.captcha_solution) {
        errors.captcha_solution = '请输入验证码';
        isValid = false;
      }
      break;
  }

  return isValid;
}

/**
 * 校验所有字段
 */
function validateAllFields(): boolean {
  let isValid = true;
  const fields: Array<keyof RegisterForm> = ['username', 'email', 'password', 'nickname', 'captcha_solution'];
  
  fields.forEach(field => {
    if (!validateField(field)) {
      isValid = false;
    }
  });

  return isValid;
}

    // 3. 调用注册API
    const res = await registerUser({
      username: formData.username,
      email: formData.email,
      password: formData.password,
      nickname: formData.nickname,
      captcha_id: captchaId.value,
      captcha_solution: formData.captcha_solution,
    });

    // 4. 注册成功
    console.log('[Register] 注册成功', res.data);
    uni.showToast({ title: '注册成功，正在登录...', icon: 'success', duration: 2000 });

    // 5. 自动登录（使用刚注册的账号）
    await autoLogin(formData.username, formData.password);

    // 6. 跳转到首页
    setTimeout(() => {
      uni.reLaunch({ url: '/pages/tabbar/home/index' });
    }, 1500);

  } catch (error: any) {
    console.error('[Register] 注册失败', error);
    
    // 6. 处理错误
    const errorMsg = error.message || '注册失败，请重试';
    uni.showToast({ title: errorMsg, icon: 'none' });

    // 7. 刷新验证码
    refreshCaptcha();

    // 8. 特殊错误处理
    if (error.code === 4009) {
      errors.username = '用户名已被占用';
    } else if (error.code === 4010) {
      errors.email = '邮箱已被注册';
    } else if (error.code === 4003) {
      errors.captcha_solution = '验证码错误或已过期';
    }

  } finally {
    isSubmitting.value = false;
  }
```

```typescript
/**
 * 校验用户名格式
 * 规则：2-50字符，仅允许字母、数字、下划线
 */
export function validateUsername(username: string): boolean {
  const regex = /^[a-zA-Z0-9_]{2,50}$/;
  return regex.test(username);
}

/**
 * 校验邮箱格式
 */
export function validateEmail(email: string): boolean {
  const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  return regex.test(email);
}

/**
 * 校验密码强度
 * 规则：至少8位，包含大小写字母+数字+特殊字符
 */
export function validatePassword(password: string): boolean {
  if (password.length < 8) return false;
  
  const hasUpperCase = /[A-Z]/.test(password);
  const hasLowerCase = /[a-z]/.test(password);
  const hasNumber = /[0-9]/.test(password);
  const hasSpecialChar = /[!@#$%^&*()]/.test(password);
  
  return hasUpperCase && hasLowerCase && hasNumber && hasSpecialChar;
}
```

```typescript
import type { PasswordStrength } from '@/types/auth';
import { PasswordStrengthLevel } from '@/types/auth';

/**
 * 计算密码强度
 * @param password 密码字符串
 * @returns 密码强度对象
 */
export function calculatePasswordStrengthLevel(password: string): PasswordStrength {
  if (!password) {
    return {
      level: PasswordStrengthLevel.VeryWeak,
      text: '请输入密码',
      color: '#9CA3AF',
      score: 0,
    };
  }

  let score = 0;

  // 1. 长度检查
  if (password.length >= 8) score++;
  if (password.length >= 12) score++; // 额外加分

  // 2. 包含大写字母
  if (/[A-Z]/.test(password)) score++;

  // 3. 包含小写字母
  if (/[a-z]/.test(password)) score++;

  // 4. 包含数字
  if (/[0-9]/.test(password)) score++;

  // 5. 包含特殊字符
  if (/[!@#$%^&*()]/.test(password)) score++;

  // 限制最大分数为5
  score = Math.min(score, 5);

  // 根据分数返回强度
  const strengthMap: Record<number, PasswordStrength> = {
    0: {
      level: PasswordStrengthLevel.VeryWeak,
      text: '密码太短',
      color: '#EF4444',
      score: 0,
    },
    1: {
      level: PasswordStrengthLevel.VeryWeak,
      text: '很弱',
      color: '#EF4444',
      score: 1,
    },
    2: {
      level: PasswordStrengthLevel.Weak,
      text: '弱',
      color: '#F97316',
      score: 2,
    },
    3: {
      level: PasswordStrengthLevel.Medium,
      text: '中',
      color: '#EAB308',
      score: 3,
    },
    4: {
      level: PasswordStrengthLevel.Strong,
      text: '强',
      color: '#22C55E',
      score: 4,
    },
    5: {
      level: PasswordStrengthLevel.VeryStrong,
      text: '很强',
      color: '#10B981',
      score: 5,
    },
  };

  return strengthMap[score];
}
```

1. **去卡片化**：不使用明显的白色卡片+阴影，整个页面保持轻背景
2. **pill按钮**：主按钮必须是完整圆角（border-radius: 高度/2）
3. **轻输入**：输入框边框轻（1-2rpx），focus时变为品牌色
4. **协议贴底**：协议区与auth-main平级，采用flex-shrink: 0确保始终可见
5. **响应式容器**：严格遵循92vw/420-460px规则，永不横向滚动
6. **垂直位置**：Mobile靠上（12vh），Desktop稍居中（18vh）

**❌ 禁止操作**：
1. 不使用明显的卡片阴影（auth-main不加box-shadow）
2. 不使用过重的模块化分割
3. 不在Mobile端使用过大的top padding（避免内容被挤到下方）
4. 不使用方形按钮（必须是pill样式）

## 6. 用户体验优化

### 6.1 实时反馈

**输入框校验**：
- 失去焦点时校验字段，立即显示错误提示
- 用户修正后，错误提示自动消失
- 输入框获得焦点时，边框颜色变为品牌主色

**密码强度**：
- 用户输入密码时，实时更新强度指示器
- 5级强度条，颜色从红色渐变到绿色
- 强度文字动态显示（很弱/弱/中/强/很强）

**验证码**：
- 点击验证码图片或"换一张"按钮刷新验证码
- 验证码输入框限制6位字符
- 自动转换为小写（后端不区分大小写）

### 6.2 防误操作

**防重复提交**：
- 点击注册按钮后，按钮禁用并显示"注册中..."
- 提交完成后（成功或失败），按钮恢复可点击状态

**返回确认**：
- 用户填写表单后点击返回，弹窗提示"是否放弃注册？"
- 避免误操作导致数据丢失

**输入限制**：
- 用户名输入框限制50字符
- 昵称输入框限制50字符
- 验证码输入框限制6字符

### 6.3 错误处理

**网络异常**：
- 请求超时：显示"网络连接超时，请检查网络"
- 无网络：显示"网络未连接，请检查网络设置"

**业务错误**：
- 用户名已存在（错误码4009）：输入框显示红色边框，下方显示"用户名已被占用"
- 邮箱已注册（错误码4010）：输入框显示红色边框，下方显示"邮箱已被注册"
- 验证码错误（错误码4003）：自动刷新验证码，提示"验证码错误或已过期"

**未知错误**：
- 显示通用错误提示"注册失败，请重试"
- 记录错误日志，方便问题排查

### 6.4 成功反馈

**注册成功后（自动登录流程）**：
1. 显示Toast提示"注册成功，正在登录..."
2. 调用 `authStore.login()` 方法（与登录页面保持一致）：
   - 内部调用登录API
   - 自动保存Access Token和Refresh Token到本地存储
   - 自动获取并保存用户信息到Pinia Store
   - 自动更新全局登录状态
3. 登录成功后跳转到首页：`uni.reLaunch({ url: '/pages/tabbar/home/index' })`
4. 整个流程约2秒完成，用户无感知切换

**错误处理**：
- 注册成功但登录失败（极少见）：提示"注册成功，请前往登录"，返回登录页
- 用户可以直接使用刚注册的账号手动登录

**技术优势**：
- 使用 `authStore.login()` 确保登录逻辑与登录页完全一致
- 避免重复代码，维护性更好
- Token管理、用户状态更新等由Store统一处理

## 8. 安全性保障

### 8.1 密码安全

**前端校验**：
- 强制要求密码至少8位
- 必须包含大小写字母+数字+特殊字符
- 实时显示密码强度，引导用户设置强密码

**后端校验**：
- 后端再次校验密码强度
- 密码加盐哈希后存储，不保存明文

### 8.2 验证码防护

**图形验证码**：
- 防止机器人批量注册
- 验证码3分钟过期，自动失效
- 验证成功后立即删除，不可重复使用

### 8.3 数据传输

**HTTPS加密**：
- 所有API请求使用HTTPS加密传输
- 防止密码在传输过程中被窃取

**敏感信息保护**：
- 密码输入框默认隐藏，支持显示/隐藏切换
- 前端不存储密码明文

### 8.4 错误信息安全

**模糊提示**：
- 用户名或邮箱已存在时，提示"用户名已被占用"或"邮箱已被注册"
- 避免泄露用户是否存在的信息（可选优化：统一提示"用户名或邮箱已被使用"）

### 14.2 API接口

**API基础URL**：
```
认证服务基础URL: https://mp.dayilive.com/api/users
```

**注意事项**：
- 认证服务（验证码、登录、注册）使用独立的基础URL
- 需要在 `.env` 文件中配置 `VITE_AUTH_API_URL`
- 前端请求时自动根据接口类型选择对应的基础URL

---

**API路径拼接说明**：

所有认证相关API都通过 `authUrl()` 函数拼接完整路径：
```typescript
const authUrl = (path: string) => 
  `${AUTH_API_URL.replace(/\/+$/, '')}/${path.replace(/^\/+/, '')}`;
// AUTH_API_URL = 'https://mp.dayilive.com/api/users'
```

---

| API名称 | 相对路径 | 完整URL | 请求方法 | 认证要求 |
|---------|---------|---------|---------|----------|
| **获取验证码** | `/auth/captcha` | `https://mp.dayilive.com/api/users/auth/captcha` | GET | 不需要 |
| **用户注册** | `/users/register` | `https://mp.dayilive.com/api/users/users/register` | POST | 不需要 |
| **用户登录** | `/auth/login` | `https://mp.dayilive.com/api/users/auth/login` | POST | 不需要 |
| **刷新Token** | `/auth/refresh` | `https://mp.dayilive.com/api/users/auth/refresh` | POST | 不需要 |
| **登出** | `/auth/logout` | `https://mp.dayilive.com/api/users/auth/logout` | POST | 需要Token |

---

**接口详细说明**：

1. **获取图形验证码**：
   - 返回数据：`{ captcha_id: string, image_base64: string }`
   - 使用方式：`const response = await getCaptcha();`

2. **用户注册**：
   - 请求参数：`{ username, email, password, nickname, captcha_id, captcha_solution }`
   - 返回数据：`{ uuid, username, nickname, email }`
   - 使用方式：`const response = await registerUser(data);`

3. **用户登录**：
   - 请求参数：`{ username, password, captcha_id, captcha_solution }`
   - 返回数据：`{ access_token, refresh_token, token_type }`
   - 使用方式：`await authStore.login(data);` （推荐）
   - 或直接调用：`const response = await login(data);`

4. **刷新Token**：
   - 请求参数：`{ refresh_token }`
   - 返回数据：`{ access_token, token_type }`

5. **登出**：
   - 请求参数：无
   - 返回数据：`{ message }`
   - 请求头需要携带：`Authorization: Bearer {access_token}`
