## 2️⃣ 组件导入规范（强制执行）

### 2.1 通用组件导入（必须使用 @ 别名）

**✅ 正确示例**：
```typescript
// 阶段一：类型定义或API文件中
import type { ComponentPublicInstance } from 'vue';

// 阶段二/三：页面或组件中
import AppButton from '@/components/common/AppButton.vue';
import RoomCard from '@/components/common/RoomCard.vue';
import UserInfoHeader from '@/components/common/UserInfoHeader.vue';
import ModalDialog from '@/components/common/ModalDialog.vue';
import RoomSelectionDialog from '@/components/common/RoomSelectionDialog.vue';
```

**❌ 错误示例**：
```typescript
// ❌ 错误1：使用旧路径（根目录）
import AppButton from '@/components/AppButton.vue';

// ❌ 错误2：使用相对路径
import AppButton from '../../components/common/AppButton.vue';

// ❌ 错误3：路径写错
import AppButton from '../@/components/common/AppButton.vue';
```

### 2.2 平台特定组件导入（需配合条件编译）

**✅ 正确示例**：
```typescript
// H5专用组件
// #ifdef H5
import VideoPlayer from '@/components/h5/VideoPlayerH5.vue';
// #endif

// App专用组件
// #ifdef APP-PLUS
import VideoPlayer from '@/components/app/VideoPlayerApp.vue';
// #endif

// 小程序专用组件
// #ifdef MP-WEIXIN
import CustomComponent from '@/components/mp/CustomComponentMp.vue';
// #endif
```

**❌ 错误示例**：
```typescript
// ❌ 错误：不使用条件编译，直接导入
import VideoPlayer from '@/components/h5/VideoPlayerH5.vue';
// 这会导致在App环境中尝试加载H5组件，引发错误

// ❌ 错误：混用不同平台组件
// #ifdef H5
import VideoPlayer from '@/components/app/VideoPlayerApp.vue';
// #endif
```

## 3️⃣ 平台检测工具（已可用）

### 3.1 工具位置
```
src/utils/platform.ts
```

### 3.2 可用函数

```typescript
import { isH5, isApp, isMP, getPlatform, importPlatformComponent } from '@/utils/platform';

// 1. 检测当前是否为H5平台
if (isH5()) {
  console.log('当前是H5环境');
  // H5特有逻辑
}

// 2. 检测当前是否为App平台
if (isApp()) {
  console.log('当前是App环境');
  // App特有逻辑（Android/iOS）
}

// 3. 检测当前是否为小程序平台
if (isMP()) {
  console.log('当前是小程序环境');
  // 小程序特有逻辑
}

// 4. 获取平台类型字符串
const platform = getPlatform(); 
// 返回值：'h5' | 'app' | 'mp-weixin' | 'unknown'

console.log(`当前平台：${platform}`);

// 5. 动态导入平台特定组件（高级用法）
const VideoPlayer = importPlatformComponent('VideoPlayer', {
  h5: () => import('@/components/h5/VideoPlayerH5.vue'),
  app: () => import('@/components/app/VideoPlayerApp.vue'),
});
```

### 3.3 使用场景

| 场景 | 推荐函数 | 示例 |
|------|---------|------|
| 组件内平台判断 | `isH5()`, `isApp()` | 不同平台显示不同内容 |
| API适配 | `getPlatform()` | 文件上传、地理定位等 |
| 日志上报 | `getPlatform()` | 区分平台的错误日志 |
| 动态组件加载 | `importPlatformComponent()` | 根据平台加载不同实现 |

## 4️⃣ 新建组件决策流程

### 4.1 决策树

在创建任何新组件前，按以下流程判断：

```
┌─────────────────────────────────────┐
│ Q: 组件是否所有平台都需要？          │
└─────────────────────────────────────┘
           │
    ┌──────┴──────┐
    │             │
   是            否
    │             │
    ▼             ▼
┌─────────┐   ┌─────────────────────┐
│创建通用组件│   │ Q: 哪个平台专用？     │
└─────────┘   └─────────────────────┘
    │              │
    │         ┌────┼────┬─────┐
    │         │    │    │     │
    │        H5   App   MP  多平台
    │         │    │    │     │
    ▼         ▼    ▼    ▼     ▼
┌─────────────────────────────────────┐
│ common/         h5/  app/ mp/ 分别创建│
│ ComponentName   -H5  -App -Mp        │
└─────────────────────────────────────┘
```

### 4.2 判断标准

#### 创建通用组件 (`common/`) 的标准：
- ✅ 不使用平台特定的API（如`document`, `window`, `plus`等）
- ✅ 不依赖浏览器专用库（如Artplayer, Chart.js等）
- ✅ 不依赖原生组件（如`<video>`, `<canvas>`的高级特性）
- ✅ 使用纯Vue组件特性和uni-app通用API

**示例**：
- `AppButton.vue` - 纯Vue按钮，所有平台适用
- `RoomCard.vue` - 展示房间信息，所有平台适用
- `ModalDialog.vue` - 弹窗，使用uni.showModal，所有平台适用

#### 创建平台特定组件的标准：

**H5专用 (`h5/`)**：
- ✅ 使用了浏览器专用库（Artplayer, hls.js, ECharts等）
- ✅ 使用了DOM API（`document.getElementById`, `window.location`等）
- ✅ 使用了Web特有功能（WebSocket, WebRTC, Canvas高级特性等）

**示例**：
- `VideoPlayerH5.vue` - 使用Artplayer（浏览器专用库）

**App专用 (`app/`)**：
- ✅ 使用了uni-app原生组件的高级特性
- ✅ 使用了App专用API（`plus.`, `uni.require('NativeModule')`）
- ✅ 使用了原生插件或模块

**示例**：
- `VideoPlayerApp.vue` - 使用uni原生`<video>`组件的全部特性

**小程序专用 (`mp/`)**：
- ✅ 使用了微信小程序特有API（`wx.`, `my.`等）
- ✅ 使用了小程序专用组件

## 6️⃣ 禁止的操作（必读）

### 6.1 禁止事项清单

```
❌ 禁止1：在 src/components/ 根目录创建组件
   正确：src/components/common/MyComponent.vue
   错误：src/components/MyComponent.vue
   原因：根目录不再用于存放组件，必须按平台分类

❌ 禁止2：使用相对路径导入组件
   正确：import AppButton from '@/components/common/AppButton.vue'
   错误：import AppButton from '../../components/common/AppButton.vue'
   原因：相对路径难以维护，容易出错

❌ 禁止3：重复创建已存在的7个组件
   已存在：AppButton, ModalDialog, RoomCard, 
          RoomSelectionDialog, UserInfoHeader,
          VideoPlayerH5, VideoPlayerApp
   原因：重复创建会导致冲突

❌ 禁止4：在非H5环境使用浏览器专用库
   错误：在App中使用 Artplayer, hls.js
   正确：Artplayer 等只能在 VideoPlayerH5.vue 中使用
   原因：浏览器专用库在原生环境无法运行

❌ 禁止5：混用平台特定组件
   错误：H5组件不使用 #ifdef H5
   错误：在H5中导入 App组件
   原因：会导致运行时错误

❌ 禁止6：修改已存在组件的位置
   错误：将 common/AppButton.vue 移动到 h5/
   原因：会破坏现有引用

❌ 禁止7：在组件文件中硬编码平台判断
   错误：if (uni.getSystemInfoSync().platform === 'ios')
   正确：使用 isH5(), isApp() 等工具函数
   原因：统一的平台检测工具更可靠
```

## 8️⃣ 平台适配开发指南

### 8.1 阶段一（数据契约与API层）

**通常不需要平台适配**：
- ✅ 类型定义（`src/types/`）：跨平台通用
- ✅ 大部分API封装（`src/api/`）：使用统一的request工具

**极少数需要适配的情况**：
```typescript
// 文件上传API需要平台适配
import { isH5, isApp } from '@/utils/platform';

export const uploadFile = (file: File | string) => {
  if (isH5()) {
    // H5上传逻辑（使用XMLHttpRequest或FormData）
    return uploadFileH5(file);
  } else if (isApp()) {
    // App上传逻辑（使用uni.uploadFile）
    return uploadFileApp(file);
  }
};
```

**需要注意平台适配**：
- ⚠️ 创建组件时参考决策流程
- ⚠️ 优先创建通用组件
- ⚠️ 确需平台特定功能时才分平台


## 9️⃣ 常见问题与解答

### Q1: 为什么不能在根目录创建组件？
**A**: 为了清晰地管理不同平台的组件，避免混乱。所有组件必须明确归类为通用或平台特定。

### Q2: 我需要创建一个在H5和App上都可用，但实现不同的组件怎么办？
**A**: 创建两个版本：
- `components/h5/ComponentNameH5.vue`
- `components/app/ComponentNameApp.vue`
然后在使用时通过条件编译导入对应版本。

### Q3: 如果我不确定组件应该放在哪个目录？
**A**: 遵循"通用优先"原则：
1. 先尝试创建通用组件（`common/`）
2. 如果发现使用了平台特定API或库，再移到对应平台目录
3. 参考决策树（第4节）

### Q4: 已存在的组件可以修改吗？
**A**: 可以修改组件内容，但**不能**：
- 移动组件位置
- 重命名组件
- 删除组件（除非确认没有任何引用）

### Q5: 我在阶段二创建了新组件，需要更新这个文档吗？
**A**: 是的，建议在 `1.3 已存在的组件清单` 中添加新组件，方便后续开发者参考。
