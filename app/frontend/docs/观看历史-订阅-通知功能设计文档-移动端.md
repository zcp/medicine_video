## 3. 前端开发规范

### 3.1 代码规范（继承全局规范）
- **TypeScript优先**：所有新增页面、组件、API调用必须使用 TypeScript，类型定义与后端接口保持一致
- **组件化开发**：观看历史、订阅、通知等功能拆分为独立组件，支持复用和单元测试
- **统一命名**：
  - 页面：`watch-history.vue`、`subscriptions.vue`、`notifications/index.vue`
  - 组件：`HistoryCard.vue`、`SubscribeButton.vue`、`NotificationItem.vue`
  - API：`api/watch-history.ts`、`api/subscriptions.ts`、`api/notifications.ts`
- **注释规范**：所有接口调用、复杂业务逻辑、B站UI参考部分需有详细中文注释

### 3.2 数据安全与隐私规范
- **观看历史脱敏**：观看历史仅本人可见，禁止上传用户隐私数据到日志/埋点
- **订阅数据保护**：订阅列表、通知内容需加密传输（HTTPS），本地存储采用加密缓存
- **敏感操作二次确认**：清空观看历史、取消订阅等操作需弹窗二次确认
- **日志脱敏**：前端日志禁止记录用户手机号、身份证、病例号等敏感信息

### 3.3 性能与体验优化
- **虚拟列表**：观看历史、通知列表等长列表采用虚拟滚动，单次渲染≤50条
- **分页加载**：每页20条，下拉刷新+上拉加载更多，支持骨架屏
- **缓存策略**：观看历史、订阅列表等数据缓存5分钟，减少接口请求
- **图片懒加载**：封面图、头像等采用懒加载，离屏图片延迟加载
- **弱网优化**：网络异常时展示缓存数据，提供"重试"按钮

## 4. 前端异常处理规范

### 4.1 网络异常
- **接口超时**：统一弹窗提示"网络请求超时，请重试"，提供"重试"按钮
- **接口异常**：根据后端返回错误码展示对应提示（如"观看历史加载失败"）
- **断网处理**：展示缓存数据并顶部提示"当前网络不可用，显示为缓存数据"

### 4.2 业务异常
- **空数据状态**：观看历史/订阅列表为空时展示友好空状态图+引导文案
- **删除失败**：删除观看历史/通知失败时Toast提示，数据回滚
- **订阅冲突**：重复订阅时提示"已订阅该直播间"

### 4.3 全局异常捕获
- 在 `App.vue` 中注册全局错误处理，捕获未处理异常并上报
- 重要操作（删除历史、清空订阅等）失败后自动刷新页面状态

## 5. 前端设计概述

### 5.1 功能模块概述

#### 5.1.1 观看历史模块

**核心功能**：
- ✅ 记录用户观看过的直播场次（基于 session_id）
- ✅ 分组展示：今天、昨天、更早（按watched_at时间聚合）
- ✅ 去重显示：同一场次仅显示最后一次观看记录（`is_latest=true`）
- ✅ 观看进度追踪：仅回放状态显示进度条（直播中无进度）
- ✅ 支持删除单条历史记录、清空全部历史
- ✅ 支持下拉刷新、上拉加载更多

**页面入口**：
- 我的页面 → "观看历史"菜单项

**现有页面状态**：
- 🔴 **文件路径**：[watch-history/index.vue](src/pages/app/tabbar/my/watch-history/index.vue)
- 🔴 **当前状态**：PlaceholderPage 占位页面（"观看历史功能即将上线"）
- ✅ **改造策略**：删除占位组件，在现有页面上实现完整功能

**技术要点**：
- 虚拟列表渲染，单次渲染≤50条
- 封面图懒加载，离屏图片延迟加载
- 观看进度实时同步（30秒上报一次）

#### 5.1.2 订阅管理模块

**核心功能**：
- ✅ 订阅预告状态的直播场次（Session，scheduled状态）
- ✅ 直播开播时推送通知（后端定时任务触发）
- ✅ 三标签分类管理（待开播、已通知、已过期）
  - **待开播**：`session.start_time > 当前时间 && session.status === 'scheduled'`
  - **已通知**：`session.start_time <= 当前时间 <= session.end_time && session.status === 'live'`
  - **已过期**：`session.end_time < 当前时间 && session.status === 'ended'`
- ✅ 订阅列表管理（Tab切换、取消订阅）
- ✅ 清除历史订阅（清除"已通知"和"已过期"状态）

**重要说明**：
- ❌ **错误理解**：订阅Room（直播间）或Expert（专家）
- ✅ **正确实现**：订阅Session（场次），因为一个Room可以有多个Session
- 🔴 **现有页面**：[subscriptions/index.vue](src/pages/app/tabbar/my/subscriptions/index.vue) 当前错误显示关注的专家列表，需重构为订阅的场次列表

**页面入口**：
- 我的页面 → "我的订阅"菜单项
- 直播间详情页（预告状态）→ "订阅开播提醒"按钮

**技术要点**：
- 订阅状态前端Mock（pending/notified/expired），后端补充后替换
- 订阅成功后Toast提示，列表实时更新
- 支持批量取消订阅

#### 5.1.3 通知中心模块

**核心功能**：
- ✅ 统一展示所有通知（订阅开播提醒、系统通知、互动通知）
- ✅ **单页面三标签切换**（参考B站）：订阅通知 / 系统通知 / 互动通知
- ✅ 顶部"全部已读"按钮（仅标记已读，不删除通知）
- ✅ 未读消息标记（红点徽章、未读数量）
- ✅ 通知详情查看、左滑删除、标记已读
- ✅ 30秒轮询机制 + 手动下拉刷新

**页面入口**：
- 首页右上角 → 🔔 图标（快捷入口）
- 我的页面 → "通知"菜单项

**现有页面状态**：
- 🔴 **文件路径**：[message/index.vue](src/pages/app/message/index.vue)
- 🔴 **当前状态**：PlaceholderPage 组件（"消息功能正在开发中"）
- ✅ **改造策略**：删除PlaceholderPage，实现单页面Tab切换布局

**UI设计参考**：
- 🎨 完全参考B站移动端消息页面
- 🎨 单页面三标签切换，无需新建子页面
- 🎨 顶部"全部已读"按钮（调用 `POST /users/me/notifications/read-all`）

## 7. 交互与UI/UX设计

### 7.1 页面原型与流程图

**页面结构总览**：
- **观看历史页面**（watch-history.vue）：展示分组历史记录，支持删除、清空、跳转详情
- **我的订阅页面**（subscriptions.vue）：展示待开播/已通知订阅，支持取消、清除历史
- **通知中心页面**（notifications/index.vue）：快捷入口 + 通知列表，支持标记已读、删除
- **订阅按钮组件**（SubscribeButton.vue）：嵌入直播间详情页，预告状态显示

**页面跳转流程**：
```
我的页面 → 观看历史 → 直播间详情 → 直播观看/回放播放
我的页面 → 我的订阅 → 直播间详情 → 订阅/取消订阅
首页/我的页面 → 通知中心 → 通知详情 → 直播间详情
直播间详情页（预告） → 订阅按钮 → 订阅成功Toast → 我的订阅页面
```

### 7.2 详细页面交互流程

#### 7.2.1 观看历史页面（watch-history.vue）

**页面加载流程**：
1. 进入页面，展示骨架屏（3个卡片占位）
2. 请求 `GET /api/v1/users/me/watch-history?is_latest=true`
3. 接口返回数据后，按时间分组（今天、昨天、更早）
4. 渲染虚拟列表，每组最多显示50条
5. 下拉刷新重新请求，上拉加载更多分页数据

**交互细节**：
- **点击卡片**：跳转到直播间详情页（传递`room_id`）
- **左滑删除**：
  - 滑动露出红色删除按钮（120rpx宽）
  - 点击删除按钮 → 弹窗二次确认"确定删除该观看记录？"
  - 确认后调用 `DELETE /api/v1/users/me/watch-history/{session_id}`
  - 删除成功Toast提示，列表移除该项（带淡出动画）
- **右上角"清空全部"**：
  - 点击弹窗确认"确定清空全部观看历史？"
  - 确认后调用 `DELETE /api/v1/users/me/watch-history`（批量删除）
  - 成功后页面切换为空状态
- **空状态**：
  - 展示空状态图标 📺 + 文案"暂无观看历史，去首页看看精彩的直播吧~"
  - 提供"去首页看看"按钮，跳转到首页

**异常处理**：
- 接口加载失败：展示错误提示 + "重试"按钮
- 删除失败：Toast提示"删除失败，请重试"，数据回滚

## 🔌 API接口调用设计

### 4.1 观看历史API

#### 4.1.1 记录观看行为

**接口**: `POST /api/v1/sessions/{session_id}/watch`

**调用时机**：
- 用户进入播放页时立即调用（progress=0）
- 播放过程中每30秒调用一次（更新progress）
- 用户退出播放页时调用（保存最终进度）

**请求示例**：
```typescript
// src/api/watchHistory.ts
export async function recordWatch(sessionId: string, progress: number) {
  const extra = {
    device: uni.getSystemInfoSync().platform,
    quality: '720p'
  }
  
  return request.post(`/api/v1/sessions/${sessionId}/watch`, {
    progress,
    extra
  })
}
```

### 6.1 观看历史防抖上报

避免频繁调用API，使用防抖策略：

```typescript
// src/composables/useWatchProgress.ts
import { ref, onUnmounted } from 'vue'
import { debounce } from 'lodash-es'

export function useWatchProgress(sessionId: string, isReplay: boolean) {
  const progressTimer = ref<number | null>(null)
  
  // 防抖上报函数（30秒内多次调用只执行最后一次）
  const debouncedReport = debounce((progress: number) => {
    recordWatch(sessionId, progress)
  }, 30000)
  
  const startTracking = () => {
    if (!isReplay) return
    
    // 立即上报初始进度
    recordWatch(sessionId, 0)
    
    // 后续每30秒上报一次
    progressTimer.value = setInterval(() => {
      const currentTime = videoPlayer.currentTime
      debouncedReport(Math.floor(currentTime))
    }, 30000)
  }
  
  const stopTracking = () => {
    if (progressTimer.value) {
      clearInterval(progressTimer.value)
      // 停止时立即上报最终进度
      const finalTime = videoPlayer.currentTime
      recordWatch(sessionId, Math.floor(finalTime))
    }
  }
  
  onUnmounted(stopTracking)
  
  return { startTracking, stopTracking }
}
```

### 6.2 观看历史分组算法

```typescript
// src/utils/groupWatchHistory.ts
import dayjs from 'dayjs'

export function groupWatchHistory(items: WatchHistoryItem[]) {
  const now = dayjs()
  const groups = {
    today: [] as WatchHistoryItem[],
    yesterday: [] as WatchHistoryItem[],
    earlier: [] as WatchHistoryItem[]
  }
  
  items.forEach(item => {
    const watchedDate = dayjs(item.watched_at)
    const diffDays = now.diff(watchedDate, 'day')
    
    if (diffDays === 0) {
      groups.today.push(item)
    } else if (diffDays === 1) {
      groups.yesterday.push(item)
    } else {
      groups.earlier.push(item)
    }
  })
  
  return groups
}
```

```typescript
// src/utils/mockSubscriptionStatus.ts
import dayjs from 'dayjs'

export type SubscriptionStatus = 'pending' | 'notified' | 'expired'

export function mockSubscriptionStatus(subscription: any): SubscriptionStatus {
  const now = dayjs()
  const startTime = dayjs(subscription.room?.next_session?.start_time)
  
  if (!startTime.isValid()) {
    return 'pending'
  }
  
  if (startTime > now) {
    // 未开播
    return 'pending'
  } else if (now.diff(startTime, 'day') <= 7) {
    // 7天内已通知
    return 'notified'
  } else {
    // 已过期
    return 'expired'
  }
}

export function getSubscriptionStatusText(status: SubscriptionStatus, startTime?: string): string {
  switch (status) {
    case 'pending':
      if (startTime) {
        const time = dayjs(startTime)
        const diffDays = time.diff(dayjs(), 'day')
        if (diffDays === 0) {
          return `今天 ${time.format('HH:mm')} 开播`
        } else if (diffDays === 1) {
          return `明天 ${time.format('HH:mm')} 开播`
        } else {
          return `${time.format('MM月DD日 HH:mm')} 开播`
        }
      }
      return '待开播'
      
    case 'notified':
      return '✅ 已通知开播'
      
    case 'expired':
      return '已结束'
  }
}
```

```typescript
export function useWatchProgress(sessionId: string, isReplay: boolean) {
  const progressTimer = ref<number | null>(null)

  const debouncedReport = debounce((progress: number) => {
    recordWatch(sessionId, progress)
  }, 30000)
  
  const startTracking = () => {
    if (!isReplay) return
    
    // 立即上报初始进度
    recordWatch(sessionId, 0)
    
    // 后续每30秒上报一次
    progressTimer.value = setInterval(() => {
      const currentTime = videoPlayer.currentTime
      debouncedReport(Math.floor(currentTime))
    }, 30000)
  }
  
  const stopTracking = () => {
    if (progressTimer.value) {
      clearInterval(progressTimer.value)
      // 停止时立即上报最终进度
      const finalTime = videoPlayer.currentTime
      recordWatch(sessionId, Math.floor(finalTime))
    }
  }
  
  onUnmounted(stopTracking)
  
  return { startTracking, stopTracking }
}
```

```typescript
// src/utils/groupWatchHistory.ts
import dayjs from 'dayjs'

export function groupWatchHistory(items: WatchHistoryItem[]) {
  const now = dayjs()
  const groups = {
    today: [] as WatchHistoryItem[],
    yesterday: [] as WatchHistoryItem[],
    earlier: [] as WatchHistoryItem[]
  }
  
  items.forEach(item => {
    const watchedDate = dayjs(item.watched_at)
    const diffDays = now.diff(watchedDate, 'day')
    
    if (diffDays === 0) {
      groups.today.push(item)
    } else if (diffDays === 1) {
      groups.yesterday.push(item)
    } else {
      groups.earlier.push(item)
    }
  })
  
  return groups
}
```

```typescript
import { defineStore } from 'pinia'
import type { WatchHistoryItem } from '@/types/watch-history'
import { getWatchHistory, deleteWatchHistory, clearAllHistory } from '@/api/watchHistory'
import { groupWatchHistory } from '@/utils/groupWatchHistory'

interface WatchHistoryState {
  // 分组后的历史记录
  groupedHistory: {
    today: WatchHistoryItem[]
    yesterday: WatchHistoryItem[]
    earlier: WatchHistoryItem[]
  }
  // 原始列表
  historyList: WatchHistoryItem[]
  // 分页信息
  pagination: {
    page: number
    size: number
    total: number
    hasMore: boolean
  }
  // 加载状态
  loading: boolean
  // 刷新状态
  refreshing: boolean
}

export const useWatchHistoryStore = defineStore('watchHistory', {
  state: (): WatchHistoryState => ({
    groupedHistory: {
      today: [],
      yesterday: [],
      earlier: []
    },
    historyList: [],
    pagination: {
      page: 1,
      size: 20,
      total: 0,
      hasMore: true
    },
    loading: false,
    refreshing: false
  }),

  getters: {
    // 总记录数
    totalCount: (state) => state.historyList.length,
    
    // 是否为空
    isEmpty: (state) => state.historyList.length === 0,
    
    // 是否还有更多数据
    canLoadMore: (state) => state.pagination.hasMore && !state.loading
  },

  actions: {
    /**
     * 获取观看历史列表
     * @param refresh 是否刷新（重置分页）
     */
    async fetchHistory(refresh: boolean = false) {
      if (refresh) {
        this.refreshing = true
        this.pagination.page = 1
        this.historyList = []
      } else {
        this.loading = true
      }

      try {
        const { data } = await getWatchHistory({
          page: this.pagination.page,
          size: this.pagination.size,
          is_latest: true
        })

        // 追加或替换数据
        if (refresh) {
          this.historyList = data.items
        } else {
          this.historyList.push(...data.items)
        }

        // 更新分页信息
        this.pagination.total = data.total
        this.pagination.hasMore = this.historyList.length < data.total

        // 分组数据
        this.groupedHistory = groupWatchHistory(this.historyList)
      } catch (error) {
        console.error('获取观看历史失败:', error)
        uni.showToast({ title: '加载失败，请重试', icon: 'none' })
      } finally {
        this.loading = false
        this.refreshing = false
      }
    },

    /**
     * 加载更多
     */
    async loadMore() {
      if (!this.canLoadMore) return
      
      this.pagination.page++
      await this.fetchHistory(false)
    },

    /**
     * 删除单条历史记录
     * @param historyId 历史记录ID
     */
    async deleteHistory(historyId: string) {
      try {
        await deleteWatchHistory(historyId)
        
        // 从列表中移除
        this.historyList = this.historyList.filter(item => item.id !== historyId)
        this.pagination.total--
        
        // 重新分组
        this.groupedHistory = groupWatchHistory(this.historyList)
        
        uni.showToast({ title: '删除成功', icon: 'success' })
      } catch (error) {
        console.error('删除历史记录失败:', error)
        uni.showToast({ title: '删除失败，请重试', icon: 'none' })
        throw error
      }
    },

    /**
     * 清空全部历史记录
     */
    async clearAll() {
      try {
        await clearAllHistory()
        
        // 清空数据
        this.historyList = []
        this.groupedHistory = {
          today: [],
          yesterday: [],
          earlier: []
        }
        this.pagination.total = 0
        this.pagination.page = 1
        
        uni.showToast({ title: '已清空', icon: 'success' })
      } catch (error) {
        console.error('清空历史记录失败:', error)
        uni.showToast({ title: '清空失败，请重试', icon: 'none' })
        throw error
      }
    }
  },

  // 持久化配置（可选）
  persist: {

    strategies: [

      }
    ]
  }
})
```

```typescript
// src/utils/mockSubscriptionStatus.ts
import dayjs from 'dayjs'

export type SubscriptionStatus = 'pending' | 'notified' | 'expired'

export function mockSubscriptionStatus(subscription: any): SubscriptionStatus {
  const now = dayjs()
  const startTime = dayjs(subscription.room?.next_session?.start_time)
  
  if (!startTime.isValid()) {
    return 'pending'
  }
  
  if (startTime > now) {
    // 未开播
    return 'pending'
  } else if (now.diff(startTime, 'day') <= 7) {
    // 7天内已通知
    return 'notified'
  } else {
    // 已过期
    return 'expired'
  }
}

export function getSubscriptionStatusText(status: SubscriptionStatus, startTime?: string): string {
  switch (status) {
    case 'pending':
      if (startTime) {
        const time = dayjs(startTime)
        const diffDays = time.diff(dayjs(), 'day')
        if (diffDays === 0) {
          return `今天 ${time.format('HH:mm')} 开播`
        } else if (diffDays === 1) {
          return `明天 ${time.format('HH:mm')} 开播`
        } else {
          return `${time.format('MM月DD日 HH:mm')} 开播`
        }
      }
      return '待开播'
      
    case 'notified':
      return '✅ 已通知开播'
      
    case 'expired':
      return '已结束'
  }
}
```

### 10.6.4 埋点数据隐私规范

**禁止上报的敏感信息**：
- ❌ 手机号、身份证号、病例号
- ❌ 用户密码、Token等认证信息
- ❌ 用户真实姓名、详细地址
- ❌ 医疗诊断结果、病史等隐私数据

**允许上报的脱敏信息**：
- ✅ 用户ID（加密后的唯一标识）
- ✅ 设备信息（平台、型号、系统版本）
- ✅ 页面路径、按钮名称等交互行为
- ✅ 统计数据（观看数量、订阅数量等）
- ✅ 时间戳、时长等通用信息

**埋点数据安全规范**：
- 所有埋点数据必须经过`sanitizeParams`脱敏处理
- 埋点上报接口必须使用HTTPS加密传输
- 本地不得存储完整的埋点数据
- 定期审查埋点代码，确保无敏感信息泄露

```typescript
import { get, post, patch, del } from '@/utils/request'
import type { NotificationItem } from '@/types/notification'
import type { ApiResponse, PaginatedResponse, QueryParams } from '@/types/common'

// 获取通知列表
export const getNotifications = (params: QueryParams = {}): Promise<ApiResponse<PaginatedResponse<NotificationItem>>> => {
  return get<ApiResponse<PaginatedResponse<NotificationItem>>>('/users/me/notifications', params, { auth: true })
}

// 标记单条通知为已读
export const markNotificationRead = (notificationId: string): Promise<ApiResponse<void>> => {
  return patch<ApiResponse<void>>(`/users/me/notifications/${notificationId}/read`, {}, { auth: true })
}

// 标记所有通知为已读
export const markAllNotificationsRead = (type?: string): Promise<ApiResponse<void>> => {
  const data = type ? { notification_type: type } : {}
  return post<ApiResponse<void>>('/users/me/notifications/mark-all-read', data, { auth: true })
}

// 删除单条通知
export const deleteNotification = (notificationId: string): Promise<ApiResponse<void>> => {
  return del<ApiResponse<void>>(`/users/me/notifications/${notificationId}`, undefined, { auth: true })
}

// 清空通知
export const clearAllNotifications = (params: { notification_type?: string; is_read?: boolean } = {}): Promise<ApiResponse<void>> => {
  return post<ApiResponse<void>>('/users/me/notifications/clear-all', params, { auth: true })
}
```
