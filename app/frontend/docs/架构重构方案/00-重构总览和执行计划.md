**步骤2**：创建 App 版本

创建文件 `src/components/app/VideoPlayerApp.vue`，复制以下代码：

<details>
<summary>点击展开 VideoPlayerApp.vue 代码</summary>

```vue
<template>
  <view class="video-player-container">
    <video
      :src="src"
      :poster="poster"
      :muted="muted"
      :autoplay="false"
      :controls="true"
      :show-center-play-btn="true"
      :show-fullscreen-btn="true"
      :enable-progress-gesture="true"
      class="video-player"
      @play="onPlay"
      @pause="onPause"
      @ended="onEnded"
      @error="onError"
    ></video>
  </view>
</template>

<script setup lang="ts">
import { ref, watch } from 'vue'

interface VideoPlayerProps {
  src?: string
  poster?: string
  muted?: boolean
}

const props = withDefaults(defineProps<VideoPlayerProps>(), {
  muted: false
})

const emit = defineEmits<{
  play: []
  pause: []
  ended: []
  error: [error: any]
}>()

const onPlay = () => {
  console.log('[VideoPlayerApp] 播放开始')
  emit('play')
}

const onPause = () => emit('pause')
const onEnded = () => emit('ended')
const onError = (e: any) => {
  console.error('[VideoPlayerApp] 播放错误:', e)
  emit('error', e)
}

watch(() => props.src, (newSrc) => {
  if (newSrc) {
    console.log('[VideoPlayerApp] 视频源更新:', newSrc)
  }
})
</script>

<style scoped>
.video-player-container {
  width: 100%;
  height: 500px;
  position: relative;
  background-color: #000;
}

.video-player {
  width: 100%;
  height: 100%;
}
</style>
```
</details>

## 🆘 遇到问题怎么办？

### 问题1：页面404错误

**可能原因**：
- pages.json 路径未更新
- 组件引用路径错误

**解决方案**：
1. 检查 pages.json 中的路径是否都去掉了 `new/`
2. 检查组件导入路径是否正确

### 问题2：组件无法显示

**可能原因**：
- 组件路径错误
- easycom 配置未更新

**解决方案**：
1. 检查组件导入路径
2. 检查 pages.json 的 easycom 配置
3. 尝试使用绝对路径导入

### 问题3：播放器不工作

**可能原因**：
- H5/App 版本引用错误
- 条件编译未生效

**解决方案**：
1. 检查条件编译语法
2. 确认 `#ifdef H5` 和 `#ifdef APP-PLUS` 正确
3. 查看控制台错误信息

### 问题4：Git冲突

**解决方案**：
```bash
# 如果重构过程中出现问题，可以回退
git reset --hard backup-before-refactor

# 重新开始重构
```
