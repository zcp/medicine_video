## 🎯 迁移策略

### 第一阶段：迁移通用组件（立即执行）

**目标**：将无平台差异的组件移到 `common/` 目录

#### 操作步骤

```bash
# Windows PowerShell 命令
# 迁移通用组件
Move-Item src/components/AppButton.vue src/components/common/AppButton.vue
Move-Item src/components/ModalDialog.vue src/components/common/ModalDialog.vue
Move-Item src/components/RoomCard.vue src/components/common/RoomCard.vue
Move-Item src/components/RoomSelectionDialog.vue src/components/common/RoomSelectionDialog.vue
Move-Item src/components/UserInfoHeader.vue src/components/common/UserInfoHeader.vue
```

#### 更新导入路径

**需要更新的文件**：
- 所有引用这些组件的页面文件
- `pages.json` 中的 easycom 配置

**查找引用**：
```bash
# 在 PowerShell 中查找引用
Get-ChildItem -Path "src" -Recurse -Filter "*.vue" | Select-String -Pattern "from '@/components/AppButton'"
Get-ChildItem -Path "src" -Recurse -Filter "*.vue" | Select-String -Pattern "from '@/components/RoomCard'"
# ... 对每个组件执行
```

**更新导入示例**：
```typescript
// ❌ 旧的导入路径
import AppButton from '@/components/AppButton.vue'
import RoomCard from '@/components/RoomCard.vue'

// ✅ 新的导入路径
import AppButton from '@/components/common/AppButton.vue'
import RoomCard from '@/components/common/RoomCard.vue'
```

**更新 pages.json（如果使用了 easycom）**：
```json
{
  "easycom": {
    "autoscan": true,
    "custom": {
      "^uni-(.*)": "@dcloudio/uni-ui/lib/uni-$1/uni-$1.vue",
      "^App(.*)": "@/components/common/App$1.vue",       // ✅ 更新路径
      "^Modal(.*)": "@/components/common/Modal$1.vue"    // ✅ 更新路径
    }
  }
}
```
