## 一、背景与结论先行

### 1.1 需求来源

项目 App/小程序端存在多种底部弹窗交互（时间滚轮、短枚举、半屏列表选择、操作菜单），经排查发现其来源、样式、主题语言高度碎片化：同一"选标签"交互在两页外观不同，同一"选日期"交互在本页用系统滚轮、另页用第三方组件，用户体感为"不像同一个产品"。需统一治理为**边界清晰的单语言体系**，且不牺牲已投入的 `--home-*` 青绿设计语言与 B 站风格搜索胶囊。

### 1.2 核心结论（三轮分析合并）

**现状定性：不是"丑到不能用"，而是"4 套来源 + 5 种交互 + 3 套主题语言并存、旧实现未收敛"。**

| # | 结论 | 依据 | 影响 |
|:-:|------|------|------|
| 1 | App 端弹窗存在 **4 类来源**：自研组件、uni-app 原生 `<picker>`/`showActionSheet`、wot-design-uni（1 处）、自研内联复制 | 全仓核查（详见第二章） | 统一治理对象 |
| 2 | 长列表选择面板存在 **4 份近似实现**（ScrollablePickerSheet 蓝色旧版 / TargetSelector / TabManager 面板 / edit 内联），其中后 3 份是同一份代码复制了 3 次 | `components/` + 页面级代码对照 | **收敛为 1 个共享组件是最高性价比改造** |

## 二、现状盘点

### 2.1 功能分类（5 大类交互，非 1 种"底部弹窗"）

| 功能类 | 用户在做什么 | 主流形态 | 现状实现 |
|---|---|------|---------|
| **A. 短枚举选择** | 2-10 个固定选项选 1（角色/状态/分类/严重度） | 底部滚轮 / ActionSheet | 原生 `<picker mode="selector">` 12+ 处 + users 角色居中卡片 1 处 |
| **B. 日期时间选择** | 选日期 / 年月日时分 | 底部滚轮 + 取消/确定 | 原生 `<picker mode="multiSelector">` 3 处 + wd-datetime-picker 2 处 |
| **C. 长列表资源选择** | 从专家/品牌/直播间/标签业务列表选（可搜/单多选） | 半屏 Sheet + 搜索 + 勾选 | 4 份自研面板（见 2.3） |
| **D. 上下文操作菜单** | 编辑/删除/分享等 | 系统 ActionSheet | 原生 `showActionSheet` 7 处 + users 角色错位 1 处 |
| **E. 表单/确认容器** | 新建/编辑整段表单 | 居中 Dialog（非底部 Sheet） | 自研 `ModalDialog`（管理页），与 A/B/C 叠用 |

### 2.2 样式族归类（现存 5 套"长相"）

| 样式族 | 长相 | 实现 | 主题 |
|--------|------|------|------|

## 三、目标规范

### 3.1 z-index 章程（四档，写 AGENTS.md，P0 起草）

| 档 | 值 | 归属 | 铁律 |
|:---:|:---:|------|------|
| 居中 Dialog | **1000** | ModalDialog | 不变 |
| 页面级底部 Sheet | **2000** | 共享 Sheet、TargetSelector 弹层 | 不变 |
| wd 弹层 | **3000**（显式传入） | 所有 wd-picker/datetime-picker 等 | **禁止依赖库默认 10/15**；若 3000 仍受父级 stacking context 限制（Dialog 内嵌场景）→ 补 `root-portal` 兜底 |
| 全屏 | **9999** | AvatarPreview 等 | 不变 |

### 3.2 wot 主题接入（P0，只动 1 个 token）

```scss
/* src/common/uni.scss :root 追加（与 --home-* 同源手段） */
--wot-color-theme: #0F766E;   /* wot 全库主题色 → 品牌青绿 */
```

- **首版仅此 1 个 token**；圆角/分割线/字重等 `--wot-*` 不映射，避免两套体系抢戏；映射表随使用扩展
- 验证方式：打开 featured 日期弹层，确认按钮/选中高亮已变青绿（**看渲染结果，非仅看变量写入**）；若某端编译未生效 → 兜底追加 `page {}` 选择器
- `loadingColor` prop 默认仍 `#4D80F0`（不随主题变量），转圈仍蓝时在 create/edit/featured 显式传 `loading-color="#0F766E"`，不扩映射表

### 3.3 共享底部选择 Sheet 组件规范（P1 新建）

**契约分层（防 API 胖化，三层）：**

```
① 壳层（纯 UI）：遮罩 rgba(0,0,0,.45) + 底部面板（max-height 70vh）+ 顶部圆角 var(--home-r-lg)
   + 标题栏（左标题/右✕）+ 0.25-0.3s 滑入滑出 + z-index:2000 + env(safe-area-inset-bottom)
② 列表能力层：single / multiple(toggle) / max / 已选计数 N / ✓ 勾选（可取消）/
   完成条「完成（已选 N/5）」（仅 multiple）+ 可选头像行（ProxyAvatarImage）/ 副标题 /
   可选搜索（.app-search-field 胶囊 + ClearButton，本地过滤由页面注入）
③ 数据层（外置）：items 进；@search/@select/@confirm 出——远程搜索、分页、数据获取全部放页面，
   组件不写死任何业务
```

**视觉语言**：`--home-*` token（bg/card/text1/text2/border/primary/pill 圆角）；满员（=max）时未选项置灰不可勾选；multiple 完成条文案 `完成（已选 {{n}}/{{max}}）`；单选可保留"点选即关"或"完成关闭"两种壳行为（配置项）。

### 3.4 时间统一规范（P0）

- create/edit 用 `wd-datetime-picker`，`type="datetime"`（默认）、`use-second=false`（默认）、min/maxDate 按业务传**时间戳**（开播时间须 > 当前）
- 契约转换收敛到 `src/utils/datetime.ts`（新增 timestamp↔ISO、wd v-model 适配 helper），页面只做绑定
- end_time 语义：**可清空**（编辑态可清空结束时间，产品文案与 featured「长期有效」占位不同，单独验收）

### 3.5 标签交互统一规范（P1）

- 两页（create/edit）统一为 **toggle 面板**：列表展示全部标签（含已选）、点选勾 ✓/再点取消、max=5、满员未选项置灰、完成条 N/5
- 页面层 chips 保留（删除快捷入口），与面板勾选实时联动
- **不做两步迁移**（先保追加再开 toggle 会让 create 迁两次）
