## 清单 B：编辑页（Gate 4）——目标页面：我的直播 → 某房间 → 编辑（标签作用于最新场次）

### B1 回显
- [ ] 进入编辑页，标签区显示该场次已绑标签 chips；专用场次（无标签）显示空态
- [ ] 观察项：标签计数格式 `N/5`

### B2 防误清空双闸
- [ ] 不触碰标签，仅修改房间标题 → 保存 → 「保存成功」返回
- [ ] 重进编辑 → 原标签状态与保存前完全一致（未误清空）

### B3 点选已有词（不触发 resolve）
- [ ] 「添加标签」→ 面板输入已有词前缀 → 出现联想列表 → **点选** → chip 落
- [ ] 保存成功；重进编辑 → 该词回显正常
- [ ] 观察项：全程无 resolve 请求副作用（新词未在词表产生重复）

### B4 resolve 新建
- [ ] 面板输入无匹配词「验收词B-<日期>」→ 出现「创建并使用」行 → 点击
- [ ] 预期：chip 落 + （首次创建）轻提示「已添加新标签」
- [ ] 保存成功 → 重进编辑回显该词 【登记 T：resolve 返回的 tag id】
- [ ] 读侧闭环：再次打开添加面板输入该词前缀 → 联想可见（公共词表立即可联想）

### B5 复用不重复
- [ ] 再次输入同名「验收词B-<日期>」→ 只显点选不显创建行（或复用 created=false）→ 不产生重复 chip、词表无重复词

### B6 违禁词
- [ ] 输入「根治」→ 创建不可用（422 toast「内容未通过审核…」固定文案）→ **不落 chip**、不产生数据

### B7 上限 5
- [ ] 累计加满 5 个 chip → 计数 `5/5`、出现满员提示、加号/输入受限；再点「创建并使用」被拦截提示

### B8 清空语义（还原专用场次）
- [ ] 删光全部 chip → 保存 → 「保存成功」
- [ ] 重进编辑 → 标签区为空（后端已清空，`replace []` 生效）
- [ ] 结果：专用场次还原为"无标签"初始态（无需 SQL 清 session_tags）

### B9 4001 剔除路径（可选，工程较繁琐；嫌繁琐可跳过并以 B8 后直接验收通过为准）
- [ ] 编辑页打开并加载完成（已选词 X 在 chip 中）→ 不保存
- [ ] 切 admin_yu：将词 X 停用（登记 T）
- [ ] 回编辑页改动任意标签 → 保存
- [ ] 预期二选一：① 自动剔除 X 并提示「部分标签已停用，已自动移除」→ 重试成功；② 词表拉取异常场景 → 「房间其他修改已保存，标签保存失败，请重试」且**停留页面**（不返回）
- [ ] 收尾：admin 恢复词 X 启用（或按台账清理）【登记 T】

### B10 legacy >5（可选，依赖 I0-5 探查结论 / dev DB 夹具）
- [ ] 若无 >5 存量夹具 → 勾"跳过"（防御拦截代码已就位，I4-5 已实现：回显正常、不可新增、保存被拦截提示）
- [ ] 若有夹具 → 编辑超限场次：正常展示全部 chips → 尝试新增被限 → 保存被拦截「最多 5 个标签，请先删除多余标签」→ 删除至 ≤5 后可保存

## 清单 C：管理端（Gate 5）——目标页面：admin_yu → 我的 → 管理后台 → 标签管理

### C1 列表回归
- [ ] 「全部 / 已启用 / 已禁用」三个 Tab 切换正常
- [ ] 分页下拉加载正常；搜索框输入名称关键词回车 → 结果过滤正确、清除后恢复
- [ ] 行内「停用/启用」按钮与「编辑」入口仍可用

### C2 治理徽章与溯源
- [ ] 历史/Admin 建的词显示「运营」徽章（青绿描边）
- [ ] 用户 resolve 词（如 B4 的「验收词B-<日期>」）显示「用户自建」徽章（灰色）
- [ ] 有 created_by 的行显示「创建者: <前8位>」；无 created_by 的行不显示该行

### C3 停用二次确认（用专用词，勿动真实运营词）
- [ ] 先新建专用词「验收停用词C-<日期>」（预期「运营」徽章）【登记 T】
- [ ] 点「停用」→ 弹确认框（文案含"不再出现在标签联想与场次绑定中"）→ **先点取消**：无任何变化
- [ ] 再点「停用」→ 确认 → toast「已停用」；该词移出「已启用」、进入「已禁用」Tab

### C4 停用即时失效（读侧闭环）
- [ ] an_test 端创建直播 → 添加标签 → 输入「验收停用词C-<日期>」→ **联想不出现**（公开接口只回启用词）
- [ ] 该词亦不可被绑定（联想不可达即验证充分）

### C5 启用恢复
- [ ] admin 对「验收停用词C-<日期>」点「启用」→ 确认 → toast「已启用」
- [ ] an_test 端再次联想该词 → 恢复可见
- [ ] 收尾：按台账处理该专用词（恢复后保留可接受，或由后端侧按台账 SQL 硬删）【登记 T】

### C6 重名冲突
- [ ] 「新增标签」输入与现有词相同的名称 → 保存 → toast 后端错误信息（4001，request 层统一提示）→ 列表无重复词产生

### C7 编辑回归
- [ ] 对任一「运营」词执行编辑（改名/描述）→ 保存成功 → 列表更新正常
