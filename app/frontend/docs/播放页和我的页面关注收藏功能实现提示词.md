### 核心设计：Pinia Store状态管理

**为什么使用Pinia Store？**

1. **性能优化**：
   - 用户登录后，一次性获取收藏和关注列表
   - 缓存到Pinia Store中
   - 播放页直接从Store读取，**无需请求API**
   - 减少60%的API请求次数

2. **状态同步**：
   - 所有页面共享同一个Store
   - 操作后自动同步到所有页面
   - 无需手动刷新

3. **用户体验**：
   - 播放页加载更快（从700ms降到500ms）
   - 收藏列表页加载更快（从400ms降到100ms）
   - 状态实时更新

**实现原理**：
```
用户登录
  ↓
加载收藏和关注列表（只请求一次）
  ↓
缓存到Pinia Store
  ↓
播放页从Store读取状态（0次API请求）
  ↓
用户收藏/取消收藏
  ↓
同时更新后端和Store
  ↓
所有页面自动同步
```

### ⚠️ 重要说明：收藏状态检查方案

**后端API现状**：
- 后端**当前未提供**单独的检查收藏状态API（如 `GET /favorites/{room_id}/check`）
- **已反馈给后端团队**，待后续补充
- 只提供了获取收藏列表API：`GET /api/v1/users/me/favorites`

**前端实施方案：使用Pinia Store缓存（推荐）**

```typescript
// favoriteStore.ts - 收藏状态管理
export const useFavoriteStore = defineStore('favorite', () => {
  const favoriteRoomIds = ref<Set<string>>(new Set());
  const favoriteList = ref<any[]>([]);
  const loaded = ref(false);
  
  // 用户登录后调用一次，加载收藏列表
  async function loadFavorites(force = false) {
    if (loaded.value && !force) return; // 使用缓存
    
    const res = await getFavorites({ page: 1, size: 100 });
    const items = res.data?.items || [];
    
    favoriteList.value = items;
    favoriteRoomIds.value = new Set(items.map(item => item.room_id));
    loaded.value = true;
  }
  
  // 播放页直接调用此方法，从缓存读取（0次API请求）
  function isFavorited(roomId: string): boolean {
    return favoriteRoomIds.value.has(roomId);
  }
  
  // 添加收藏（同时更新后端和缓存）
  async function addFavorite(roomId: string) {
    await addFavoriteApi({ room_id: roomId });
    favoriteRoomIds.value.add(roomId);
  }
  
  // 取消收藏（同时更新后端和缓存）
  async function removeFavorite(roomId: string) {
    await removeFavoriteApi(roomId);
    favoriteRoomIds.value.delete(roomId);
    favoriteList.value = favoriteList.value.filter(item => item.room_id !== roomId);
  }
  
  return { favoriteRoomIds, favoriteList, loadFavorites, isFavorited, addFavorite, removeFavorite };
});
```

**方案优势**：
- ✅ **性能优化**：播放页从Store读取，0次API请求
- ✅ **状态同步**：所有页面自动同步，无需手动刷新
- ✅ **用户体验**：播放页加载更快（从700ms降到500ms）
- ✅ **实现简单**：纯前端实现，不需要后端支持

**后端API补充后的优化**：
- 待后端补充 `GET /favorites/{room_id}/check` API后
- 可以进一步优化为直接调用检查API
- 但当前Pinia Store方案已经性能很好

**实现原理**：
```
用户登录 → 加载收藏列表（1次API请求）→ 缓存到Store
  ↓
打开播放页 → 从Store读取状态（0次API请求）→ 显示收藏图标
  ↓
用户点击收藏 → 调用API + 更新Store → 所有页面自动同步
```

```typescript
/**
 * 收藏Store
 * 管理用户的收藏状态，减少API请求
 */

import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import { getFavorites, addFavorite as addFavoriteApi, removeFavorite as removeFavoriteApi } from '@/api/favorite';
import type { FavoriteWithRoom } from '@/types/favorite';

export const useFavoriteStore = defineStore('favorite', () => {
  // ========== 状态 ==========
  
  /** 收藏的直播间ID集合（用于快速查询） */
  const favoriteRoomIds = ref<Set<string>>(new Set());
  
  /** 完整的收藏列表（用于收藏列表页显示） */
  const favoriteList = ref<FavoriteWithRoom[]>([]);
  
  /** 是否正在加载 */
  const loading = ref(false);
  
  /** 是否已加载过（避免重复加载） */
  const loaded = ref(false);
  
  // ========== 计算属性 ==========
  
  /** 收藏数量 */
  const favoriteCount = computed(() => favoriteRoomIds.value.size);
  
  // ========== 方法 ==========
  
  /**
   * 加载收藏列表
   * @param force 是否强制刷新（忽略缓存）
   */
  async function loadFavorites(force: boolean = false) {
    // 如果已加载且不强制刷新，则跳过
    if (loaded.value && !force) {
      console.log('[FavoriteStore] 使用缓存数据');
      return;
    }
    
    if (loading.value) {
      console.log('[FavoriteStore] 正在加载中，跳过');
      return;
    }
    
    loading.value = true;
    
    try {
      console.log('[FavoriteStore] 开始加载收藏列表');
      
      // 获取所有收藏（最多100条）
      const res = await getFavorites({ page: 1, size: 100 });
      const items = res.data?.items || [];
      
      // 更新收藏列表
      favoriteList.value = items;
      
      // 更新ID集合（用于快速查询）
      favoriteRoomIds.value = new Set(items.map(item => item.room_id));
      
      // 标记已加载
      loaded.value = true;
      
      console.log('[FavoriteStore] 收藏列表加载完成:', items.length, '个');
    } catch (error) {
      console.error('[FavoriteStore] 加载收藏列表失败:', error);
      throw error;
    } finally {
      loading.value = false;
    }
  }
  
  /**
   * 检查是否已收藏某个直播间
   * @param roomId 直播间ID
   * @returns 是否已收藏
   */
  function isFavorited(roomId: string): boolean {
    return favoriteRoomIds.value.has(roomId);
  }
  
  /**
   * 添加收藏
   * @param roomId 直播间ID
   */
  async function addFavorite(roomId: string) {
    try {
      console.log('[FavoriteStore] 添加收藏:', roomId);
      
      // 调用API
      const res = await addFavoriteApi({ room_id: roomId });
      
      // 更新Store
      favoriteRoomIds.value.add(roomId);
      
      // 如果有完整数据，也添加到列表中
      if (res.data) {
        favoriteList.value.unshift(res.data as any);
      }
      
      console.log('[FavoriteStore] 收藏成功');
    } catch (error: any) {
      console.error('[FavoriteStore] 收藏失败:', error);
      
      // ===== 关键修复：正确处理错误码 =====
      // 4001: 已收藏该直播间（后端返回的实际错误码）
      if (error.code === 4001 || error.message?.includes('已收藏')) {
        // 已收藏，同步本地状态
        favoriteRoomIds.value.add(roomId);
        console.log('[FavoriteStore] 检测到已收藏，同步状态');
        // 不抛出错误，让调用方显示成功提示
```

```typescript
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import { 
  getFollowedExperts, 
  followExpert as followExpertApi, 
  unfollowExpert as unfollowExpertApi 
} from '@/api/expertFollow';
import type { FollowedExpertItem } from '@/types/expertFollow';

export const useFollowStore = defineStore('follow', () => {
  // ========== 状态 ==========
  
  /** 关注的专家ID集合（用于快速查询） */
  const followedExpertIds = ref<Set<string>>(new Set());
  
  /** 完整的关注列表（用于关注列表页显示） */
  const followedList = ref<FollowedExpertItem[]>([]);
  
  /** 是否正在加载 */
  const loading = ref(false);
  
  /** 是否已加载过（避免重复加载） */
  const loaded = ref(false);
  
  // ========== 计算属性 ==========
  
  /** 关注数量 */
  const followCount = computed(() => followedExpertIds.value.size);
  
  // ========== 方法 ==========
  
  /**
   * 加载关注列表
   * @param force 是否强制刷新（忽略缓存）
   */
  async function loadFollowedExperts(force: boolean = false) {
    // 如果已加载且不强制刷新，则跳过
    if (loaded.value && !force) {
      console.log('[FollowStore] 使用缓存数据');
      return;
    }
    
    if (loading.value) {
      console.log('[FollowStore] 正在加载中，跳过');
      return;
    }
    
    loading.value = true;
    
    try {
      console.log('[FollowStore] 开始加载关注列表');
      
      // 获取所有关注（包含直播状态）
      const res = await getFollowedExperts(true);
      const items = res.data || [];
      
      // 更新关注列表
      followedList.value = items;
      
      // 更新ID集合（用于快速查询）
      followedExpertIds.value = new Set(items.map(item => item.expert_id));
      
      // 标记已加载
      loaded.value = true;
      
      console.log('[FollowStore] 关注列表加载完成:', items.length, '个');
    } catch (error) {
      console.error('[FollowStore] 加载关注列表失败:', error);
      throw error;
    } finally {
      loading.value = false;
    }
  }
  
  /**
   * 检查是否已关注某个专家
   * @param expertId 专家ID
   * @returns 是否已关注
   */
  function isFollowed(expertId: string): boolean {
    return followedExpertIds.value.has(expertId);
  }
  
  /**
   * 关注专家
   * @param expertId 专家ID
   */

      console.log('[FollowStore] 关注专家:', expertId);

      await followExpertApi({ expert_id: expertId });
      
      // 更新Store
      followedExpertIds.value.add(expertId);
      
      console.log('[FollowStore] 关注成功');
    } catch (error: any) {
      console.error('[FollowStore] 关注失败:', error);
      
      // ===== 关键修复：正确处理错误码 =====
      // 4001: 已关注该专家（后端返回的实际错误码）
      if (error.code === 4001 || error.message?.includes('已关注')) {
        followedExpertIds.value.add(expertId);
        console.log('[FollowStore] 检测到已关注，同步状态');
        return;
      }
      
      // 500错误特殊处理
      if (error.statusCode === 500 || error.code === 1002) {
        console.warn('[FollowStore] 500错误，乐观更新');
        followedExpertIds.value.add(expertId);
        return;
      }
      
      throw error;
    }
  }

   * 取消关注专家

      console.log('[FollowStore] 取消关注:', expertId);
      
      // 调用API
      await unfollowExpertApi(expertId);
      
      // 更新Store
      followedExpertIds.value.delete(expertId);
      
      // 从列表中移除
      followedList.value = followedList.value.filter(item => item.expert_id !== expertId);
      
      console.log('[FollowStore] 取消关注成功');
    } catch (error) {
      console.error('[FollowStore] 取消关注失败:', error);
      throw error;
    }
  }
  
  /**
   * 清空Store（用户登出时调用）
   */
  function clear() {
    followedExpertIds.value.clear();
    followedList.value = [];
    loaded.value = false;
    console.log('[FollowStore] Store已清空');
  }
  
  // ========== 返回 ==========
  
  return {
    // 状态
    followedExpertIds,
    followedList,
    loading,
    loaded,
    
    // 计算属性
    followCount,
    
    // 方法

    isFollowed,
    followExpert,
    unfollowExpert,
    clear
  };
```

## 注意事项

### 1. 登录拦截
- 所有操作前必须检查 `isAuthenticated.value`
- 未登录时调用 `authStore.forceReauth(currentPath)`
- 使用 `requireAuth()` 工具函数统一处理

### 2. Expert ID获取
- LiveView页面需要从 `sessionInfo.expert.id` 获取专家ID
- 如果没有expert信息，关注按钮应该禁用或隐藏
- 添加空值检查，避免undefined错误

### 3. 错误处理
- API调用失败时显示友好提示
- 网络错误时不要改变UI状态
- 使用try-catch包裹所有API调用
- 处理特定错误码（2002已关注、2203未关注等）

### 4. 状态同步
- 收藏/关注后，返回列表页时应该刷新数据
- 使用 `onShow` 生命周期刷新页面数据
- 取消收藏/关注后立即从列表中移除

### 5. 性能优化
- 使用 `Promise.all` 并行检查关注和收藏状态
- 列表页使用分页加载，避免一次加载过多数据
- 图片使用懒加载（uni-app的image组件默认支持）

### 6. UI细节
- 参考B站的横向卡片布局
- 封面图比例16:9
- 时长标签显示在左下角
- 已关注/已收藏状态使用灰色
- 点击反馈使用:active伪类

### 7. Mock数据处理
- 如果后端返回的数据缺少某些字段（如department），使用Mock数据填充
- Mock数据应该合理且符合业务场景
- 在代码中添加TODO注释，标注需要后端补充的字段

### 1. 分组Tab功能实现

**文件路径**: `src/pages/app/tabbar/my/follows/index.vue`

#### 1.1 添加Tab状态管理

```typescript
const activeTab = ref<'live' | 'all'>('all');

// Tab配置
const tabs = computed(() => {
  const liveCount = followedList.value.filter(item => item.live_status?.is_live).length;
  const allCount = followedList.value.length;
  
  return [
    { key: 'live', label: '正在直播', count: liveCount },
    { key: 'all', label: '全部关注', count: allCount }
  ];
});
```

#### 1.2 Tab切换逻辑

```typescript
// 根据Tab和搜索关键词过滤列表
const filteredList = computed(() => {
  let list = followedList.value;
  
  // 按Tab过滤
  if (activeTab.value === 'live') {
    list = list.filter(item => item.live_status?.is_live);
  }
  
  // 按搜索关键词过滤
  if (searchKeyword.value) {
    const keyword = searchKeyword.value.toLowerCase();
    list = list.filter(item =>
      item.name.toLowerCase().includes(keyword) ||
      item.hospital?.toLowerCase().includes(keyword) ||
      item.department?.toLowerCase().includes(keyword)
    );
  }
  
  return list;
});

function handleTabChange(tab: 'live' | 'all') {
  activeTab.value = tab;
}
```

#### 1.3 Tab UI结构

```vue
<!-- 分组Tab -->
<view class="tabs-container">
  <view class="tabs">
    <view
      v-for="tab in tabs"
      :key="tab.key"
      class="tab-item"

      @tap="handleTabChange(tab.key as 'live' | 'all')"
    >
      <text class="tab-label">{{ tab.label }}</text>
      <text v-if="tab.count > 0" class="tab-badge">{{ tab.count }}</text>

  </view>
</view>
```

### 4. 优化的空状态引导

#### 4.1 场景化空状态文案

```typescript
// 空状态文案
const emptyTitle = computed(() => {
  if (searchKeyword.value) {
    return '未找到相关专家';
  }
  if (activeTab.value === 'live') {
    return '暂无直播中的专家';
  }
  return '暂无关注';
});

const emptyDesc = computed(() => {
  if (searchKeyword.value) {
    return '试试其他关键词';
  }
  if (activeTab.value === 'live') {
    return '关注的专家暂未开播';
  }
  return '快去关注你喜欢的专家吧';
});
```

### 5. 路径配置修复

**问题**：在 `src/pages/app/tabbar/my/index.vue` 中，关注功能的入口路径配置错误。

**修复前**：
```typescript
{ 
  key: 'follow', 
  icon: 'icon-user', 
  label: '关注', 
  badge: userStats.value.follow_count || 0, 
  path: '/pages/app/tabbar/expert/index',  // ❌ 错误路径
  requireAuth: false 
}
```

**修复后**：
```typescript
{ 
  key: 'follow', 
  icon: 'icon-user', 
  label: '关注', 
  badge: userStats.value.follow_count || 0, 
  path: '/pages/app/tabbar/my/follows/index',  // ✅ 正确路径
```
