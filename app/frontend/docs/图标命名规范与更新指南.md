## 项目图标命名规范

### 规范原则

1. **使用连字符命名**（kebab-case）
   ```css
   .icon-arrow-left   ✅ 正确
   .icon-arrowleft    ❌ 错误
   ```

2. **语义化命名**
   - 描述图标功能，而非外观
   - 例如：`icon-delete`（删除）而非 `icon-trash`（垃圾桶）

3. **状态区分**
   - `-filled`：实心/填充状态
   - `-outline`：空心/线框状态
   - `-active`：激活状态
   ```css
   .icon-star-outline   /* 空心星星 */
   .icon-star-filled    /* 实心星星 */
   ```

4. **方向标识**
   - `-left`, `-right`, `-up`, `-down`
   ```css
   .icon-arrow-left
   .icon-arrow-right
   ```

5. **向后兼容**
   - 保留旧名称作为别名
   ```css
   .icon-arrowdown:before,
   .icon-arrow-down:before {
     content: "\e692";
   }
   ```

## 需要添加的图标清单

### 高优先级（必需）
✅ **已完成**：
1. **icon-eye-slash** - 眼睛+斜线（密码隐藏） - Unicode: `\e777`

5. **icon-check** / **icon-success** - 成功/对勾

## 如何更新图标

### 步骤1：在 iconfont.cn 添加图标
1. 访问项目：https://www.iconfont.cn/manage/index?manage_type=myprojects&projectId=5133124
2. 搜索并添加以下图标：
   - 搜索关键词：`eye slash` 或 `eye off`
   - 选择风格与现有图标一致的版本
3. 点击"下载代码"

### 步骤2：替换字体文件
将下载的文件复制到项目：
```bash
src/static/fonts/
  ├── iconfont.css      # 覆盖
  ├── iconfont.ttf      # 覆盖
  ├── iconfont.woff     # 覆盖
  └── iconfont.woff2    # 覆盖
```

### 步骤3：规范化命名
下载后的 `iconfont.css` 可能包含不规范的类名，需要手动调整：

**调整前**（iconfont默认命名）：
```css
.icon-eye-off:before {
  content: "\e999";
}
```

**调整后**（项目规范命名）：
```css
/* 眼睛+斜线（隐藏密码） */
.icon-eye-off:before,
.icon-eye-slash:before,
.icon-eye-closed:before {
  content: "\e999";
}
```

### 步骤4：更新图标清单
在本文档的"完整图标清单"部分添加新图标信息。

## 代码使用示例

### Vue模板中使用
```vue
<!-- 密码可见性切换 -->
<text 
  class="iconfont" 
  :class="showPassword ? 'icon-eye-slash' : 'icon-eye'"
  @click="togglePassword"
></text>

<!-- 收藏按钮 -->
<text 
  class="iconfont" 
  :class="isCollected ? 'icon-star-filled' : 'icon-star-outline'"
  @click="toggleCollect"
></text>

<!-- 点赞按钮 -->
<text 
  class="iconfont" 
  :class="isLiked ? 'icon-like-filled' : 'icon-like-outline'"
  @click="toggleLike"
></text>
```

### SCSS样式中使用
```scss
.password-icon {
  font-size: 40rpx;
  color: #0F766E;
  
  &.icon-eye,
  &.icon-eye-slash {
    cursor: pointer;
    transition: opacity 0.2s;
    
    &:active {
      opacity: 0.7;
    }
  }
}
```

## 注意事项

1. **更新前备份**
   ```bash
   cp -r src/static/fonts src/static/fonts.backup
   ```

2. **清除缓存**
   更新字体文件后需要：
   - 清除浏览器缓存
   - 重启开发服务器
   - 重新编译uni-app

3. **跨平台测试**
   字体图标在不同平台可能有渲染差异，需测试：
   - H5浏览器
   - 微信小程序
   - Android/iOS App

4. **图标大小建议**
   ```scss
   .iconfont {
     font-size: 32rpx;  // 小图标（TabBar）
     font-size: 40rpx;  // 中图标（输入框）
     font-size: 48rpx;  // 大图标（按钮）
   }
   ```
