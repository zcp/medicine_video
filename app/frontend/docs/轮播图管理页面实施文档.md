# 轮播图管理页面实施文档

> **文件**：`src/pages/app/admin/featured/index.vue`
> **角色**：首页运营位配置后台
> **对象**：焦点图（`featured_content`）
> **实施日期**：2026-07-26
> **实施方式**：单阶段实施（无分页/无筛选/无 Tab，列表简单）
> **最后更新**：2026-07-28 — 顶栏布局优化，按钮统一

---

## 一、页面定位

| 维度 | 说明 |
|------|------|
| 核心问题 | "首页的 banner 应该展示什么内容？顺序怎么排？跳转到什么页面？" |
| 使用者 | 运营人员 |
| 频率 | 中低频（焦点图更新频率低，通常 5-10 张） |
| 依赖关系 | 可关联房间/场次/专题/品牌/专家/外部链接等多种目标类型 |
| 入口 | "我的"页面 → 管理功能菜单 → "轮播图管理" |

### 与其他管理页面的职责划分

| 页面 | 管理对象 | 核心操作 |
|------|---------|---------|
| 专家分类管理 | 科室（`expert_departments`） | 创建/审核/合并/删除科室 |
| 专家管理 | 专家（`experts`） | 审核/分配科室/编辑/删除/导入专家 |
| **轮播图管理（本页）** | 焦点图（`featured_content`） | 创建/编辑/删除/排序焦点图 |

### 与前两个管理页面的关键差异

| 维度 | 专家分类管理 | 专家管理 | 轮播图管理 |
|------|:--:|:--:|:--:|
| 分页 | ✅ 20/页 | ✅ 20/页 | ❌ 全量返回 |
| 筛选栏 | 搜索+分类 | 搜索+分类+科室 | ❌ 无 |
| Tab 切换 | 2 个 | 3 个 | 0 个 |
| 数据源 | 1 个 API | 2 个 API | 1 个 API |
| 卡片风格 | 文字行 | 头像+文字 | **大图封面** |
| 总数 | 通常 20-100+ | 通常 50-500+ | **通常 5-10** |

## 三、功能清单

| # | 功能 | API 函数 | 后端端点 |
|:--:|------|------|------|
| 1 | 轮播图列表（全量） | `getFeaturedContent()` | `GET /featured-content` |
| 2 | 创建轮播图 | `createFeaturedContent()` | `POST /admin/featured-content` |
| 3 | 编辑轮播图 | `updateFeaturedContent()` | `PATCH /admin/featured-content/{id}` |
| 4 | 删除轮播图 | `deleteFeaturedContent()` | `DELETE /admin/featured-content/{id}` |
| 5 | 下拉刷新 | 重新调用 `getFeaturedContent()` | 同 1 |
| 6 | 图片加载兜底 | 纯前端（`coverErrors` Set） | — |

### 表单字段

| 字段 | 必填 | 类型 | 控件 | 说明 |
|------|:--:|------|------|------|
| `title` | ✅ | string | `<input>` | 焦点图标题 |
| `subtitle` | ❌ | string | `<input>` | 副标题 |
| `image_url` | ✅ | string | `<input>` | 图片 URL |
| `target_type` | ❌ | enum | `<picker>` | 跳转目标类型（7 选 1） |
| `target_id` | ❌ | UUID | `<input>` | 目标实体 ID（非 external 时） |
| `target_url` | ❌ | URL | `<input>` | 外部链接（external 时） |
| `cta_text` | ❌ | string | `<input>` | CTA 按钮文案 |
| `sort_order` | ❌ | number | `<input type=number>` | 排序权重 |

### 跳转目标类型枚举

| 值 | 标签 | target_id 含义 |
|------|------|------|
| `null` | 无跳转 | — |
| `room` | 房间 | 直播间 ID |
| `session` | 场次 | 场次 ID |
| `topic` | 专题 | 专题 ID |
| `brand` | 品牌 | 品牌 ID |
| `expert` | 专家 | 专家 ID |
| `external` | 外部链接 | 使用 `target_url` 字段 |

## 四、数据流

```
loadList()
  ├─ getFeaturedContent() → ApiResponse<FeaturedContent[]>
  ├─ res.data → items (全量替换，非分页追加)
  └─ 无 total/page/hasMore 概念

创建/编辑:
  ├─ handleFormConfirm → createFeaturedContent / updateFeaturedContent
  ├─ 成功后 → closeForm + loadList()

删除:
  ├─ uni.showModal 确认 → deleteFeaturedContent
  └─ 成功后 → items = items.filter(...) 本地移除（免刷新）
```

## 七、已知限制

| 限制 | 影响 | 后续计划 |
|------|------|------|
| 无拖拽排序 | 修改排序需编辑表单逐个改数字 | 后续接入拖拽排序组件 |
| 无图片本地上传 | 仅支持输入图片 URL，不能从相册选择 | 后续对接 `POST /admin/featured-content/{id}/image` |
| 无分页 | 焦点图超过 20 张时列表较长 | 当前业务场景下不构成问题 |
| 无目标实体选择器 | target_id 需手动输入 UUID | 后续对接对应实体的搜索选择器 |
