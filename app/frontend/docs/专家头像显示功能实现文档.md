# 专家头像显示功能实现文档

## 文档说明

本文档记录了 uni-app Android 端专家头像显示功能的完整实现方案，包括遇到的问题、解决思路和最终方案。

---

## 一、背景问题

### 1.1 原始需求
- 显示50+专家头像（外部URL：`https://www.fahsysu.org.cn/sites/.../*.jpg`）
- 列表页（ExpertCard）和详情页（ExpertProfile）都需要显示

### 1.2 核心问题
专家头像图片设置了**防盗链保护**，直接在 `<image>` 标签中使用外部URL会导致：
```
错误：unexpected end of stream
原因：服务器检测到请求不包含有效的 Referer 头，拒绝返回图片
```

---

## 二、解决方案演进

### 2.1 方案一：base64转码（失败）❌
**思路**：使用 uni.request 下载图片并转 base64，直接赋值给 `<image>` src
```javascript
const res = await uni.request({
  url: imageUrl,
  responseType: 'arraybuffer',
  header: {
    'Referer': 'https://www.fahsysu.org.cn'
  }
})
const base64 = uni.arrayBufferToBase64(res.data)
avatarSrc.value = `data:image/jpeg;base64,${base64}`
```

**失败原因**：
- 头像图片大小 130-300KB
- Android Image 组件对 base64 图片大小有限制
- 导致部分图片无法渲染

### 2.2 方案二：文件系统API（失败）❌
**思路**：使用 `uni.getFileSystemManager` 保存文件
```javascript
const fs = uni.getFileSystemManager()
fs.writeFile({
  filePath: `${uni.env.USER_DATA_PATH}/avatar_${Date.now()}.jpg`,
  data: buffer
})
```

**失败原因**：
- `uni.getFileSystemManager()` 在 Android APP 环境下不可用
- 此API仅适用于微信小程序

### 2.3 方案三：uni.saveFile + 路径转换（成功）✅

#### 核心流程
```
外部URL → uni.downloadFile (with headers) → tempFilePath
→ uni.saveFile → savedFilePath (_doc/uniapp_save/xxx.jpg)
→ plus.io.convertLocalFileSystemURL → /storage/emulated/0/...
→ 添加 file:// 前缀 → file:///storage/emulated/0/...
→ Image 组件加载 ✅
```

```typescript
/**
 * 转换文件路径为可用的URL格式
 * @description Android image 组件不支持相对路径，必须转换为 file:// 格式的绝对路径
 */
function normalizeFilePath(filePath: string): string {
  if (!filePath) return filePath;
  
  // 已经是完整URL，直接返回
  if (filePath.startsWith('file://') || filePath.startsWith('http://') || filePath.startsWith('https://')) {
    return filePath;
  }
  
  // APP端：所有路径都需要转换为绝对路径
  // @ts-ignore
  if (typeof plus !== 'undefined' && plus.io && plus.io.convertLocalFileSystemURL) {
    try {
      // 统一转换：相对路径通过 convertLocalFileSystemURL 处理
      // @ts-ignore
      const absolutePath = plus.io.convertLocalFileSystemURL(filePath);
      
      // convertLocalFileSystemURL 返回纯绝对路径（/storage/...），需添加 file:// 前缀
      if (absolutePath && !absolutePath.startsWith('file://')) {
        const fileUrl = 'file://' + absolutePath;
        logger.info('[ImageProxy] 路径标准化: ' + filePath.substring(0, 30) + '... -> file://...' + absolutePath.substring(absolutePath.length - 20));
        return fileUrl;
      }
      
      return absolutePath;
    } catch (e) {
      logger.error('[ImageProxy] 路径转换失败:', filePath, e);
      // 转换失败时，尝试降级处理
      if (filePath.startsWith('/')) {
        return 'file://' + filePath;
      }
      return filePath;
    }
  }
  
  // 非 APP 环境：直接返回
  return filePath;
}

/**
 * 使用代理下载图片（支持防盗链）
 */
export async function loadImageWithProxy(url: string): Promise<string | null> {
  // 检查缓存
  const cached = getFromCache(url);
  if (cached) {
    logger.info('[ImageProxy] ✅ 缓存命中');
    return cached;
  }
  
  // 避免重复请求
  if (pendingRequests.has(url)) {
    return pendingRequests.get(url)!;
  }
  
  const promise = (async () => {
    try {
      // 下载图片（带防盗链请求头）
      const downloadRes: any = await new Promise((resolve, reject) => {
        uni.downloadFile({
          url: url,
          header: {
            'Referer': 'https://www.fahsysu.org.cn',
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'
          },
          success: resolve,
          fail: reject
        });
      });
      
      if (downloadRes.statusCode !== 200) {
        throw new Error(`下载失败: ${downloadRes.statusCode}`);
      }
      
      const tempFilePath = downloadRes.tempFilePath;
      let savedFilePath = tempFilePath;
      
      // 保存到永久存储
      try {
        const saveRes: any = await new Promise((resolve, reject) => {
          uni.saveFile({
            tempFilePath: tempFilePath,
            success: resolve,
            fail: reject
          });
        });
        
        savedFilePath = saveRes.savedFilePath;
        
        // 缓存文件路径
        saveToCache(url, savedFilePath);
      } catch (e) {
        logger.warn('[ImageProxy] 保存文件失败，使用临时文件:', e);
      }
      
      // 🔥 转换路径格式为可用的URL（确保 image 组件能正确加载）
      const normalizedPath = normalizeFilePath(savedFilePath);
      
      logger.info('[ImageProxy] ✅ 图片加载成功，返回路径:', normalizedPath.substring(0, 80));
      return normalizedPath;
    } catch (e: any) {
      logger.error('[ImageProxy] ❌ 图片加载失败:', e.message);
      return null;
    } finally {
      pendingRequests.delete(url);
    }
  })();
  
  pendingRequests.set(url, promise);
  return promise;
}
```

```typescript
async function loadAvatar(url: string) {
  if (!url) {
    avatarSrc.value = DEFAULT_AVATAR;
    return;
  }
  
  const isExternal = /^https?:\/\//i.test(url);
  
  if (isExternal) {
    // 外部URL：通过代理加载
    avatarSrc.value = DEFAULT_AVATAR; // 先显示默认头像
    isLoadingProxy.value = true;
    
    try {
      const proxyUrl = await loadImageWithProxy(url);
      if (proxyUrl) {
        console.info('[ExpertCard] ✅ 头像代理成功');
        console.info('[ExpertCard] 完整路径:', proxyUrl);
        
        // 文件存在性检测（可选，用于调试）
        // @ts-ignore
        if (typeof plus !== 'undefined' && plus.io) {
          try {
            // @ts-ignore
            const realPath = proxyUrl.replace('file://', '');
            // @ts-ignore
            plus.io.resolveLocalFileSystemURL(realPath, (entry) => {
              console.info('[ExpertCard] ✅ 文件确认存在:', entry.fullPath);
            }, (e) => {
              console.error('[ExpertCard] ❌ 文件不存在或无法访问:', e.message);
            });
          } catch (e) {
            console.error('[ExpertCard] 文件检查异常:', e);
          }
        }
        
        avatarSrc.value = proxyUrl;
      }
    } catch (e) {
      console.error('[ExpertCard] 头像代理加载异常:', e);
    } finally {
      isLoadingProxy.value = false;
    }
  } else {
    // 本地URL：直接使用
    avatarSrc.value = url;
  }
}
```

## 四、技术关键点

### 4.1 为什么必须添加 file:// 前缀？

Android `<image>` 组件的路径格式要求：
- ❌ 相对路径：`_doc/uniapp_save/xxx.jpg`（不可靠）
- ❌ 绝对路径无协议：`/storage/emulated/0/.../xxx.jpg`（被拒绝）
- ✅ **File URL**：`file:///storage/emulated/0/.../xxx.jpg`（正确格式）

### 4.2 为什么详情页成功但列表页失败？

**初始化方式差异导致**：

```typescript
// 列表页（失败）
const avatarSrc = ref(props.avatar || DEFAULT_AVATAR); // 直接用外部URL初始化
// → Image组件立即尝试加载外部URL → 触发防盗链错误

// 详情页（成功）
const avatarSrc = ref(DEFAULT_AVATAR); // 用默认头像初始化
// → Image组件加载默认头像 → 异步加载完成后切换 → 成功
```

### 4.3 关键API说明

| API | 作用 | 返回值示例 |
|-----|------|-----------|
| `uni.downloadFile({url, header})` | 下载文件，支持自定义请求头 | `{tempFilePath: '_doc/tmp/xxx.jpg'}` |
| `uni.saveFile({tempFilePath})` | 保存临时文件到永久存储 | `{savedFilePath: '_doc/uniapp_save/xxx.jpg'}` |
| `plus.io.convertLocalFileSystemURL(path)` | 转换相对路径为绝对路径 | `/storage/emulated/0/.../xxx.jpg` |
| `plus.io.resolveLocalFileSystemURL(path, success, fail)` | 检查文件是否存在 | FileEntry 对象或错误回调 |

## 五、问题排查指南

### 5.1 头像显示为默认头像（灰色方块）

**可能原因**：
1. 代理下载失败（网络问题）
2. 文件保存失败（存储权限问题）
3. 路径转换失败（`plus.io` 不可用）

**排查方法**：
```javascript
// 查看控制台日志
[ImageProxy] ❌ 图片加载失败: xxx // 下载失败
[ImageProxy] 路径转换失败: xxx    // 转换失败
[ExpertCard] 头像代理加载失败    // 返回null
```

### 5.2 头像闪烁或重复加载

**可能原因**：
- 组件重复挂载/卸载
- `watch` 触发多次

**解决方法**：
```typescript
// 添加防抖或标记位
const isLoading = ref(false);

async function loadAvatar(url: string) {
  if (isLoading.value) return;
  isLoading.value = true;
  
  try {
    // 加载逻辑...
  } finally {
    isLoading.value = false;
  }
}
```

### 5.3 文件确认存在但仍显示默认头像

**可能原因**：
- 路径格式问题（缺少 `file://` 前缀）
- Image 组件缓存问题

**排查方法**：
```javascript
// 检查日志中的路径格式
[ExpertCard] avatarSrc已更新为: file:///storage/... // ✅ 正确
[ExpertCard] avatarSrc已更新为: /storage/...       // ❌ 错误，缺少 file://
```

## 七、已知限制

1. **首次加载延迟**：外部头像首次加载需要下载，会有短暂延迟
2. **存储空间占用**：50个头像约 10-15MB 存储空间
3. **缓存过期**：7天后需要重新下载
4. **网络依赖**：无网络时无法下载新头像

---

## 八、未来优化方向

1. **后端代理**：由后端提供代理接口，前端直接请求内部URL
2. **WebP 格式**：压缩图片大小，减少存储和带宽
3. **渐进式加载**：先显示低分辨率，再加载高清图
4. **离线包**：将常用专家头像打包到APP中
