  • 公开接口：无需认证即可访问
  • 请求参数：limit（默认10，最大50）
  • 返回字段：id（UUID）、name（姓名）、title（职称）、hospital（医院）、department（科室）、avatar_url（头像）、is_featured、sort_order等
  • 排序规则：按sort_order升序、created_at降序

      • 后端直连：http://124.220.235.226:8000/api/v1/featured-experts（包含v1）

⚠️ 关于头像图片CORS错误说明：

  • 控制台红色错误是正常现象：头像图片来自外部域名 www.fahsysu.org.cn，该服务器未配置允许跨域的CORS响应头
  • 不影响功能使用：图片加载失败时会自动显示专家姓名首字母占位头像（彩色圆形背景）
  • 解决方案：生产环境建议后端提供图片代理接口，避免前端直接跨域请求外部图片资源
  • 技术原因：浏览器安全策略限制跨域资源访问，虽然API数据正常返回，但图片URL无法直接加载

🔍 【新增】测试全局搜索API

📖 API路径: GET /api/v1/search
✨ 特点: 支持跨直播间、专家、专题、品牌的全局搜索，返回匹配分数和高亮文本
🎯 参数: q (关键词), type (资源类型), category_id (分类筛选), page, size

💡 API说明：

  • Endpoint：GET /api/v1/search
  • 认证：公开访问，无需JWT Token
  • 必需参数：q（搜索关键词，至少2个字符）
  • 可选参数：type（资源类型，如room,expert,topic,brand）、category_id（分类筛选）、page（页码）、size（每页数量）
  • 返回结构：分页数据（total、page、size、items）
  • 结果字段：type（类型）、id（UUID）、title（标题）、subtitle（副标题）、match_score（匹配分数）、highlighted_title（高亮标题）、extra_info（额外信息）
  • 用途：全局搜索功能、搜索结果页展示

💡 【新增】测试搜索建议API（热门搜索/自动补全）

📖 Endpoint: GET /api/v1/search/suggestions
🔓 认证: 公开访问，无需JWT Token
🎯 用途: 获取搜索建议词（用于搜索框自动补全或首页热门搜索展示）
📦 返回: 建议关键词数组（按搜索频率降序排序）
💡 场景:
  • 用户输入搜索前缀时显示自动补全建议（传入q参数）
  • 搜索前页面显示热门搜索词（传入空字符串或不传q参数）

💡 传入前缀可获取匹配的建议词；留空或传空字符串可尝试获取全部热门搜索词

💡 默认5个，最大10个

💡 API设计说明（来自后端文档）：

  • Endpoint：GET /api/v1/search/suggestions
  • 认证：公开访问，无需JWT Token
  • 请求参数：
      • q (string, 必需): 搜索前缀（最少1个字符）
      • limit (int, 可选, 默认5, 最大10): 返回建议数量
  • 返回格式：{"code": 200, "data": {"suggestions": ["关键词1", "关键词2", ...]}, "timestamp": "..."}
  • 执行流程：
      1. 参数解析与校验
      2. 从搜索历史表或Redis缓存中查询热门搜索词
      3. 前缀匹配：筛选以q为前缀的搜索词
      4. 排序：按搜索频率降序排序
      5. 限制：应用limit参数
      6. 返回响应
  • ⚠️ 前端热门搜索功能说明：
      • 由于后端API的q参数是必需的，前端实现热门搜索有两种方案：
      • 方案1（推荐）：传入空字符串q=''或通配符q='*'，尝试获取所有热门词
      • 方案2（备选）：如果方案1不可行，使用配置数据或Mock数据作为热门搜索词
      • 长期方案：建议后端新增独立的GET /api/v1/search/hot API（无需q参数）
  • 用途：
      • 搜索自动补全：用户输入"肝"时，显示"肝胆外科"、"肝胆外科微创手术"等建议
      • 热门搜索展示：搜索前页面显示6个热门搜索词胶囊按钮
  • ⚠️ 路径规则：
      • 后端直连：http://124.220.235.226:8000/api/v1/search/suggestions（包含v1）
      • 前端代理：https://mp.dayilive.com/api/core/search/suggestions（不含v1）
