# 观看历史页面问题分析与解决方案

## 问题现象

1. **直播标题和封面不显示** - 页面显示为"直播标题"和默认封面
2. **长按删除功能失败** - 删除请求返回404错误
3. **记录观看历史返回500错误** - 但数据实际已保存

## 根本原因分析

### 1. 标题和封面不显示的原因

**问题根源：后端返回的观看历史数据不完整**

从控制台日志可以看到：
```
[WatchHistoryStore] 处理观看历史项:,  {"id":"fad3ed65-9bce-4a36-8302-d69d0da49e6b"}
```

后端返回的数据只包含 `id` 和 `session_id`，**缺少以下关键字段**：
- `session_title` - 场次标题
- `room_cover_url` - 房间封面
- `title` - 直播标题  
- `cover_url` - 封面URL

**前端代码期望**：
```typescript
title: item.session_title || item.title || '直播标题'
cover_url: item.room_cover_url || item.cover_url || '/static/default-cover.png'
```

由于所有这些字段都是 `undefined`，所以最终显示默认值。

### 2. 删除功能失败的原因

**问题根源：后端DELETE接口实现问题**

从日志可以看到：
```
🌐 请求: DELETE /users/me/watch-history/4040795a-fb94-42cb-97b7-6abb69273b62
🌐 响应: statusCode=404
```

可能的原因：
- 后端DELETE接口路径不正确
- 后端使用了不同的ID字段（如使用session_id而非id）
- 权限验证问题
- 数据库记录已被自动清理

### 3. 记录观看历史500错误的原因

**问题根源：后端POST接口内部错误**

```
POST /users/me/watch-history
statusCode=500
[LiveView] 记录观看历史失败: Error: 内部服务器错误
```

但从后续查询可以看到**数据实际已保存**，说明是后端逻辑问题：
- 可能是在保存数据后的某个处理步骤失败（如发送通知、更新统计等）
- 返回的response格式不符合前端期望
- 事务提交成功但response构造失败

## 解决方案

### 已实现的修复

#### 1. 修复标题和封面显示问题

**方案：通过session_id获取完整数据**

```typescript
// src/store/watchHistory.ts
const enrichedList = await Promise.all(
  historyItems.map(async (item) => {
    let sessionTitle = item.session_title || item.title
    let roomCover = item.room_cover_url || item.cover_url
    
    // 如果缺少关键信息，通过session_id获取
    if (item.session_id && (!sessionTitle || !roomCover)) {
      try {
        const sessionRes = await request<any>({
          url: `/sessions/${item.session_id}`,
          method: 'GET'
        })
        
        if (sessionRes.data) {
          sessionTitle = sessionRes.data.title || sessionTitle
          roomCover = sessionRes.data.room_cover_url || roomCover
        }
      } catch (error) {
        console.error('获取session详情失败:', error)
      }
    }
    
    return {
      ...item,
      session_title: sessionTitle,
      title: sessionTitle || '直播标题',
      room_cover_url: roomCover,
      cover_url: roomCover || '/static/default-cover.png',
      // Mock专家信息
      expert_name: '房树强',
      expert_title: '主任医师、教授',
      expert_avatar: '/static/医生头像mock.jpg',
      expert_hospital: '北京大学人民医院 肝胆胰外科'
    }
  })
)
```

**优点**：
- 通过额外的API调用补全缺失数据
- 兼容后端数据不完整的情况
- 不依赖后端修复

**缺点**：
- 每个观看历史项需要一次额外的API请求
- 网络开销较大
- 加载速度可能较慢

### 需要后端修复的问题

**接口**: `GET /users/me/watch-history`

**当前返回**：

**应该返回**：
```json

      "session_id": "7fdcc904-5ede-419e-ac24-ab074c4ac8ea",
      "watched_at": "2026-02-05T00:31:00Z",
      "progress": 120,

      "title": "峰云镜会｜3D腹腔镜IIIb型肝门胆管癌根治术",
      "room_cover_url": "https://example.com/cover.jpg",
      "cover_url": "https://example.com/cover.jpg"
    }
  ]
}
```

**修复建议**：
在查询观看历史时 JOIN sessions 和 rooms 表：
```sql
SELECT 
  wh.id,
  wh.session_id,
  wh.watched_at,
  wh.progress,
  s.title as session_title,
  r.title,
  r.cover_url as room_cover_url,
  s.cover_url
FROM watch_history wh
LEFT JOIN sessions s ON wh.session_id = s.id
LEFT JOIN rooms r ON s.room_id = r.id
WHERE wh.user_id = ?
ORDER BY wh.watched_at DESC
```
