无需粘贴代码，一键修复焦点图排序和封面问题

⚠️ 重要说明：
所有焦点图的sort_order都是0，导致展示顺序不可控！
使用此工具可一键修复为：0, 1, 2, 3...

💡 如何拖动到书签栏：
1. 鼠标按住上面的蓝色按钮不放
2. 拖动到浏览器顶部的书签栏
3. 松开鼠标
4. ✅ 书签创建完成！

🚀 第2步：使用书签

📌 功能1：修复排序

  1. 访问 https://mp.dayilive.com
  2. 点击书签栏的 "🔧 修复焦点图排序" 书签
  3. 在弹窗中点击"确定"
  4. ✅ 等待完成提示

🖼️ 功能2：批量修改封面

  1. 访问 https://mp.dayilive.com
  2. 点击书签栏的 "🖼️ 批量修改封面" 书签
  3. 确认封面URL后点击"确定"
  4. ✅ 等待完成提示
