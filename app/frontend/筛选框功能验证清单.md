# 筛选框功能验证清单

## 📋 功能检查点

### ✅ 1. 固定定位
- [x] **SearchBar 固定在顶部**
  - 位置：`position: fixed; top: 0; z-index: 999;`
  - 高度：`statusBarHeight + 44px`（动态计算）
  
- [x] **CategoryTabs 固定在 SearchBar 下方**
  - 外层容器：`.sticky-categories { position: fixed; z-index: 998; }`
  - 动态位置：`:style="{ top: \`\${searchBarHeight}px\` }"`
  - 高度测量：`nextTick()` 后动态测量实际高度（~40px）

- [x] **主内容区正确偏移**
  - 位置：`:style="{ top: \`\${headerHeight}px\` }"`
  - 计算公式：`headerHeight = searchBarHeight + tabsHeight`
  - 滚动区层级：`z-index: 1`（低于固定头部）

### ✅ 2. 数据显示
- [x] **分类数据加载**
  - 数据源：Mock 数据（`mockCategories`）
  - 包含：推荐、肝胆外科、胃肠外科、骨科、心血管科、神经外科
  - 加载时机：`loadPageData()` 在 `onMounted` 时调用

- [x] **分类项渲染**
  - 模板：`v-for="category in categories"`
  - 显示内容：`category.name`
  - 当前选中：`:class="{ 'tab-item--active': activeId === category.id }"`
  - 激活指示器：底部蓝色下划线

### ✅ 3. 交互功能
- [x] **点击切换**
  - 事件绑定：`@tap="handleTabClick(category.id)"`
  - 事件发送：`emit('change', categoryId)`
  - 父组件处理：`@change="handleCategoryChange"`
  - 状态更新：`activeCategoryId.value = categoryId`

- [x] **自动滚动**
  - 监听器：`watch(() => props.activeId, ...)`
  - 滚动逻辑：选中项居中显示
  - 动画：`:scroll-with-animation="true"`

- [x] **数据刷新**
  - 切换分类时重新加载房间列表
  - 显示加载状态：`isLoading.value = true`
  - 重置分页：`currentPage.value = 1`
