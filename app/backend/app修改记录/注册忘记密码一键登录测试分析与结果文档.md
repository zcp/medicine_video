import sys, os, types

## 三、修复的旧测试（3 个）

### 3.1 `test_send_otp_code_success_for_register`

**失败原因：** Phase 2 将 OTP Redis 存储从纯字符串 `"123456"` 改为 JSON `{"code":"123456","attempts":0,...}`。旧断言 `call_args[0][1] == "123456"` 不再成立。

**修复：**
```python
# 旧断言
assert call_args[0][1] == "123456"

# 新断言
stored_data = json.loads(call_args[0][1])
assert stored_data["code"] == "123456"
assert stored_data["attempts"] == 0
assert stored_data["max_attempts"] == 5
```

**修复同时增强：** 不仅验证验证码值，还验证 JSON 结构完整性（`attempts`、`max_attempts`）。

---

### 3.2 `test_hash_password`

**失败原因：** Phase 1 用 bcrypt 替换 SHA-256。旧断言 `len(hashed) == 64`（SHA-256 固定 64 位 hex）不再成立。

**修复：**
```python
# 旧断言
assert len(hashed) == 64  # SHA256 hex length

# 新断言
assert hashed.startswith("$2b$") or hashed.startswith("$2a$")
```

---

### 3.3 `test_refresh_access_token_success`

**失败原因：** Phase 1 新增了 `_is_user_sessions_revoked()` 检查，该方法调用 `redis_client.exists()`。但测试中的 `mock_redis_client` 的 `exists` 返回 `AsyncMock` 而非整数，导致 `> 0` 比较抛出 `TypeError`。

**修复：** 在测试 Arrange 阶段增加 `auth_service.redis_client.exists.return_value = 0`。

---

### 3.4 `test_perform_password_reset_fails_if_token_is_invalid`

**失败原因：** Phase 1 将密码强度校验前置到 `perform_password_reset()` 方法的最前面（两种凭据路径共用）。旧测试的 `new_password="new_strong_password"` 未通过真实强度校验（缺大写字母和特殊字符），导致在检查 token 之前就抛出 `WeakPasswordException`，而非预期的 `InvalidResetTokenException`。

**修复：** 在测试 Arrange 阶段 mock `_validate_password_strength` 返回 `True`，使测试能到达 token 无效分支。

## 八、问题与解决

### 8.1 pytest conftest 发现路径问题

**现象：**
```
ModuleNotFoundError: No module named 'app.database' (from /app/tests/conftest.py)
```

**根因：** pytest 7.4.3 的 conftest 发现机制使用独立解析，不继承父进程的 `sys.path` 修改，即使设置了 `PYTHONPATH=/app` 也无效。

**解决：** 创建 `run_preload.py` 预加载脚本，在 `pytest.main()` 调用前将 `app.database` 等模块预加载到 `sys.modules` 缓存中。与 Tab 测试使用相同方案。

### 8.2 Docker 容器缺少 Phase 修改文件

**现象：** 测试运行时使用的仍是旧版 `auth_service.py`（无 `verify_otp_and_issue_ticket` 方法）、旧版 `schemas/auth.py`（`PasswordResetConfirmRequest.reset_token` 仍为必填）。

**解决：** 通过 `docker cp` 将修改后的源文件部署到容器。

### 8.3 Docker 容器缺少 bcrypt

**现象：**
```
ModuleNotFoundError: No module named 'app.core.password'
```

**根因：** 上一轮 `rebuild.bat -c` 仅重建代码层，未重新构建 Docker 镜像（因此未执行 `pip install bcrypt`）。

**解决：** 在容器内 `pip install bcrypt` 临时安装。下次 `rebuild.bat -f` 全量重建时会随 `requirements.txt` 自动安装。
