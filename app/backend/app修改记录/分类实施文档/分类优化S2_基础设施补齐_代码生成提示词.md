```python
def _match_broad_category(department_text: str) -> Optional[Tuple[str, str]]:
    """启发式匹配科室文本 → (matched_dept_name, matched_category_name)。

    匹配优先级：
    1. 子串匹配（根分类名包含在科室文本中）
    2. 别名表匹配（DEPARTMENT_CATEGORY_MAP）

    Returns:
        (normalized_dept_name, matched_category_name) 或 None
    """
    normalized = _normalize_department_text(department_text)
    if not normalized:
        return None

    for rc in STANDARD_ROOT_CATEGORIES:       # ← 先执行
        if rc in normalized:
            return (normalized, rc)

    mapped = DEPARTMENT_CATEGORY_MAP.get(normalized)  # ← 后执行
    if mapped:
        return (normalized, mapped)

    return None
```

**⚠️ 此优先级修复已在 Sprint 1 完成**（调换了执行顺序，代码中 MAP 已在子串循环之前）。**Sprint 2 仅需做变量名重命名**：`STANDARD_ROOT_CATEGORIES` → `ROOT_CATEGORIES`。不需再次修改匹配顺序——那是 Sprint 1 的职责。

**Bug 分析**（回顾——已修复）：

- 注释写"别名表是优先级 2"，但代码中别名表**放在了子串循环之后**
- 子串匹配命中时立即 `return`，导致别名表中**纠正子串误判的规则可能被跳过**
- **影响面**（按实际后果分三类）：
  1. **1 条产生明确错误归类**：`"骨肿瘤科"` → 子串 `"肿瘤科"`（位置 1-3 连续）命中 → 错误返回 `"肿瘤科"`。`DEPARTMENT_CATEGORY_MAP['骨肿瘤科'] = '骨科'` 是正确的——但执行不到
  2. **2 条结果正好与 MAP 一致**（走错路径但归类不错误）：`泌尿外科/男科` 的子串路径也命中 `"泌尿外科"`；`显微创伤外手科` 连子串都未命中（无连续匹配）→ 兜底走到了 MAP
  3. **"心脏大血管外科"不在 MAP 中**：这不是优先级 bug，是子串匹配的**固有限制**——即使调换顺序也仍然错误命中 `"血管外科"`。需要之后新增别名条目 `'心脏大血管外科': '心胸外科'`，不在 Sprint 2 范围内

**修复后的正确顺序**：

```python
def _match_broad_category(department_text: str) -> Optional[Tuple[str, str]]:
    normalized = _normalize_department_text(department_text)
    if not normalized:
        return None

    # 优先级 1（真正应该优先的）：别名表精确匹配
    # 人工审核过的规则，优先级必须高于纯算法的子串匹配
    mapped = DEPARTMENT_CATEGORY_MAP.get(normalized)
    if mapped:
        return (normalized, mapped)

    # 优先级 2：子串匹配（纯算法，可能有误判，兜底用）
    for rc in ROOT_CATEGORIES:                # ← 引用新常量名
        if rc in normalized:
            return (normalized, rc)

    return None
```

**需要同步更新的**：
- 变量名 `STANDARD_ROOT_CATEGORIES` → `ROOT_CATEGORIES`（Sprint 1 已修逻辑，Sprint 2 只改变量名）
- 函数 Docstring 中"匹配优先级"的编号已是正确顺序（Sprint 1 已修）

def seed_categories(session: Session) -> list[Category]:
    """种子: 分类数据"""
    created: list[Category] = []
    for cat_data in CATEGORIES_DATA:
        existing = session.query(Category).filter_by(name=cat_data["name"]).first()

        cat = Category(

            sort_order=cat_data["sort_order"],

        created.append(cat)
    if created:
        session.flush()
    return created

## 4. 架构约束 (Architecture Constraints)

### 4.1 单一真相源原则

```
✅ 正确模式:
   category_constants.py  ← 唯一定义 ROOT_CATEGORIES 和 CATEGORIES_SEED_DATA
     ├── seed.py          ← from app.core.category_constants import CATEGORIES_SEED_DATA
     └── expert_service.py ← from app.core.category_constants import ROOT_CATEGORIES

❌ 禁止模式:
   seed.py 维护一份列表 A
   expert_service.py 维护一份列表 B
   两个列表"应该一样"但没有机制保证它们一样
```

### 4.2 常量文件的设计原则

- `ROOT_CATEGORIES`：`list[str]`——只包含分类**名称**。用于纯字符串匹配（子串查找、名称比对）
- `CATEGORIES_SEED_DATA`：`list[dict]`——包含完整种子数据（name + slug + sort_order）。用于 seed.py 的 Category 对象创建
- **两个常量共享同一份名称集合**。在文件中用注释标注这一关系：

```python
# ============================================================
# ROOT_CATEGORIES 由 CATEGORIES_SEED_DATA 自动派生
# 新增根分类时只需修改 CATEGORIES_SEED_DATA
# ============================================================
ROOT_CATEGORIES = [item["name"] for item in CATEGORIES_SEED_DATA]
```

### 4.3 不修改列表内容

```
Sprint 2 的职责:  统一引用方式（"怎么引用"）
Sprint 4 的职责:  决定列表内容（"有哪些分类"）

本次禁止:
  ❌ 不新增分类名（如"呼吸内科"——留给 Sprint 4 业务决策）
  ❌ 不删除分类名
  ❌ 不修改分类名
  ❌ 不调整 sort_order
```

### 4.4 行为等价性约束

```
Sprint 2 改动前后，以下行为必须完全一致:

  ✅ seed_categories() 生成的 Category 列表 → 完全相同（21 条、顺序相同）
  ✅ _match_broad_category() 的子串匹配行为 → 完全相同（除优先级修复外）
  ✅ STANDARD_ROOT_CATEGORIES 的遍历顺序 → 与改动前完全一致

def _match_broad_category(department_text: str) -> Optional[Tuple[str, str]]:
    """启发式匹配科室文本 → (matched_dept_name, matched_category_name)。

    匹配优先级：
    1. 别名表精确匹配（DEPARTMENT_CATEGORY_MAP）— 优先于子串匹配
    2. 子串匹配（根分类名包含在科室文本中）

    Returns:
        (normalized_dept_name, matched_category_name) 或 None
    """
    normalized = _normalize_department_text(department_text)
    if not normalized:
        return None

    mapped = DEPARTMENT_CATEGORY_MAP.get(normalized)
    if mapped:
        return (normalized, mapped)

    for rc in ROOT_CATEGORIES:   # ← 唯一改动：STANDARD_ROOT_CATEGORIES → ROOT_CATEGORIES
        if rc in normalized:
            return (normalized, rc)

    return None
```
