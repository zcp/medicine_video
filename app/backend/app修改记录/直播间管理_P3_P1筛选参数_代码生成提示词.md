## 3. 核心上下文 (Core Context)

### 3.1 数据表关系（筛选路径）

```
                        categories
                            ↑
                     live_room_categories  ← category_ids 筛选
                            ↑
    experts ← live_session_experts ← live_sessions ← live_rooms
                                              ↑
                                      session_tags → tags   ← tag_id 筛选
```

筛选路径：

| 参数 | EXISTS 子查询关联路径 | 语义 |
|------|------|------|
| `category_ids` | `LiveRoomCategory.room_id == LiveRoom.id AND LiveRoomCategory.category_id IN (...)` | 查找关联了指定分类的房间（多选取并集） |
| `expert_id` | `LiveSession.room_id == LiveRoom.id → LiveSessionExpert.session_id → expert_id == :eid` | 查找任一 session 中出现了指定专家的房间 |
| `tag_id` | `LiveSession.room_id == LiveRoom.id → SessionTag.session_id → tag_id == :tid` | 查找任一 session 中打了指定标签的房间 |
| `session_start_after/before` | 直接引用 `latest_subq.c.session_start_time` | 按最新 session 的 start_time 范围筛选 |

#### 4.3.2 在计数查询之前追加 WHERE 条件块

在 `get_rooms_with_latest_session()` 中，`created_before` 筛选之后、计数查询（`count_query = ...`）之前，追加以下 4 块 WHERE 条件：

```python
        # ← 时间范围筛选（P2 已有，供参考位置）
        if created_after:
            dt_after = datetime.fromisoformat(created_after) if isinstance(created_after, str) else created_after
            query = query.where(LiveRoom.created_at >= dt_after)
        if created_before:
            dt_before = datetime.fromisoformat(created_before) if isinstance(created_before, str) else created_before
            query = query.where(LiveRoom.created_at <= dt_before)

        # ↓ ========== P3 新增：4 类筛选条件 ==========

        # 1. 分类筛选（多选，取并集——房间关联了任一指定分类即匹配）
        if category_ids:
            try:
                cat_uuids = [uuid.UUID(c) for c in category_ids]
            except ValueError:
                raise InvalidParameterException("无效的分类ID格式", code=4001)
            query = query.where(
                exists().where(
                    and_(
                        LiveRoomCategory.room_id == LiveRoom.id,
                        LiveRoomCategory.category_id.in_(cat_uuids),
                    )
                )
            )

        # 2. 专家筛选（该专家在房间任一 session 中出现过即匹配）
        if expert_id:
            try:
                eid = uuid.UUID(expert_id)
            except ValueError:
                raise InvalidParameterException("无效的专家ID格式", code=4001)
            query = query.where(
                exists().where(
                    and_(
                        LiveSession.room_id == LiveRoom.id,
                        LiveSessionExpert.session_id == LiveSession.id,
                        LiveSessionExpert.expert_id == eid,
                    )
                )
            )

        # 3. 标签筛选（该标签在房间任一 session 中被标记过即匹配）
        if tag_id:
            try:
                tid = uuid.UUID(tag_id)
            except ValueError:
                raise InvalidParameterException("无效的标签ID格式", code=4001)
            query = query.where(
                exists().where(
                    and_(
                        LiveSession.room_id == LiveRoom.id,
                        SessionTag.session_id == LiveSession.id,
                        SessionTag.tag_id == tid,
                    )
                )
            )

        # 4. 场次开播时间范围（基于窗口函数子查询的 session_start_time 列）
        if session_start_after:
            dt_after = datetime.fromisoformat(session_start_after) if isinstance(session_start_after, str) else session_start_after
            query = query.where(latest_subq.c.session_start_time >= dt_after)
        if session_start_before:
            dt_before = datetime.fromisoformat(session_start_before) if isinstance(session_start_before, str) else session_start_before
            query = query.where(latest_subq.c.session_start_time <= dt_before)

        # ↑ ========== P3 新增结束 ==========

        # 计数查询（P2 已有，不要改动）
        count_query = select(func.count()).select_from(query.subquery())
```

**关键说明**：
- `category_ids` 使用 `.in_()` 实现多选取并集（OR 语义：房间关联了任意一个指定分类即匹配）
- `expert_id` 和 `tag_id` 为单值，使用 `==` 精确匹配
- `session_start_after/before` 直接引用 `latest_subq.c.session_start_time`——这是 P2 中窗口函数子查询输出的列，已在主查询的 SELECT 和 OUTER JOIN 中可用
- 所有 UUID 参数做 `uuid.UUID()` 转换 + try/except 校验，无效格式抛 `InvalidParameterException(code=4001)`
- `latest_subq` 是 P2 中定义的窗口函数子查询变量名（`latest_subq = (...).subquery()`）
