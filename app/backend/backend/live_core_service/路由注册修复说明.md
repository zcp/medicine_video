# Batch Import 路由注册修复说明

## 🚨 问题诊断

**错误现象**：所有批量导入测试返回 `404 Not Found`

**根本原因**：`batch_import` 和 `session_import` 路由在 `app/api/v1/api.py` 中**未注册**

**影响范围**：
- ❌ `/api/v1/rooms/import/batch` - 批量导入端点（404）
- ❌ `/api/v1/rooms/{room_id}/sessions/import` - 会话导入端点（可能也 404）

---

## ✅ 后端修复方法（最小改动）

### 修改文件：`app/api/v1/api.py`

**当前位置**：第 7-11 行

**当前代码**：
```python
from fastapi import APIRouter

from app.api.v1.endpoints import room, session, topic, live_features

from app.api.v1.endpoints import internal
```

**需要修改为**：
```python
from fastapi import APIRouter

from app.api.v1.endpoints import room, session, topic, live_features
from app.api.v1.endpoints import batch_import, session_import  # ✅ 新增导入

from app.api.v1.endpoints import internal
```

**然后，在路由注册部分添加**（在第 17 行之后）：

**当前代码**（第 15-17 行）：
```python
# 注册各个模块的路由
api_router.include_router(room.router, prefix="/rooms", tags=["rooms"])
api_router.include_router(session.router, prefix="", tags=["sessions"])
```

**需要修改为**：
```python
# 注册各个模块的路由
api_router.include_router(room.router, prefix="/rooms", tags=["rooms"])
api_router.include_router(session.router, prefix="", tags=["sessions"])

# ✅ 注册 Import 和 Batch Import 路由
api_router.include_router(
    session_import.router,
    prefix="/rooms",  # 路径：/api/v1/rooms/{room_id}/sessions/import
    tags=["Session Import"]
)
api_router.include_router(
    batch_import.router,
    prefix="/rooms",  # 路径：/api/v1/rooms/import/batch
    tags=["Batch Import"]
)
```

## 📝 完整修改后的 api.py 代码（第 1-20 行）

```python
"""
LiveCore Service - API Router

聚合所有v1版本的API路由
"""

from fastapi import APIRouter

from app.api.v1.endpoints import room, session, topic, live_features
from app.api.v1.endpoints import batch_import, session_import  # ✅ 新增

from app.api.v1.endpoints import internal

api_router = APIRouter()

# 注册各个模块的路由
api_router.include_router(room.router, prefix="/rooms", tags=["rooms"])
api_router.include_router(session.router, prefix="", tags=["sessions"])

# ✅ 注册 Import 和 Batch Import 路由
api_router.include_router(
    session_import.router,
    prefix="/rooms",
    tags=["Session Import"]
)
api_router.include_router(
    batch_import.router,
    prefix="/rooms",
    tags=["Batch Import"]
)

# ... 其余代码保持不变
```

## ⚠️ 注意事项

1. **路由顺序**：`batch_import` 路由路径是 `/import/batch`，`session_import` 路由路径是 `/{room_id}/sessions/import`
2. **路径冲突**：由于都使用 `/rooms` prefix，FastAPI 会按注册顺序匹配：
   - `/rooms/import/batch` - 匹配 `batch_import`（必须在前）
   - `/rooms/{room_id}/sessions/import` - 匹配 `session_import`
3. **建议注册顺序**：先注册 `batch_import`，再注册 `session_import`，避免路径冲突
