## 三、live_features.py 修改详情

### 3.1 去除重复的 user_display_name 赋值

- **位置**: `list_room_tabs` 中“从当前用户信息中提取昵称/名称”的逻辑。  
- **问题**: 同一逻辑写了两遍（多行形式 + 单行形式），仅保留一处即可。  
- **修改**: 保留多行形式赋值，删除后面重复的单行赋值。

### 3.2 upload_tab_image 异常处理与 room 端点对齐

与 `room.py` 中 `upload_room_cover` 的学院派规范保持一致：

1. **导入**: 在 `fastapi` 的 import 中增加 `HTTPException`。
2. **日志变量**: 在 `try` 前定义 `room_id_log = str(room_id)`，便于异常处理与日志中安全使用。
3. **HTTPException**:
   - 单独捕获 `HTTPException`（由 `FileHandler.validate_image_file` / `save_tab_image_file` 抛出的 400 等）。
   - 使用 `logger.warning` 记录“文件验证”类失败。
   - 返回 `JSONResponse(status_code=e.status_code, content=error_response(code=4001, message=...))`，其中 `message` 取 `e.detail`（非字符串时转为 `str(e.detail)`）。
4. **通用 Exception**:
   - 单独捕获 `Exception`，使用 `logger.error(..., exc_info=True)`。
   - 返回 500 与 `error_response(code=1000, message="文件保存失败")`，不再使用 `getattr(e, "status_code", 400)` 等，避免将服务端错误误报为 400。
