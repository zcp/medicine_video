## 二、服务概述

### 2.1 服务定位
媒体下载服务是一个独立的微服务，负责处理直播平台中的媒体资源下载任务，包括视频流下载（HLS、MP4）、图片下载等功能。该服务采用异步处理方式，支持高并发下载任务处理，并提供完善的失败处理和重试机制。

### 2.2 核心功能
- HLS视频流下载
- MP4视频文件下载
- 图片资源下载
- 并发下载控制
- (修改) 下载任务去重 (API层防止重复排队，Worker层防止重复下载)
- 断点续传
- 下载任务管理
- (新增) 批量任务导入 (通过同步CSV文件)
- 资源存储管理
- 失败任务重试
- 下载状态检查
- 失败记录管理
- (新增) 手动任务列表刷新机制

### 2.3 技术栈选型
- 开发语言：Python 3.8+
- Web框架：FastAPI
- 任务队列：Celery + Redis
- 存储系统：本地文件系统 + 对象存储
- 数据库：PostgreSQL
- 监控：Prometheus + Grafana


### 2.4 身份认证与授权
媒体下载服务采用JWT Token认证机制，与用户服务集成实现统一的身份验证：

- **认证方式**: JWT Token (JSON Web Token)
- **认证流程**: 用户通过用户服务进行SSO登录，获得JWT Token后访问媒体下载服务
- **权限控制**: 用户只能访问和操作自己创建的下载任务
- **Token验证**: 使用与用户服务相同的JWT密钥进行Token验证
- **安全机制**: 支持Token过期检查、签名验证、用户权限验证

**(新增) 5.2.4 触发批量任务导入 (新功能二)**

  * **接口**: `POST /api/v1/download/tasks/import`

  * **描述**: (新增) 手动触发**批量任务导入**。服务将执行一个程序，该程序读取服务器上指定路径的CSV文件，与数据库`download_tasks`表 进行比对（基于`resource_url`），并将CSV中所有**新**的任务批量插入到数据库中。

  * **认证**: 需要JWT Token认证。建议此接口需要特定权限（例如管理员）。

  * **(新增) 业务逻辑说明**:

    1.  **认证与鉴权**: 验证用户Token及权限。
    2.  **触发导入**: 调用内部的"批量导入服务"。
    3.  **导入服务执行**:
        a.  从数据库`download_tasks`表 中查询所有已存在的 `(resource_url, liveroom_id, liveroom_title)` 组合，并存入一个 Set 中用于快速去重。
        b.  读取配置文件中指定的CSV文件路径（例如 `settings.TASK_IMPORT_CSV_PATH`）。
        c.  逐行解析CSV。对每一行，检查其 `(resource_url, liveroom_id, liveroom_title)` 组合是否已在 Set 中。
        d.  如果**不存在**，则创建一个新的 `DownloadTask` 实体，从CSV行中映射所有字段（`video_id`, `liveroom_id`等），并将 `status` 设为 `pending`，`user_id` 设为当前操作员ID。
        e.  如果**已存在**，则跳过该行。
        f.  **批量插入**所有新任务到数据库。
    4.  **返回结果**: 返回一个导入摘要，告知有多少新任务被添加。

  * **请求参数 (Body)**: (无，仅为触发)

  * **成功响应 (`200 OK`)**:

```python
def verify_user_authentication(token: str) -> Dict:
    """
    验证用户JWT Token
    :param token: JWT Token字符串
    :return: 用户信息字典
    """
    try:
        # 1. 验证Token签名和格式
        payload = jwt.decode(
            token, 
            JWT_SECRET_KEY, 
            algorithms=[JWT_ALGORITHM]
        )
        
        # 2. 检查Token过期时间
        if payload.get('exp') and time.time() > payload['exp']:
            raise HTTPException(status_code=401, detail="认证凭证已过期")
        
        # 3. 提取用户信息
        user_info = {
            "user_id": payload.get("user_id"),
            "username": payload.get("username"),
            "role": payload.get("role", "user"),
            "permissions": payload.get("permissions", [])
        }
        
        # 4. 验证必要字段
        if not user_info["user_id"]:
            raise HTTPException(status_code=401, detail="Token中缺少用户ID")
        
        return user_info
        
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=401, detail="认证凭证无效")
    except Exception as e:
        raise HTTPException(status_code=401, detail=f"认证验证失败: {str(e)}")
```

```python
def verify_user_permission(user_id: str, resource_id: str, resource_type: str = "task") -> bool:
    """
    验证用户对资源的访问权限
    :param user_id: 用户ID
    :param resource_id: 资源ID
    :param resource_type: 资源类型（task/video/failure）
    :return: 是否有权限访问
    """
    try:
        if resource_type == "task":
            # 验证下载任务权限
            task = get_download_task(resource_id)
            return task and task.user_id == user_id
        elif resource_type == "video":
            # 验证视频记录权限（通过task_id关联）
            video = get_downloaded_video(resource_id)
            if video and video.task_id:
                task = get_download_task(video.task_id)
                return task and task.user_id == user_id
            return False
        elif resource_type == "failure":
            # 验证失败记录权限（通过task_id关联）
            failure = get_download_failure(resource_id)
            if failure and failure.task_id:
                task = get_download_task(failure.task_id)
                return task and task.user_id == user_id
            return False
        else:
            return False
    except Exception:
        return False
```

```python
def create_storage_path(video_id: str, liveroom_id: str) -> str:
    """
    创建符合规范的存储路径
    :param video_id: 视频的唯一标识ID (UUID)
    :param liveroom_id: 直播间ID
    :return: 存储路径
    """
    timestamp = datetime.now().strftime("%Y%m%dT%H%M%S")
    base_path = f"/media/video_{video_id}"
    
    # 创建目录结构
    paths = {
        'raw': f"{base_path}/raw",
        'hls': f"{base_path}/hls_1080p_4Mbps",
        'hls_ts': f"{base_path}/hls_1080p_4Mbps/ts",

def download_video(task_id: str, video_type: str):
    """
    视频下载主流程
    :param task_id: 下载任务ID
    :param video_type: 视频类型（hls/mp4）
    """
    logger = logging.getLogger('download_service')
    try:
        # 1. 获取任务信息
        task = get_task(task_id)
        if not task:
            logger.error(f"Task {task_id} not found")
            raise TaskNotFoundException(f"Task {task_id} not found")
        
        # 2. 检查是否已下载
        # 2. (重大修改) Worker 端下载去重检查
        # 检查 'downloaded_videos' 表 是否已存在相同 URL 且已完成或部分完成的记录
        existing_video = db.query(DownloadedVideo).filter(
            DownloadedVideo.video_url == task.resource_url, # 比较 URL
            DownloadedVideo.status.in_(['completed', 'partial_completed']) # 比较状态（包含部分完成）
        ).first()

        if existing_video:
            logger.info(f"Worker Deduplication Hit: Video for URL {task.resource_url} already downloaded with status '{existing_video.status}'.")
            logger.info(f"Task {task_id} will be marked as '{existing_video.status}' without re-downloading.")
            
            # (可选) 可以在此将 task.id 关联到 existing_video.task_id，
            # 但 'downloaded_videos' 表当前设计为 1:1 关联，
            # 因此我们选择直接将新任务标记为相应状态。
            
            if existing_video.status == 'completed':
                mark_task_as_completed(task_id, "视频已存在 (去重)")
            else:  # partial_completed
                mark_task_as_partial_completed(task_id, "视频已部分完成 (去重)")
            return # (关键) 跳过下载，直接返回
        # 3. 创建存储目录
        storage_path = create_storage_path(task.video_id, task.liveroom_id)
        logger.info(f"Created storage path: {storage_path}")
        
        # 4. 下载视频
        video_success = False
        image_success = True
        timestamp = datetime.now().strftime("%Y%m%dT%H%M%S")
        
        if video_type == 'hls':
            # 4.1 HLS下载流程
            try:
                # 下载m3u8文件
                m3u8_path = f"{storage_path}/hls_1080p_4Mbps/index_{task.video_id}_transcoded_{timestamp}.m3u8"
                m3u8_content = download_m3u8(task.video_url)
                with open(m3u8_path, 'w') as f:
                    f.write(m3u8_content)
                
                segments = parse_m3u8(m3u8_content)
                total_segments = len(segments)
                failed_segments = 0
                
                # 并发下载分片
                with ThreadPoolExecutor(max_workers=settings.MAX_CONCURRENT_DOWNLOADS) as executor:
                    future_to_segment = {
                        executor.submit(
                            download_segment, 
                            segment,
                            f"{storage_path}/hls_1080p_4Mbps/ts/segment_{i:03d}_{task.video_id}_transcoded_{timestamp}.ts"
                        ): segment 
                        for i, segment in enumerate(segments)
                    }
                    
                    for future in as_completed(future_to_segment):
                        segment = future_to_segment[future]
                        try:
                            future.result()
                        except Exception as e:
                            failed_segments += 1
                            logger.error(f"Failed to download segment {segment.id}: {str(e)}")
                            handle_download_failure(task_id, segment.id, e)
                
                # 检查下载结果
                if failed_segments == 0:
                    video_success = True
                    logger.info(f"Successfully downloaded all segments for video {task.video_id}")
                elif failed_segments / total_segments <= 0.05:
                    video_success = True
                    logger.warning(f"Partially downloaded video {task.video_id}: {failed_segments} segments failed")
                    mark_task_as_partial_completed(task_id, f"视频下载基本完成，但有{failed_segments}个分片下载失败")
                else:
                    video_success = False
                    logger.error(f"Failed to download video {task.video_id}: {failed_segments} segments failed")
                    mark_task_as_failed(task_id, f"视频下载失败，{failed_segments}个分片下载失败")
                    
            except Exception as e:
                logger.error(f"Error in HLS download process: {str(e)}")
                handle_download_failure(task_id, None, e)
                video_success = False
                
        elif video_type == 'mp4':
            # 4.2 MP4下载流程
            try:
                mp4_path = f"{storage_path}/mp4/video_{task.video_id}_transcoded_1080p_{timestamp}.mp4"
                download_mp4(task.video_url, mp4_path)
                video_success = True
                logger.info(f"Successfully downloaded MP4 video {task.video_id}")
            except Exception as e:
                logger.error(f"Failed to download MP4 video {task.video_id}: {str(e)}")
                handle_download_failure(task_id, None, e)
                video_success = False
        
        # 5. 下载相关图片
        if task.cover_url:
            try:
                cover_path = f"{storage_path}/images/cover_{task.video_id}_upload_{timestamp}.jpg"
                download_image(task.cover_url, cover_path)
                logger.info(f"Successfully downloaded cover image for video {task.video_id}")
            except Exception as e:
                logger.error(f"Failed to download cover image for video {task.video_id}: {str(e)}")
                handle_download_failure(task_id, None, e, 'image')
                image_success = False
        
        # 6. 更新任务状态
        if video_success:
            if image_success:
                mark_task_as_completed(task_id)
                logger.info(f"Task {task_id} completed successfully")
                # 记录下载成功的视频信息
                record_downloaded_video(
                    video_id=task.video_id,
                    liveroom_id=task.liveroom_id,
                    liveroom_title=task.liveroom_title,
                    liveroom_url=task.liveroom_url,
                    video_type=video_type,
                    video_url=task.video_url,
                    storage_path=storage_path,
                    cover_url=task.cover_url,
                    cover_path=cover_path if task.cover_url else None,
                    download_task_id=task_id
                )
            else:
                mark_task_as_partial_completed(task_id, "视频下载成功，但部分图片下载失败")
                logger.warning(f"Task {task_id} partially completed: video success but image failed")
        else:
            mark_task_as_failed(task_id, "视频下载失败")
            logger.error(f"Task {task_id} failed: video download failed")
            
    except Exception as e:
        logger.error(f"Download task {task_id} failed: {str(e)}", exc_info=True)
        mark_task_as_failed(task_id, f"下载任务异常: {str(e)}")
        raise
```

```python
    """
    处理下载失败
    :param task_id: 任务ID
    :param segment_id: 分片ID（对于HLS视频）
    :param error: 错误信息
    :param resource_type: 资源类型（video/image）
    """
    # 记录失败信息
    failure = create_failure_record(task_id, segment_id, error, resource_type)
    
    # 更新任务状态
    if resource_type == 'video':
        if segment_id:
            # HLS视频分片失败，检查失败比例
            total_segments = get_total_segments(task_id)
            failed_segments = get_failed_segments_count(task_id)
            failure_ratio = failed_segments / total_segments
            
            if failure_ratio <= 0.05:  # 允许5%的分片失败
                update_task_status(task_id, 'partial_completed')
                log_segment_failure(task_id, segment_id, error)
            else:
                update_task_status(task_id, 'failed')
                mark_task_as_failed(task_id, f"视频下载失败: 失败分片比例超过5%")
        else:
            # MP4视频下载失败，直接标记任务失败
            update_task_status(task_id, 'failed')
            mark_task_as_failed(task_id, f"视频下载失败: {str(error)}")
    else:
        # 图片下载失败，记录失败但不影响任务状态
        update_task_status(task_id, 'partial_completed')
        log_image_failure(task_id, error)
```

### 6.5 重试机制流程
```python
def retry_failed_segments(task_id: str, segment_ids: List[str] = None, resource_type: str = None):
    """
    重试失败的下载
    :param task_id: 任务ID
    :param segment_ids: 要重试的分片ID列表（可选）
    :param resource_type: 要重试的资源类型（video/image，可选）
    """
    # 获取失败记录
    failures = get_failures_to_retry(task_id, segment_ids, resource_type)
    if not failures:
        return
    
    # 记录重试开始
    log_retry_start(task_id, len(failures))
    
    # 重试下载
    success_count = 0
    for failure in failures:
        try:
            if failure.segment_type == 'mp4':
                download_mp4(failure.segment_url, failure.file_path)
            elif failure.segment_type == 'image':
                download_image(failure.segment_url, failure.file_path)
            else:
                download_segment(failure.segment_id)
            
            # 下载成功，删除失败记录
            remove_failure_record(failure.id)
            success_count += 1
            
        except Exception as e:
            # 更新失败记录
            update_failure_record(failure.id, e)
    
    # 检查是否所有失败记录都已处理成功
    remaining_failures = get_failures_to_retry(task_id)
    if not remaining_failures:
        # 所有失败记录都已处理成功
        task = get_task(task_id)
        if task.video_type == 'hls':
            # 检查是否所有分片都已下载成功
            if all_segments_completed(task_id):
                mark_task_as_completed(task_id)
                log_retry_success(task_id, "所有分片下载成功")
        else:
            mark_task_as_completed(task_id)
            log_retry_success(task_id, "下载任务完成")
    else:
        # 仍有失败记录
        task = get_task(task_id)
        if task.video_type == 'hls':
            # 检查失败分片比例
            total_segments = get_total_segments(task_id)
            failed_segments = len(remaining_failures)
            if failed_segments / total_segments <= 0.05:
                mark_task_as_partial_completed(task_id, f"重试后仍有{failed_segments}个分片下载失败")
            else:
                mark_task_as_failed(task_id, f"重试后仍有过多分片下载失败")
        else:
            mark_task_as_failed(task_id, "重试后仍有下载失败")
    
    # 记录重试结果
    log_retry_result(task_id, success_count, len(failures) - success_count)
```

### 6.6 失败记录管理
```python
def get_failures_to_retry(task_id: str, segment_ids: List[str] = None, resource_type: str = None) -> List[Dict]:
    """
    获取需要重试的失败记录
    :param task_id: 任务ID
    :param segment_ids: 要重试的分片ID列表（可选）
    :param resource_type: 要重试的资源类型（可选）
    :return: 失败记录列表
    """
    query = {
        "task_id": task_id,
        "retry_count": {"$lt": MAX_RETRY_COUNT}  # 限制最大重试次数
    }
    
    if segment_ids:
        query["segment_id"] = {"$in": segment_ids}
    if resource_type:
        query["resource_type"] = resource_type
    
    return list(failures_collection.find(query).sort("created_at", 1))

def remove_failure_record(failure_id: str):
    """
    删除失败记录
    :param failure_id: 失败记录ID
    """
    failures_collection.delete_one({"_id": failure_id})

def update_failure_record(failure_id: str, error: Exception):
    """
    更新失败记录
    :param failure_id: 失败记录ID
    :param error: 错误信息
    """
    failures_collection.update_one(
        {"_id": failure_id},
        {
            "$inc": {"retry_count": 1},
            "$set": {
                "last_error": str(error),
                "last_retry_at": datetime.utcnow()
            }
        }
    )
```

```python
    logger = logging.getLogger('import_service')
    
    try:
        # 1. (去重) 从数据库获取所有已存在的任务键值（resource_url, liveroom_id, liveroom_title）
        existing_task_keys = get_existing_task_keys()
        logger.info(f"Found {len(existing_task_keys)} existing task combinations.")

        new_tasks_to_add = []

        csv_path = settings.TASK_IMPORT_CSV_PATH
        if not os.path.exists(csv_path):
            raise FileNotFoundError(f"CSV file not found at: {csv_path}")

        with open(csv_path, mode='r', encoding='utf-8') as f:
            reader = csv.DictReader(f)
            for row in reader:
                total_in_csv += 1
                task_url = row.get('resource_url')
                liveroom_id = row.get('liveroom_id')
                liveroom_title = row.get('liveroom_title', '')
                
                if not task_url:
                    logger.warning("Skipping row with empty resource_url.")
                    skipped_count += 1
                    continue
                
                # 3. (去重) 检查任务组合 (resource_url, liveroom_id, liveroom_title) 是否已存在
                task_key = (task_url, liveroom_id, liveroom_title)
                if task_key in existing_task_keys:
                    skipped_count += 1
                else:
                    # 4. (新增) 准备批量插入
                    new_task = parse_csv_row(row, current_user_id)
                    new_tasks_to_add.append(new_task)
                    existing_task_keys.add(task_key) # 避免CSV内部重复

        # 5. (新增) 批量插入数据库
        if new_tasks_to_add:
            db.bulk_save_objects(new_tasks_to_add)
            db.commit()
            logger.info(f"Successfully imported {len(new_tasks_to_add)} new tasks.")
        
        return {
            "tasks_in_csv": total_in_csv,
            "new_tasks_created": len(new_tasks_to_add),
            "tasks_skipped_duplicates": skipped_count
        }

        db.rollback()

        raise  # 抛出异常，API层会捕获并返回 500
```
