## 📋 **文档使用指南**

### **场景1：新团队成员入职**
**阅读顺序：**
1. 先读 `直播核心功能设计文档v4-增加专题.md`（全面了解系统架构）
2. 再读具体负责的功能模块文档（如专题功能）

### **场景2：开发新功能**
**操作步骤：**
1. 复制 `专题功能完整设计文档-修正版.md` 作为模板
2. 参考其结构创建新的功能模块文档
3. 在本 README.md 中添加索引
4. 明确新功能与核心功能的依赖关系

### **场景3：修改现有功能**
**操作步骤：**
1. 只修改对应的功能模块文档
2. 如果涉及核心架构变更，同时更新核心文档
3. 在文档顶部的"版本信息"中记录修改历史

### **场景4：代码审查**
**检查清单：**
- ✅ 数据库设计是否符合核心文档规范？
- ✅ API接口是否遵循通用响应结构？
- ✅ 权限控制是否遵循JWT验证机制？
- ✅ 日志记录是否符合统一规范？
