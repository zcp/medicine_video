## ⚠️ 注意事项

### 1. 环境区分验证

与直播核心功能保持一致：
- **生产环境**: 强制验证，配置错误时抛出异常阻止启动
- **开发环境**: 友好警告，提供提示信息，不阻止启动

### 2. 配置管理统一

创建的 `app/core/config.py` 采用与直播核心功能相同的设计：
- 使用 `Settings` 类
- 支持 `ENVIRONMENT` 环境变量
- 提供动态属性（`DATABASE_URL`, `BACKEND_CORS_ORIGINS`）
- 实现 `_validate_production_config()` 和 `_validate_development_config()`

### 3. 日志脱敏

提供了与直播核心功能相同的日志脱敏机制：
- 数据库URL中的密码
- JWT密钥
- Authing密钥
- 通用密码字段

### 4. 健康检查端点

实现了标准的健康检查端点：
- `/api/v1/health` - 基本健康检查
- `/api/v1/health/ready` - 就绪检查（数据库+Redis）
- `/api/v1/health/config` - 配置检查（仅开发环境）
