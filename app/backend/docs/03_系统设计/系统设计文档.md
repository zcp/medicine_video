### 1.1 整体架构图
```

                                     ↑
                                     |
[用户端] → [负载均衡] → [API网关] → [流媒体服务集群] → [存储服务]

   |          |            |              |               |
[Web前端] ← [缓存层] ← [业务服务] ← [消息队列] ← [数据库集群]
```

### 2.1 错误码定义
| 错误码 | 错误类型 | 错误描述 | 处理建议 |
|--------|----------|----------|----------|
| 1001 | 推流错误 | 推流地址无效 | 检查推流地址配置 |
| 1002 | 推流错误 | 推流密钥错误 | 检查推流密钥 |
| 1003 | 推流错误 | 推流超时 | 检查网络连接 |
| 2001 | 播放错误 | 播放地址无效 | 检查播放地址配置 |
| 2002 | 播放错误 | 播放密钥错误 | 检查播放密钥 |
| 2003 | 播放错误 | 播放超时 | 检查网络连接 |
| 3001 | 系统错误 | 服务不可用 | 检查服务状态 |
| 3002 | 系统错误 | 资源不足 | 扩容或优化资源 |

```sql
CREATE TABLE download_tasks (
    id VARCHAR(36) PRIMARY KEY,
    url VARCHAR(1024) NOT NULL,
    save_path VARCHAR(1024) NOT NULL,
    status VARCHAR(20) NOT NULL,
    progress INT DEFAULT 0,
    retry_count INT DEFAULT 0,
    create_time TIMESTAMP NOT NULL,
    update_time TIMESTAMP NOT NULL,
    error_message TEXT,
    file_size BIGINT,
    downloaded_size BIGINT,
    priority INT DEFAULT 0,
    user_id VARCHAR(36),
    task_type VARCHAR(20)
);
```

2. 下载历史表
```sql
CREATE TABLE download_history (
```
