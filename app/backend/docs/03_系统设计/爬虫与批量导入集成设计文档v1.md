## 一、需求分析

### 1.1 业务背景

当前系统存在两个独立的功能模块：
1. **爬虫模块** (`dynamicCrawler_vzan.py`)：从指定URL爬取直播间数据，生成CSV文件
2. **批量导入模块** (`batch_import_tasks_from_csv`)：从CSV文件批量创建下载任务

两个模块之间存在以下问题：
- 需要手动执行爬虫脚本生成CSV
- 需要手动上传CSV文件到批量导入接口
- 爬虫配置（特别是token）硬编码在代码中，难以维护和安全管理
- 无法实现自动化的端到端流程

### 1.2 核心需求

#### 1.2.1 功能需求

**FR1 - 爬虫配置管理**
- 将爬虫配置（token、用户名、密码等）从代码中移除，通过环境变量管理
- 支持多个爬虫源的配置
- 配置变更不需要修改代码

**FR2 - 自动化爬取与导入**
- 提供统一的API接口，一键完成"爬取 → 导入"流程
- 支持指定爬取的URL和参数
- 返回详细的执行结果（爬取成功数、导入成功数、失败详情等）

**FR3 - 错误隔离与容错**
- 爬取失败不影响后续导入（如果有历史CSV数据）
- 单行数据错误不中断整体流程
- 详细的错误日志和错误返回

**FR4 - 安全性**
- Token等敏感信息加密存储
- API接口需要用户认证（JWT）
- 爬虫执行限流，防止滥用

#### 1.2.2 非功能需求

**NFR1 - 性能要求**
- 单次爬取支持最多10,000条数据
- 爬取+导入总耗时不超过5分钟
- 支持异步执行（不阻塞API响应）

**NFR2 - 可维护性**
- 爬虫代码与业务代码解耦
- 配置集中管理
- 完整的日志记录

**NFR3 - 可扩展性**
- 支持添加多种爬虫源（vzan、抖音、快手等）
- 爬虫逻辑插件化

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Optional
from pathlib import Path

class BaseCrawler(ABC):
    """爬虫基类，定义统一接口"""
    
    def __init__(self, config: Dict):
        self.config = config
        self.timeout = config.get('timeout', 10)
    
    @abstractmethod
    def crawl(self, config: Dict, **kwargs) -> Dict:
        """
        执行爬取任务
        
        Args:
            config: 爬虫配置字典，包含 username, password, token 等
            **kwargs: 其他参数（如分页参数、筛选条件等）
        
        Returns:
            Dict: 爬取结果摘要
                {
                    "csv_file": str,             # 主 CSV 文件路径
                    "incremental_file": str,     # 增量 CSV 文件路径
                    "failed_file": str,          # 失败记录文件路径
                    "total_rows": int,           # 总爬取行数
                    "failed_rows": int,          # 失败行数
                    "incremental_rows": int      # 本次新增行数
                }
        
        Raises:
            CrawlerError: 爬取失败时抛出
        """
        pass
    
    @abstractmethod
    def validate_config(self) -> bool:
        """
        验证配置是否完整有效
        
        Returns:
            bool: 配置是否有效
        """
        pass
```

#### 3.2.2 微赞爬虫实现

`app/crawlers/vzan_crawler.py`:

**设计说明**: 本类采用**适配器模式**复用 `dynamicCrawler_vzan.py` 的已有爬取逻辑。

**文件路径信息**（来自 `dynamicCrawler_vzan.py`）：

| 文件类型 | 属性名 | 完整路径 | 文件名 |
|:---|:---|:---|:---|
| 临时目录 | `temp_dir` | `tempfile.gettempdir() / 'vzan_crawler'` | - |
| 主CSV文件 | `liveroom_list_savefile` | `{temp_dir}/liveroomlist_vzan.csv` | `liveroomlist_vzan.csv` |
| 增量CSV文件 | `liveroom_list_savefile_inc` | `{temp_dir}/liveroomlist_inc_vzan.csv` | `liveroomlist_inc_vzan.csv` |
| 失败记录文件 | `failed_liveroomlist_url` | `{temp_dir}/failed_liveroomlist_urls_vzan.txt` | `failed_liveroomlist_urls_vzan.txt` |

**路径示例**：
- Windows: `C:\Users\<username>\AppData\Local\Temp\vzan_crawler\liveroomlist_vzan.csv`
- Linux: `/tmp/vzan_crawler/liveroomlist_vzan.csv`

**CSV列名说明**（重要）：

⚠️ **列名不匹配问题**: `dynamicCrawler_vzan.py` 生成的CSV使用**中文列名**，而 `batch_import_tasks_from_csv` 期望**英文列名**。

**爬虫输出列名**（来自 `dynamicCrawler_vzan.py` 第721-736行）：

| 爬虫输出列名（中文） | 批量导入期望列名（英文） | 说明 | 状态 |
|:---|:---|:---|:---:|
| `直播间ID` | `liveroom_id` | 直播间唯一标识（必填）| ⚠️ 列名不匹配 |
| `标题` | `liveroom_title` | 直播间标题（可选）| ⚠️ 列名不匹配 |
| `直播间url` | `liveroom_url` | 直播间URL（可选）| ⚠️ 列名不匹配 |
| `播放url` | `resource_url` | 视频资源URL（必填）| ⚠️ 列名不匹配 |
| - | `resource_type` | 固定值 `'hls'`（微赞默认HLS格式，如从其他源导入可为mp4或image）| ⚠️ 缺失字段 |
| `创建时间` | - | 不导入 | - |
| `开始时间` | - | 不导入 | - |
| `结束时间` | - | 不导入 | - |
| `直播类型` | - | 不导入 | - |
| `直播状态` | - | 不导入 | - |
| `封面图片` | - | 不导入 | - |
| `观看次数` | - | 不导入 | - |
| `zbID` | - | 不导入 | - |
| `enc_tpid` | - | 不导入 | - |
| `直播间总数` | - | 不导入 | - |

**解决方案**（本设计采用方案B）：

**方案B**: 在 `VzanCrawler` 中添加CSV列名转换逻辑
- 在 `VzanCrawler.crawl()` 方法中，爬取完成后添加转换步骤
- 读取中文列名CSV → 转换为英文列名CSV → 原地覆盖原文件
- 优点: 不修改已有爬虫模块 `dynamicCrawler_vzan.py`
- 缺点: 需要额外转换步骤（性能影响可忽略，单次转换约50ms/1000行）
- 实现: 新增私有方法 `_convert_csv_columns(csv_file_path: str) -> int`

**资源管理注意事项**：
1. ⚠️ `DuanShuCrawler_vzan` 初始化时会启动 Playwright 浏览器（`headless=False`）
2. ⚠️ 爬取完成后必须调用 `crawler.close()` 关闭浏览器，否则会导致进程泄漏
3. ⚠️ 不要调用 `crawler.clean_old_files()` 方法（会删除正在使用的CSV文件）

```python
import csv
import logging
import os
import requests
import tempfile
import platform
from pathlib import Path
from datetime import datetime
from typing import Dict, List, Optional, Tuple
from .base_crawler import BaseCrawler
from app.core.exceptions import CrawlerError, CrawlerConfigError, CrawlerAPIError, CrawlerTimeoutError

logger = logging.getLogger(__name__)

class VzanCrawler(BaseCrawler):
    """
    微赞直播间爬虫
    
    核心功能：
    1. 分页爬取微赞直播间列表数据
    2. 支持增量爬取（跳过已爬取的直播间）
    3. 多步骤数据提取：基础信息 → enc_tpid → 视频 URL
    4. 批量写入 CSV 文件
    5. 错误隔离（单条数据失败不影响整体流程）
    """
    
    # 微赞 API 端点
    API_LIVEROOM_LIST = "https://live-liveapi.vzan.com/api/v1/topic/get_topicdatas"
    API_LIVEROOM_URL_PREFIX = "https://inter.dayilive.com/live/page/"
    API_TOPIC_CONFIG_PREFIX = "https://live-play.vzan.com/api/topic/topic_config?isPcBrowser=true&topicId="
    API_VIDEO_CONFIG_PREFIX = "https://live-play.vzan.com/api/topic/video_config?tpId={enc_tpid}&domain=inter.dayilive.com&agentId="
    
    def __init__(self, config: Dict):
        super().__init__(config)
        self.username = config.get('username')
        self.password = config.get('password')
        self.token = config.get('token')
        self.batch_size = config.get('batch_size', 100)
        
        # 动态生成临时目录（根据操作系统）
        if platform.system() == 'Windows':
            self.temp_dir = Path(tempfile.gettempdir()) / 'vzan_crawler'
        else:
            self.temp_dir = Path(tempfile.gettempdir()) / 'vzan_crawler'
        
        self.temp_dir.mkdir(parents=True, exist_ok=True)
        
        # 输出文件路径
        self.liveroom_list_file = self.temp_dir / "liveroomlist_vzan_api.csv"
        self.liveroom_list_inc_file = self.temp_dir / "liveroomlist_inc_vzan_backup.csv"
        self.failed_file = self.temp_dir / "failed_liveroomlist_urls_vzan.txt"
    
    def validate_config(self) -> bool:
        """验证配置"""
        if not all([self.username, self.password, self.token]):
            logger.error("VzanCrawler: Missing required config (username, password, token)")
            return False
        return True
    
    def crawl(self, config: Dict, **kwargs) -> Dict:
        """
        执行微赞爬取（主入口）
        
        Args:
            config: 爬虫配置字典 (包含 token)
            **kwargs: 
                - page_size: 每页数据量（默认10）
                - max_pages: 最大爬取页数（默认全部）
        
        Returns:
            Dict: 爬取结果摘要
        """
        # 1. 验证配置
        if not self.validate_config():
            raise CrawlerConfigError("VzanCrawler配置无效")
        
        # 2. 提取参数
        token = config['token']
        page_size = kwargs.get('page_size', 10)
        max_pages = kwargs.get('max_pages', None)
        
        # 3. 读取已爬取的直播间 ID（用于增量爬取）
        existing_ids = self._load_existing_ids()
        is_first_crawl = not existing_ids
        
        logger.info(f"VzanCrawler: Starting crawl, existing IDs: {len(existing_ids)}")
        
        try:
            # 4. 调用核心爬取逻辑
            result = self._execute_vzan_crawl(
                token=token,
                page_size=page_size,
                max_pages=max_pages,
                existing_ids=existing_ids
            )
            
            logger.info(f"VzanCrawler: Crawl completed - {result['total_rows']} total, "
                       f"{result['incremental_rows']} new, {result['failed_rows']} failed")
            
            return result
            
        except Exception as e:
            logger.error(f"VzanCrawler: Crawl failed - {str(e)}", exc_info=True)
            raise CrawlerError(f"爬取失败: {str(e)}")
    
    def _execute_vzan_crawl(self, token: str, page_size: int, max_pages: Optional[int], 
                            existing_ids: set) -> Dict:
        """
        执行微赞API调用（核心爬取逻辑）
        
        流程：
        1. 调用 get_topicdatas API 获取直播间列表
        2. 对每个直播间，调用 topic_config API 提取 enc_tpid
        3. 对每个直播间，调用 video_config API 提取视频 URL 和封面图
        4. 批量写入 CSV 文件（主文件 + 增量文件）
        5. 记录失败的数据
        """
        # 1. 获取第一页确定总数
        first_page_data = self._get_liveroom_list(token, page=1, psize=page_size)
        if not first_page_data or 'dataObj' not in first_page_data:
            raise CrawlerAPIError("获取直播间列表失败：API响应格式错误")
        
        total_count = first_page_data['dataObj'].get('count', 0)
        if total_count == 0:
            logger.warning("VzanCrawler: 直播间总数为0")
            return {
                "csv_file": str(self.liveroom_list_file),
                "incremental_file": str(self.liveroom_list_inc_file),
                "failed_file": str(self.failed_file),
                "total_rows": 0,
                "failed_rows": 0,
                "incremental_rows": 0
            }
        
        # 2. 计算总页数
        total_pages = (total_count + page_size - 1) // page_size
        if max_pages:
            total_pages = min(total_pages, max_pages)
        
        logger.info(f"VzanCrawler: Total count: {total_count}, pages: {total_pages}")
        
        # 3. 初始化数据容器
        all_new_data = []
        all_failed_data = []
        new_ids = set(existing_ids)
        
        # 4. 创建增量文件
        self._save_to_csv([], self.liveroom_list_inc_file, mode='w')
        
        # 5. 分页爬取
        for page in range(1, total_pages + 1):
            try:
                # 5.1 获取当前页数据
                page_data = self._get_liveroom_list(token, page=page, psize=page_size)
                if not page_data or 'dataObj' not in page_data:
                    logger.error(f"Page {page} 数据格式错误")
                    continue
                
                # 5.2 提取直播间数据（包括调用额外 API 获取 enc_tpid 和视频 URL）
                live_data, failed_data = self._extract_liveroomlist_data(page_data)
                
                # 5.3 过滤新增数据
                new_data = [item for item in live_data 
                           if str(item.get('id', '')).strip() not in new_ids]
                
                if new_data:
                    all_new_data.extend(new_data)
                    new_ids.update(str(item['id']) for item in new_data)
                    logger.info(f"Page {page}/{total_pages}: {len(new_data)} new items")
                
                if failed_data:
                    all_failed_data.extend(failed_data)
                
                # 5.4 批量写入
                if len(all_new_data) >= self.batch_size:
                    self._save_to_csv(all_new_data, self.liveroom_list_file, mode='a')
                    self._save_to_csv(all_new_data, self.liveroom_list_inc_file, mode='a')
                    all_new_data = []
                
            except Exception as e:
                logger.error(f"Page {page} 处理失败: {str(e)}", exc_info=True)
                continue
        
        # 6. 保存剩余数据
        if all_new_data:
            self._save_to_csv(all_new_data, self.liveroom_list_file, mode='a')
            self._save_to_csv(all_new_data, self.liveroom_list_inc_file, mode='a')
        
        # 7. 保存失败数据
        if all_failed_data:
            self._save_to_csv(all_failed_data, self.failed_file, mode='w')
        
        incremental_count = len(new_ids) - len(existing_ids)
        
        return {
            "csv_file": str(self.liveroom_list_file),
            "incremental_file": str(self.liveroom_list_inc_file),
            "failed_file": str(self.failed_file),
            "total_rows": len(new_ids),
            "failed_rows": len(all_failed_data),
            "incremental_rows": incremental_count
        }
    
    def _get_liveroom_list(self, token: str, page: int, psize: int) -> Optional[Dict]:
        """
        调用微赞 API 获取直播间列表
        
        注意：请求头包含完整的微赞 API 必需参数
        """
        headers = {
            'accept': 'application/json, text/plain, */*',
            'accept-language': 'en-US,en;q=0.9',
            'admin-token': 'undefined',
            'appcode': 'agent_setting',
            'authorization': f'Bearer {token}',
            'content-type': 'application/json;charset=UTF-8',
            'generalizeshopid': '0',
            'lid': '11749549',  # 固定值，微赞 API 必需
            'origin': 'https://live.vzan.com',
            'referer': 'https://live.vzan.com/',
            'user-agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
            'zbid': '11749549'  # 固定值，微赞 API 必需
        }
        
        data = {
            "keyword": "",
            "keytype": 1,
            "state": -2,  # -2 表示全部状态
            "psize": psize,
            "page": page,
            "livescene": -1,
            "typeid": -1,
            "types": -1,
            "chanid": 0,
            "isOnShelf": -1,
            "isHQOut": 0,
            "isGHHQOut": 0,
            "starttime": "",
            "endtime": ""
        }
        
        try:
            response = requests.post(
                self.API_LIVEROOM_LIST, 
                headers=headers, 
                json=data, 
                timeout=self.timeout
            )
            
            if response.status_code == 200:
                return response.json()
            else:
                logger.error(f"API 请求失败，状态码: {response.status_code}")
                return None
                
        except requests.exceptions.Timeout:
            raise CrawlerTimeoutError(f"请求超时（{self.timeout}秒）")
        except requests.exceptions.RequestException as e:
            raise CrawlerAPIError(f"API 请求失败: {str(e)}")
    
    def _extract_liveroomlist_data(self, response_data: Dict) -> Tuple[List[Dict], List[Dict]]:
        """
        从 API 响应中提取直播间数据
        
        多步骤提取流程：
        1. 从 get_topicdatas 响应中提取基础信息（id, title, status 等）
        2. 调用 topic_config API 提取 enc_tpid
        3. 调用 video_config API 提取视频 URL 和封面图
        
        Returns:
            (成功数据列表, 失败数据列表)
        """
        if not isinstance(response_data, dict) or 'dataObj' not in response_data:
            return [], []
        
        live_list = response_data['dataObj'].get('list', [])
        extracted_data = []
        failed_data = []
        
        for item in live_list:
            try:
                live_info = {
                    'id': item.get('id', ''),
                    'title': item.get('title', ''),
                    'status': item.get('status', ''),
                    'addtime': item.get('addtime', ''),
                    'starttime': item.get('starttime', ''),
                    'liveType': item.get('liveType', ''),
                    'viewCount': item.get('viewcts', 0),
                    'zbId': item.get('zbId', ''),
                    'liveroom_url': f"{self.API_LIVEROOM_URL_PREFIX}{item.get('id', '')}"
                }
                
                # 步骤2: 获取 enc_tpid
                topic_url = f"{self.API_TOPIC_CONFIG_PREFIX}{live_info['id']}"
                enc_tpid = self._extract_enc_tpid(topic_url)
                if not enc_tpid:
                    live_info['error_reason'] = "提取 enc_tpid 失败"
                    failed_data.append(live_info)
                    continue
                
                live_info['enc_tpid'] = enc_tpid
                
                # 步骤3: 获取视频 URL
                video_url = self.API_VIDEO_CONFIG_PREFIX.format(enc_tpid=enc_tpid)
                play_url, cover_url = self._extract_play_url(video_url)
                if not play_url:
                    live_info['error_reason'] = "提取 play_url 失败"
                    failed_data.append(live_info)
                    continue
                
                live_info['video_url'] = play_url
                live_info['cover_url'] = cover_url
                extracted_data.append(live_info)
                
            except Exception as e:
                logger.error(f"提取直播间数据失败 ID:{item.get('id', 'unknown')}: {str(e)}")
                if 'live_info' in locals():
                    live_info['error_reason'] = str(e)
                    failed_data.append(live_info)
        
        return extracted_data, failed_data
    
    def _extract_enc_tpid(self, topic_url: str) -> str:
        """从 topic_config API 提取 enc_tpid"""
        try:
            response = requests.get(topic_url, timeout=self.timeout)
            if response.status_code != 200:
                return ""
            
            data = response.json()
            if not isinstance(data, dict) or 'dataObj' not in data:
                return ""
            
            return data['dataObj'].get('enc_tpid', '')
        except Exception as e:
            logger.error(f"提取 enc_tpid 失败: {str(e)}")
            return ""
    
    def _extract_play_url(self, video_url: str) -> Tuple[str, str]:
        """从 video_config API 提取播放 URL 和封面图"""
        try:
            response = requests.get(video_url, timeout=self.timeout)
            if response.status_code != 200:
                return "", ""
            
            data = response.json()
            if not isinstance(data, dict) or 'dataObj' not in data:
                return "", ""
            
            data_obj = data['dataObj']
            play_url = data_obj.get('playUrl', '')
            cover_url = data_obj.get('cover', '')
            
            return play_url, cover_url
        except Exception as e:
            logger.error(f"提取 play_url 失败: {str(e)}")
            return "", ""
    
    def _load_existing_ids(self) -> set:
        """从主 CSV 文件加载已爬取的直播间 ID"""
        if not self.liveroom_list_file.exists():
            return set()
        
        try:
            with open(self.liveroom_list_file, 'r', encoding='utf-8-sig') as f:
                reader = csv.DictWriter(f, fieldnames=[])
                next(reader)  # 跳过表头
                return {row['liveroom_id'] for row in reader if row.get('liveroom_id')}
        except Exception as e:
            logger.error(f"加载已有 ID 失败: {str(e)}")
            return set()
    
    def _save_to_csv(self, data: List[Dict], filepath: Path, mode: str = 'w') -> None:
        """
        保存数据到 CSV 文件
        
        CSV 字段（与批量导入所需字段对应）：
        - liveroom_id: 直播间ID（必填）
        - liveroom_title: 直播间标题（必填）
        - liveroom_url: 直播间URL（可选）
        - resource_url: 视频资源URL（必填，批量导入的核心字段）
        - resource_type: 资源类型（hls/mp4/image）
        - created_at: 创建时间
        - start_time: 开始时间
        - live_type: 直播类型
        - status: 状态
        - cover_url: 封面图
        - view_count: 观看次数
        - zb_id: zbID
        - enc_tpid: enc_tpid
        """
        if not data and mode == 'w':
            # 创建空文件并写入表头
            fieldnames = [
                'liveroom_id', 'liveroom_title', 'liveroom_url', 'resource_url', 'resource_type',
                'created_at', 'start_time', 'live_type', 'status', 'cover_url',
                'view_count', 'zb_id', 'enc_tpid'
            ]
            with open(filepath, 'w', newline='', encoding='utf-8-sig') as f:
                writer = csv.DictWriter(f, fieldnames=fieldnames)
                writer.writeheader()
            return
        
        file_exists = filepath.exists()
        fieldnames = [
            'liveroom_id', 'liveroom_title', 'liveroom_url', 'resource_url', 'resource_type',
            'created_at', 'start_time', 'live_type', 'status', 'cover_url',
            'view_count', 'zb_id', 'enc_tpid'
        ]
        
        with open(filepath, mode, newline='', encoding='utf-8-sig') as f:
            writer = csv.DictWriter(f, fieldnames=fieldnames)
            
            if not file_exists or mode == 'w':
                writer.writeheader()
            
            for item in data:
                row = {
                    'liveroom_id': item.get('id', ''),
                    'liveroom_title': item.get('title', ''),
                    'liveroom_url': item.get('liveroom_url', ''),
                    'resource_url': item.get('video_url', ''),  # 批量导入的核心字段
                    'resource_type': 'hls',  # 微赞视频默认为 HLS 格式
                    'created_at': item.get('addtime', ''),
                    'start_time': item.get('starttime', ''),
                    'live_type': item.get('liveType', ''),
                    'status': item.get('status', ''),
                    'cover_url': item.get('cover_url', ''),
                    'view_count': item.get('viewCount', 0),
                    'zb_id': item.get('zbId', ''),
                    'enc_tpid': item.get('enc_tpid', '')
                }
                writer.writerow(row)
```

```python
def crawl_and_import_tasks(
    self,
    crawler_type: str,
    user_id: uuid.UUID,
    skip_duplicates: bool = True,
    auto_start: bool = False,
    **crawl_kwargs

    """
    执行爬取并批量导入下载任务
    
    Args:
        crawler_type: 爬虫类型（vzan, douyin等）
        user_id: 当前用户ID

            - page_size: 每页数据量（默认10）
            - max_pages: 最大爬取页数（默认全部）
    
    Returns:
        Dict: {
            "crawl_status": "success" | "failed",
            "crawl_rows": int,           # 爬取到的行数
            "crawl_file": str,           # 主 CSV 文件路径
            "incremental_file": str,     # 增量 CSV 文件路径
            "failed_file": str,          # 失败记录文件路径
            "import_result": {           # 导入结果（与batch_import_tasks_from_csv返回格式一致）
                "total": int,
                "success": int,
                "failed": int,
                "skipped": int,
                "created_task_ids": List[str],
                "failed_rows": List[Dict],
                "skipped_rows": List[Dict],
                "processing_time": float
            },
            "error_message": str  # 错误信息（如果有）
        }
    
    Raises:
        CrawlerError: 爬虫执行失败
        ValueError: 参数错误
        DatabaseError: 数据库操作失败
    
    实现流程（遵循服务层方法实现通用流程）：
    
    【第一步：变量提取（安全异步异常处理）】
        - 提取 `user_id_for_logging = str(user_id)`
        - 提取 `crawler_type_for_logging = crawler_type`
        - 目的：在异常处理中安全使用这些值，避免访问失效的ORM对象
    
    【第二步：记录开始日志】
        - `logger.info(f"Starting crawl_and_import - User: {user_id_for_logging}, Crawler: {crawler_type_for_logging}")`
    
    【第三步：try-except包裹】
        将以下所有业务逻辑包裹在try-except块中
    
    【第四步：执行业务逻辑】
        1. 验证 crawler_type 参数
        2. 从环境变量读取爬虫配置（username, password, token）
        3. Token 解密（使用 TokenEncryption.decrypt）
        4. 创建爬虫实例（使用 CrawlerFactory.create）
        5. 执行爬取（调用 crawler.crawl）
        6. **选择导入文件**（重要：优先增量文件）：
           a. 检查增量文件是否存在且非空（incremental_rows > 0）
           b. 如果增量文件可用：
              - 使用增量文件导入
              - 记录日志：`logger.info(f"使用增量文件导入 - 行数: {incremental_rows}")`
           c. 如果增量文件不可用（不存在/为空/读取失败）：
              - 使用主文件导入
              - 强制启用去重：`skip_duplicates = True`
              - 记录日志：`logger.info(f"增量文件不可用，使用主文件导入（启用去重）")`
        7. 读取选定的 CSV 文件内容（file_content）
        8. 调用 batch_import_tasks_from_csv 方法导入数据
           注意：此方法内部已有异常处理和rollback，此处无需额外rollback
        9. 根据配置决定是否删除临时 CSV 文件
           ⚠️ 重要：只删除增量文件和失败文件，不删除主文件
           - 主文件必须保留，作为下次增量爬取的基准
           - 如果删除主文件，下次爬取会被视为首次爬取，失去增量爬取能力
        10. 记录成功日志：`logger.info(f"Crawl and import completed - User: {user_id_for_logging}, Rows: {crawl_rows}")`
    
    【第五步：异常处理】
        - CrawlerConfigError: 
          * 记录日志：`logger.error(f"Crawler config error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
          * 抛出异常：`raise CrawlerConfigError(f"爬虫配置错误: {str(e)}")`
          * 无需rollback（未涉及数据库操作）
        - CrawlerTimeoutError:
          * 记录日志：`logger.error(f"Crawler timeout - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
          * 抛出异常：`raise CrawlerTimeoutError(f"爬取超时: {str(e)}")`
        - CrawlerAPIError:
          * 记录日志：`logger.error(f"Crawler API error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
          * 抛出异常：`raise CrawlerAPIError(f"API调用失败: {str(e)}")`
        - FileNotFoundError:
          * 记录日志：`logger.error(f"CSV file not found - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
          * 抛出异常：`raise FileNotFoundError(f"CSV文件未生成: {str(e)}")`
        - ValueError:
          * 记录日志：`logger.error(f"Parameter error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
          * 抛出异常：`raise ValueError(f"参数错误: {str(e)}")`
        - SQLAlchemyError:
          * 记录日志：`logger.error(f"Database error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
          * 执行 `self.db.rollback()`
          * 抛出异常：`raise DatabaseError(f"数据库错误: {str(e)}")`
        - Exception:
          * 记录日志：`logger.error(f"Unexpected error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
          * 执行 `self.db.rollback()`（安全起见）
          * 抛出异常：`raise`
    
    【第六步：返回结果】
        - 返回类型：Dict（爬取和导入的综合结果）
        - 包含字段：crawl_status, crawl_rows, crawl_file, incremental_file, failed_file, import_result, error_message
    
    异常处理：
        - CrawlerConfigError: 返回业务错误码 400
        - CrawlerTimeoutError: 返回业务错误码 500，记录超时日志
        - CrawlerAPIError: 返回业务错误码 500，记录 API 错误日志
        - FileNotFoundError: CSV 文件未生成，返回业务错误码 500
        - ValueError: 参数验证失败，返回业务错误码 400
        - 数据库异常: 执行 rollback，返回业务错误码 500
        - 未知异常: 记录详细日志，返回业务错误码 1000
    
    日志记录：
        - INFO: 爬取开始、爬取完成、导入开始、导入完成
        - WARNING: 部分数据导入失败
        - ERROR: 爬取失败、导入失败、文件操作失败
    """
```

  * HTTP状态码：200

```python
    - douyin (未来): ...
    - kuaishou (未来): ...
    """
    page_size: Optional[int] = Field(10, ge=1, le=100, description="每页数据量")
    max_pages: Optional[int] = Field(None, ge=1, description="最大爬取页数（None表示全部）")
    
    model_config = ConfigDict(extra='allow')  # 允许扩展字段

class CrawlAndImportRequest(BaseModel):
    """爬取并导入请求模型"""
    crawler_type: str = Field(..., description="爬虫类型（vzan, douyin等）")
    skip_duplicates: bool = Field(True, description="是否跳过重复任务组合（resource_url + liveroom_id + liveroom_title）")
    auto_start: bool = Field(False, description="导入后是否自动启动任务")
    crawl_options: Optional[CrawlOptions] = Field(None, description="爬虫特定参数")
    
    @field_validator('crawler_type')
    def validate_crawler_type(cls, v):
        allowed_types = ['vzan', 'douyin', 'kuaishou']  # 支持的爬虫类型
        if v not in allowed_types:
            raise ValueError(f"不支持的爬虫类型: {v}，支持的类型: {', '.join(allowed_types)}")
        return v
```

## 五、安全设计

### 5.1 Token安全管理

#### 5.1.1 Token加密存储

**方案**: 使用Fernet对称加密

```python
from cryptography.fernet import Fernet
import os

class TokenEncryption:
    """Token加密工具"""
    
    def __init__(self):
        # 从环境变量读取加密密钥
        # 密钥应在部署时生成并安全保存，不提交到版本控制
        encryption_key = os.getenv('TOKEN_ENCRYPTION_KEY')
        if not encryption_key:
            raise ValueError("TOKEN_ENCRYPTION_KEY环境变量未设置")
        self.cipher = Fernet(encryption_key.encode())
    
    def encrypt(self, token: str) -> str:
        """加密token"""
        return self.cipher.encrypt(token.encode()).decode()
    
    def decrypt(self, encrypted_token: str) -> str:
        """解密token"""
        return self.cipher.decrypt(encrypted_token.encode()).decode()
```

**使用流程**:
1. 初次配置时，管理员手动加密token: `python scripts/encrypt_token.py <原始token>`
2. 将加密后的token写入 `.env` 文件: `VZAN_TOKEN=<加密后的token>`
3. 应用启动时，自动解密token使用

#### 5.1.2 Token刷新机制

- 定期检查token是否过期（通过API返回状态判断）
- 如果token过期，记录错误日志并通知管理员
- 管理员手动更新token并重启服务（未来可实现自动刷新）

```python
class CrawlerError(Exception):
    """爬虫基础异常"""

    pass

    """爬虫超时错误"""
    pass

    """爬虫API调用错误"""
    pass
```

#### 6.1.2 异常处理流程

```python
try:
    # 1. 执行爬取
    csv_path = crawler.crawl(url, **options)
except CrawlerConfigError as e:
    # 配置错误，直接返回400
    return JSONResponse(
        status_code=200,
        content=create_error_response(message=f"爬虫配置错误: {str(e)}", code=400)
    )
except CrawlerTimeoutError as e:
    # 超时错误，返回500，但不影响后续重试
    return JSONResponse(
        status_code=200,
        content=create_error_response(message=f"爬取超时: {str(e)}", code=500)
    )
except CrawlerAPIError as e:
    # API错误，返回500
    return JSONResponse(
        status_code=200,
        content=create_error_response(message=f"API调用失败: {str(e)}", code=500)
    )
except Exception as e:
    # 未知错误
    logger.error(f"Crawl failed with unexpected error: {str(e)}", exc_info=True)
    return JSONResponse(
        status_code=200,
        content=create_error_response(message="系统内部错误", code=1000)
    )
```

#### 7.3.1 Token加密脚本

`scripts/encrypt_token.py`:

```python
#!/usr/bin/env python3
"""Token加密工具"""
import sys
from cryptography.fernet import Fernet

def generate_key():
    """生成新的加密密钥"""
    key = Fernet.generate_key()
    print(f"生成的加密密钥: {key.decode()}")
    print("请将此密钥保存到环境变量 TOKEN_ENCRYPTION_KEY 中")
    return key

def encrypt_token(token: str, key: str):
    """加密token"""
    cipher = Fernet(key.encode())
    encrypted = cipher.encrypt(token.encode())
    print(f"加密后的Token: {encrypted.decode()}")
    return encrypted.decode()

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("用法: python encrypt_token.py <token> [encryption_key]")
        print("如果未提供encryption_key，将生成新密钥")
        sys.exit(1)
    
    token = sys.argv[1]
    
    if len(sys.argv) == 3:
        key = sys.argv[2]
    else:
        key = generate_key().decode()
    
    encrypt_token(token, key)
```

**使用步骤**:

```bash

# 输出:
# 生成的加密密钥: x3K8fN2pQ7...
# 加密后的Token: gAAAAABf...

# 2. 将输出的密钥和加密后的token添加到.env
echo "TOKEN_ENCRYPTION_KEY=x3K8fN2pQ7..." >> .env
echo "VZAN_TOKEN=gAAAAABf..." >> .env
```
