## 4. API 变更（新增端点）

### 4.1.x 获取焦点图详情（Admin）

**Endpoint**: `GET /api/v1/featured-content/admin/{content_id}`

**描述**: 管理员根据焦点图 ID 获取单条焦点图完整信息，用于详情页展示。返回内容与分页列表中的单条结构一致（即主文档 Section 3.1 的 `FeaturedContentItem`），不做 is_active/start_at/end_at 过滤。

**认证**: 需要 `ADMIN` 或 `SUPERADMIN` 角色；与更新/删除一致，使用 `Depends(get_current_user)`，Service 层 `_check_admin_permission(role)`。

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `content_id` | UUID | 是 | 焦点图 ID |

**请求体**: 无。

**成功响应** (`200 OK`): 统一成功格式，`data` 为单条 `FeaturedContentItem`（与主文档 Section 3.1、分页列表单条一致），例如：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": "30ff8a3e-d108-4a94-ba95-2a9a1b42b792",
    "title": "全国骨科学术研讨会",
    "subtitle": "2026年1月10-12日",
    "image_url": "/media/featured_content/30ff8a3e-.../image_1770178321.jpg",
    "target_type": "session",
    "target_id": "session_uuid_123",
    "target_url": null,
    "sort_order": 0,
    "is_active": true,
    "start_at": "2025-10-25T00:00:00Z",
    "end_at": "2025-11-25T23:59:59Z",
    "created_at": "2025-10-23T14:00:00Z",
    "updated_at": "2025-10-23T14:00:00Z"
  },
  "timestamp": "2026-02-04T12:00:00Z"
}
```

**执行流程**:

1. **鉴权**: API 层 `Depends(get_current_user)`；Service 层 `_check_admin_permission(role)`，非管理员返回 403（业务码 `3002`）。
2. **路径参数**: 解析 `content_id` 为 UUID（由 FastAPI 路径参数自动校验）。
3. **查询**: Service 调用 CRUD `get_featured_content_by_id(db, content_id)`，不施加 is_active/start_at/end_at 过滤。
4. **不存在**: 若 CRUD 返回 `None`，Service 抛出 `NotFoundException("焦点图不存在: {content_id}")`，API 返回 404，业务码 `2001`。
5. **序列化与返回**: Service 将 ORM 对象序列化为 `FeaturedContentItem`（`FeaturedContentItem.model_validate(content).model_dump(mode='json')`），放入统一响应 dict（code、message、data、timestamp）；API 返回 `JSONResponse(status_code=200, content=result)`。

**错误响应**:

- `401`: 未提供 Token 或 Token 无效。
- `403` / 业务码 `3002`: 非 ADMIN/SUPERADMIN。
- `404` / 业务码 `2001`: 焦点图不存在（无该 `content_id` 或已硬删除）。

## 7. 执行流程与错误处理

### 7.1 获取焦点图详情（Admin）（新增）

1. API 层：`Depends(get_current_user)`，提取 `user_id`、`role`（`.upper()`），进入 try 块。
2. 调用 Service：`get_featured_content_detail_admin(db, content_id, user_id, role)`。
3. Service 层：`_check_admin_permission(role)`；`content = crud.get_featured_content_by_id(db, content_id)`；若 `content is None` 则 `raise NotFoundException("焦点图不存在: {content_id}")`；否则 `content_item = FeaturedContentItem.model_validate(content).model_dump(mode='json')`，返回 `success_response(data=content_item)` 或与同文件其他 Admin 方法一致的 dict 格式（code、message、data、timestamp）。
4. API 层：成功则 `JSONResponse(status_code=200, content=result)`；异常映射：PermissionDeniedException → 403/3002；NotFoundException → 404/2001；Exception → 500/5001。

- 权限：无 Token 或 REGULAR Token 调用同一 URL，断言 401 或 403。
