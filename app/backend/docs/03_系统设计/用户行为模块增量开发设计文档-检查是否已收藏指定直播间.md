## API 变更（新增端点）

### 4.1.4 检查是否已收藏指定直播间（用户）

**Endpoint**: `GET /api/v1/rooms/{room_id}/is-favorited`

**描述**: 检查当前用户是否已收藏指定直播间。形态对齐专家模块 `GET /api/v1/experts/{expert_id}/is-followed`。

**认证**: Strict Auth（需要 JWT Token，无 Token 返回 401）

**路径参数**:
- `room_id` (UUID)：直播间 ID

**成功响应** (`200 OK`):
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "is_favorited": true
  },
  "timestamp": "2025-10-23T14:25:00Z"
}
```
或 `"is_favorited": false`。

**错误响应**:
- `400` / `4001`：room_id 格式无效（非 UUID）
- `404` / `2001`：直播间不存在
- `401` / `3001`：未认证（Token 缺失或无效）
- `500` / `1002`：数据库错误（遵循主文档 6.1）

**业务规则**:
1. 校验直播间存在：查询 `live_rooms`，不存在则返回 2001。
2. 查询 `user_favorites`：条件为 `user_id` + `room_id` + `is_active = true`；存在则 `is_favorited = true`，否则 `false`。
3. 错误码与日志遵循主文档 Section 1.4.3、6.1。

## 执行流程与错误处理

### 检查是否已收藏（4.1.4）执行流程

1. **JWT 验证**：提取 `user_id`（Strict Auth，无 Token 返回 401）。
2. **路径参数校验**：验证 `room_id` 为合法 UUID，否则返回 400/4001。
3. **直播间存在性校验**：调用 room CRUD/Service 查询 `live_rooms` 表；若不存在则抛出 `NotFoundException`，API 层返回 404、code 2001。
4. **收藏状态查询**：调用 `get_favorite(db, user_id, room_id)`；`is_favorited = (favorite is not None and favorite.is_active)`。
5. **日志**：DEBUG 级别记录 user_id（前 8 位）、room_id（前 8 位）、is_favorited，遵循主文档 1.4.3 脱敏。
6. **响应**：返回 `{"code": 200, "data": {"is_favorited": true|false}}`。

错误隔离：直播间不存在与未收藏区分明确（不存在即 404，存在则仅返回 false）。

## 测试建议

- **正常**：已收藏该直播间 → 200，`data.is_favorited === true`；未收藏 → 200，`data.is_favorited === false`。
- **边界**：room_id 不存在 → 404、code 2001；room_id 非 UUID → 400/422、code 4001；无 Token → 401、code 3001。
- **与专家 is-followed 对齐**：响应结构一致（单布尔字段），错误码与主文档一致。
