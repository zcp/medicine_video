#### **3.4. 数据库初始化脚本说明 (重要)**

项目中有两个数据库初始化脚本，它们的工作方式不同：

##### **脚本1: `app/init_db.py` (推荐使用)**

**特点**: 通过包级导入自动识别所有模型

```python
# init_db.py 第8行
import app.models  # 确保所有模型被导入
```

**工作原理**:
1. `import app.models` 会执行 `models/__init__.py`
2. `models/__init__.py` 中的所有 `from .xxx import YYY` 会被执行
3. 所有导出的模型会自动注册到 `Base.metadata`
4. `Base.metadata.create_all(bind=engine)` 会创建所有表

**增量开发适配**:
- ✅ **完美适配**: 只需在 `models/__init__.py` 中追加导入
- ✅ **无需修改**: `init_db.py` 本身不需要任何修改
- ✅ **自动识别**: 新模型会被自动识别和创建

**使用方式**:
```bash
cd backend/live_core_service
python app/init_db.py
```

---

##### **脚本2: `app/scripts/create_tables.py` (不推荐修改)**

**特点**: 需要显式导入每个模型类

```python
# create_tables.py 第46-52行
from ..models.live_core import (
    Base,
    LiveRoom,
    LiveSession, 
    SessionStatistics,
    LiveSessionStatus
)
```

**工作原理**:
1. 显式从 `models/live_core.py` 导入每个模型类
2. 每个导入的模型会注册到 `Base.metadata`
3. `Base.metadata.create_all(bind=engine)` 创建所有注册的表

**增量开发适配**:
- ❌ **不适配**: 需要修改脚本添加新模型的导入
- ❌ **违反原则**: 修改已有文件违反增量开发原则
- ❌ **维护成本**: 每次添加模型都要修改此文件

**如果要使用** (不推荐):

#### **3.5. 数据库设计规范 (Database Design Specification)**

根据 `docs/03_系统设计/专题功能完整设计文档-修正版.md` 的要求：

**表1: topics (专题表)**
- **主键**: `id` (UUID, 应用层生成)
- **用户关联**: `user_id` (UUID, NOT NULL, 需要索引)
  - ⚠️ **重要说明**: `user_id` 对应 `users` 表的 `public_id` 字段（而非 `id` 字段）
  - 📌 **外键约束**: 不使用数据库级 `ForeignKey`，通过应用层（JWT Token）保证引用完整性
  - 📌 **原因**: User 服务可能独立部署，且 JWT Token 中存储的是 `public_id`
- **业务字段**: 
  - `title` (VARCHAR(100), NOT NULL)
  - `description` (TEXT, 可选)
  - `banner_url` (VARCHAR(255), 可选)
  - `status` (ENUM: 'draft', 'published', 'archived', DEFAULT 'draft')
- **时间戳**: `created_at`, `updated_at` (TIMESTAMPTZ, NOT NULL)
- **索引**: `user_id`, `status`, `created_at` (DESC)
- **关联**: 一对多关联到 `topic_categories`

**表2: topic_categories (专题内分类表)**
- **主键**: `id` (UUID, 应用层生成)
- **外键**: `topic_id` (UUID, NOT NULL, REFERENCES topics(id) ON DELETE CASCADE)
- **业务字段**:
  - `name` (VARCHAR(50), NOT NULL)
  - `sort_order` (INT, DEFAULT 0)
- **时间戳**: `created_at`, `updated_at` (TIMESTAMPTZ, NOT NULL)
- **索引**: `topic_id`, 组合索引 `(topic_id, sort_order)`
- **关联**: 
  - 多对一关联到 `topics`
  - 一对多关联到 `topic_category_rooms`

**表3: topic_category_rooms (关联表)**
- **主键**: `id` (UUID, 应用层生成)
- **外键**: 
  - `category_id` (UUID, NOT NULL, REFERENCES topic_categories(id) ON DELETE CASCADE)
  - `room_id` (UUID, NOT NULL, REFERENCES live_rooms(id) ON DELETE CASCADE)
- **业务字段**: `sort_order` (INT, DEFAULT 0)
- **时间戳**: `created_at`, `updated_at` (TIMESTAMPTZ, NOT NULL)
- **唯一约束**: `UNIQUE(category_id, room_id)`
- **索引**: `category_id`, `room_id`, 组合索引 `(category_id, sort_order)`
- **关联**: 
  - 多对一关联到 `topic_categories`
  - 多对一关联到 `live_rooms`
