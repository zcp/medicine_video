## 4. 审查清单 (Audit Checklist)

### 4.1 表与模型映射

- [ ] 表 `official_accounts` 对应模型 `OfficialAccount`，__tablename__ = "official_accounts"
- [ ] 表 `live_room_official_accounts` 对应模型 `LiveRoomOfficialAccount`，__tablename__ = "live_room_official_accounts"

### 4.2 字段与列完全对应

**official_accounts**:
- [ ] id UUID PRIMARY KEY，应用层 default=uuid.uuid4
- [ ] name VARCHAR(100) NOT NULL UNIQUE
- [ ] slug VARCHAR(120) NULL
- [ ] app_id VARCHAR(255) NULL
- [ ] description VARCHAR(500) NULL
- [ ] is_active BOOLEAN NOT NULL DEFAULT true
- [ ] created_at, updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP；updated_at 触发器或 onupdate=func.now()

**live_room_official_accounts**:
- [ ] room_id UUID NOT NULL，FK(live_rooms.id) ON DELETE CASCADE，主键之一
- [ ] account_id UUID NOT NULL，FK(official_accounts.id) ON DELETE CASCADE，主键之一
- [ ] created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP

### 4.3 主键与外键

- [ ] official_accounts 主键 id
- [ ] live_room_official_accounts 复合主键 (room_id, account_id)
- [ ] 外键命名与 DDL 一致；ON DELETE CASCADE

### 4.4 索引

- [ ] idx_official_accounts_name(name)、idx_official_accounts_is_active(is_active)
- [ ] idx_live_room_official_accounts_room_id(room_id)、idx_live_room_official_accounts_account_id(account_id)

### 4.5 项目规范

- [ ] Base 从 app.database 导入
- [ ] TIMESTAMP 从 sqlalchemy 导入；UUID 从 sqlalchemy.dialects.postgresql 导入
- [ ] 使用 __table_args__ 显式索引，未使用 index=True
