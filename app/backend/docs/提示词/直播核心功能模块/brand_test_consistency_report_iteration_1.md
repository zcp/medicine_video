### 问题根源分析

虽然测试失败的错误是`AttributeError: type object 'BrandTopic' has no attribute 'topic'`，但**问题不在测试代码**，而在**后端CRUD实现代码**。

**证据**：
1. 设计文档（Section 1777-1787行）要求通过JOIN查询获取关联专题，而不是通过ORM关系属性
2. BrandTopic模型注释（app/models/brand.py:98行）明确说明："Topic模型由专题功能模块定义，这里不定义relationship，避免循环导入"
3. 后端CRUD代码（app/crud/brand.py:82行）使用了`selectinload(BrandTopic.topic)`，但BrandTopic模型没有定义`topic`关系属性

**修复建议**：
- **修复目标**：后端CRUD代码（`app/crud/brand.py`）
- **修复方法**：修改`get_brand_with_topics`函数，使用JOIN查询或通过`topic_id`手动查询Topic对象，而不是使用不存在的`BrandTopic.topic`关系

**建议**: 测试代码无需修改，应修复后端CRUD实现代码。
