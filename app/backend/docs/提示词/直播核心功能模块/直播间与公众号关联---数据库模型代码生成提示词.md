### 3.2 现有代码参考 (Existing Code Reference)

参考 `app/models/content_management.py` 中的 **Tag**、**Category**（主表）与 **LiveRoomCategory**（关联表）风格：

**关键观察点**：
1. Base 导入：`from app.database import Base`
2. 导入：`uuid`、`Column, String, Text, Integer, ForeignKey, Boolean, Index, TIMESTAMP`（TIMESTAMP 从 `sqlalchemy` 导入）、`UUID` 从 `sqlalchemy.dialects.postgresql`、`relationship`、`func`
3. UUID 主键：`Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)`
4. 时间戳：`TIMESTAMP(timezone=True), nullable=False, server_default=func.now()`，updated_at 使用 `onupdate=func.now()`
5. 索引：`__table_args__ = (Index('idx_表名_字段名', '字段名'), ...)`
6. 唯一约束：表级 `UNIQUE (name)` 对应 Column 上 `unique=True`，或 `__table_args__` 中 `UniqueConstraint`
7. 关联表：复合主键 `room_id` + `account_id`，外键 `ForeignKey("表.id", ondelete="CASCADE")`，`relationship` 与 `backref`/`back_populates`
8. 软删除：主表用 `is_active`；关联表硬删除，ON DELETE CASCADE
9. 字段注释：关键字段使用 `comment=`
10. `__repr__`：建议为每个模型添加，仅包含非敏感标识（如 id、name）

### 3.5 设计文档 DDL 提取（须与下列完全一致）

#### 表 1：official_accounts（公众号主表）

- **表名**: `official_accounts`
- **字段**:
  - `id` UUID PRIMARY KEY（应用层 uuid.uuid4()）
  - `name` VARCHAR(100) NOT NULL, UNIQUE
  - `slug` VARCHAR(120) NULL
  - `app_id` VARCHAR(255) NULL
  - `description` VARCHAR(500) NULL
  - `is_active` BOOLEAN NOT NULL DEFAULT true
  - `created_at` TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
  - `updated_at` TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP（由触发器更新）
- **索引**: idx_official_accounts_name(name), idx_official_accounts_is_active(is_active)
- **触发器**: 设计文档中由 `trigger_set_timestamp_official_accounts` 更新 updated_at；SQLAlchemy 可用 `onupdate=func.now()` 或依赖数据库触发器，二者择一即可，与现有 content_management 一致用 `onupdate=func.now()`

#### 表 2：live_room_official_accounts（直播间-公众号关联表）

- **表名**: `live_room_official_accounts`
- **字段**:
  - `room_id` UUID NOT NULL，FK → live_rooms(id) ON DELETE CASCADE，主键之一
  - `account_id` UUID NOT NULL，FK → official_accounts(id) ON DELETE CASCADE，主键之一
  - `created_at` TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
- **主键**: (room_id, account_id)
- **索引**: idx_live_room_official_accounts_room_id(room_id), idx_live_room_official_accounts_account_id(account_id)

## 4. 代码生成具体要求 (Specific Code Generation Requirements)

### 4.1 导入语句

```python
"""
直播间与公众号关联模块的数据库模型
"""
import uuid
from sqlalchemy import Column, String, Text, Boolean, ForeignKey, Index, TIMESTAMP
from sqlalchemy.dialects.postgresql import UUID
from sqlalchemy.orm import relationship
from sqlalchemy.sql import func

from app.database import Base  # 注意：Base 在 database.py 中，不是 models/base.py
```

- TIMESTAMP 从 `sqlalchemy` 导入；UUID 从 `sqlalchemy.dialects.postgresql` 导入
- 不使用 Enum 时无需 SAEnum

### 4.2 OfficialAccount 模型

- `__tablename__ = "official_accounts"`
- 字段顺序：id → name, slug, app_id, description, is_active → created_at, updated_at
- name：`String(100), nullable=False, unique=True, comment='公众号名称，全局唯一'`
- description：`String(500)` 或 `Text`，设计文档为 VARCHAR(500)，建议 `String(500)`
- 索引：`idx_official_accounts_name`, `idx_official_accounts_is_active`
- `__repr__`：可返回 `f"<OfficialAccount(id={self.id}, name={self.name})>"`

### 4.3 LiveRoomOfficialAccount 模型

- `__tablename__ = "live_room_official_accounts"`
- 复合主键：`room_id`、`account_id` 均为 `primary_key=True`
- 外键：`ForeignKey("live_rooms.id", ondelete="CASCADE")`、`ForeignKey("official_accounts.id", ondelete="CASCADE")`
- `created_at`：`TIMESTAMP(timezone=True), nullable=False, server_default=func.now()`
- 索引：`idx_live_room_official_accounts_room_id`、`idx_live_room_official_accounts_account_id`
- relationship：可 `relationship("OfficialAccount", ...)` 与对 LiveRoom 的 backref，注意避免循环导入（LiveRoom 在 live_core 中）

### 4.4 增量开发（初始模式）说明

- **仅新建** `app/models/liveroom_official_accounts.py`
- **仅修改** `app/models/__init__.py`：在**文件末尾**追加：
  - `from .liveroom_official_accounts import OfficialAccount, LiveRoomOfficialAccount`
- 不修改 `database.py`、`init_db.py`、`live_core.py`、`content_management.py`
- 创建表：运行 `python app/init_db.py`（通过 `import app.models` 自动注册本模块模型）
