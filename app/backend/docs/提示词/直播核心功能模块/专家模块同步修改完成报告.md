#### 问题2：HTTP方法从 `PUT` 改为 `PATCH`

**修改位置**：
- 文件：`backend/live_core_service/app/api/v1/endpoints/experts.py`
- 函数：`update_expert`
- 行号：69

**修改前**：
```python
@router.put("/experts/{expert_id}")
```

**修改后**：
```python
@router.patch("/experts/{expert_id}")
```

**理由**：
- `PATCH` 用于部分更新，`PUT` 用于完整替换
- `ExpertUpdate` Schema 中所有字段都是可选的，应该使用 `PATCH`
- 符合 REST 最佳实践和设计文档规范
