## 3. 核心实现规范（继承既有测试提示词 Section 3）

- **3.1** 测试环境：conftest 已有 `db_session`、`async_client`、`async_session_factory`；增量模式仅允许添加新 Fixture，禁止修改/删除已有内容。
- **3.2** 所有用例遵循 Arrange-Act-Assert，并用注释分段。
- **3.3** 使用 `async for db in db_session:`、`async for client in async_client:` 解包，禁止直接使用 fixture 参数。
- **3.4** **函数式测试**：禁止类式测试（`class TestXXX:`），新测试一律为模块级函数。
- **3.5** 外键：**禁止**用 `uuid.uuid4()` 作为外键；先创建 LiveRoom、Category，再用其 id。Live_Room_Categories 依赖 live_rooms、categories。
- **3.6** 唯一字段使用 Faker 或 `uuid.uuid4().hex[:8]`，禁止硬编码。
- **3.7** 增量验证：创建前记录 count/ids，创建后断言增量；列表断言新 id 在结果中。
- **3.8** Service 层：`db` 使用 `AsyncMock()`；CRUD 使用 `mocker.patch(..., new_callable=AsyncMock)`；Mock 路径为 `app.crud.content_management.xxx`、`app.crud.room.get`。
- **3.9** 默认不 `commit`；仅唯一性/级联/外键测试可 commit。

## 4. 按层级断言规范（继承既有测试提示词 Section 4）

- **API**：断言 status_code、`response.json()["code"]`、`response.json()["data"]`；错误时断言 2001/4001/3003。
- **Service**：`pytest.raises(NotFoundException|PermissionDeniedException|InvalidParameterException)`；Mock 调用 `assert_called_once_with(...)`，参数与源码一致。
- **CRUD**：操作后 `db.refresh(obj)` 或再次 select 验证；增量场景验证 count+1 或新 id 在列表中。

## 7. 具体测试任务列表（仅增量：Live_Room_Categories）

以下测试**追加**到已有文件，不修改已有用例。

### A. CRUD 层（追加到 `tests/unit/test_crud_content_management.py`）

- **get_categories_by_room_id(db, room_id)**  
  - `test_get_categories_by_room_id_success`：先创建 LiveRoom、2 个 Category（is_active=True）、2 条 LiveRoomCategory；调用 get_categories_by_room_id；断言返回 2 个 Category，且仅含 is_active=True。  
  - `test_get_categories_by_room_id_empty`：创建 LiveRoom，不创建 LiveRoomCategory；调用 get_categories_by_room_id；断言返回空列表。  
  - `test_get_categories_by_room_id_excludes_inactive`：创建 LiveRoom、1 个 is_active=True 的 Category、1 个 is_active=False 的 Category，均关联到 room；调用 get_categories_by_room_id；断言只返回 1 个（is_active=True）。

- **set_live_room_categories(db, room_id, category_ids, mode)**  
  - `test_set_live_room_categories_replace_mode`：创建 LiveRoom、3 个 Category；先关联 2 个，再 set_live_room_categories(mode="replace", category_ids=[第3个])；断言 get_categories_by_room_id 仅返回第 3 个。  
  - `test_set_live_room_categories_append_mode`：创建 LiveRoom、3 个 Category；先关联 1 个，再 set_live_room_categories(mode="append", category_ids=[第2、3个])；断言返回 3 个。  
  - `test_set_live_room_categories_integrity_error`：room_id 或 category_id 不存在时（如随机 UUID），断言抛出 DatabaseIntegrityException（或 DB 层等价异常）。

- **delete_live_room_category(db, room_id, category_id)**  
  - `test_delete_live_room_category_success`：创建 LiveRoom、Category、LiveRoomCategory；调用 delete_live_room_category；再 get_categories_by_room_id 断言该分类不再出现；断言返回 True。  
  - `test_delete_live_room_category_not_found`：创建 LiveRoom、Category，不建立关联；调用 delete_live_room_category(room_id, category_id)；断言返回 False。

### B. Service 层（追加到 `tests/unit/test_service_content_management.py`）

- **get_live_room_categories_list(db, room_id, current_user_id, role)**  
  - `test_get_live_room_categories_list_success`：Mock `crud_room.get` 返回 Mock LiveRoom，Mock `crud_content_management.get_categories_by_room_id` 返回 2 个 Category；调用 get_live_room_categories_list；断言 response.data 长度为 2。  
  - `test_get_live_room_categories_list_room_not_found`：Mock `crud_room.get` 返回 None；调用 get_live_room_categories_list；断言 raise NotFoundException。

- **set_live_room_categories(db, room_id, body, current_user_id, role)**  
  - `test_set_live_room_categories_as_admin_success`：Mock _check_admin_permission 不抛，crud_room.get 返回 room，select Category 返回 body 中 category_ids 且 is_active=True，set_live_room_categories 返回列表；调用 set_live_room_categories；断言返回 LiveRoomCategoriesSetResponse，data.categories 长度正确。  
  - `test_set_live_room_categories_permission_denied`：role 非 ADMIN/SUPERADMIN；断言 raise PermissionDeniedException。  
  - `test_set_live_room_categories_room_not_found`：Mock crud_room.get 返回 None；断言 raise NotFoundException。  
  - `test_set_live_room_categories_invalid_category_ids`：Mock 部分 category_id 不存在或 is_active=False；断言 raise InvalidParameterException。

- **delete_live_room_category(db, room_id, category_id, current_user_id, role)**  
  - `test_delete_live_room_category_as_admin_success`：Mock _check_admin_permission，delete_live_room_category 返回 True；调用 delete_live_room_category；断言返回 dict 含 "message"。  
  - `test_delete_live_room_category_not_found`：Mock delete_live_room_category 返回 False；断言 raise NotFoundException。  
  - `test_delete_live_room_category_permission_denied`：role 非 ADMIN/SUPERADMIN；断言 raise PermissionDeniedException。

### C. API 层（追加到 `tests/integration/test_api_content_management.py`）

- **GET /api/v1/rooms/{room_id}/categories**  
  - `test_api_get_live_room_categories_success`：创建 LiveRoom、2 个 Category、2 条 LiveRoomCategory；GET `/api/v1/rooms/{room_id}/categories`（可不带 token）；断言 200，code=200，data 长度为 2。  
  - `test_api_get_live_room_categories_room_not_found`：GET `/api/v1/rooms/{uuid4()}/categories`；断言 404，code=2001。

- **POST /api/v1/admin/rooms/{room_id}/categories**  
  - `test_api_set_live_room_categories_as_admin_success`：创建 LiveRoom、2 个 Category；用 admin token POST `/api/v1/admin/rooms/{room_id}/categories`，body `{"category_ids": [id1, id2], "mode": "replace"}`；断言 200，data.categories 长度 2。  
  - `test_api_set_live_room_categories_permission_denied`：用 regular token POST；断言 403，code=3003。  
  - `test_api_set_live_room_categories_room_not_found`：用 admin token POST 不存在的 room_id；断言 404，code=2001。  
  - `test_api_set_live_room_categories_invalid_category_id`：body 中含不存在或未启用的 category_id；断言 400，code=4001。

- **DELETE /api/v1/admin/rooms/{room_id}/categories/{category_id}**  
  - `test_api_delete_live_room_category_as_admin_success`：创建 LiveRoom、Category、LiveRoomCategory；用 admin token DELETE 对应 URL；断言 200。  
  - `test_api_delete_live_room_category_not_found`：创建 LiveRoom、Category，不建立关联；DELETE；断言 404，code=2001。  
  - `test_api_delete_live_room_category_permission_denied`：用 regular token DELETE；断言 403，code=3003。
