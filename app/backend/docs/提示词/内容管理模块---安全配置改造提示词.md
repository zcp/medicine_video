## 2. 核心安全配置要求

### 2.1. 环境变量配置安全规范

#### 2.1.1. CORS 配置规范

**核心内容**：
- **禁止**在代码中硬编码 CORS 配置（如 `allow_origins=["*"]`）
- **必须**从环境变量读取 CORS 配置
- **配置格式**: 支持逗号分隔的多个域名（如 `http://localhost:5175,https://example.com`）

**实现示例**：
```python
# config.py
CORS_ORIGINS_STR: str = os.getenv("CORS_ORIGINS", "*")
BACKEND_CORS_ORIGINS: List[str] = [
    origin.strip() 
    for origin in CORS_ORIGINS_STR.split(",") 
    if origin.strip()
]

# main.py
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.BACKEND_CORS_ORIGINS,  # 从配置读取
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**生产环境要求**: CORS 配置**必须**为具体域名，**严禁**使用 `["*"]`

#### 2.1.2. 敏感信息配置规范

**核心内容**：
- **禁止**在代码中硬编码以下敏感信息:
  - 数据库密码、用户名
  - JWT 密钥（`JWT_SECRET_KEY`）
  - 第三方服务密钥（如 Redis、Celery broker）
- **必须**通过环境变量读取所有敏感配置
- **禁止**为敏感信息设置不安全的默认值

**正确和错误的示例对比**：
- ❌ 错误: `POSTGRES_PASSWORD = os.getenv("POSTGRES_PASSWORD", "CHANGE_ME")`
- ❌ 错误: `JWT_SECRET_KEY = os.getenv("JWT_SECRET_KEY", "my-key")`
- ✅ 正确: `POSTGRES_PASSWORD = os.getenv("POSTGRES_PASSWORD", "")`

#### 2.1.3. 配置验证规范

**核心内容**：
- **必须**在应用启动时验证必需的敏感配置
- **缺失配置**必须抛出明确的异常，而非使用不安全的默认值
- **数据库密码验证**: 检查密码是否为空
- **JWT 密钥验证**: 检查密钥长度（≥32字符）

**实现示例**：
```python
class Settings(BaseSettings):
    # 数据库配置
    POSTGRES_PASSWORD: str = os.getenv("POSTGRES_PASSWORD", "")
    
    # JWT 配置
    JWT_SECRET_KEY: str = os.getenv("JWT_SECRET_KEY", "")
    
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self._validate_required_configs()
    
    def _validate_required_configs(self):
        """验证必需的敏感配置"""
        if not self.POSTGRES_PASSWORD:
            raise ValueError(
                "POSTGRES_PASSWORD 环境变量未设置。"
                "生产环境必须设置此变量，不允许使用默认值。"
            )
        if not self.JWT_SECRET_KEY:
            raise ValueError(
                "JWT_SECRET_KEY 环境变量未设置。"
                "生产环境必须设置此变量，且长度应至少32个字符。"
            )
        if len(self.JWT_SECRET_KEY) < 32:
            raise ValueError(
                "JWT_SECRET_KEY 长度不足32个字符，存在安全风险。"
                "请使用更长的密钥（推荐64字符以上）。"
            )
```

### 2.2. 日志安全规范（适用于所有模块）

#### 2.2.1. 禁止在日志中打印敏感信息

**核心内容**：
- ❌ **禁止**: 打印完整的数据库连接 URL（包含密码）
- ✅ **必须**: 只打印非敏感的连接信息

**正确和错误的示例对比**：
```python
# 错误示例
logger.info(f"尝试连接数据库: {DATABASE_URL}")

# 正确示例
logger.info(
    f"尝试连接数据库: "
    f"server={settings.POSTGRES_SERVER}, "
    f"port={settings.POSTGRES_PORT}, "
    f"database={settings.POSTGRES_DB}, "
    f"user={settings.POSTGRES_USER}"
    # 不打印密码
)
```

#### 2.2.2. 日志脱敏规范（推荐实现）

**核心内容**：
- 创建日志脱敏工具函数 `app/core/logging_utils.py`
- 实现脱敏日志格式化器 `SanitizedFormatter`
- 自动脱敏数据库连接 URL 和 JWT 密钥

**实现示例**：
```python
import re
import logging

def sanitize_log_message(message: str) -> str:
    """对日志消息进行脱敏处理"""
    # 移除数据库连接 URL 中的密码
    message = re.sub(
        r'postgresql\+[a-z]*://[^:]+:([^@]+)@',
        r'postgresql://***:***@',
        message,
        flags=re.IGNORECASE
    )
    
    # 移除 JWT 密钥（如果意外出现在日志中）
    message = re.sub(
        r'JWT_SECRET_KEY["\']?\s*[:=]\s*["\']?([^"\'\s]+)',
        r'JWT_SECRET_KEY="***"',
        message,
        flags=re.IGNORECASE
    )
    
    return message

class SanitizedFormatter(logging.Formatter):
    """脱敏日志格式化器"""
    def format(self, record):
        record.msg = sanitize_log_message(str(record.msg))
        return super().format(record)
```

#### 2.2.3. 错误消息脱敏

**核心内容**：
- **禁止**在异常处理中暴露敏感信息
- **必须**只返回通用的错误消息给客户端

**实现示例**：
```python
try:
    # 数据库操作
    pass
except Exception as e:
    logger.error(f"数据库操作失败: {type(e).__name__}")
    # 不要打印完整的异常信息（可能包含连接字符串）
    raise HTTPException(status_code=500, detail="内部服务器错误")
```

### 2.4. 生产环境安全规范（适用于所有模块）

import json

def get_secret(secret_name: str) -> dict:
    """从 AWS Secrets Manager 获取密钥"""
    client = boto3.client('secretsmanager')
    response = client.get_secret_value(SecretId=secret_name)
    return json.loads(response['SecretString'])

# 在 config.py 中使用

### 2.5. 密钥生成最佳实践（适用于所有模块）

#### 2.5.1. JWT 密钥生成

**核心内容**：
- **推荐长度**: 64 字符（128位加密强度）
- **生成方式**:
  ```bash
  # 使用 openssl（推荐）
  openssl rand -hex 32
  
  # 使用 Python
  python -c "import secrets; print(secrets.token_hex(32))"
  ```

#### 2.5.2. 数据库密码生成

**核心内容**：
- **推荐长度**: 16-32 字符
- **生成方式**:
  ```bash
  # 使用 openssl
  openssl rand -base64 16
  
  # 使用密码生成工具
  pwgen -s 16 1
  ```

#### 2.5.3. 密钥命名规范

**核心内容**：
- 使用大写字母和下划线：`POSTGRES_PASSWORD`, `JWT_SECRET_KEY`
- 使用有意义的名称：`CORS_ORIGINS` 而非 `CORS`
- 分组前缀：`POSTGRES_*`, `JWT_*`, `CELERY_*`

### 5.1. 更新 `app/core/config.py`

**更新内容**：
1. 移除硬编码的 CORS 配置（如果有）
2. 添加从环境变量读取 CORS 配置
3. 移除敏感信息的不安全默认值
4. 添加配置验证逻辑

**示例代码**：
```python
from typing import List
import os
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    # ========== CORS配置 ==========
    CORS_ORIGINS_STR: str = os.getenv("CORS_ORIGINS", "*")
    
    @property
    def BACKEND_CORS_ORIGINS(self) -> List[str]:
        """从环境变量解析 CORS 允许的源"""
        if self.CORS_ORIGINS_STR == "*":
            return ["*"]
        return [
            origin.strip()
            for origin in self.CORS_ORIGINS_STR.split(",")
            if origin.strip()
        ]
    
    # ========== 数据库配置 ==========
    POSTGRES_SERVER: str = os.getenv("POSTGRES_SERVER", "localhost")
    POSTGRES_PORT: int = int(os.getenv("POSTGRES_PORT", "5432"))
    POSTGRES_DB: str = os.getenv("POSTGRES_DB", "live_core_test")
    POSTGRES_USER: str = os.getenv("POSTGRES_USER", "postgres")
    POSTGRES_PASSWORD: str = os.getenv("POSTGRES_PASSWORD", "")  # 无默认值
    
    # ========== JWT配置 ==========
    JWT_SECRET_KEY: str = os.getenv("JWT_SECRET_KEY", "")  # 无默认值
    JWT_ALGORITHM: str = "HS256"
    JWT_ACCESS_TOKEN_EXPIRE_MINUTES: int = 30
    JWT_REFRESH_TOKEN_EXPIRE_DAYS: int = 7
    
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self._validate_required_configs()
    
    def _validate_required_configs(self):
        """验证必需的敏感配置"""
        # 验证数据库密码
        if not self.POSTGRES_PASSWORD:
            raise ValueError(
                "POSTGRES_PASSWORD 环境变量未设置。"
                "生产环境必须设置此变量，不允许使用默认值。"
            )
        
        # 验证 JWT 密钥
        if not self.JWT_SECRET_KEY:
            raise ValueError(
                "JWT_SECRET_KEY 环境变量未设置。"
                "生产环境必须设置此变量，且长度应至少32个字符。"
            )
        
        # 验证 JWT 密钥长度
        if len(self.JWT_SECRET_KEY) < 32:
            raise ValueError(
                "JWT_SECRET_KEY 长度不足32个字符，存在安全风险。"
                "请使用更长的密钥（推荐64字符以上）。"
            )

settings = Settings()
```

### 5.3. 创建 `app/core/logging_utils.py`

**新增文件内容**：
```python
import re
import logging

def sanitize_log_message(message: str) -> str:
    """
    对日志消息进行脱敏处理
    
    Args:
        message: 原始日志消息
    
    Returns:
        str: 脱敏后的日志消息
    """
    # 移除数据库连接 URL 中的密码
    message = re.sub(
        r'postgresql\+[a-z]*://[^:]+:([^@]+)@',
        r'postgresql://***:***@',
        message,
        flags=re.IGNORECASE
    )
    
    # 移除 Redis 连接 URL 中的密码
    message = re.sub(
        r'redis://:[^@]+@',
        r'redis://***@',
        message,
        flags=re.IGNORECASE
    )
    
    # 移除 JWT 密钥（如果意外出现在日志中）
    message = re.sub(
        r'JWT_SECRET_KEY["\']?\s*[:=]\s*["\']?([^"\'\s]+)',
        r'JWT_SECRET_KEY="***"',
        message,
        flags=re.IGNORECASE
    )
    
    return message

class SanitizedFormatter(logging.Formatter):
    """
    脱敏日志格式化器
    
    在输出日志前自动对敏感信息进行脱敏处理
    """
    def format(self, record):
        if isinstance(record.msg, str):
            record.msg = sanitize_log_message(record.msg)
        return super().format(record)
```

## 7. 使用说明

### 7.1. Cursor 使用说明

**改造代码时必须使用 Cursor 的 `@` 标记引用**：

```python
# 正确的引用方式
@app.core.config  # ← 使用 @app.core.config 引用配置文件
@app.main  # ← 使用 @app.main 引用主应用文件
```

### 7.2. 读取现有代码

**改造前必须读取现有代码**：
1. 使用 `@app/core/config` 读取 `app/core/config.py`
2. 使用 `@app/main` 读取 `app/main.py`
3. 仔细分析现有配置
4. 只修改安全配置相关的代码，不改变业务逻辑

### 7.3. 最小幅度修改原则

**改造时必须遵守的原则**：
1. 只添加或修改安全配置相关的代码
2. 不修改任何业务逻辑执行流程
3. 不删除或重命名任何现有方法
4. 不改变任何方法的返回值结构
5. 保持代码风格和结构一致
