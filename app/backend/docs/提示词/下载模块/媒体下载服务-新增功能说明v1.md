## 一、功能概述

本文档描述两个新增功能：

1. **视频去重功能**：在启动下载任务时，自动检查是否已有相同资源URL的已完成视频，避免重复下载
2. **CSV批量导入功能**：支持通过上传CSV文件批量创建下载任务

---

## 二、功能一：视频去重

### 2.1 需求背景

多个任务可能具有相同的`resource_url`，但它们的`liveroom_title`或`liveroom_id`不同。为避免重复下载相同的视频资源，需要在开始下载前检查该资源是否已下载完成。

### 2.2 实现方案

#### 2.2.1 触发时机
在`DownloadService.start_download_task()`方法中，将任务状态更新为`processing`后，立即进行去重检查。

#### 2.2.2 检查逻辑说明

**查询条件**：
- `video_url == task.resource_url`
- `status IN ('completed', 'partial_completed')`

**状态处理**：
- 如果找到`status='completed'`的视频：任务标记为`completed`，progress=1.0
- 如果找到`status='partial_completed'`的视频：任务标记为`partial_completed`

**不触发去重的情况**：
- 找到的视频status='failed'：继续正常下载
- 未找到任何记录：继续正常下载

```python
def start_download_task(self, task_id: uuid.UUID, user_id: uuid.UUID, retry_flag: bool = False) -> DownloadTask:
    """启动下载任务（含视频去重）"""
    
    # 1. 获取任务并验证权限
    task = self.get_download_task(task_id, user_id)
    
    # 2. 验证任务状态
    if task.status not in [TaskStatus.PENDING, TaskStatus.FAILED, TaskStatus.PARTIAL_COMPLETED]:
        raise ValueError(f"任务状态为{task.status}，不能启动")
    
    # 3. 更新状态为processing
    task.status = TaskStatus.PROCESSING
    task.updated_at = datetime.utcnow()
    self.db.commit()
    self.db.refresh(task)
    
    # ==================== 新增：视频去重检查 ====================
    try:
        # 4. 查询是否存在相同resource_url且已完成或部分完成的视频
        existing_video = self.db.query(DownloadedVideo).filter(
            DownloadedVideo.video_url == task.resource_url,
            DownloadedVideo.status.in_(['completed', 'partial_completed'])
        ).first()
        
        if existing_video:
            logger.info(
                f"视频去重命中 - 任务ID: {task_id}, "
                f"resource_url: {task.resource_url}, "
                f"已存在视频ID: {existing_video.video_id}, "
                f"已存在视频状态: {existing_video.status}, "
                f"存储路径: {existing_video.storage_path}"
            )
            
            # 4.1 直接标记任务状态（根据已存在视频的状态）
            if existing_video.status == 'completed':
                task.status = TaskStatus.COMPLETED
                task.progress = 1.0
            elif existing_video.status == 'partial_completed':
                task.status = TaskStatus.PARTIAL_COMPLETED
                # progress保持原有值，因为partial_completed状态下progress已经正确计算
            
            task.completed_at = datetime.utcnow()
            task.updated_at = datetime.utcnow()
            
            # 4.2 创建新的downloaded_video记录（关联到当前任务）
            # 注意：必须创建新记录，因为liveroom信息可能不同
            new_video = DownloadedVideo(
                video_id=task.video_id,
                task_id=task.id,
                liveroom_id=task.liveroom_id,
                liveroom_title=str(task.liveroom_title),
                liveroom_url=task.resource_url,
                video_type=existing_video.video_type,
                video_url=task.resource_url,
                storage_path=existing_video.storage_path,  # 复用存储路径
                file_size=existing_video.file_size,
                duration=existing_video.duration,
                resolution=existing_video.resolution,
                format=existing_video.format,
                cover_url=existing_video.cover_url,
                cover_path=existing_video.cover_path,
                status=existing_video.status,  # 复用已存在视频的状态
                download_start_time=datetime.utcnow(),
                download_end_time=datetime.utcnow()
            )
            self.db.add(new_video)
            
            self.db.commit()
            self.db.refresh(task)
            
            logger.info(
                f"任务 {task_id} 通过视频去重完成 - "
                f"最终状态: {task.status.value}, "
                f"视频状态: {existing_video.status}"
            )
            return task
    
    except SQLAlchemyError as e:
        # 数据库查询异常，记录日志并继续正常下载流程
        logger.warning(
            f"视频去重检查失败 - 任务ID: {task_id}, "
            f"错误: {str(e)}, "
            f"将继续正常下载流程"
        )
        # 回滚可能的部分更改，确保数据一致性
        self.db.rollback()
        # 重新刷新task对象，恢复到processing状态
        self.db.refresh(task)
    
    except Exception as e:
        # 其他未预期的异常，记录详细日志并继续正常下载流程
        logger.error(
            f"视频去重检查发生未预期错误 - 任务ID: {task_id}, "
            f"错误类型: {type(e).__name__}, "
            f"错误信息: {str(e)}, "
            f"将继续正常下载流程",
            exc_info=True
        )
        # 回滚可能的部分更改
        self.db.rollback()
        # 重新刷新task对象
        self.db.refresh(task)
    # ==================== 视频去重检查结束 ====================
    
    # 5. 继续正常下载流程
    try:
        # 根据resource_type调用不同的下载方法
        if task.resource_type == 'hls':
            result = self.download_m3u8(task, save_dir)
            self._process_download_m3u8_result(task, result, user_id)
        elif task.resource_type in ['mp4', 'image']:
            result = self.download_mp4_image(task, save_dir)
            self._process_download_mp4_result(task, result, user_id)
        else:
            raise ValueError(f"不支持的资源类型: {task.resource_type}")
        
        return task
        
    except Exception as e:
        logger.error(f"下载失败: {str(e)}", exc_info=True)
        task.status = TaskStatus.FAILED
        task.last_error = str(e)
        task.updated_at = datetime.utcnow()
        self.db.commit()
        raise
```

### 2.3 关键设计点

#### 2.3.1 为何创建新的downloaded_video记录？

**原因**：不同任务的元数据可能不同
- `liveroom_id`: 可能不同
- `liveroom_title`: 可能不同
- `liveroom_url`: 可能不同
- `task_id`: 必须不同（关联到当前任务）

**好处**：
1. 保持数据完整性：每个任务都有对应的视频记录
2. 便于追溯：可以通过task_id查询到对应的视频
3. 支持不同直播间：相同视频可能来自不同直播间

#### 2.3.2 复用存储路径

**字段**：`storage_path`、`file_size`、`duration`等
**原因**：节省存储空间，避免重复下载
**注意**：必须确保storage_path指向的文件确实存在

### 2.6 测试场景

1. **场景1：无去重**
   - 前提：resource_url首次下载
   - 预期：正常下载流程

2. **场景2：去重命中（完全成功）**
   - 前提：存在相同resource_url且status='completed'的记录
   - 预期：跳过下载，创建新video记录（status='completed'），任务标记为completed

3. **场景3：去重命中（部分成功）**
   - 前提：存在相同resource_url且status='partial_completed'的记录
   - 预期：跳过下载，创建新video记录（status='partial_completed'），任务标记为partial_completed

4. **场景4：失败的视频**
   - 前提：存在相同resource_url但status='failed'的记录
   - 预期：不触发去重，正常下载

## 三、功能二：CSV批量导入

### 3.1 API接口定义

#### 3.1.1 基本信息

- **接口**: `POST /api/v1/download/tasks/batch-import`
- **描述**: 通过上传CSV文件批量创建下载任务
- **认证**: 需要JWT Token认证
- **Content-Type**: `multipart/form-data`

#### 3.1.2 请求参数

**Form Data**:

| 参数名 | 类型 | 必填 | 描述 |
|:---|:---|:---|:---|
| `file` | `File` | 是 | CSV文件，最大10MB |
| `skip_duplicates` | `Boolean` | 否 | 是否跳过重复的resource_url（默认false） |
| `auto_start` | `Boolean` | 否 | 导入后是否自动启动任务（默认false） |

#### 3.1.3 CSV文件格式

**文件要求**:
- **编码**: UTF-8
- **分隔符**: 逗号(`,`)
- **表头**: 必须包含（第一行）
- **最大行数**: 1000行（不含表头）
- **最大文件大小**: 10MB

**必需列**:
- `liveroom_id`: 直播间ID，长度10-20字符
- `resource_url`: 资源下载URL
- `resource_type`: 资源类型（hls/mp4/image）

**可选列**:
- `liveroom_title`: 直播间标题，最大255字符
- `liveroom_url`: 直播间URL

**CSV示例**:
```csv
liveroom_id,liveroom_title,liveroom_url,resource_url,resource_type
8723901837,精彩直播间1,https://example.com/room/8723901837,https://example.com/video1.m3u8,hls
8723901838,精彩直播间2,https://example.com/room/8723901838,https://example.com/video2.mp4,mp4
8723901839,精彩直播间3,https://example.com/room/8723901839,https://example.com/cover.jpg,image
```

### 3.3 错误处理

#### 3.3.1 文件验证错误

| 错误类型 | HTTP状态码 | 错误信息 |
|:---|:---|:---|
| 文件类型错误 | 400 | 文件类型错误，只允许上传CSV文件 |
| 文件过大 | 413 | 文件大小超过限制，最大允许10MB |
| 文件编码错误 | 400 | 文件编码错误，请使用UTF-8编码 |
| CSV格式错误 | 400 | CSV文件格式错误: 缺少必需列 {column_name} |
| CSV为空 | 400 | CSV文件为空或只包含表头 |
| 行数超限 | 400 | CSV行数超过限制（最多1000行） |

#### 3.3.2 数据验证错误

每行数据的验证错误会记录在`failed_rows`中，包含：
- `row`: 行号（从2开始，第1行是表头）
- `liveroom_id`: 直播间ID
- `resource_url`: 资源URL
- `error`: 具体错误信息

常见验证错误：
- `liveroom_id长度必须在10-20之间`
- `resource_url格式错误，必须是有效的URL`
- `resource_type必须是hls、mp4或image`
- `缺少必填字段`

### 3.4 实现流程

#### 3.4.1 服务层方法

```python
class DownloadService:
    def batch_import_tasks_from_csv(
        self,
        file_content: bytes,
        user_id: uuid.UUID,
        skip_duplicates: bool = False,
        auto_start: bool = False
    ) -> Dict:
        """
        从CSV文件批量导入下载任务
        
        :param file_content: CSV文件内容（字节）
        :param user_id: 用户ID
        :param skip_duplicates: 是否跳过重复的resource_url
        :param auto_start: 导入后是否自动启动任务
        :return: 导入结果字典
        """
        
        start_time = time.time()
        
        # 统计数据
        total = 0
        success = 0
        failed = 0
        skipped = 0
        created_task_ids = []
        failed_rows = []
        skipped_rows = []
        
        try:
            # 1. 解码CSV文件
            csv_text = file_content.decode('utf-8')
            csv_reader = csv.DictReader(io.StringIO(csv_text))
            
            # 2. 验证表头
            required_columns = {'liveroom_id', 'resource_url', 'resource_type'}
            if not required_columns.issubset(csv_reader.fieldnames):
                missing = required_columns - set(csv_reader.fieldnames)
                raise ValueError(f"缺少必需列: {', '.join(missing)}")
            
            # 3. 逐行处理
            for row_num, row in enumerate(csv_reader, start=2):
                total += 1
                
                # 检查行数限制
                if total > 1000:
                    raise ValueError("CSV行数超过限制（最多1000行）")
                
                try:
                    # 3.1 提取数据
                    liveroom_id = row.get('liveroom_id', '').strip()
                    resource_url = row.get('resource_url', '').strip()
                    resource_type = row.get('resource_type', '').strip()
                    
                    # 验证必填字段
                    if not liveroom_id or not resource_url or not resource_type:
                        raise ValueError("缺少必填字段")
                    
                    # 3.2 去重检查（如果开启）
                    if skip_duplicates:
                        existing = self.db.query(DownloadTask).filter(
                            DownloadTask.user_id == user_id,
                            DownloadTask.resource_url == resource_url
                        ).first()
                        
                        if existing:
                            skipped += 1
                            skipped_rows.append({
                                "row": row_num,
                                "liveroom_id": liveroom_id,
                                "resource_url": resource_url,
                                "reason": "resource_url已存在"
                            })
                            continue
                    
                    # 3.3 构造任务数据
                    task_data = DownloadTaskCreate(
                        liveroom_id=liveroom_id,
                        liveroom_title=row.get('liveroom_title', '').strip() or None,
                        liveroom_url=row.get('liveroom_url', '').strip() or None,
                        resource_url=resource_url,
                        resource_type=resource_type
                    )
                    
                    # 3.4 创建任务
                    task = self.create_download_task(task_data, user_id)
                    created_task_ids.append(str(task.id))
                    success += 1
                    
                    # 3.5 批量提交（每100行提交一次）
                    if success % 100 == 0:
                        self.db.commit()
                    
                    # 3.6 自动启动（如果开启）
                    if auto_start:
                        try:
                            self.start_download_task(task.id, user_id)
                        except Exception as e:
                            logger.warning(f"自动启动任务失败: {task.id}, 错误: {str(e)}")
                
                except ValidationError as e:
                    failed += 1
                    failed_rows.append({
                        "row": row_num,
                        "liveroom_id": liveroom_id,
                        "resource_url": resource_url,
                        "error": str(e.errors()[0]['msg'])
                    })
                    logger.error(f"第{row_num}行验证失败: {str(e)}")
                
                except Exception as e:
                    failed += 1
                    failed_rows.append({
                        "row": row_num,
                        "liveroom_id": liveroom_id,
                        "resource_url": resource_url,
                        "error": str(e)
                    })
                    logger.error(f"第{row_num}行处理失败: {str(e)}")
            
            # 4. 最终提交
            self.db.commit()
            
            # 5. 构造结果
            processing_time = round(time.time() - start_time, 2)
            
            logger.info(
                f"批量导入完成 - "
                f"用户ID: {user_id}, "
                f"总数: {total}, "
                f"成功: {success}, "
                f"失败: {failed}, "
                f"跳过: {skipped}, "
                f"耗时: {processing_time}s"
            )
            
            return {
                "total": total,
                "success": success,
                "failed": failed,
                "skipped": skipped,
                "created_task_ids": created_task_ids[:100],  # 最多返回前100个
                "failed_rows": failed_rows,
                "skipped_rows": skipped_rows,
                "processing_time": processing_time
            }
        
        except UnicodeDecodeError:
            logger.error("CSV文件编码错误")
            raise ValueError("文件编码错误，请使用UTF-8编码")
        
        except csv.Error as e:
            logger.error(f"CSV格式错误: {str(e)}")
            raise ValueError(f"CSV文件格式错误: {str(e)}")
        
        except Exception as e:
            logger.error(f"批量导入失败: {str(e)}", exc_info=True)
            self.db.rollback()
            raise
```

#### 3.4.2 API端点实现

```python
@router.post("/tasks/batch-import", status_code=status.HTTP_201_CREATED)
async def batch_import_tasks(
    file: UploadFile = File(..., description="CSV文件，最大10MB"),
    skip_duplicates: bool = Form(False, description="是否跳过重复的resource_url"),
    auto_start: bool = Form(False, description="导入后是否自动启动任务"),
    current_user: dict = Depends(get_current_user),
    db: Session = Depends(get_db)
) -> Dict:
    """批量导入下载任务"""
    
    try:
        # 1. 验证文件类型
        if not file.filename.endswith('.csv'):
            return create_error_response(
                "文件类型错误，只允许上传CSV文件",
                code=400
            )
        
        # 2. 读取并验证文件大小
        file_content = await file.read()
        if len(file_content) > 10 * 1024 * 1024:  # 10MB
            return create_error_response(
                "文件大小超过限制，最大允许10MB",
                code=413
            )
        
        # 3. 验证文件不为空
        if len(file_content) == 0:
            return create_error_response(
                "上传的文件为空",
                code=400
            )
        
        # 4. 调用服务层方法
        service = DownloadService(db)
        result = service.batch_import_tasks_from_csv(
            file_content=file_content,
            user_id=uuid.UUID(current_user["user_id"]),
            skip_duplicates=skip_duplicates,
            auto_start=auto_start
        )
        
        # 5. 根据结果返回不同状态码
        if result["success"] == 0:
            return create_error_response(
                "批量导入失败，所有行都处理失败",
                code=400,
                data=result
            )
        elif result["failed"] > 0:
            return create_response(
                code=207,
                message="批量导入部分成功",
                data=result
            )
        else:
            return create_response(
                code=201,
                message="批量导入任务成功",
                data=result
            )
    
    except ValueError as e:
        logger.error(f"参数验证错误: {str(e)}")
        return create_error_response(str(e), code=400)
    
    except UnicodeDecodeError:
        logger.error("CSV文件编码错误")
        return create_error_response(
            "文件编码错误，请使用UTF-8编码",
            code=400
        )
    
    except Exception as e:
        logger.error(f"批量导入失败: {str(e)}", exc_info=True)
        return create_error_response(
            f"批量导入失败: {str(e)}",
            code=500
        )
```

### 3.5 Pydantic Schema定义

```python
from typing import List
from pydantic import BaseModel, Field

class BatchImportFailedRow(BaseModel):
    """导入失败行信息"""
    row: int = Field(..., description="行号（从2开始）")
    liveroom_id: str = Field(..., description="直播间ID")
    resource_url: str = Field(..., description="资源URL")
    error: str = Field(..., description="错误信息")

class BatchImportSkippedRow(BaseModel):
    """导入跳过行信息"""
    row: int = Field(..., description="行号")
    liveroom_id: str = Field(..., description="直播间ID")
    resource_url: str = Field(..., description="资源URL")
    reason: str = Field(..., description="跳过原因")

class BatchImportResponse(BaseModel):
    """批量导入响应模型"""
    total: int = Field(..., description="总行数")
    success: int = Field(..., description="成功创建的任务数")
    failed: int = Field(..., description="失败的行数")
    skipped: int = Field(..., description="跳过的行数")
    created_task_ids: List[str] = Field(..., description="成功创建的任务ID列表（最多100个）")
    failed_rows: List[BatchImportFailedRow] = Field(..., description="失败的行详情")
    skipped_rows: List[BatchImportSkippedRow] = Field(..., description="跳过的行详情")
    processing_time: float = Field(..., description="处理耗时（秒）")
```

### 3.6 性能优化

1. **批量提交事务**：每处理100行提交一次，避免频繁提交
2. **限制文件大小**：最大10MB，防止内存溢出
3. **限制行数**：最多1000行，控制单次处理时间
4. **异步启动任务**：如果开启auto_start，建议使用任务队列异步启动

### 3.7 安全考虑

1. **文件验证**：
   - 检查文件扩展名
   - 限制文件大小
   - 限制CSV行数

2. **权限控制**：
   - 所有导入的任务都关联到当前用户
   - 使用JWT Token认证

3. **SQL注入防护**：
   - 使用ORM操作数据库
   - 参数化查询

4. **资源限制**：
   - 限制同时处理的CSV文件数
   - 避免阻塞其他请求

## 五、测试场景

### 5.1 视频去重功能测试

| 场景 | 前提条件 | 预期结果 |
|:---|:---|:---|
| 无去重 | resource_url首次下载 | 正常下载流程 |
| 去重命中（完全成功） | 存在相同resource_url且status='completed' | 跳过下载，创建新video记录（status='completed'），任务标记为completed |
| 去重命中（部分成功） | 存在相同resource_url且status='partial_completed' | 跳过下载，创建新video记录（status='partial_completed'），任务标记为partial_completed |
| 失败视频 | 存在相同resource_url但status='failed' | 不触发去重，正常下载 |

### 5.2 CSV批量导入测试

| 场景 | 输入 | 预期结果 |
|:---|:---|:---|
| 正常导入 | 100行有效数据 | 创建100个任务 |
| 部分失败 | 100行，其中20行数据错误 | 创建80个任务，返回20个错误详情 |
| 全部失败 | 100行，全部数据错误 | 返回400错误 |
| 文件过大 | 15MB文件 | 返回413错误 |
| 格式错误 | 缺少必需列 | 返回400错误 |
| 去重跳过 | skip_duplicates=true，50行重复 | 跳过50行，创建50个任务 |
| 自动启动 | auto_start=true | 导入后自动启动所有任务 |
