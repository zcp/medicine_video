## 一、问题回答

### Q1: batch_import相关代码是否需要改动？

**答案**: ✅ **不需要改动现有代码，只需新增。**

**详细说明**:

| 模块 | 操作类型 | 说明 |
|:---|:---|:---|
| `batch_import_tasks_from_csv()` 服务层方法 | **保持不变** | 现有代码完全复用 |
| `POST /tasks/batch-import` API接口 | **保持不变** | 现有接口完全复用 |
| 爬虫配置管理 | **新增** | 新增环境变量、配置类、Token加密工具 |
| 爬虫模块 | **新增** | 新增 `app/crawlers/` 目录及所有文件 |
| `crawl_and_import_tasks()` 服务层方法 | **新增** | 新增方法，内部调用现有的`batch_import_tasks_from_csv()` |
| `POST /tasks/crawl-and-import` API接口 | **新增** | 新增接口，调用新增的服务层方法 |

**新增文件清单**:

### 步骤2: 使用代码生成指令（文档2）生成代码

```bash

python scripts/encrypt_token.py --generate-key

# 2. 加密你的token
python scripts/encrypt_token.py "<your_vzan_token>" "<your_encryption_key>"

# 3. 配置.env文件
echo "TOKEN_ENCRYPTION_KEY=<your_encryption_key>" >> .env
echo "VZAN_TOKEN=<encrypted_token>" >> .env
echo "VZAN_USERNAME=<your_username>" >> .env
echo "VZAN_PASSWORD=<your_password>" >> .env
```
