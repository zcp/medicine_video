**修改为**:
```
实现流程（遵循服务层方法实现通用流程）：

【第一步：变量提取（安全异步异常处理）】
    - 提取 `user_id_for_logging = str(user_id)`
    - 提取 `crawler_type_for_logging = crawler_type`
    - 目的：在异常处理中安全使用这些值，避免访问失效的ORM对象

【第二步：记录开始日志】
    - `logger.info(f"Starting crawl_and_import - User: {user_id_for_logging}, Crawler: {crawler_type_for_logging}")`

【第三步：try-except包裹】
    将以下所有业务逻辑包裹在try-except块中

【第四步：执行业务逻辑】
    1. 验证 crawler_type 参数
    2. 从环境变量读取爬虫配置（username, password, token）

    6. 读取生成的 CSV 文件（优先读取增量文件）
    7. 调用 batch_import_tasks_from_csv 方法导入数据
       注意：此方法内部已有异常处理和rollback，此处无需额外rollback
    8. 根据配置决定是否删除临时 CSV 文件
    9. 记录成功日志

【第五步：异常处理】
    - CrawlerConfigError: 
      * 记录日志：`logger.error(f"Crawler config error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)`
      * 返回业务错误码 400
      * 无需rollback（未涉及数据库操作）
    - CrawlerTimeoutError:
      * 记录日志（同上）
      * 返回业务错误码 500
    - CrawlerAPIError:
      * 记录日志（同上）
      * 返回业务错误码 500
    - FileNotFoundError:
      * 记录日志（同上）
      * 返回业务错误码 500
    - ValueError:
      * 记录日志（同上）
      * 返回业务错误码 400
    - SQLAlchemyError:
      * 记录日志（同上）
      * 执行 self.db.rollback()
      * 返回业务错误码 500
    - Exception:
      * 记录日志（同上）
      * 返回业务错误码 1000

【第六步：返回结果】
    - 返回类型：Dict（爬取和导入的综合结果）
    - 包含字段：crawl_status, crawl_rows, crawl_file, incremental_file, failed_file, import_result, error_message
```

```markdown
**响应处理规范**:

本接口遵循统一响应处理规范：
- **成功响应**: 使用 `create_response(code, message, data)` 函数构建
  * 函数位置：`app/core/response.py`
  * HTTP状态码：200
  * 业务状态码：在 response body 的 `code` 字段中返回（200/201/207等）
  
- **错误响应**: 使用 `create_error_response(code, message, data)` 函数构建
  * 函数位置：`app/core/response.py`
  * HTTP状态码：200
  * 业务状态码：在 response body 的 `code` 字段中返回（400/500等）

- **重要**: API端点不直接返回 `JSONResponse(status_code=..., content=create_error_response(...))`，
  而是由异常处理中间件统一处理，端点只需抛出自定义异常或返回 `create_response` 的结果。
```

### 修改3: 异常处理流程示例 (P1)

**位置**: 第六节 6.1.2节

**修改示例代码**:

**现有代码**:
```python
try:
    # 1. 执行爬取
    csv_path = crawler.crawl(url, **options)
except CrawlerConfigError as e:
    # 配置错误，直接返回400
    return JSONResponse(
        status_code=200,
        content=create_error_response(code=400, message=f"爬虫配置错误: {str(e)}")
    )
```

**修改为**:
```python
# ========== 第一步：变量提取 ==========
user_id_for_logging = str(user_id)
crawler_type_for_logging = crawler_type

# ========== 第二步：记录开始日志 ==========
logger.info(f"Starting crawl_and_import - User: {user_id_for_logging}, Crawler: {crawler_type_for_logging}")

# ========== 第三步：try-except包裹 ==========
try:
    # ========== 第四步：执行业务逻辑 ==========
    # 1. 执行爬取
    csv_path = crawler.crawl(config, **options)
    
    # 2. 导入数据
    import_result = self.batch_import_tasks_from_csv(...)
    
    # 3. 记录成功日志
    logger.info(f"Crawl and import completed - User: {user_id_for_logging}, Rows: {result['crawl_rows']}")
    
# ========== 第五步：异常处理 ==========
except CrawlerConfigError as e:
    # ✅ 使用之前提取的局部变量记录日志
    logger.error(
        f"Crawler config error - User: {user_id_for_logging}, Crawler: {crawler_type_for_logging}, Error: {str(e)}",
        exc_info=True  # 包含完整堆栈跟踪
    )
    # 配置错误，返回400（由异常处理中间件转换为统一响应）
    raise CrawlerConfigError(f"爬虫配置错误: {str(e)}")
    
except CrawlerTimeoutError as e:
    logger.error(f"Crawler timeout - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)
    raise CrawlerTimeoutError(f"爬取超时: {str(e)}")
    
except CrawlerAPIError as e:
    logger.error(f"Crawler API error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)
    raise CrawlerAPIError(f"API调用失败: {str(e)}")
    
except SQLAlchemyError as e:
    logger.error(f"Database error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)
    self.db.rollback()  # 必须rollback
    raise DatabaseError(f"数据库错误: {str(e)}")
    
except Exception as e:
    # 未知错误
    logger.error(f"Unexpected error - User: {user_id_for_logging}, Error: {str(e)}", exc_info=True)
    self.db.rollback()  # 安全起见，执行rollback
    raise

# ========== 第六步：返回结果 ==========
return {
    "crawl_status": "success",
    "crawl_rows": crawl_rows,
    "crawl_file": str(csv_path),
    "import_result": import_result,
    "error_message": None
}
```
