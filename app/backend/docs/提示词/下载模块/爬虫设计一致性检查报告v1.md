## 三、修改建议

为使设计文档与实际实现保持一致，建议以下修改：

### 3.1 配置管理部分
1. **保留环境变量方式**（符合安全规范），但调整字段定义：
   - `VZAN_USERNAME`, `VZAN_PASSWORD`, `VZAN_TOKEN` 保持不变
   - `CRAWLER_TIMEOUT` 默认值改为 `10` 秒（与实际一致），允许范围 `1-600`
   - 移除 `CRAWLER_MAX_RETRIES`（实际未使用显式重试逻辑）
   - 将 `CRAWLER_MAX_ROWS` 重命名为 `CRAWLER_BATCH_SIZE`，默认值 `100`（用于批量写入）
   - 保留集成配置（`CRAWL_IMPORT_AUTO_START` 等），但明确说明这些用于服务层，而非爬虫本身

### 3.2 爬虫基类部分
1. **保留抽象基类设计**（利于扩展），但调整方法签名：
   - `crawl(config: Dict, **kwargs) -> Dict` （返回爬取结果摘要，而非文件路径）
   - 返回格式：`{"csv_file": str, "total_rows": int, "failed_rows": int, "incremental_rows": int}`

### 3.3 微赞爬虫实现部分
1. **明确 `VzanCrawler` 封装 `DuanShuCrawler_vzan` 的核心逻辑**，而非完全复制：
   - `VzanCrawler.__init__(config)` 应初始化实际爬虫实例，或直接在类内部实现核心逻辑
   - `VzanCrawler.crawl()` 应调用实际的 `get_liveroom_list()`, `extract_liveroomlist_data()`, `save_liveroomlist_to_csv()` 等方法
   
2. **添加核心方法说明**：
   - `_get_liveroom_list(token, page, psize)`: 调用微赞 API 获取直播间列表
   - `_extract_enc_tpid(response_data)`: 从 topic 配置中提取 enc_tpid
   - `_extract_play_url(response_data)`: 从视频配置中提取播放 URL 和封面图
   - `_extract_liveroomlist_data(response_data)`: 综合提取并调用额外 API
   - `_save_to_csv(data, filepath, mode)`: 保存数据到 CSV

3. **详细说明多步骤数据提取流程**：
   ```
   1. 调用 get_topicdatas API 获取直播间基础信息
   2. 对每个直播间，调用 topic_config API 获取 enc_tpid
   3. 对每个直播间，调用 video_config API 获取视频 URL
   4. 批量保存到 CSV 文件
   ```

4. **明确输出文件**：
   - 主文件: `liveroomlist_vzan.csv`
   - 增量文件: `liveroomlist_inc_vzan.csv`
   - 失败记录文件: `failed_liveroomlist_urls_vzan.txt`
