### 2.1 配置模块 (`app/core/config.py`)

**代码生成指令现状** (第96-123行):
```python
CRAWLER_TIMEOUT: int = Field(default=300, ge=60, le=600, description="爬虫执行超时时间（秒）")
CRAWLER_MAX_RETRIES: int = Field(default=3, ge=1, le=10, description="最大重试次数")
CRAWLER_TEMP_DIR: str = Field(default="/tmp/crawler_csv", description="CSV临时文件目录")
CRAWLER_MAX_ROWS: int = Field(default=10000, ge=1, le=50000, description="单次爬取最大行数")
```

**设计文档要求** (任务1修改后):
```python
CRAWLER_TIMEOUT: int = Field(default=10, ge=1, le=600, description="爬虫单个请求超时时间（秒）")
# CRAWLER_MAX_RETRIES 已移除
CRAWLER_TEMP_DIR: str = Field(default="/tmp/vzan_crawler", description="CSV临时文件目录")
CRAWLER_BATCH_SIZE: int = Field(default=100, ge=10, le=1000, description="批量写入CSV的数据条数")
```

**不一致点**:
1. ❌ `CRAWLER_TIMEOUT`: 默认值 `300` → 应为 `10`，最小值 `ge=60` → 应为 `ge=1`

3. ❌ `CRAWLER_TEMP_DIR`: 默认值 `/tmp/crawler_csv` → 应为 `/tmp/vzan_crawler`
4. ❌ `CRAWLER_MAX_ROWS`: 应重命名为 `CRAWLER_BATCH_SIZE`，默认值 `10000` → 应为 `100`

```python
    # 不需要 max_retries

@abstractmethod
def crawl(self, config: Dict, **kwargs) -> Dict:
    """
    执行爬取任务
    
    Args:
        config: 爬虫配置字典，包含 username, password, token 等
        **kwargs: 其他参数
    
    Returns:
        Dict: 爬取结果摘要

                "csv_file": str,             # 主 CSV 文件路径
```
