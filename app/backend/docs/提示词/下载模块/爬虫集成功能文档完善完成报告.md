### 2.2 问题2修复：`clean_old_files()` 警告

#### 修改位置
- `爬虫与批量导入集成功能代码生成指令v1.md` → 4.2.5 重要警告（新增）
- `爬虫与批量导入集成功能代码生成指令v1.md` → 5.1.2 第十一步
- `爬虫与批量导入集成设计文档v1.md` → 3.2.2 资源管理注意事项

#### 新增内容

**警告说明**：

⚠️ **关于 `clean_old_files()` 方法**：

`DuanShuCrawler_vzan` 类中有一个 `clean_old_files()` 方法，它会删除以下文件：
- 主文件 (`liveroom_list_savefile`)
- 失败文件 (`failed_liveroomlist_url`)

**注意**：
1. ✅ **不要在爬取后、导入前调用此方法**，否则CSV文件会被删除
2. ✅ 增量文件不在清理列表中，不会被删除
3. ✅ VzanCrawler 适配器**不应调用**此方法

**正确的清理时机**：
- 在 `crawl_and_import_tasks` 服务层方法的 finally 块中清理
- 使用 `os.remove()` 直接删除，而非调用 `clean_old_files()`

**第十一步清理代码**：
```python
finally:
    # 清理临时文件
    if settings.CRAWL_IMPORT_DELETE_TEMP_FILE:
        # ⚠️ 重要：只删除增量文件和失败文件，不删除主文件
        files_to_delete = [
            incremental_file,  # ✅ 删除增量文件（已导入，无需保留）
            failed_file        # ✅ 删除失败文件（可选）
        ]
        # ❌ 不删除主文件：csv_path (需要保留作为下次增量爬取的基准)
        
        for file_path in files_to_delete:
            try:
                if file_path and os.path.exists(file_path):
                    os.remove(file_path)
                    logger.info(f"已删除临时文件: {file_path}")
            except Exception as e:
                logger.warning(f"删除临时文件失败: {file_path}, 错误: {str(e)}")
        
        # 记录主文件保留
        if csv_path and os.path.exists(csv_path):
            logger.info(f"保留主文件用于下次增量爬取: {csv_path}")
```

#### 解决的问题
✅ 防止AI生成代码时：
1. 错误地调用 `clean_old_files()` 方法
2. 删除主文件导致失去增量爬取能力
3. 在导入前删除CSV文件
4. 导致导入失败

### 2.3 问题3修复：浏览器资源管理

#### 修改位置
- `爬虫与批量导入集成功能代码生成指令v1.md` → 4.2.6 浏览器资源管理（新增）
- `爬虫与批量导入集成设计文档v1.md` → 3.2.2 资源管理注意事项

#### 新增内容

**资源管理说明**：

⚠️ **重要**：`DuanShuCrawler_vzan` 在初始化时会启动 Playwright 浏览器。

**影响**：
1. 初始化时自动启动浏览器（`headless=False`，会显示浏览器窗口）
2. 爬取完成后需要调用 `self.crawler.close()` 关闭浏览器
3. 未关闭会导致浏览器进程泄漏

**VzanCrawler 实现要求**：

在 `crawl()` 方法中**必须**添加 finally 块：

```python
def crawl(self, config: Dict, **kwargs) -> Dict:
    try:
        # ... 爬取逻辑 ...
        self.crawler.parse_all_liveroomlist_data(config)
        
        # 构造返回结果
        result = {...}
        return result
        
    except Exception as e:
        logger.error(f"VzanCrawler: 爬取失败 - {str(e)}", exc_info=True)
        raise CrawlerError(f"爬取失败: {str(e)}")
    
    finally:
        # 关闭浏览器，释放资源（重要！）
        try:
            if hasattr(self, 'crawler') and self.crawler:
                self.crawler.close()
                logger.info("VzanCrawler: 已关闭浏览器")
        except Exception as e:
            logger.warning(f"VzanCrawler: 关闭浏览器失败 - {str(e)}")
```

#### 解决的问题
✅ 确保AI生成代码时：
1. 在 finally 块中关闭浏览器
2. 即使爬取失败也释放资源
3. 防止浏览器进程泄漏
