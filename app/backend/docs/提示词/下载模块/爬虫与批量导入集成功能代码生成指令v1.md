## 二、基础规范要求

### 2.1 编码规范

**必须遵循**:
- 所有新增代码遵循 `@开发规范文档` 中的通用规范（1.1-1.4节）
- 所有新增代码遵循 `@媒体下载服务功能代码生成指令v4-已修正.md` 中的实现规范（第二节）

### 2.2 安全异步异常处理

**核心原则**（来自主文档2.1.4节）:
- 在任何`try...except`块中，如果需要在`except`块中使用ORM对象的属性进行日志记录，这些属性**必须在进入`try`块之前**提取到局部变量
- 严禁在捕获了数据库相关异常的`except`块中直接访问可能已失效的ORM对象属性

### 2.3 环境变量驱动配置

**核心原则**（来自主文档2.1.5节）:
- 所有外部服务（爬虫API、Token）的连接信息**必须**通过环境变量读取
- 代码中不允许硬编码任何敏感信息

### 2.4 响应处理规范

**核心原则**（来自主文档2.3节）:
- **成功响应**：必须调用 `create_response(code, message, data)`
- **错误响应**：必须返回 `JSONResponse(status_code=200, content=create_error_response(code, message))`
- **注意**：API统一返回HTTP 200，业务状态码在响应体的`code`字段

### 4.1 创建 `app/crawlers/base_crawler.py`

爬虫基类定义：

```python
"""
爬虫基类模块

定义所有爬虫必须实现的统一接口
"""
from abc import ABC, abstractmethod
from typing import Dict, Optional
from pathlib import Path
import logging

logger = logging.getLogger(__name__)


class BaseCrawler(ABC):
    """
    爬虫基类，定义统一接口
    
    所有具体的爬虫实现（如VzanCrawler）必须继承此类并实现抽象方法
    """
    
    def __init__(self, config: Dict):
        """
        初始化爬虫
        
        Args:
            config: 爬虫配置字典，至少包含:
                - timeout: 超时时间（秒），默认10秒
                - temp_dir: 临时文件目录
        """
        self.config = config
        self.timeout = config.get('timeout', 10)
        
        logger.info(f"{self.__class__.__name__} initialized with timeout={self.timeout}s")
    
    @abstractmethod
    def crawl(self, config: Dict, **kwargs) -> Dict:
        """
        执行爬取任务（抽象方法，子类必须实现）
        
        Args:
            config: 爬虫配置字典，包含 username, password, token 等
            **kwargs: 爬虫特定的额外参数，如:
                - page_size: 每页数据量（默认10）
                - max_pages: 最大爬取页数（默认全部）
        
        Returns:
            Dict: 爬取结果摘要
                {
                    "csv_file": str,             # 主 CSV 文件路径
                    "incremental_file": str,     # 增量 CSV 文件路径
                    "failed_file": str,          # 失败记录文件路径
                    "total_rows": int,           # 总爬取行数
                    "failed_rows": int,          # 失败行数
                    "incremental_rows": int      # 本次新增行数
                }
        
        Raises:
            CrawlerError: 爬取失败时抛出
            CrawlerTimeoutError: 爬取超时时抛出
            CrawlerAPIError: API调用失败时抛出
        """
        pass
    
    @abstractmethod
    def validate_config(self) -> bool:
        """
        验证配置是否完整有效（抽象方法，子类必须实现）
        
        Returns:
            bool: 配置是否有效
        """
        pass
    
    def _generate_csv_filename(self, prefix: str = "crawl") -> Path:
        """
        生成带时间戳的CSV文件名
        
        Args:
            prefix: 文件名前缀
        
        Returns:
            Path: 完整的CSV文件路径
        """
        from datetime import datetime
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        filename = f"{prefix}_{timestamp}.csv"
        return self.temp_dir / filename
```

**设计要点**:
- 使用ABC定义抽象接口
- 提供通用的初始化和工具方法
- 详细的文档字符串
- 自动创建临时目录

#### 4.2.3 实现流程

**【第一步：初始化】** (`__init__`)
1. 调用 `super().__init__(config)`
2. 提取配置：`self.username`, `self.password`, `self.token`
3. 创建已有爬虫实例：

4. 异常处理：如果初始化失败，抛出 `CrawlerConfigError`

**【第二步：配置验证】** (`validate_config`)
1. 检查必需配置：`username`, `password`, `token` 均不为空
2. 返回 `True` 或 `False`

**【第三步：执行爬取】** (`crawl`)
1. **变量提取**（用于日志）：
   - `config_for_logging = {'username': config.get('username'), 'has_token': bool(config.get('token'))}`
   
2. **验证配置**：
   - 调用 `self.validate_config()`
   - 如果失败，抛出 `CrawlerConfigError`

3. **调用已有爬虫**：
   ```python
   try:
       # 调用已有爬虫的核心方法
       self.crawler.parse_all_liveroomlist_data(config)
   except Exception as e:
       raise CrawlerError(f"爬取失败: {str(e)}")
   ```

4. **构造返回结果**：
   - 读取已有爬虫生成的文件路径：

     * `self.crawler.liveroom_list_savefile_inc` (增量文件)

   - 统计CSV行数：调用 `_count_csv_rows()` 辅助方法
   - 返回字典格式的结果摘要

5. **异常处理**：
   - 捕获所有异常，记录日志
   - 转换为 `CrawlerError` 重新抛出

#### 4.2.5 重要警告

⚠️ **关于 `clean_old_files()` 方法**：

`DuanShuCrawler_vzan` 类中有一个 `clean_old_files()` 方法，它会删除以下文件：
- 主文件 (`liveroom_list_savefile`)
- 失败文件 (`failed_liveroomlist_url`)
- 其他相关文件

**注意**：
1. ✅ **不要在爬取后、导入前调用此方法**，否则CSV文件会被删除，导致导入失败
2. ✅ 增量文件不在清理列表中，不会被删除
3. ✅ 当前 `dynamicCrawler_vzan.py` 的 `main()` 中已注释此方法（`#crawler.clean_old_files()`）
4. ✅ VzanCrawler 适配器**不应调用**此方法

**正确的清理时机**：
- 在 `crawl_and_import_tasks` 服务层方法的 finally 块中清理
- 根据 `CRAWL_IMPORT_DELETE_TEMP_FILE` 配置决定是否删除
- 使用 `os.remove()` 直接删除，而非调用 `clean_old_files()`

#### 4.2.6 浏览器资源管理

⚠️ **重要**：`DuanShuCrawler_vzan` 在初始化时会启动 Playwright 浏览器。

**影响**：
1. 初始化时自动启动浏览器（`headless=False`，会显示浏览器窗口）
2. 爬取完成后需要调用 `self.crawler.close()` 关闭浏览器
3. 未关闭会导致浏览器进程泄漏

**VzanCrawler 实现要求**：

在 `crawl()` 方法中**必须**添加 finally 块：

```python
def crawl(self, config: Dict, **kwargs) -> Dict:
    try:
        # ... 爬取逻辑 ...
        
        # 调用已有爬虫
        self.crawler.parse_all_liveroomlist_data(config)
        
        # 构造返回结果
        result = {
            "csv_file": str(self.crawler.liveroom_list_savefile),
            "incremental_file": str(self.crawler.liveroom_list_savefile_inc),
            "failed_file": str(self.crawler.failed_liveroomlist_url),
            "total_rows": self._count_csv_rows(str(self.crawler.liveroom_list_savefile)),
            "incremental_rows": self._count_csv_rows(str(self.crawler.liveroom_list_savefile_inc)),
            "failed_rows": self._count_csv_rows(str(self.crawler.failed_liveroomlist_url))
        }
        
        return result
        
    except Exception as e:
        logger.error(f"VzanCrawler: 爬取失败 - {str(e)}", exc_info=True)
        raise CrawlerError(f"爬取失败: {str(e)}")
    
    finally:
        # 关闭浏览器，释放资源（重要！）
        try:
            if hasattr(self, 'crawler') and self.crawler:
                self.crawler.close()
                logger.info("VzanCrawler: 已关闭浏览器")
        except Exception as e:
            logger.warning(f"VzanCrawler: 关闭浏览器失败 - {str(e)}")
```

**注意**：
- ✅ 务必在 finally 块中关闭浏览器
- ✅ 即使爬取失败，也要关闭浏览器
- ✅ 捕获关闭异常，防止掩盖原始错误

```python
"""
爬虫模块

提供爬虫工厂和统一的爬虫接口
"""

from .base_crawler import BaseCrawler
from .vzan_crawler import VzanCrawler
from app.core.exceptions import CrawlerError
import logging

logger = logging.getLogger(__name__)


class CrawlerFactory:
    """
    爬虫工厂类
    
    根据爬虫类型创建相应的爬虫实例
    """
    
    # 注册的爬虫类型映射
    _crawlers = {
        'vzan': VzanCrawler,
        # 未来可扩展其他爬虫
        # 'douyin': DouyinCrawler,
        # 'kuaishou': KuaishouCrawler,
    }
    
    @classmethod
    def create(cls, crawler_type: str, config: Dict) -> BaseCrawler:
        """
        创建爬虫实例
        
        Args:
            crawler_type: 爬虫类型（vzan, douyin等）
            config: 爬虫配置字典
        
        Returns:
            BaseCrawler: 爬虫实例
        
        Raises:
            CrawlerError: 不支持的爬虫类型
        """
        crawler_class = cls._crawlers.get(crawler_type.lower())
        
        if not crawler_class:
            supported_types = ', '.join(cls._crawlers.keys())
            logger.error(f"不支持的爬虫类型: {crawler_type}，支持的类型: {supported_types}")
            raise CrawlerError(
                f"不支持的爬虫类型: {crawler_type}。"
                f"支持的类型: {supported_types}"
            )
        
        logger.info(f"CrawlerFactory: 创建{crawler_type}爬虫实例")
        return crawler_class(config)
    
    @classmethod
    def get_supported_types(cls) -> list:
        """
        获取支持的爬虫类型列表
        
        Returns:
            list: 支持的爬虫类型
        """
        return list(cls._crawlers.keys())


# 导出公共接口
__all__ = ['BaseCrawler', 'VzanCrawler', 'CrawlerFactory']
```

## 十二、常见问题与解决方案

### Q1: Token解密失败

**问题**: 运行时报错 "Token解密失败：Token无效或已损坏"

**解决方案**:
1. 检查 `TOKEN_ENCRYPTION_KEY` 是否正确配置
2. 确认使用的加密密钥与加密token时的密钥一致
3. 重新使用 `encrypt_token.py` 生成加密token

### Q2: 爬虫超时

**问题**: 爬取时报错 "请求超时"

**解决方案**:
1. 增加 `CRAWLER_TIMEOUT` 值
2. 检查网络连接
3. 检查目标API是否可访问
4. 增加 `CRAWLER_MAX_RETRIES` 重试次数

### Q3: CSV文件编码错误

**问题**: 导入时报错 "文件编码错误"

**解决方案**:
1. 确认爬虫写入CSV时使用 `encoding='utf-8'`
2. 检查源数据是否包含非UTF-8字符
3. 在爬虫中添加编码转换逻辑

### Q4: 临时文件未清理

**问题**: `/tmp/crawler_csv/` 目录占用空间过大

**解决方案**:
1. 确认 `CRAWL_IMPORT_DELETE_TEMP_FILE=true`
2. 手动清理: `rm -rf /tmp/crawler_csv/*`
3. 添加定时清理任务
